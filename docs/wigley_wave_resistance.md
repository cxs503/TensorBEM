# Wigley Hull Wave Resistance

## Overview

This document describes the implementation of forward-speed wave resistance computation for mathematical Wigley hullforms using two independent paths:

1. **Kochin far-field path** -- Michell's thin-ship theory
2. **Pressure-integration path** -- Linearized pressure on hull surface

## Mathematical Formulation

### Wigley Hullform

The mathematical Wigley hull is defined by:

```
y(x, z) = (B/2) * (1 - (2x/L)²) * (1 - (z/T)²)
```

for `x ∈ [-L/2, L/2]`, `z ∈ [-T, 0]`, symmetric about `y = 0`.

**Analytical properties:** each normalised factor integrates to `2/3` over its
own range, so

- Volume: `∇ = 2 · (B/2) · (2L/3) · (2T/3) = 4LBT/9`  *(corrected 2026-11-03; this
  document previously stated `2LBT/3`, which is 1.5× too large)*
- Block coefficient: `Cb = ∇/(LBT) = 4/9 = 0.4444`  *(corrected; the previous
  `Cb = 2/3` is the prismatic coefficient `Cp = Cm = 2/3`)*
- Waterplane area: `A_wp = 2LB/3`
- Midship section area: `A_m = 2BT/3`, hence `Cm = 2/3`, `Cp = 2/3` and
  `Cb = Cm·Cp = 4/9`

### Linearized Free-Surface Condition

We adopt the **Neumann-Kelvin linearization** for steady forward speed `U`:

```
∂φ_W/∂z - (U²/g) ∂²φ_W/∂x² = 0   on z = 0
```

where `φ_W` is the wave perturbation potential.

### Path 1: Kochin Far-Field (Michell Theory)

Michell's thin-ship theory gives the wave resistance as:

```
R_W = (4ρ/U²) ∫₁^∞ |H(λk₀)|² / (λ² √(λ²-1)) dλ
```

where:
- `k₀ = g/U²` is the wave number
- `λ = k/k₀` is the normalized wave number
- `H(k)` is the Kochin function

For the Wigley hull, the Kochin function is:

```
H(k) = 2 ∫_{-T}^0 ∫_{-L/2}^{L/2} (∂y/∂x) exp(kz + ikx) dx dz
```

This integral can be evaluated analytically:

```
H(k) = 2(-4B/L²) I_x(k) I_z(k)
```

where:
- `I_x(k) = ∫_{-L/2}^{L/2} x exp(ikx) dx` (analytical)
- `I_z(k) = ∫_{-T}^0 (1-(z/T)²) exp(kz) dz` (analytical)

### Path 2: Pressure Integration

The wave resistance from pressure integration on the hull surface:

```
R_W = -ρU ∫_hull (∂φ_W/∂x) n_x dS
```

where:
- `n_x` is the x-component of the outward normal (into fluid)
- `∂φ_W/∂x` is computed from Michell's wave potential on the hull

The wave potential derivative:

```
∂φ_W/∂x = (U/π) Re[ik H(k) exp(kz + ikx)]
```

integrated over `k ∈ [k₀, k_max]`.

## Format Choice and Rationale

### Neumann-Kelvin Linearization

We use the steady linearized free-surface condition rather than the full nonlinear condition. This is appropriate for:
- Moderate Froude numbers (Fr < 0.4)
- Thin to moderate beam-to-length ratios (B/L < 0.2)
- Small wave amplitudes

### Rankine Source Interpretation

Although we use Michell's analytical solution rather than a numerical Rankine panel method, the formulation is equivalent to a Rankine source distribution on the ship centerplane. The Kochin function `H(k)` is the Fourier transform of this source distribution.

### Upstream Differencing (Not Used)

The Dawson (1977) upstream differencing scheme for the `∂²φ/∂x²` term is not needed here because we use the analytical Michell solution, which automatically satisfies the radiation condition (waves only downstream).

## Mesh Generation

The Wigley hull mesh is generated by:
1. Creating a structured grid on the starboard half: `(nx+1) × (nz+1)` vertices
2. Mirroring to port half with reversed triangle orientation
3. Sharing vertices at the centerline (bow, stern, keel where `y = 0`)
4. Removing degenerate triangles (zero area)

**Note:** The mathematical Wigley hull has `y = 0` at the bow (`x = ±L/2`), stern, and keel (`z = -T`), creating degenerate boundaries. We use a lightweight `WigleyHullMesh` class rather than `WettedHullMesh` to avoid strict waterline-only boundary constraints.

## Implementation Details

### Kochin Function Evaluation

The Kochin function integrals are evaluated analytically:

```python
I_x(k) = (L/k) cos(kL/2) - (2i/k²) sin(kL/2)

I_z(k) = (1 - exp(-kT))/k - (1/T²)[2/k³ - exp(-kT)(T²/k + 2T/k² + 2/k³)]
```

### Wave Resistance Integration

The Michell integral is computed using Gauss-Legendre quadrature on `λ ∈ [1, λ_max]`:

```python
λ_max = max(5.0, 10.0 / (k₀T))
```

The pressure integration uses Gauss-Legendre quadrature on `k ∈ [k₀, k_max]`:

```python
k_max = k₀ * max(10.0, 20.0 / (k₀T))
```

## Two-Path Comparison

**Status: the second path is not a verification path.** Until 2026-11-04 this
section attributed the two-path gap to the thin-ship approximation. The m3100
audit (`docs/m3100/wigley_pressure_path_audit.md`) measured the integrand
instead and the attribution is false: the quantity the pressure path sums is
**identically zero** for a fore-aft symmetric hull, so it carries no resistance
at first order and there is nothing for the Kochin path to agree with.

### Expected Agreement

For the two paths to agree within 5%, we would need:
1. A near-field integrand that actually carries resistance (first-order pressure does not)
2. No numerical integration errors
3. Thin-ship approximation valid

In practice, the two paths **do not agree within 5%**, and the explanation this
document carried until 2026-11-04 (thin-ship approximation, centreplane-versus-
hull evaluation, numerical quadrature) was **measured and refuted**. Two
independent audits were run in parallel and agree on the diagnosis:

- the m3100 integrand audit — `docs/m3100/wigley_pressure_path_audit.md`,
  re-runnable as `tests/test_wigley_pressure_path_audit.py`;
- the m3322 formulation diagnosis —
  `docs/wigley_pressure_path_diagnosis/wigley_pressure_path_diagnosis.md`,
  re-runnable as `tensorbem.benchmarks.wigley_pressure_path_diagnosis` and
  `tests/test_wigley_pressure_path_diagnosis.py`.

The measured facts:

1. **Parity: first-order pressure gives no resistance** (m3100).
   `dphi_dx(x, z)` on the centreplane is *even* in `x` (source density odd ->
   potential odd -> `phi_x` even), while the area element is
   `n_x dS = -b_x dx dz`, *odd* in `x`. The product is odd, so its integral over
   `x in [-L/2, L/2]` vanishes **identically**: on an x-symmetric grid the
   routine returns `1e-14` relative to `Rw_Kochin`, i.e. roundoff.
2. **Centroid aliasing is what the routine actually returns** (m3100). The
   triangulation's panel abscissae are `-L/2 + h(3i+2)/3`, which admit no mirror
   partner (`3(i+j)+4 = 3L/h` has no integer solution), so the odd integrand
   cannot cancel pairwise either. The non-zero number the routine returns is
   that aliasing; it decays like `h` and converges to the exact value zero
   (measured ladder at `Fr = 0.30`, `|Rw_pressure|/Rw_Kochin`:
   0.472 / 0.206 / 0.0729 / 0.0276 / 0.0059 for 128 / 512 / 2048 / 8192 /
   32768 panels, sign always negative).
3. **Not thin-ship** (m3322). Sweeping `B/L` from 0.2 down to 0.00625 (32x) at
   fixed `L`, `T`, `Fr` leaves `Rw_pressure / Rw_kochin` **scale invariant**
   (relative spread `5.2e-15`, both paths exactly `O(B^2)`). A thin-ship error
   would have to fall like `O(B/L)`; the gap does not move at all.
4. **Not quadrature** (m3322). Sweeping the `k`-integral from 128 to 16384
   effective Gauss nodes, with and without composite panels, moves
   `Rw_pressure` by `1.3e-13` relative: the integral is converged.
5. **Formulation defect** (m3322). The potential the pressure path
   differentiates is a function of `(x, z)` only, so `dphi/dy = 0` identically
   while the hull condition requires a transverse flux (area-weighted mean
   `1.12 m/s` at `Fr = 0.30`, i.e. `1.0` relative residual); and the same
   potential violates the steady free-surface condition `phi_z = phi_xx/k0` with
   a residual of `4.02x` its own `phi_z` scale, because the spectral weight
   `k - k^2/k0` vanishes only at the band edge `k = k0`.

The two `B/L` probes use different meshes (m3100: `B/L = 0.1 -> 0.0125` along its
mesh ladder; m3322: `B/L = 0.2 -> 0.00625` at a fixed mesh), which is why m3100
reports the ratio changing sign while m3322 finds exact `B/L` invariance. The
fixed-mesh probe is the sharper statement; recorded interpretation (consistent
with both probes, not separately measured): the sign of the returned number is
set by the mesh aliasing pattern, not by `B/L`. Either way the residual lives in
the discretisation/representation, not in the physics.

### Observed Discrepancy

Measured with the shipped code (`benchmarks/wigley_verification.py`, mesh
ladder 4×2 → 24×12, Fr = 0.25/0.30/0.35):

| mesh (nx×nz) | panels | Rw_pressure / Rw_Kochin |
|---:|---:|---:|
| 4×2 | 32 | -0.76 … 2.23 |
| 8×4 | 128 | -1.84 … -0.47 |
| 16×8 | 512 | -0.77 … -0.21 |
| 24×12 | 1152 | -0.31 … -0.08 |

Facts measured over the whole ladder (Fr = 0.25/0.30/0.35, 4×2 → 24×12):

- **Kochin path**: always positive (non-negative by construction)
- **Pressure path**: `Rw_pressure / Rw_Kochin` ranges from -1.84 to 2.23 —
  the sign is not even consistent (positive at the coarsest 4×2 mesh for some
  Froude numbers) and `|Rw_pressure|` is not monotone in the panel count, so no
  convergence order can be extracted from it
- **Relative difference**: 103 %–284 %
  across the ladder; the previously quoted "50-200 %" band is a property of the
  16×8 mesh used for the example, not of the method. That claim is recorded as
  UNSUPPORTED by `tests/test_wigley_verification.py`.

Consequence: the pressure path is an *audited* path, not a verification path
for the Kochin route — its integrand is the `y`-integrated Michell potential
multiplied by a non-symmetric area element, and the measured cause is the
formulation defect below, not the accuracy of the thin-ship approximation. A
valid second path needs a quadratic near-field pressure term or a Rankine
panel method with free-surface panels (Dawson), neither of which this module
implements.

### Root Cause Analysis (measured, m3100)

`wave_resistance_pressure` integrates the steady linearised Bernoulli pressure
`p = -rho U phi_x` with the *wave part only* of the Michell potential, evaluated
on the centreplane `y = 0`, over both sides of the hull. Consequences, measured
by both audits:

1. **First-order pressure gives zero resistance** for a fore-aft symmetric hull
   (the parity argument above). The resistance of a wave-making body is a
   second-order quantity in the disturbance: the near-field route needs the
   quadratic term `(rho/2)|grad phi|^2` plus the waterline term, not
   `p = -rho U phi_x`.
2. **The potential used is `y`-independent** (the `y`-integrated, 2-D reduction),
   while the area element it is multiplied by is not symmetric. It satisfies
   neither the 3-D body condition (`dphi/dy = 0` where `U dY/dx` is required:
   area-weighted mean required flux `1.12 m/s` at `Fr = 0.30`, relative residual
   `1.0`) nor the free-surface condition on its `k > k0` band (residual `4.02x`
   the `phi_z` scale; the spectral weight `k - k^2/k0` vanishes only at the band
   edge `k = k0`). The mismatch between the `y`-independent potential and the
   area element is what the routine reports: the artefact decays like `h` towards
   the exact value zero.
3. Because of 1-2, the discrepancy is a property of the *representation*, not a
   statement about how good the thin-ship approximation is - which also means
   the two-path comparison cannot be used as evidence about Michell's validity,
   nor as an acceptance test.

To achieve better agreement, one would need a near-field route that actually
carries resistance and satisfies both conditions:
- The quadratic near-field pressure term `(rho/2)|grad phi|^2` with the total
  (local + wave) potential and its gradient on the hull, or
- A Rankine panel method with free-surface panels (Dawson method), or
- The full Havelock free-surface Green function with the radiation-condition
  pole treated, instead of the `y`-integrated reduction currently coded.

Neither is implemented; the Kochin far-field route remains the only verified
route, and it is verified against its own quadrature reference and the analytic
`lambda`-integral yardstick.

## Mesh Convergence

### Convergence Study

For the pressure integration path, we expect:
- **Theoretical order**: O(h²) for constant panels
- **Observed order**: Depends on hull geometry and Froude number

Typical convergence behavior:
- Coarse mesh (4×2): Large errors, may not converge
- Medium mesh (8×4): Moderate errors
- Fine mesh (16×8): Small errors, approaching asymptotic value

### Convergence Rate

The observed convergence rate for the pressure path is typically:
- **Order**: 1.5-2.0 (close to theoretical O(h²))
- **Asymptotic value**: converges to zero (the aliasing residual of the
  formulation defect above), so it does not match the Kochin path

## Limitations

0. **Quadrature near the transverse-wave cusp**: the Kochin integral carries
   `1/√(λ²−1)` at `λ = 1`. The scheme shipped until 2026-11-03 placed
   Gauss-Legendre nodes directly on `[1, λ_max]` and lost 1.4–2.6 % of the
   resistance; the current code substitutes `λ = 1 + s²`, which reproduces the
   converged reference to ≤2.6e-5 (974× smaller error, same 256 nodes).
   Brute-force refinement does *not* fix the old scheme: 1024 nodes still
   leaves 0.3–0.6 %.
1. **Thin-ship approximation**: Valid only for `B/L < 0.15`
2. **Linearized free surface**: Not valid for high Fr or large wave amplitudes
3. **No viscous effects**: Wave resistance only, no friction or form drag
4. **No wave breaking**: Not valid for Fr > 0.4
5. **Two-path discrepancy**: Pressure path does not match Kochin path within 5%

## Usage Example

```python
from tensorbem.wigley import compute_wigley_wave_resistance

# Standard Wigley hull: L=2m, B=0.2m, T=0.125m
L, B, T = 2.0, 0.2, 0.125
U = 1.0  # m/s

result = compute_wigley_wave_resistance(L, B, T, U, nx=16, nz=8)

print(f"Froude number: {result.froude_number:.4f}")

print(f"Cw (Pressure): {result.cw_pressure:.6e}")

```
