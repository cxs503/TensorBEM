# CASE-BEM-HULME-DIFF-VERIF：六量第三方 Richardson 极限与参考解偏差

> 锚点 `CASE-BEM-HULME-DIFF-VERIF`（算例池 id 177，TensorBEM）。本文件由 `benchmarks/verified/casepool_bem_hulme_diff_verif/independent_limits.py` 从已提交的 capytaine 四级面元阶梯程序化生成，数字零手抄。

## 1. 案例介绍

漂浮半球（a = 1 m，平底贴合静水面，无限水深）的三维绕射激励力与垂荡/纵荡辐射系数。算例判据：TensorBEM 的 Kelvin 自由面 Green 函数 BEM 对多极级数参考解的复相对误差 <5%。

| 项 | 值 |
|---|---|
| 波压归一化标尺 ρgAa² | 10051.816 N |
| 排水体积 ∇ | 2.094395 m³ |
| 参考解 | `tensorbem.analytic.hulme_hemisphere_radiation`（144 项，quad 512） |
| 第三方码 | capytaine 3.1.dev0，面元 256/576/1024/1600 |
| 阶梯工件 sha256 | `f9b0463fd2d65b2c` |
| 外推 | 3-point Richardson in x = 1/panels, order p estimated per cell; two overlapping 3-point ladders bound the limit |
| Froude-Krylov | exact reduced quadrature (run_case.exact_froude_krylov), mesh independent |

## 2. 怎么做的

参考解与求解器共用 `tensorbem.free_surface3d.wave_function_3d`；核内缺陷会让两条路线同向漂移而门禁照绿。第三方码此前只被用在**单一有限网格**上（1600 面，激励力最差 2.3%），有限网格分不清「参考解偏 2%」与「第三方码偏 2%」。本工件对全程 ka∈[0.2,2.0]、全部六量做零面元外推：

1. 逐量在 x = 1/N 上做三点 Richardson 外推，阶 p 每格单独估计；
2. 激励力极限 = 外推散射力 + 精确 Froude-Krylov（与网格无关），第三方码的 FK 求积误差不进入极限；
3. 参考解由 `analytic.py` 现场重算，不读任何存储数字；
4. 每格记录外推质量：估计阶 p、模型残差、两条重叠三点外推的离散度。

判据（动手前固定）：G1 复相对 ≤5%（台账容差）；G2 力波压归一化绝对误差 ≤1%（相消区伴随度量）；G3 相位差 ≤3°；G4 外推离散度 ≤2%。

## 4. 误差判定

- 最差复相对误差：**0.37%**（A11@ka=0.2），门限 5% → PASS；
- 最差波压归一化绝对误差：**0.19%**（Fx@ka=2），门限 1% → PASS；
- 最差相位差：**0.09°**（Fx@ka=2），门限 3° → PASS；
- 外推质量：0 格超离散度门限 → PASS。

**总判定：PASS**（48 格）。

## 4b. 本单前后的对照

| 口径 | 激励力最差 | 辐射最差 | 覆盖面 |
|---|---|---|---|
| 改进前：第三方码单一有限网格（1600 面） | 2.33% | 3.36% | 与有限网格比，含第三方自身离散误差 |
| 改进前：已提交外推极限文件 | 未覆盖 | 1.72% | 4 个辐射量 × 2 个频率 |
| 本单：外推极限 + 精确 Froude-Krylov | 0.16% | 0.37% | 6 量 × 6 频率 = 48 格 |

> **自纠一处实现缺陷**：首版把 x=1/N 升序当成降序传入三点外推，极限退化为最粗网格值，给出假 FAIL（5.8%）；修正排序后 48 格最差偏差落到 0.37%。缺陷由「两条重叠外推离散度」与「阶 p 触及上界」共同暴露，现已固化为测试不变量（p 必须由阶梯反解、每格必须 limit_usable）。

## 5. 注意点与局限

- capytaine 在 1600 面处相邻差比约 0.6，仍未完全收敛；外推极限带约 1% 量级不确定度，因此本工件给出的是**带不确定度的界**，不是把参考解钉到 0.1%。
- 参考解与求解器共用自由面核；本工件能发现「核 + 参考解同向偏离第三方」，不能单独定位核内缺陷。
- Hulme (1982) 原文表格数字在沙箱内不可得（无网络、无原文），本工件**不声称**与原文逐位比较。
- 只覆盖零速、深水、线性势流；不含粘性、非线性、有限水深。
