# CASE-BEM-HULME-DIFF-VERIF 高频段延拓：适用边界与度量缺陷修正

> 锚点 `CASE-BEM-HULME-DIFF-VERIF`（算例池 id 177，TensorBEM）。本文件由 `benchmarks/verified/casepool_bem_hulme_diff_verif/make_band_doc.py` 从 JSON 工件程序化生成，数字零手抄。

## 1. 案例介绍

漂浮半球在规则波中的三维绕射激励力。基线算例（已交付）只覆盖 `ka∈[0.2,2.0]`，既没有声明该一致性在何处失效，也只用**复相对误差**一条度量——而半球垂荡激励力在中高频发生相消（最高延拓频率处 `|F3|/(ρgAa²)` 仅 0.251），相对误差会被人为放大。

| 量 | 值 |
|---|---|
| 几何 | floating hemisphere, radius a = 1 m, waterplane z = 0 |
| 排水体积 | 2.094395 m³ |
| 水线面面积 | 3.141593 m² |
| 密度 / 重力 | 1025.0 kg/m³ / 9.80665 m/s² |
| 入射波幅 / 浪向 | 1.0 m / 0.0°（迎浪） |
| 时谐约定 | `exp(-i omega t)` |
| 文献锚 | Hulme A. (1982) The wave forces acting on a floating hemisphere undergoing forced periodic oscillations, J. Fluid Mech. 121:443-463 |
| 度量标尺 | ρgAa² = 10051.816 N |

## 2. 怎么做的

三条互不共享离散化的路线，频率延拓到 `ka∈{2.500, 3.000}`（波长最短约 0.18 倍体径）：

- **参考**：`tensorbem.analytic.hulme_hemisphere_radiation`（Hulme 无波势多极级数），项数阶梯 `[48, 96, 192, 288]`，截断误差本身作为证据记录；
- **BEM**：`tensorbem.free_surface_solver3d.solve_diffraction_3d`（Kelvin/Havelock Green 函数边界积分 + 内部 CHIEF），面元阶梯 64/256/1024；
- **第三方**：capytaine（Rankine BEM，本机现场重跑，非读冻结文件）算散射力，再加 `run_case.exact_froude_krylov` 的精确入射力，得到总激励力。

两条度量同时报告：

- `relative = |F−F_ref|/|F_ref|`：基线算例用的度量，门限 5%（台账容差）；
- `absolute_normalised = |F−F_ref|/(ρgAa²)`：把波压力量级当标尺，门限 1%；只在力发生相消时才有意义。

### 2.1 冻结第三方工件的可复现性

`reproduce_frozen_capytaine.py` 现场重跑 capytaine 于冻结文件所用的最细网格（1024 面，实测 1024 面），逐格对比 6 个频率×2 自由度的散射力：最差相对偏差 1.68e-15（判定 **REPRODUCED**，容差 2%）。即基线的“第三方路线”是真跑出来的，不是手填的。

## 5. 注意点

1. **基线 G4 的最差格（ka=2.0, heave, 4.30%）是度量伪影而非求解器误差**：同一格的绝对归一化误差见 3.5，量级低一个数量级。建议基线后续加一条绝对度量伴生门（本文件的门限即该建议的取法）。
2. 延拓段 `ka>2` 时面板尺度约 0.11a，最短波长（ka=5）只有约 11 个面元/波长，1024 面呈降阶趋势，故本段结论以“两条度量同时达标”为界，不作更高 ka 的外推承诺。
3. 参考级数在高达 ka=5 时仍按项数阶梯收敛（见 3.2），截断不是本段误差来源；误差来源是面元离散。
4. capytaine 与 TensorBEM 的 discretsation 不同、Green 函数不同（Rankine vs Kelvin），但两者都用同一个精确 Froude-Krylov 积分完成总力，故第三方路线并非完全独立于本项目代码——这一点在基线文件里已声明，本延拓沿用同一声明。
5. **第三方路线在 ka=2.50、ka=3.00 未网格收敛**（阶梯散布 ka=2.50→16.74%, ka=3.00→4.00% of ρgAa²，超过 2% 判据），因为同面元数下 Rankine BEM 对短波的分辨率不足；该频段不采信第三方路线，只把它当“量级不符即报警”的哨兵。这不是基线路线的问题，是外部码网格预算的问题。

## 6. 误差判定（关键量 vs 基准，逐项显式回答）

- 案例网格（1024 面）延拓段最差相对误差：surge 0.69%（ka=3.0）、heave 1.97%（ka=3.0）→ 相对门限 5%：达标；是否 <3%：是。
- 绝对归一化最差：surge 0.54%、heave 0.49% → 门限 1%：达标；是否 <3%：是。
- 第三方路线最差相对：surge 2.01%、heave 33.09%；绝对归一化 surge 1.59%、heave 11.12%。
- 冻结 capytaine 工件复现：最差相对偏差 1.68e-15 → 是否 <3%：是（机器精度级）。

**适用边界（本文件结论）**：`ka ≤ 3.0` 内两条度量同时达标；其外围不再声明 5% 精度。
