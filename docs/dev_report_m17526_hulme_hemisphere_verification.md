# CASE-BEM-HULME-HEMISPHERE 验证报告

**任务**: m17526 · 算例池·Hulme 浮半球辐射/绕射（3D）
**锚点**: `CASE-BEM-HULME-HEMISPHERE` (feature_ledger slug)
**容差**: <5% 相对误差（算例池预声明门）
**参考**: Hulme, A. (1982) J. Fluid Mech. 121:443-463

---

## 1. 案例介绍

**物理背景**: 半径 a=1.0 m 的浮半球，平面与平均自由液面齐平，深水条件。
半球在规则波中受迫振荡，产生辐射波和绕射波。Hulme (1982) 给出了基于球谐
波-free 多极展开的半解析解，是三维自由液面 BEM 求解器的经典基准。

**几何参数**:
| 参数 | 值 |
|---|---|
| 半径 a | 1.0 m |
| 排水体积 ∇ | 2πa³/3 = 2.0944 m³ |
| 水线面面积 | πa² = 3.1416 m² |
| 密度 ρ | 1025.0 kg/m³ |
| 重力 g | 9.80665 m/s² |
| 波幅 A | 1.0 m |

**无量纲频率**: ka = k·a，扫描范围 0.2–2.0（避开 ka≈2.58 不规则频率点）

**验证量**:
- 辐射系数: A11/(ρ∇), B11/(ρω∇), A33/(ρ∇), B33/(ρω∇)
- 绕射力: |Fx|/(ρgAa²), |Fz|/(ρgAa²) 及相位

---

## 2. 方法

**求解器**: `tensorbem.free_surface_solver3d` — 三维 Kelvin (Havelock) Green 函数
边界积分方程，常值面板离散，内部 CHIEF 零场方程正则化（`chief_points='auto'`）。

**网格**: 递归八面体细分生成的半球湿表面网格
- 粗网格: subdivisions=3 → 256 面板
- 案例网格: subdivisions=4 → 1024 面板

**参考解**: `tensorbem.analytic.hulme_hemisphere_radiation` — Hulme (1982) 球谐波-free
多极展开，144 项截断（经 48→96→144 项自收敛验证，96→144 漂移 <6.5e-5，远低于 5% 门）。

**预声明门**:
- G1: 案例网格上所有量、所有 ka 的相对误差 < 5%
- G2: 网格体积/水线面误差 < 2%
- G3: 细化不恶化（1024 面板最坏误差 ≤ 256 面板）
- G4: 参考截断漂移至少 20 倍低于 5% 门

## 5. 注意点

1. **B33 误差最大**: 在 ka=2.0 时 B33 误差达 1.15%，是所有量中最大的。
   这是因为高频下辐射阻尼对面板分辨率更敏感，且 ka=2.0 接近不规则频率
   区域（ka≈2.58），数值条件开始变差。

2. **参考解自收敛**: Hulme 多极展开的 96→144 项漂移仅 6.5e-5，比 5% 门
   低约 770 倍，参考截断误差可忽略。

3. **独立软件验证**: `test_hulme_reference_vs_independent_limits.py` 使用
   capytaine（Rankine 面板法）Richardson 外推极限验证了 Hulme 参考解在
   ka=1.0 和 2.0 处与独立代码偏差 < 3%。

4. **CHIEF 正则化**: 在 ka=1.0 和 2.0 处关闭 CHIEF 对方程条件数和结果影响
   极小（条件数 2.68→2.69），说明这两个频率点远离不规则频率。
