## 1. 案例介绍：为什么这是欠账

`docs/verification.md` §1 的算例选择表里，有一行长期挂着「后续」：

| 典型算例 | 核心验证目标 | 本次状态（改前） |
|---|---|---|
| 圆环径向导热，\(u=A\log r+B\) | 多连通边界、内外法向 | **后续：需多边界组件** |

这不是文档疏漏，而是**代码事实**：`tensorbem.geometry.PanelMesh` 只接受**一个**逆时针闭合多边形
（`__post_init__` 里 `area2 > 0` 强制 CCW），`tensorbem.solver` 的全部入口
（`assemble_matrices` / `solve_laplace_dirichlet` / `evaluate_interior_field`）都建立在这个单环表示上。
于是**任何多连通区域（圆环、带支柱的月池剖面、多腔体截面）都无法装配**——不是精度不够，是根本没有入口。
这是「已验证功能」之外的能力缺口，也是本单选的实质增量：把缺口补成一个有解析基准的算例，
而不是再去复算一遍已经在 `docs/ursell_*`、`docs/three_dimensional_bem.md` 里被钉住的数字。

**物理背景**：二维 Laplace 方程是势流（绕流/附加质量）、稳态导热、静电势的共同模型。
圆环区域对应「月池」「带内筒的浮体剖面」「内冷外热的套管壁」等真实几何：
其边界由两条互不相连的闭曲线组成，内边界的外法向指向**孔洞内部**（即材料域的外法向），
外边界的外法向指向外部。两环方向相反，这正是单环数据结构装不下的原因。

**几何与参数**（全部无量纲/单位制一致）：

| 项 | 值 |
|---|---|
| 区域 | 圆环 \(b<r<a\)，\(a=1.0\)，\(b=0.5\)（厚度比 \(b/a=0.5\)） |
| 外环离散 | 正多边形内接于 \(r=a\)，\(N_o\) 边 |
| 内环离散 | 正多边形内接于 \(r=b\)，\(N_i\) 边，法向翻转指向孔内 |
| 面元 | 常数强度、中点配点、直线面元解析积分核 |
| 核参考长度 | \(L=2\)（与全包一致，见 §5 的容量陷阱） |
| 加密梯队 | \(N_o/N_i = 16/8,\ 32/16,\ 64/32,\ 128/64\)（\(N=24\ldots192\)） |
| 内部测点 | \(r\in\{0.6,0.75,0.9\}\times 16\) 个均匀角度 = 48 点，全部严格位于域内 |
| 算例 A（径向） | \(u=A\log r+B\)，\(A=0.7,\ B=1.3\)：两环数据不同，直接检验孔洞是否被正确装配 |
| 算例 B（角向） | \(u=(r+c^2/r)\cos\theta\)，\(c=0.4\)：非径向，内环法向导数沿环**不是常数** |

**参考解是闭式公式**，不是第二个离散解：两个算例的 \(u\) 与 \(\partial u/\partial n\) 都由
`benchmarks/annulus_laplace.py` 里的解析函数给出，并由单元测试用中心差分反查（见 §5 第 3 条）。

## 2. 怎么做的

1. **新增多环网格组件** `MultiLoopMesh`（`src/tensorbem/multiloop.py`）：
   持有若干 `PanelMesh`，把 `vertices/ends/vectors/lengths/centers/normals` 逐环拼接。
   关键点是**闭合段必须逐环 roll**——若对拼接后的大数组直接 `np.roll`，会凭空生成一条
   「末环末点 → 首环首点」的假面元，法向与长度全错。`ends` 属性因此逐环计算。
2. **朝向约定写进数据结构**：`PanelMesh` 只能存 CCW 多边形，所以把「哪些环是孔洞」记在
   `MultiLoopMesh.hole_loops`，`normals` 属性对孔洞环取负号，使**全边界法向统一为材料域外法向**。
   这不是风格选择：见 §4 的负控，朝反了误差从 \(1.8\times10^{-3}\) 跳到 \(1.66\)（≈900 倍）。
3. **求解器复用而不重写**：`solve_laplace_multiloop` 直接调用已验证的
   `solver.assemble_matrices` 与同一直接法公式 \(S q = (\tfrac12 I + H)g\)，
   并沿用其条件数守门（`_MAX_CONDITION`）。因此圆环结果**不是一个需要单独信任的新代码路径**：
   核函数、解析面元积分、配点约定全部与已发布路径相同，新增的只有「多环装配 + 朝向」。
4. **场重构** `evaluate_multiloop_field`：把 Green 表示式对**全部面板**求和。
   测点位于外环内、孔洞外，两个环的指示函数在环形区域相消，`c=1` 照常成立，
   所以不需要任何拓扑记账——这一点由 §3 的 `field RMSE`（\(10^{-4}\) 量级）实测确认。
5. **通量守恒** `boundary_flux`：逐环算 \(\oint q\,\mathrm ds\)。对调和场，
   \(\oint_{\text{外}}q = -\oint_{\text{内}}q = 2\pi A\)（径向算例），角向算例则为 0。
   这是「孔洞被真的当成边界」的物理判据——忽略内环的求解器外环数据能对上，外环通量会差一倍。
6. **三个对照**随算例一起跑，随时可复算：
   `flux_balance`（逐环通量 vs 解析）、`orientation_control`（内环法向不翻转）、
   `capacity_sweep`（外半径逼近参考长度 \(L=2\) 时的条件数悬崖）。
7. **数字零手抄**：`python -m tensorbem.benchmarks.annulus_laplace --output docs/annulus_laplace/study.json`
   写出严格 JSON（含 `acceptance` 阈值与 `verdict()` 判定），本页 §3 的表格由
   `--write-doc` 从该 JSON 渲染；`tests/test_multiloop_annulus.py` 一方面校验 JSON 全部 PASS，
   一方面**重算 64/32 级并逐字段比对**（`rel=1e-8`），文档数字因此不能悄悄漂移。

**工具链**：Python 3.11 / NumPy（稠密直接解，`np.linalg.solve` + `cond`），matplotlib(Agg) 出图；
全套复算约 19 s（128/64 级为最大规模，\(N=192\) 的稠密装配是主要开销），单元测试 11 条共约 11 s。

## 4. 误差判定（逐项，显式回答是否 <3%）

判定基准是**闭式解析解**（非第二个离散解），比较量为边界法向导数 \(q=\partial u/\partial n\)
与内部 48 个测点的势值。最细网格 = 128/64（\(N=192\)）：

| 算例 | 量 | 实测相对误差 | 基准 | 是否 <3% |
|---|---|---|---|---|
| radial_log | \(q\) 相对 \(L_2\) | \(4.70\times10^{-4}\) | \(u=0.7\log r+1.3\) 解析 \(\partial u/\partial n\) | **是**（0.047%） |
| radial_log | \(q\) 相对 \(L_\infty\) | \(5.71\times10^{-4}\) | 同上 | **是** |
| radial_log | 内部场 RMSE | \(8.77\times10^{-5}\)（绝对值，场量级 1.3） | 解析 \(u\) | **是**（≈0.007%） |
| radial_log | 逐环通量相对误差 | \(2.90\times10^{-4}\) | \(\pm2\pi A=\pm4.39823\) | **是** |
| angular_cos | \(q\) 相对 \(L_2\) | \(1.57\times10^{-3}\) | 解析 \(\partial u/\partial n\) | **是**（0.157%） |
| angular_cos | 内部场 RMSE | \(9.85\times10^{-5}\) | 解析 \(u\) | **是** |
| angular_cos | 闭合环通量不平衡 | \(7.03\times10^{-16}\)（绝对值，按 \(\oint|q|ds\) 归一后 \(3.8\times10^{-16}\)） | 解析 0（无对数项） | **是** |

**收敛阶**：\(q\) 误差观测阶 1.937 / 1.947 / 1.969（算例 A）、2.070 / 2.018 / 2.006（算例 B），
内部场 RMSE 观测阶 2.129 / 2.144 / 2.049 与 2.025 / 2.173 / 2.011。

**结论**：所有关键量在最细网格上误差均 **< 3%**（实际 ≤ 0.16%），且误差随加密单调下降、观测阶 ≈ 2
（与常数面元+中点配点在光滑数据上的预期一致）。**本单为代码验证（verification），不是工程试验确认（validation）**：
基准是解析解，不含实验不确定度。

**负控（朝向）**：内环法向不翻转时，64/32 面元的 \(q\) 相对误差
由 \(1.84\times10^{-3}\) 劣化到 \(1.660\)（径向）、由 \(6.32\times10^{-3}\) 劣化到 \(1.514\)（角向）
——即「用错朝向」不是小瑕疵而是 O(1) 错误，证明该约定必须由测试钉住。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **内环法向是最容易错的一步，而且错得"看起来还行"**。第一版实现直接把内环按 CCW 存进 `PanelMesh`
   （看起来自然：内圆也是逆时针），结果 \(q\) 相对误差 1.66、通量 11.73 vs 精确 4.398（2.67 倍）。
   防线有两条：`MultiLoopMesh.hole_loops` 让约定显式化，以及一条把「错误朝向必须比正确朝向差 100 倍以上」写成断言的负控测试。
2. **逐环闭合段**：对拼接数组直接 `roll` 会造出假面元（上条已述）。这是"多环装配"最隐蔽的实现陷阱，
   `MultiLoopMesh.ends` 逐环 `roll` 修复，并由 `test_mesh_geometry_and_normals` 守住面元数与法向对齐。
3. **解析梯度的自证**：算例 B 的 \(\partial u/\partial n\) 是手推的。手推必错的风险用**中心差分反查**消除
   （`test_analytic_normal_derivatives_match_finite_differences`，容差 \(10^{-6}\)）。
   若只让"数值解 ≈ 解析解"，一个同样错的解析梯度会给出虚假的"吻合"，所以必须先证明参考解是参考解。
4. **为什么算例 B 的通量不能用"相对误差"归一**：\(u=(r+c^2/r)\cos\theta\) 无对数项，闭式通量恰为 0；
   用精确通量作分母会得到 \(1.87\times10^{1}\) 这种无意义的"相对误差"。本包因此改用
   \(\oint|q|\,\mathrm ds\) 归一（并同时报绝对不平衡量）。判定指标的分母必须先想清楚再写。
5. **参考长度 \(L=2\) 的容量悬崖（适用范围）**：对数核的参考长度决定单层算子的容量尺度。
   本包取 \(L=2\)（历史上为避免单位圆容量退化）。把外半径从 1 推到 2.01 时，
   \(S\) 的条件数由 33 跳到 489、\(q\) 误差由 \(7.1\times10^{-3}\) 升到 \(2.8\times10^{-1}\)；
   越过 \(L\) 之后（\(R=2.5\)）又回落。**多连通性没有消除这个退化**，它只是把退化留给了每个环。
   使用建议：把几何缩放到「每个环的对数容量明显偏离 \(L=2\)」的尺度，或显式传 `reference_length`。
6. **适用范围**：只做二维、常数面元的 Laplace Dirichlet 问题。**未**支持：混合 Dirichlet/Neumann 的多环组合
   （`tensorbem.mixed` 是单环）、多孔（三个以上环）、以及带自由液面的多连通域（如带月池的 2-D 辐射问题）。
   后者需要把本组件与 `free_surface_solver` 的核组合，属单独立项。
7. **计算成本**：装配是 \(O(N^2)\) 的 Python 循环（沿用已发布实现，未向量化），\(N=192\) 时全套 19 s；
   若要做 \(N\gtrsim10^3\) 的多环算例，应先向量化 `assemble_matrices`——本单**没有**做这件事，如实记录。
