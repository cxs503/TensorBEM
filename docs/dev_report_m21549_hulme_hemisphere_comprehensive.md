## ① 案例介绍（物理背景/几何/参数表）

### 物理背景

Hulme (1982) *J. Fluid Mech.* **121**:443-463 给出了漂浮半球在无限深水中的辐射/绕射问题半解析解。
该解基于无波自由多极展开（wave-free multipole expansion in spherical harmonics），是三维水动力学
边界元方法（BEM）的经典验证基准。半球半径 a = 1 m，平面与静水面齐平，在入射波作用下产生
六个自由度的激励力，同时在强迫振荡下产生辐射附加质量和阻尼。

### 几何

| 项目 | 取值 |
|---|---|
| 几何体 | 浮半球（下半球面 + 水线圆盘） |
| 半径 a | 1.0 m |
| 排水体积 ∇ | 2πa³/3 = 2.094395 m³（精确值） |
| 水线面面积 A_wp | πa² = 3.141593 m² |
| 水深 | 无限深 |

### 物理参数

| 项目 | 取值 |
|---|---|
| 密度 ρ | 1025.0 kg/m³ |
| 重力加速度 g | 9.80665 m/s² |
| 入射波幅 A | 1.0 m |
| 波向 | 迎浪（β = 0） |
| 时谐约定 | exp(−iωt) |

### 无量纲频率带

| ka | ω√(a/g) | λ/a |
|---|---|---|
| 0.2 | 0.447 | 31.4 |
| 0.5 | 0.707 | 12.6 |
| 0.8 | 0.894 | 7.85 |
| 1.0 | 1.000 | 6.28 |
| 1.5 | 1.225 | 4.19 |
| 2.0 | 1.414 | 3.14 |

### 归一化

- 附加质量：A/(ρ∇)
- 阻尼系数：B/(ρω∇)
- 激励力：|F|/(ρgAa²) = |F|/10051.8 N

### 网格

| 级别 | subdivisions | 面元数 |
|---|---|---|
| 粗网格 | 2 | 64 |
| 中网格 | 3 | 256 |
| 主网格（算例） | 4 | 1024 |

网格由递归八面体细分生成（`hemisphere_hull_mesh`），水线顶点严格落在 z = 0。

## ② 怎么做的（方法/流程/关键设置/工具链）

### 求解器

`tensorbem.free_surface_solver3d` 实现三维自由面 BEM：

1. **Green 函数**：Kelvin/Havelock 深水 Green 函数，Rankine 直项与镜像项分别用 Van Oosterom–Strackee
   立体角与 polar/Duffy 近奇积分
2. **内部 CHIEF**：空场方程（`chief_points='auto'`）抑制不规则频率
3. **辐射问题**：`solve_radiation_3d`，surge（mode 0）与 heave（mode 2），单位速度幅值
4. **绕射问题**：`solve_diffraction_3d`，wave_angle = 0（迎浪），取复数激励力

### 参考解

`tensorbem.analytic.hulme_hemisphere_radiation` 实现 Hulme 无波多极级数：
- 截断项数阶梯：48/96/144 项
- 激励力由原点 Kochin 振幅/Haskind 互易关系给出
- 物面不可穿透残差经独立审计（m21013）：144 项最坏 2.64e-4（比 BEM 离散误差小 43 倍）

### 第三方交叉验证

- **capytaine** 3.1.dev0：1600 面元 BEM 解，独立离散化
- **刚性盖级数**：ka→0 极限下 surge 附加质量趋于 0.5（Kirchhoff 球减半论证）

### 工具链

```
geometry3d.hemisphere_hull_mesh → free_surface_solver3d.assemble → solve_radiation_3d / solve_diffraction_3d
                                                                        ↓
                                              hulme_hemisphere_radiation（参考）
                                                                        ↓
                                              evidence/build_evidence.py → evidence bundle
```

## ⑤ 注意点（踩过的坑/局限/适用范围）

### 已知问题与修复历史

1. **numpy 版本漂移（m20910）**：numpy 2.0.1 在 loongarch64 上的 LAPACK 后端导致复数最小二乘
   残差 49%（健康环境 1.8e-4），已定位到求解阶段并建立 E0 准入判据隔离失效档。
2. **证据包 SHA256 不同步（m20370）**：run_case.py 修改后证据清单未更新，已修复。
3. **缺失图工件**：independent_axis_figure.png 和 surge_lowfreq/figure.png 缺失，本单已补全。

### 局限

- **共享核风险**：参考解与求解器共用 `tensorbem.free_surface3d.wave_function_3d`；该核若有缺陷
  只会间接体现在物面残差里。第三方 capytaine 交叉验证是独立于该核的。
- **Hulme 原文数字不可得**：出版商付费墙，无法获取印刷数字。参考解是 Hulme 方法的重新推导，
  非原文数字转录。
- **频带限制**：ka∈[0.2, 2.0]，避开首个不规则频率 ka≈2.58。更短波需加密网格，更长波受截断影响。
- **4096 面元档**：健康环境的 4096 面元档尚未取回，当前阶梯止于 1024 面元。

### 适用范围

- 几何：浮半球（a=1m），平面与液面齐平
- 水深：无限深
- 频率：ka∈[0.2, 2.0]（λ/a≈3.1–31.4）
- 线性势流假设（无黏、无航速、小振幅波）
