## 1. 历史问题陈述（原 m2930 分支）

原 m2930 分支采用**积分表示法**（Fourier-Bessel 积分 + 核减法主值积分）实现三维有限水深 Green 函数。在深水极限交叉验证中，发现离轴场点的相对误差**不随水深增加而减小**：

| 场点 | R [m] | h=8 | h=20 | h=60 | 收敛？ |
|---|---:|---:|---:|---:|---|
| (0.5, 0, -0.5) | 0.5 | 0.347 | 0.345 | 0.345 | **否** |
| (2.0, 1.0, -1.5) | 2.24 | 3.20 | 3.20 | 3.20 | **否** |
| (0, 0, -0.2) | 0.0 | 0.002 | 6e-5 | 2e-6 | **是** |

相对误差 `|G_fd - G_dw| / |G_dw|` 在离轴点上为实值、随 R 增大且不收敛。

### 1.1 根因分析

积分表示法的深水极限为：

$$G_{fd} \xrightarrow{h\to\infty} \frac{1}{4\pi r} + \frac{1}{4\pi}\int_0^\infty \frac{k+\nu}{k-\nu} e^{k(z+\zeta)} J_0(kR)\,dk$$

分解被积函数：

$$\frac{k+\nu}{k-\nu} = 1 + \frac{2\nu}{k-\nu}$$

第一项积分给出镜像源项 $1/r_1$，第二项给出 $2\nu W$，故：

$$G_{fd} \xrightarrow{h\to\infty} \frac{1}{4\pi r} + \frac{1}{4\pi r_1} + \frac{\nu}{2\pi} W = G_{dw}$$

**公式层面完全等价**。问题出在数值实现：

1. **核减法中的高斯 bump 宽度选择**：`bump = 0.1 * k0`，当 `k0 → ν`（深水极限）时，bump 宽度固定为 `0.1*ν`，但被积函数的奇异性尺度随 R 变化，导致离轴点的核减法残留误差。
2. **面板网格的振荡分辨率**：`width = max(min(oscillation, 0.1*k0, bump/6.0), 1e-12)`，其中 `oscillation = 2π/R/6`。当 R 较小时面板过宽，R 较大时面板过密但积分上限 `k_max` 由 `exp(-k_max*α) < 1e-17` 决定，对浅源（zeta → 0）需要极大的 k_max，计算成本爆炸。
3. **缩放因子的数值稳定性**：`exp(-k*h)` 缩放在 `k0*h > 700` 时下溢，但分母的 `0.5*(k*(1-exp(-2kh)) - nu*(1+exp(-2kh)))` 在 `exp(-2kh) → 0` 时退化为 `0.5*(k - nu)`，与深水极限的分母 `k - nu` 一致，但分子中的 `exp(k*zeta) + exp(-k*(2h+zeta))` 第二项在深水时下溢，导致数值精度损失。

### 1.2 结论

积分表示法在原理上正确，但数值实现对离轴点的深水极限收敛性差，且计算成本随源点接近自由面急剧增加。该实现标记为 **UNVERIFIED**，不建议用于求解器。

## 2. 现行实现（John 特征级数法）

当前 main 采用 **John (1950) 特征级数法**，将垂直方向谱离散化为本征模态展开：

$$G(x,\xi) = \frac{1}{2\pi}\sum_{n\ge1}\frac{\phi_n(z)\phi_n(\zeta)}{N_n}K_0(\mu_n R) + \frac{i}{4}\frac{\phi_0(z)\phi_0(\zeta)}{N_0}H_0^{(1)}(k_0 R)$$

其中：
- 传播模态：$\phi_0 = \cosh k_0(z+h)$，$k_0\tanh(k_0 h) = \nu$
- 消逝模态：$\phi_n = \cos\mu_n(z+h)$，$\mu_n\tan(\mu_n h) = -\nu$
- $N_n = \int_{-h}^0 \phi_n^2 dz$ 为模态范数
- $K_0$ 为修正贝塞尔函数，$H_0^{(1)}$ 为第一类 Hankel 函数

### 2.1 为何特征级数法更优

| 方面 | 积分表示法 | John 特征级数法 |
|---|---|---|
| 深水极限 | 需数值积分，离轴收敛差 | 解析极限：$k_0\to\nu$，$\mu_n\to(n-1/2)\pi/h$，级数自然收敛 |
| 计算成本 | 随源点接近自由面急剧增加 | 仅依赖模态数，自动截断 |
| 数值稳定性 | `exp(-k*h)` 缩放在 `k0*h>700` 下溢 | 纯级数求和，无指数缩放问题 |
| 验证状态 | UNVERIFIED（离轴深水极限失败） | VERIFIED（26 项测试全通过） |

### 2.2 深水极限验证

现行实现的深水极限验证结果（`tests/test_finite_depth3d.py::test_deep_water_limit_recovers_kelvin_kernel`）：

| h [m] | k0h | max relative deviation from `free_surface3d` |
|---|---|---|
| 10 | 6.0 | 5.745e-01 |
| 20 | 12.0 | 4.685e-02 |
| 40 | 24.0 | 1.804e-03 |

误差随水深增加单调递减，**离轴点同样收敛**（与积分表示法的关键区别）。

## 4. 适用范围与局限

### 4.1 适用范围

- 常数水深、线性势流理论
- 源点和场点均在流体层内（-h ≤ z ≤ 0）
- 频率范围：νh 从浅水（~0.01）到深水（~100+）
- 水平距离 R > 0（R = 0 时级数发散，需用 Rankine 源项处理）

### 4.2 局限

- 仅提供垂直导数 ∂G/∂z 的解析表达式；水平导数需 K₁/H₁，留给边界元层
- 模态数自动截断针对 `exp(-μₙR_min) ≤ 1e-12`，对极小 R 需要大量模态（上限 40000）
- 不规则频率（irregular frequencies）问题未在此核中处理，需在求解器层用 CHIEF 或 overdetermined 方法解决
