# 有限水深辐射求解器：`ka` 与 `f/a` 扫掠验证（结清 limitation 5）

**日期**：2026-11-03　**模块**：`tensorbem.benchmarks.finite_depth_frequency_sweep`
**上游欠账**：`docs/finite_depth_radiation.md` §5 局限 5 ——「只在圆形截面、`ka=0.6`、`f/a=2` 上验证；未扫 `ka` 与 `f/a`」

## 1. 案例介绍

无限长圆柱截面（半径 `a`）水平潜没于等深水池，轴线位于静水面下 `f`，水深 `h`，作单位速度垂荡（heave）与横荡（sway）振动；求单位宽度附加质量 `A` 与阻尼 `B`。

| 参数 | 值 |
|---|---|
| 半径 `a` | 1.0 m |
| 水深 `h` | 50.0 m（`h/a = 50.0`） |
| 潜深比 `f/a` | 1.50, 2.00, 3.00 |
| 无量纲频率 `ka` | 0.20, 0.60, 1.00, 1.50 |
| 密度 `rho` | 1025.0 kg/m³ |
| 重力加速度 `g` | 9.80665 m/s² |
| 面元数 `N` | 64（常数面元，等弧长） |
| 参考解 | Ursell 深水多极子闭式解（`tensorbem.analytic`）+ 深水面板求解器（同网格） |

选择 `h/a = 50` 的理由：此时有限水深核相对深水核只剩指数小项，任何与水**无关**的差异都只能来自实现，因此扫掠把「水深的物理」与「核/装配的实现」分离开。

## 2. 怎么做的

1. 对每个 `(ka, f/a)` 用有限水深间接（单层位势）求解器`tensorbem.finite_depth_solver.solve_radiation` 求 `A`、`B`；**垂荡与横荡分别求解**——对称体在垂荡下的水平力恒为零，若用一个解的两个分量去比较，就会拿零比零（本次开发中真实踩到，见 §5）。
2. 同网格、同 `ka` 再用深水面板求解器 `free_surface_solver.solve_radiation_indirect`求一份 `A`、`B`，作为「核实现」判据的基准：它包含面板离散误差，但与有限水深核完全无关。
3. 与 Ursell 深水多极子闭式解（零共享代码）比较，得到含离散误差的总误差。
4. 能量恒等式：由辐射波幅算得 `B = 2 rho g c_g |eta_a|²`（远场）与压力积分 `omega rho Im(F)`（近场）比较。
5. 模态数充分性：把自动模态数 `24 nu h` 乘 2 倍重算，报告系数相对变化。
6. 面板加密：扫掠中最粗与最细两个工况做 `N = 32/64/128`，报告观测收敛阶。

工具链：Python 3.11 / NumPy 2.4.6 / matplotlib（图）/ pytest（判据）。整轮耗时 851.2 s，单机 128 核，进程为单核 2-D BEM，未占用重算力。

### 3.2 汇总判据

| 判据 | 实测最大值 | 门限 | 结论 |
|---|---|---|---|
| 与深水面板解的最大偏差（核实现） | +9.19e-04 | 1e-2 | PASS |
| 与 Ursell 闭式解的最大偏差（含离散） | +2.47e-02 | 3e-2 | PASS |
| 能量恒等式最大偏差 | +1.10e-02 | 3e-2 | PASS |

- 最差 Ursell 偏差出现在 `ka = 0.20`、`f/a = 1.50`；
- 最差核偏差出现在 `ka = 0.20`、`f/a = 1.50`；
- 能量恒等式比值全程落在 [1.0100, 1.0110]，系统偏正约 1.05%，与 `docs/finite_depth_energy_identity/report.md` 的结论（一阶离散偏移）一致；
- 模态研究工况：`ka = 1.50`、`f/a = 1.50`，自动模态数 1800 → 3600，附加质量相对变化 heave -5.24e-06 / sway -1.04e-07，阻尼相对变化 heave -1.45e-05 / sway -7.06e-06。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **踩坑（已修）**：第一版扫掠对每个 `(ka, f/a)` 只求解一次，然后从同一个解里读两个力分量。对称体垂荡时水平力**恒为零**，于是「深水面板 vs 有限水深」的偏差出现 1e+15 量级，`A_sway` 读出 `-0.0`。修法是两个运动各解一次，并在测试里用`test_cases_are_non_degenerate` 把「系数必须非零」钉死。**这类零比零的伪一致/伪失效在对称问题上会静默发生，比发散更难发现。**
2. **深水塌缩判据证明的是「核实现」而不是「物理精度」**：`h/a=50` 时物理水深效应已低于 0.1%，所以该判据只能抓实现缺陷；有限水深的**物理**正确性依赖核级验证（`docs/finite_depth_2d.md`）与能量恒等式。
3. **自动模态数在 `ka=1.5` 处并非 1e-6 级收敛**：2 倍模态使系数变化 ~1e-5（见 §3.2），比 `docs/finite_depth_2d.md` 的核级地板（`nu h=400` 时最坏 2e-5）同量级。相对 ~1% 的离散误差这完全可忽略，但**不能**宣称系数已收敛到 1e-6。
4. **仍是 2-D、常数面元、常水深、无流、线性势流**；未接船体几何，没有实验/文献实测数据（有限水深附加质量的文献表本机不可得）。因此结论是「实现正确性 + 离散误差量级」，不是「某工况的工程精度」。
5. **未扫净空**：`h/a=50` 时净空很大；浅水/近底阻塞（陡峭的 `h/a<4`）不在本单范围，`docs/finite_depth_radiation.md` 已单独覆盖深度扫描。
6. `sway` 在 `f/a` 较大的工况下与 `heave` 只差 1e-3 量级（深水极限两者相等），这正是检验对称性的物理依据，但也意味着本扫掠对 `sway` 的**独立**信息量弱于 `heave`。

## 6. 误差判定

基准：Ursell 深水多极子闭式解（`tensorbem.analytic.ursell_cylinder_added_mass`，与求解器零共享代码）与深水面板解（同网格）。

| 关键量 | 最大相对误差 | 基准 | 是否 < 3% |
|---|---|---|---|
| `A`（heave/sway，含离散） | +2.47e-02 | Ursell 闭式解 | 是 |
| `A`（heave，核实现） | +9.19e-04 | 深水面板解（同网格） | 是 |
| `B_far/B_near`（能量恒等式） | +1.10e-02 | 波幅能量平衡 | 是 |

**逐项回答「是否 <3%」**：

- 附加质量对 Ursell 闭式解：是（最大 2.47%，出现在 `ka=0.20, f/a=1.50`；该误差是 64 面元的离散误差，加密到 128 面元降到 1% 量级，见 §3.3）；
- 有限水深核相对深水面板核：是（最大 +9.19e-04）；
- 能量恒等式：是（最大 +1.10e-02）；
- 与实验/文献实测值比较：**无基准，未做**。有限水深圆柱附加质量的文献表（Yu & Ursell 类）本机不可得，故本单不宣称任何「对实物/实船的精度」。
