## 1 案例与物理背景

敞水（open-water）是螺旋桨单独在均匀来流中运转的基准工况：给定进速比 `J = V_a/(nD)`，量测推力系数 `K_T = T/(ρn²D⁴)`、扭矩系数 `K_Q = Q/(ρn²D⁵)`，效率 `η0 = J·K_T/(2πK_Q)`。它是船舶总体推进链 `η_D = η_H·η_R·η_0` 的乘性首项，因此敞水锚值的**量纲口径**（10KQ 还是 KQ）与**效率恒等**一旦出错，推进因子会整链失守。

## 2 方法

1. **锚件登记**：O&O 1975 的 39 项 K_T / 47 项 K_Q 回归系数从仓内已登记锚件 `benchmarks/anchors/wageningen_b_series.json` 读取，按 B4-70 几何在 J=0.1…0.8 独立求值；KP505 的 Table 2 逐行地从 PDF 转写文本解析（引句与数字同源），并与锚 JSON 交叉核对到 1e-12。
2. **η0 恒等复算**：另写一条独立通路 `η0 = J·K_T/(2π·K_Q)`，其中 `K_Q = 10K_Q/10`，与锚件登记的 η0 逐点比较，残差门限 0.5 %（该通路能抓 10KQ/KQ 的口径错位）。
3. **求解器对表**：TensorBEM 涡格敞水核在**同样的 J 点**各跑一遍——B4-70 用 `B4_70_FINE`（16×2 面元、geometric 尾迹 L/D=2.0/48 步、ITTC-78 摩擦）；KP505 用模块默认（16×2=32 面元/叶，与仓内 `benchmarks/kp505_openwater_bem/points.csv` 同一构型），逐点出 `dK_T`、`d(10K_Q)`、`dη0`。
4. **ηR 口径审计**：向平台推进块与阻力块各递交同一个 11 状态网格（单船体 L=180 m、B=32 m、T=11 m、Cb=0.82；S1–S6 为 12–17 kn @100 rpm 速度扫描，S7–S10 为 85/90/95/105 rpm @15 kn 转速扫描，S11 为 P/D=1.05 @15 kn/100 rpm），原始回执逐字存档于 `data/w30/propulsion_states/api_receipts.json`（sha256 `37a26be1ba93c5c4`）。每个状态给出三个 ηR：平台返回值、平台自身乘积恒等反解、跨模块（阻力块 P_E / 推进块 P_D）反解，逐条判 [0.90, 1.10]。

工具链：`python benchmarks/anchors/build_openwater_efficiency_closure.py`（求解器本地核，单点 ~0.8 s，18 点共 ~15 s，未压集群；三节点/大网格扫描不在本单范围）。

## 5 注意点与局限

- The Oosterveld & van Oossanen anchor is a CLOSED-FORM anchor: the printed NSMB tables are not in this worktree, so no table digit is claimed.  What is claimed is that the published 39/47-term regression, fed the machine-chain coefficients already registered in benchmarks/anchors/wageningen_b_series.json, reproduces the registered B4-70 curve and satisfies the efficiency identity.
- The KP505 anchor is a LITERATURE_TABLE anchor but a SECONDARY_REPRODUCTION: the digits are the 'Experimental' columns of Table 2 of Iftikhar & Takinaci (MARINE 2023), not the KRISO handout; the paper does not state where its experimental column came from.
- The eta_R window judgement on the platform path is possible at all only because the resistance module and the propulsion module are independent code paths; without that second P_E the identity is a tautology (see etaR_audit.summary).
- Receipt precision: the archived endpoint fields carry 2 dp (kW) / 4 dp (dimensionless), which is what bounds the identity residuals at ~1e-3, not a solver effect.
- 锚件真实性：O&O 锚是**闭式重算**而非印刷表数字化；KP505 锚是二手转写（MARINE 2023 的 Experimental 列，该文未注明其实验数据来源），要用于对外精度声明前必须回到 KRISO 原始表核对。
- 回执精度：平台回执为 2 位小数（kW）/4 位小数（无量纲），因此恒等残差的 1e-3 量级是**精度限制**，不是求解器误差。
- 11 状态网格是本单自定的（单船体、速度+转速扫描+一个 P/D 点，预登记于脚本头部），不是审计原网格；9/11 是计数复现，不是状态集同一性证明。
- `prop_pitch` 字段语义为 P/D 比值而非螺距长度（5.4 被回执报为 “P/D=5.400 超出 B 系列有效域”），用螺距[m]填表会静默产生越域结果（该状态 P_D 推进块仍返回 open_water_eff=0.999、propulsive_eff=1.0689>1）。

## 6 误差判定（逐项回答「是否 < 3 %」）

| 量 | 基准 | 最大偏差 | < 10 % ? | < 3 % ? |
|---|---|---|---|---|
| dK_T (B4-70, 8 点) | O&O 1975 闭式 | 15.45 % | 7/8 | 2/8 |
| d10K_Q (B4-70, 8 点) | O&O 1975 闭式 | 11.92 % | 7/8 | 2/8 |
| dK_T (KP505, 10 点) | Table 2 实验列 | 240.71 % | 5/10 | 0/10 |
| d10K_Q (KP505, 10 点) | Table 2 实验列 | 84.13 % | 5/10 | 0/10 |
| η0 恒等残差 (18 锚点) | 锚件登记 η0 | 1.71e-14 % | YES | **YES** |
| η0 平台复算残差 (11 状态) | 平台返回 open_water_eff | 0.036 % | YES | **YES** |
| ηR (跨模块反解, 11 状态) | 物理窗 [0.90, 1.10] | 121.1 %（相对 1.0） | — | **NO（9/11 越窗）** |

逐条回答：**η0 恒等与平台 η0 复算均 < 3 %**（前者 ~1e-14 %，后者 ≤ 0.036 %，后者受回执 4 位小数限制）；**敞水求解器对表不满足 < 3 %**：B4-70 仅 2/8 点同时满足 K_T 与 10K_Q 的 3 %，KP505 0/10 点；B4-70 在 J=0.80、KP505 在 J≥0.60 连 10 % 门限都不满足。**ηR 的物理窗判定不通过**：平台返回值虽恒在窗内，但它是未计算的常数；以独立模块 P_E 反解时 9/11 越窗，属物理不可容许，按本单要求显式报出（不粉饰）。

结论：判据 C1/C2 通过，C3/C4 失败（C5 为信息项）。敞水锚件与 η0 恒等已核销；推进块的真缺陷是 ηH/ηR 常数化 + 推进块不消费阻力/推进未与阻力匹配，表现为 ηR 物理窗的 9/11 越界。修复建议（下一单）：(a) 推进块按自航点反解 rpm（使 `T(1-t)=R_T`）而不是接受任意 rpm；(b) ηR 用 Holtrop(1984) 经验式或 B 系列自航数据计算，不得恒取 1.0；(c) 对乘积恒等增加“非平凡性”断言——任一因子为常数即判该恒等不可用于诊断；(d) 涡格核在高 J 端需引入片空化/前缘分离修正，否则不得用于 J>0.5 的精度声明。
