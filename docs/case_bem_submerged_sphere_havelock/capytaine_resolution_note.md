# capytaine 分辨率研究 —— 第三方交叉核对能证到多准（对抗式复核）

锚点：`CASE-BEM-SUBMERGED-SPHERE-HAVELOCK`（算例池·Havelock 潜球辐射，频域）
性质：验证欠账 / 对抗式复核（不是新功能）
工件：`capytaine_refinement_ladder.json`（本单新算）、`gf_singularity_probe.json`（本单新算）、
`capytaine_crosscheck.json`（既有，未改动）
脚本：`scripts/case_havelock_capytaine_refinement_ladder.py`

## 1. 被复核的主张

既有的 `capytaine_crosscheck.json`（`scripts/case_havelock_capytaine_crosscheck.py`，两档网格 320/1280）
顶层 `verdict: FAIL`（最差 6.76%，ka=5 b11 @320），而 `note` 同时主张：

> agreement below the 5 % pool tolerance certifies that the reference column is not an
> artefact of one code

这两句话互相矛盾，而且都不可直接采信：单档网格上的偏差是
**capytaine 自身的离散误差 + 参考解偏差**之和，无法分离。若 capytaine 在该档的离散误差本身就有 3–7%，
"低于 5% 即认证参考解"这句话在逻辑上不成立（它认证的是两套离散的互相接近，不是参考解）。

## 2. 做法

对同一物理问题（a=1 m，f/a=2.0，ρ=1025，g=9.80665，无限水深，ω²=gk，7 个 ka=0.1…5.0）
用 capytaine（第三方 BEM，独立代码库）在**四档自相似网格**上求解：subdivision 1/2/3/4 =
80 / 320 / 1280 / 5120 面元（TensorBEM 的 `submerged_sphere_mesh`＝测地二十面体细分，h 每档减半）。
归一化两侧都用**精确球体积** 4/3πa³（多面体体积亏损保持可见，不被抵消）。

预声明判据（在看到数之前固定，写在脚本 `criteria` 里）：

* C1：最细一档（5120）上，非退化项的 |偏差| < 1%；
* C2：至少 90% 的项的 |偏差| 随加密单调下降（有衰减才允许谈"收敛到参考解"）；
* 退化项（|ref| < 10% 带宽尺度）另看尺度归一化偏差。

另做一个证伪实验：把 capytaine 的近场奇异项设置从 `low_freq`（默认）换成
`low_freq_with_rankine_part`（该版本最精确档），检验"平台化偏差是不是积分奇异性假象"。

## 3. 结果

### 3.1 网格几何（自证细化是自相似的）

| subdivision | 面元 | 多面体体积亏损 |
|---|---|---|
| 1 | 80 | 12.6547% |
| 2 | 320 | 3.3839% |
| 3 | 1280 | 0.8606% |
| 4 | 5120 | 0.2161% |

亏损比 3.93 / 3.98 → 几何亏损确为 O(h²)，网格族自相似。

### 3.3 判据结果（honest）

| 判据 | 结果 |
|---|---|
| C1（最细档全部 <1%） | **FAIL**：28 项中 12 项 <1%；非退化项最差 **1.903%**（ka=0.5 b33），含退化项最差 2.487%（ka=5 b33，\|ref\|=1.0e-6） |
| C2（≥90% 项单调衰减） | **PASS**：27/28 = **96.4%** 衰减；唯一上升项是 ka=5 b33，比值 1.372 |
| 顶层 verdict | **FAIL**（按预声明 1% 判据，未下调判据） |

### 3.4 证伪实验（`gf_singularity_probe.json`）

ka=1.0、320 / 1280 两档，`low_freq` 与 `low_freq_with_rankine_part` 的有符号偏差
在 4 位小数上完全一致（a33 +3.8965/+2.5719，b33 +1.9293/+2.6189，a11 +3.8101/+2.5982，
b11 +2.0509/+2.7124）→ **假设被证伪**：残余偏差不是近场奇异项积分档位造成的假象，
而是 capytaine 平板离散本身，随加密衰减。

### 3.5 TensorBEM 结果对第三方细网格的独立测量

TensorBEM 案定网格（1280 面元）对 capytaine 5120 面元值：28 项，最大 **3.27%**（ka=0.5 b33），
**0/28** 超过 5% 池判据。即：换一条独立代码路径测量，算例池的 PASS 仍然成立，
但独立路线的分歧量级约 3%，而不是算例自报的 1.43%。

## 4. 结论与订正

1. **既有 crosscheck 的 FAIL 不是对参考解的反证**。capytaine 的偏差随加密单调衰减
   （3.9% → 2.6% → 1.4~1.9%），无平台、无变号 → **没有证据**表明多极参考解存在 ~1% 量级的系统偏差。
2. **但"低于 5% 即认证参考解"的措辞是过强的**，必须订正为：单档网格比较只证明两套离散互相接近
   （320 档 capytaine 自身误差 1.3–6.8%，1280 档 1.8–3.9%）；参考解在此路线下只能被认证到
   **约 2%（5120 档）**，<1% 的认证**未达成**（C1 FAIL，保留）。
3. capytaine 在 5120 面元上（~1.4–1.9%）并不比 TensorBEM 在 1280 面元上（1.43%）更准，
   所以"用第三方更准的网格来裁判 TensorBEM"这条路线本身有天花板；要裁判到 <1% 需要
   20000+ 面元的第三方解或更高阶面元（未做）。
4. 因此本算例的精度结论应保持为：**TensorBEM vs 多极参考 1.43%（算例自报）**，
   独立路线的交叉证据**支持到 ~3%**；两者都 <5% 池判据。

## 5. 局限

* capytaine 5120 面元左右仍有 ~1.4–1.9% 离散误差，本单**没有**做到 20480 面元（稠密矩阵 6.7 GB/解，未递交）。
* 未做 capytaine 的阶次收敛拟合的极限外推（四档偏差非渐近，2–3 参拟合不稳定，故不使用外推值做判据）。
* 未与文献表值比对（付费墙，见 `CASE.md` §1）。
* 第三方解与参考解的偏差来源未进一步定位到具体积分项（本单只证伪了奇异项档位假设）。
