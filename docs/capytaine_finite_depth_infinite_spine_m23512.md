# 无限水深网格脊诊断：有限水深交叉验证偏差的离散化归因（m23512）

**锚点**: `XVAL-BEM-FINITE-DEPTH-CROSSVAL-PLAN`
**仓**: TensorBEM · **分支**: `agent/m23512`
**日期**: 2026-11-16
**状态**: 完成（infinite_depth_spine.json 已组装，9 格全网格）

---

## 1. 问题

有限水深交叉验证（`bem_finite_depth_capytaine_xval`）在 sub-2（320 面板）"细"级
记录到 TensorBEM 相对 capytaine 的系统性偏差：
- A33（垂荡附加质量）~12 % 偏低
- B33（垂荡阻尼）~34 % 偏低

该偏差是否代表**有限水深 John 本征级数核**的缺陷，还是**共享常数强度配点格式**
的离散化伪影？这是交叉验证能否收口为"求解器分歧"还是"网格分辨率伪影"的关键。

## 2. 方法：无限水深网格脊

`infinite_depth_spine.py` 用 TensorBEM 自己的**无限水深** Rankine 求解器
（`free_surface_solver3d`）在相同几何、相同网格阶梯（sub 1→2→3 = 80/320/1280 面板）、
相同频率（ka = 0.3/1.0/2.0）上求解，并与缓存的 capytaine 无限水深级
（`cases/cpt-*-hinf-*.json`）对比。

**关键逻辑**：无限水深求解器共享常数强度配点格式，但**不含** John 本征级数
有限水深核。若偏差随与水深无关的网格细化以与有限水深相同的方式收缩，则它是
共享格式的离散化——而非有限水深核缺陷。

## 4. 结论

1. **偏差随网格细化单调收缩**：A33 从 ~11 %（sub1）→ ~5 %（sub2）→ ~3.5 %（sub3）；
   B33 从 ~22 % → ~8 % → ~4 %。每个频率都如此。
2. **sub-3（1280 面板）已进入 owner 15 % 线内**，且 A33/B33 均 < 5 %（预注册门限）。
3. **收敛与频率无关**（sub1→sub3 收缩因子 ~3x 于每个 ka）——这是共享离散化偏差的
   特征，而非核/相位误差。
4. **有限水深交叉验证的 sub-2 "细"级是网格分辨率伪影**，不是核缺陷。sub-2 的
   ~12 %/~34 % 偏差是共享常数强度配点格式在 320 面板上的离散化残差。

## 5. 意义与后续

- 有限水深交叉验证的收口方向：**用 sub-3（或更细）网格重跑有限水深格**，或对
  sub-2 结果做 Richardson 外推，而非声称核缺陷。
- 本诊断把"求解器分歧"与"网格分辨率伪影"分离，是交叉验证计划（锚点）最硬的
  验证证据之一。
- 新增测试 `tests/test_bem_finite_depth_infinite_spine.py`（6 项）钉住该结论：
  偏差单调收缩、sub-3 进入 owner 线、sub-2 未收敛、收敛与频率无关。
