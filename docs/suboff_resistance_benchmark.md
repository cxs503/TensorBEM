## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **几何先验**：回转体以 (L, D, S) 表征；有效容积系数 = 表面丰满度 `S/(πDL)`（圆柱=1），Cauchy-Schwarz 下界 `Cb ≥ (S/(πDL))²`。SUBOFF：`S/(πDL)=0.7796`，`Cb∈[0.6078, 1.0]`。
2. **根因定位**：平台 `calc.resistance`（"ITTC-57 + Holtrop"）对 SUBOFF 用硬编码 MOCK `base_ct = 0.0055 + 0.002·Fn`。`0.0055` 基数是真实 ITTC-57 摩擦系数（Re≈1.3e7 时 C_F≈0.0029）的 **~1.9 倍**，导致总阻力系数 **~1.7 倍** 偏高（|err| 66–69%）。且 Holtrop 兴波项对**全潜体**物理不适用（无自由面）。
3. **修正模型**：`C_T = C_F(ITTC-57) + C_R`，`C_R = 0.002·Fn`（残差/形状阻力，线性于 Fn，Fn=0 时退化为纯摩擦）。对 4 例正典重算。
4. **工具链**：Python 3.11 + matplotlib（Agg，仅出对比曲线）；脚本 `artifacts/suboff_resistance_benchmark/compute_suboff_benchmark.py` 程序化注入，零手抄。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **正典 C_T 为 DERIVED**：4 例 C_T（0.0038→0.0044）是线性于 V 的构造值（`0.0038+0.0002·(V-3)`），非原始实验散点；修正模型以「摩擦+残差」分解复现之，误差 <1.2%。
2. **Holtrop 不适用于全潜体**：其兴波项 `R_W` 对无自由面的回转体是伪项；本修正显式剔除，只保留 ITTC-57 摩擦线。
3. **几何口径**：回转体无独立 Cb 发布值，以 `S/(πDL)` 表面丰满度作为有效 Cb（0.7796）；m27641 旧预设 `cb=0.542` 与几何不一致，是旧链失准的次要来源。
4. **适用范围**：本模型为模型尺度（L=4.356 m）拖曳水池校准；实船尺度需另加粗糙度/相关 allowance（C_A），本单未涉及。
