## 1. 案例介绍

### 1.1 物理背景

三维有限水深自由面 Green 函数 $G(x,\xi;\nu,h)$ 是水动力 BEM 的核心核函数，满足：
- 自由面条件：$\partial_z G = \nu G$ at $z=0$（$\nu = \omega^2/g$）
- 海底条件：$\partial_z G = 0$ at $z=-h$
- 远场辐射条件：出射柱面波 $O(R^{-1/2})$

TensorBEM 采用 John (1950) 本征级数表示 + 直接配点格式；capytaine（v3.1.dev0）
采用波数积分 + 色散关系求根路线。**两条独立数值路线在相同几何/参数下的一致性**
是有限水深能力最硬的验证证据。

## 2. 方法

### 2.1 求解路线对比

| 路线 | 模块 | 核心方法 |
|---|---|---|
| TensorBEM | `finite_depth_solver3d` | John 本征级数 + 直接配点 + Rankine 奇性分裂 |
| capytaine | `BEMSolver` | 波数积分 + 色散关系求根 + 间接单层 |

### 2.2 Richardson 外推

采用三阶 Richardson 外推：$v(N) = v_\infty + C N^{-p}$，阶 $p$ 由三级梯级**量出**（非假定）。
外推公式：
$$p: \frac{n_3^{-p} - n_2^{-p}}{n_2^{-p} - n_1^{-p}} = \frac{v_3 - v_2}{v_2 - v_1}$$
$$v_\infty = v_3 + \frac{v_3 - v_2}{n_3^{-p} - n_2^{-p}} n_3^{-p}$$

### 2.3 预注册门禁

| 门禁 | 判据 | 阈值 |
|---|---|---:|
| G1 | 附加质量跨代码误差（A33/A11） | 3% |
| G2 | 阻尼跨代码误差（B33/B11） | 5% |
| G3 | 负控分离（有限水深 vs 深水） | 2% |
| G4 | TensorBEM 梯级渐近性（$p \geq 0.3$） | 0.3 |
| G5 | 线性解残差 | $10^{-10}$ |
