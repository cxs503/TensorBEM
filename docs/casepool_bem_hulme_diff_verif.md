# m17537 CASE-BEM-HULME-DIFF-VERIF：漂浮半球三维绕射（总激励力）三路线验证

## 1. 案例介绍

算例池 id 177（锚点 `CASE-BEM-HULME-DIFF-VERIF`，TensorBEM）。几何：floating hemisphere, r = a = 1 m, waterplane z = 0，体积 2.094395 m³，水线面 3.141593 m²，ρ=1025.0 kg/m³，g=9.80665 m/s²，入射波幅 1 m，迎浪（β=0）。频率带 ka∈[0.2, 0.5, 0.8, 1.0, 1.5, 2.0]，归一化 F/(ρgAa²)，时谐 exp(-iωt)。文献锚：Hulme A. (1982) The wave forces acting on a floating hemisphere undergoing forced periodic oscillations, J. Fluid Mech. 121:443-463。

## 2. 怎么做的

三条互不共享离散化的路线：

- **参考**：`tensorbem.analytic.hulme_hemisphere_radiation`（Hulme 无波势多极级数，项数阶梯 [48, 96, 144]，激励力取原点 Kochin 振幅/Haskind 互易）；
- **求解器**：`tensorbem.free_surface_solver3d.solve_diffraction_3d`（Kelvin/Havelock Green 函数 BIE + 内部 CHIEF），面元阶梯 [2, 3, 4] → 64/256/1024 面元；
- **第三方**：scripts/capytaine_hulme_diff_scattered.py (capytaine DiffractionProblem, scattered force) + exact Froude-Krylov quadrature from this module。

门限（动手前固定）：G1 复相对误差 ≤5%、G2 相位差 ≤3°、G3 面元单调+观测阶 ≥0.8、G4 独立路线 ≤5%、G5 参考解长波极限（外推）≤1%、G6 Haskind 互易 ≤2%。

## 5. 注意点

- **口径坑（本单核心发现）**：capytaine `DiffractionProblem.forces` 只含绕射（散射压力）力，不含 Froude-Krylov；直接与总激励力对比会误判。冻结文件用 ka=0.05 长波探针钉死：capytaine 给出 0.0931·ρga²→0，而总激励力应趋于 π·ρga²。本算例把精确 FK 加到 capytaine 绕射上再比，才成为真正的独立路线。
- TensorBEM `solve_diffraction_3d(...).excitation_force` 是**总**激励力（FK+绕射），与 `froude_krylov_force_3d` 文档一致；`scattered-only` 已同时存进 results 便于逐项对账。
- 参考解不是 Hulme 原文印刷数字（本环境无原文获取途径），因此额外给 G4（第三方代码）与 G5（长波解析极限 π·A_wp/a²）两条非自证外部锚。
- 适用域 ka∈[0.2,2.0]（a=1 m ⇒ λ/a≈3.1–31）；更短波需加密网格，更长波受截断影响。

## 6. 误差判定

- G1 复相对误差最坏 0.54%（ka=0.5，surge）→ **<3% 成立**，且相对台账 <5% 有 9× 裕度；
- G2 相位差最坏 0.050° → 远小于 3°；
- G4 独立路线最坏 4.30%（Richardson 7.48%）→ **不满足 <3%，但满足本条预声明判据 ≤5%**；这是非自证锚，其残差主要来自 1024 面元 capytaine 的自身离散（自收敛 1.1%）与外推不确定度，如实记录；
- G5 长波极限：ka=0.02 原始 3.06378 vs π=3.14159（2.48%，O(ka) 逼近），线性外推 3.14186（0.01%）→ **<3% 成立**；
- G6 Haskind 互易最坏 0.83% → <3% 成立。
- **总判定 PASS**（6/6 门 PASS）。
