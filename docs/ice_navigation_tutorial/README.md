# 冰区航行教程体系 · 核心章节（TensorBEM 验证层）

> 总账锚点：`ICE-SHOW-TUTORIAL-CORE`「冰区航行教程体系核心章节（≥8 章全链路）」
> 本目录 = 教程正文 + 机器渲染数值 + 判据登记表 + 复现门禁；全部数值由
> `examples/ice_tutorial/render.py` 生成，无手抄。

## 1. 这套教程回答什么问题

冰区航行不是"把敞水结果除以一个系数"。一艘船的冰区性能由三条链共同决定：

1. **环境与对象**：冰型、冰厚、冰密集度、冰级；船体几何与排水量。
2. **水动力–冰耦合物理**：冰盖如何改变自由面边界条件，从而改变波场、附加惯性、
   波浪激励与运动响应。
3. **工程判据与验证协议**：冰压力与结构载荷、冰阻力、精度容差、证据分级。

本教程把这三条链拆成 **9 个可独立讲授的章节**。其中 ch01–ch04 的每一个数字都由本仓
已合并的验证代码现场算出（BEM 与解析解双路线），ch05 给出本仓已完成的
"波–冰–船辐射绕射"链路的证据指针，ch06–ch08 是工程/法规判据章（这些能力的实现
**不在本仓**，本仓按 `WITHHELD` 记账而不是假装算过），ch09 是这套教程自己的验证协议。

## 3. 证据分级与容差（与平台一致）

| 等级 | 含义 | 本教程中的例子 |
|---|---|---|
| REAL | 真实算法，有可复算的参考值/解析解 | ch02 色散 BEM vs Weitz-Keller；ch04 附加质量 vs Lamb |
| MOCK | 硬编码/随机占位 | 本教程无（任何 MOCK 数值禁止入章） |
| STUB | 空壳接口 | 本教程无 |
| WITHHELD | 证据不足，能力不在本仓 | ch03 冰区波场衰减（碎冰散射/耗散）、ch06 冰阻力实现、ch07 结构冰载荷、ch05 真实 PC6 型值表 |
| NOT_SUPPORTED | 明确不支持 | 冰脊演化、冰-船 DEM 接触（属 TensorDEM 线） |

容差层级（`PLATFORM-STD`）：

* **< 3 %**：与解析解/文献基准对比的理想目标（ch02/ch04 的锚定判据在此量级）；
* **< 5 %**：算例池数值容差（ch04 的 Lamb 极限判据）；
* **≤ 10 %**：冰区工程复算容差（ch06 的模型试验/实船对标）；
* **> 15 %**：不可接受，不得以"工程近似"措辞放行。

## 4. 如何复现（三行命令）

```bash
# 1) 重新计算全部章节数值、判据与图，并把结果注入章节 markdown
python examples/ice_tutorial/render.py

# 2) 只校验不写盘（CI 用；有判据不通过时退出码 1）
python examples/ice_tutorial/render.py --check

# 3) 教程自身的门禁测试（判据重算 + 渲染指纹 + 章节结构）
python -m pytest tests/test_ice_tutorial.py -q
```

产物位置：

* `artifacts/tutorial_numbers.json` — 单一证据包（参数表、数据表、判据裁决、渲染指纹）；
* `numbers/chXX.md` — 人可读数值表（章节内嵌的就是它）；
* `figs/fig_chXX_*.png` — 场量/曲线图（matplotlib，160 dpi）。

## 5. 红队自检（章节可独立讲授）

每个章节的开头都有 `## 0. 学习目标` 与 `## 0.1 前置知识`，结尾都有
`## 5. 练习`、`## 6. 参考文献`、`## 7. 复现命令`。也就是说，任何一章都可以
**单独发给一位工程师**，他不读其他章节也能跑出该章的图和数。这条规矩由
`tests/test_ice_tutorial.py::test_chapters_are_self_contained` 检查，而不是靠自觉。

判据的出处检查是硬门禁：`criteria.py` 里每个 `Criterion` 的 `ref_key` 必须命中
`REFS` 字典，构造期即抛异常，不存在"忘了写出处"的路径。

## 6. 本教程不主张什么（诚实边界）

1. **不含冰阻力实现**：Lindqvist/Riska 经验链由 `ship-performance-platform` 的
   `C1-ICE-RESIST` 承担。本教程只教判据与容差，不给"本仓算出的冰阻力"。
2. **不含结构 FEM**：冰带/冰板 FEM 在 `H4-ICE-BELT-FEM` / `H3-ICE-PLATE-FEM` 条目下。
3. **mass loading 无耗散**：因此本仓的冰区波场"不衰减"是模型结论而非数值 bug；
   真实冰区的衰减来自碎冰散射与耗散（Squire 2007），本仓未建模 → `WITHHELD`。
4. **无真实 PC6 型值表**：ch05 的 RAO 证据基于参数化船体，对真实船型的适用性未证。
5. **参考文献题录已核、DOI/页码待核**：本席在离线环境工作，所有条目在 `REFS` 中
   标注 `OFFLINE` 状态；在线核验属于 `ICE-SHOW-KNOWLEDGE-CURATION` 条目。
