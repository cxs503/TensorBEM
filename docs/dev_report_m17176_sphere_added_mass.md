# CASE-BEM-SPHERE-ADDED-MASS 球体附加质量 BEM 算例（m17176）

## ① 问题与 ref 出处

**物理**：半径 R=1 的球体以速度 U=1 在无限域不可压无粘流体中平动（x 向）。
外域 Dirichlet 闭式解 φ = −(1/2)U a³ cosθ / r²（r≥a），边界迹
u = −(1/2)U a cosθ，流体域法向导数 q = −U cosθ。
**目标量**：附加质量 m_A = 0.5·ρ·V = (2/3)πρR³（经典结果）。

**ref 出处（双源，零手抄）**：
1. 教科书：Lamb, *Hydrodynamics*, 6th ed. (1932), §6.10（球体平动：附加质量
   = 排开流体质量之半）；同式见 Milne-Thomson, *Theoretical Hydrodynamics*
   (1968) 球体节。
2. 仓内闭式（本单实际对照值）：`tensorbem.analytic.ellipsoid_added_mass((R,R,R),ρ)`
   —— Lamb(1932) §115 / Newman(1977) eq. 4.132 椭球公式的球极限 α=2/3。
   本单实测输出 2146.754979948129，与 0.5ρV = 2146.754979953025 机器精度一致。

**判据**：|m_A,comp − m_A,ref| / m_A,ref < 3%（任务书容差）。

## ② 方法与实现

- **复用现有能力**（不另起炉灶）：`tensorbem.benchmarks.sphere_added_mass`
  —— 外域 Dirichlet 型 `S q = (½I − H)u`（`tensorbem.solver3d.solve_laplace_surface`，
  常数三角面板 + 质心配点 + c=1/2 + 解析双层立体角 + Duffy 单层求积 + 稠密直接解）。
- 几何：`geometry3d.icosphere` 平面化二十面体；边界值取质心角坐标处的精确迹
  （消除质心内偏的 O(h²) 深度偏差）。
- 附加质量 = 边界能量积分 m_A = (ρ/U²)∮ u·q_comp dS（用计算通量）。
- 网格：sub1=80 / sub2=320 / sub3=1280 / sub4=5120 面板
  （sub3/sub4 重计算递交集群 cj1448，本地 setsid 并行复跑，两路互验）。

## ⑤ 收敛性与参数敏感性（≥2 点）

- **收敛**：4 点（80→5120 面板，面板比 4），
  观测阶 0.95 / 0.98 / 0.99（渐近趋于 1.0）。README 对圆柱/椭球族声明 h²（1.99–2.01），
  并声明球体逐面板通量近一阶；本单球体附加质量积分观测 ~1.0，与通量一阶一致
  （见 ⑥ 讨论）。
- **敏感性 1（线性标度不变性）**：(ρ,U)=(1025,1) 与 (1000,2) 的相对误差
  1.738069e-02 vs 1.738069e-02 —— 完全一致（Laplace 问题线性，
  误差与 ρ、U 标度无关），符合理论预期。
- **敏感性 2（网格单调性）**：误差随面板数单调下降，无平台/发散；
  单层层数 18.6→154.0（O(N) 增长，直接解仍稳）。
