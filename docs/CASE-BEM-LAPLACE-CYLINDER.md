## 1. 案例介绍

半径 $a$ 的圆柱在无界无粘不可压流中以速度 $U$ 沿 $+x$ 均匀来流，复势
$W(z)=U(z+a^2/z)$（$z=x+iy$）。扰动势 $\phi'=\phi-Ux=Ua^2\cos\theta/r$ 在无穷远以 $1/r$ 衰减，
速度 $u-iv=dW/dz=U(1-a^2/z^2)$。物面纯切向，速度 $2U|\sin\theta|$，
压力系数 $Cp=1-4\sin^2\theta$（肩部 $-3$、驻点 $1$，即 d'Alembert 零阻力佯谬）。

几何：正 $N$ 边形内接于 $r=a$ 的圆，$a=1$、$U=1$；面板阶梯 [32, 64, 128]，预算 $N=128$；外部测点 64 个（环 $r/a=[1.25, 1.5, 2.0, 3.0]$，每环 16 方位）。

## 2. 怎么做的

本算例补的是**外部场求值**欠账：旧版 `evaluate_interior_field` 对 `domain != 'interior'` 直接抛错，
BEM 只给边界量、拿不到物体外速度场。本单新增：

- `kernels.integrate_single_layer_panel_gradient` / `integrate_double_layer_panel_gradient`：
  直线常值面板单/双层积分对目标点的**闭式梯度**（速度场不含差分步长）；
- `solver.evaluate_exterior_field`：外部 Green 表示
  $u=\oint G q_e\,ds+\oint u\,\partial G/\partial n_{body}\,ds$ 的势与梯度求值，
  并对「点在体内 / 贴边界」设门（界外表示仍返回有限值，不设门就会静默给错数）；
- `solver.evaluate_exterior_surface_velocity`：物面流体侧速度（法向用解出的 $q_e$，
  切向用边界势的弧长中心差分）。

两条路线共用同一算子：

1. 路线 D（Dirichlet）：解析扰动势 $\phi'$ 加在面板中点 → 第一类外部 Dirichlet 问题 →
   新求值器给出外部测点的 $\phi'$ 与 $\nabla\phi'$，加回 $U\hat x$ 与 $dW/dz$ 比较；
2. 路线 N（Neumann）：解析流体法向导数 $q_e=Ua^2\cos\theta/r^2$（等价于物面无穿透）→
   第二类外部 Neumann 问题 → 物面速度与 $2U|\sin\theta|$ 比较，外部测点比较速度场；
3. 路线 $\Gamma$（给定环量 / 旋转圆柱）：环量由**数据给定**（无 Kutta 条件）。扰动拆成**单值**偶极子 $\phi_d=Ua^2\cos\theta/r$（Neumann 数据 $q_e=\nabla\phi_d\cdot n_e$）与**单位点涡响应**（数据 $q_e=v_{unit}\cdot n_{body}$），各解一次外部 Neumann 问题；
   总速度 $U\hat x+\nabla\phi_d+\Gamma(v_{unit}+\nabla\phi_c)$，再与 Kutta-Joukowski 升力、驻点角、$Cp$ 闭式逐项对照（模块 `tensorbem.lifting_cylinder`）。**实测**：内接多面体的面板中点法向恰为径向、点涡在该点纯切向，故响应数据恒为零（$\sim10^{-16}$，`tests/test_lifting_cylinder.py` 已钉住该零、并在椭圆网格上验证其非零），即圆柱阶梯上环量由解析项承载，BEM 解的是折面体上的偶极子 Neumann 问题。

参考值全部由闭式公式在同一点现算（`hand_typed_numbers = 0`），并以有限差分反查参考自身满足
$\nabla^2\phi'=0$、$\nabla\times v=0$；闭式面板梯度再以势的中心差分反查（`field_gradient_matches_finite_difference`）。

### 远场多极矩（路线 M，本轮新增）

在 $r/a=$ 1.5, 2.5, 4 三个环上采样 BEM 外部势，按 $\cos n\theta,\sin n\theta\ (n\le 4))$ 做最小二乘谐波拟合（`tensorbem.multipole2d`），并用「环均值 vs $\log r$ 的斜率」分离二维源项（单个环无法与常数分离）。

**误差归因（第 3 轮修订）**：把物面两条迹换成解析值（去掉求解误差）后，表示误差本身在 $\delta=0.1h_{{max}}$ 处由 1.757e-01（常值）降到 1.261e-01（线性，改善 1.4×）。但即便如此，贴壁残差仍停在 $\sim10^{-1}$ —— 说明主项两者都不是，而是**折面几何**：内接正多边形面板中点半径 $a\cos(\pi/N)=a(1-h^2/8)$，所以从圆周量起的 $\delta=0.1h_{{max}}$ 相对真实物面是 $(0.1h+h^2/8)/h$，该偏移是 $\delta$ 的 $O(h)$ 倍，正解释上表实测的一阶饱和。把探针距离改为从折面（$a\cos\pi/N$）量起——注意方向：折面在圆周**内**（$a\cos(\pi/N)<a$），所以同一名义 $\delta$ 对应的真实间隙**变小**，误差必须**升高**，而不是收敛。最细网格上误差由 1.261e-01 升到 1.306e-01（1.036×）；折面几何能解释的是**增长率**：单位偏移的放大 0.69 / 0.61 / 0.58 （粗→细）与层无关，而放大本身随 $h$ 单调下降（1.170 / 1.075 / 1.036），即折面偏移是 $O(h)$。原判据写成「改参考面后误差塌缩 3 倍」，方向与几何相反（cj3969 实测 1.04× 反向），已按实测改写。结论：近壁误差预算 = 折面几何（一阶，$\propto h/\delta$）+ 基函数（可被一阶矩项压掉）+ 边界迹求解误差（$O(h^2)$，被 $1/\delta$ 放大）；要再收窄窗口需曲边面板/更高阶求解。

判读二（排除区在中点方向被低估）：$\delta=0.1h_{max}$ 处逐层中点误差 0.198、0.186、0.180，面内最差却达 0.601、0.584、0.577（顶点/中点比 3.03–3.20）。理由：常值密度在顶点处**不连续**，而折面顶点相对真实圆的偏差最直接地投影到该方向。结论：排除区里的「18%」只是最有利方位的数字，贴壁任意方向应按 ~60% 或更大预留误差；守门参数照旧建议 $\ge1$–$2h_{max}$。

## 5. 注意点

- 多面体不是圆：离散体是内接正 $N$ 边形，离散解只能**收敛**到圆柱解；面板中点半径
  $a\cos(\pi/N)$，故物面数据本身带 $O(h^2)$ 偏置，所有误差按实测报告；
- 外部 Neumann 的势只确定到常数，势比较先减去常数（速度不受影响）；
- 单层算子 $S$ 的条件数随加密增长（对数容量退化），本算例 $L=2$、$a=1$ 远离退化点，
  但仍逐级报告 $cond(S)$；第二类算子 $\frac12 I-H$ 条件数 $O(1)$；
- 只在 $r/a\ge 1.25$ 求值：贴壁/体内点必须被守门拒绝；
- 路线 $\Gamma$ 的环量是**给定**的（旋转圆柱），不是解出来的：本算例验证的是「带环量的外部 Neumann 问题 + 压力积分 + 驻点定位」，不验证 Kutta 条件（后者见 `docs/lifting_kutta_closure.md` 与 lifting 家族算例）；
- 圆柱阶梯上点涡响应数据实测恒为零（见 §2 第 3 条），所以本路线的数值部分=折面体偶极子解；不把「升力吻合」读成「环量被 BEM 解出来」；
- 环量须满足 $|\Gamma|<4\pi Ua$ 才有两个物面驻点；超临界时物面无驻点，模块直接拒绝；
- 只验证势流算子链（边界积分、外部场求值、物面速度），无粘性尾流/分离/自由面，
  不能当阻力预报用（$L'=-\rho U\Gamma$ 是理想化结果，真实旋转圆柱有粘性分离与 Magnus 失效）。
