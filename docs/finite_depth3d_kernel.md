## 1. 案例介绍（物理背景）

TensorBEM 的深水三维 Kelvin 核（`free_surface3d.py`）由半空间 Fourier 路线得到：垂直结构 `exp(νz)` 在连续水平波数下对角化，自由面条件塌缩成极点 `k − ν`。一旦加入平底 `z = −h`，垂直结构不再是 `exp(νz)`，`z` 方向谱变成离散的，连续极点被 Bessel 型超越色散关系取代——这正是 `docs/marine_bem_benchmarks.md` 第 8 项标注为「有限水深 John 核待建」的那块。本文件用与二维有限水深模块（`finite_depth.py`）**相同的垂直本征函数路线**补上三维版本，不引入第二种 Havelock 主值积分。

约定与 `free_surface3d` 完全一致：

| 项 | 取值 |
|---|---|
| 坐标系 | `z` 向上，静水面 `z = 0`，平底 `z = −h`，流体域 `−h ≤ z ≤ 0` |
| 时间因子 | `Re{φ·exp(−iωt)}` |
| Rankine 核归一 | `G₀ = 1/(4π·|x−ξ|)`，`−∇²G₀ = δ` （正号，与三维 Laplace 层一致） |
| 波数参数 | `ν = ω²/g > 0` |
| 自由面条件 | `∂G/∂z − νG = 0` at `z = 0` |
| 底面条件 | `∂G/∂z = 0` at `z = −h` |

垂直本征问题（`φ'' = λφ`，`φ'(0) − νφ(0) = 0`，`φ'(−h) = 0`）：

* 传播模态：`φ₀ = cosh(k₀(z+h))`，`k₀·tanh(k₀h) = ν`；
* 衰减模态：`φₙ = cos(μₙ(z+h))`，`μₙ·tan(μₙh) = −ν`，`μₙ ∈ ((n−½)π/h, nπ/h)`。

把垂直 delta 在该完备正交集上展开、逐模态解水平方程，得到轴对称源表示

```text
G(x,ξ) = P₀(z,z₀)·g₀(R) + Σ_{n≥1} Pₙ(z,z₀)·gₙ(R)
Pₘ     = φₘ(z)φₘ(z₀)/Nₘ,     Nₘ = ∫_{−h}^{0} φₘ² dz
g₀(R)  = (i/4)·H₀⁽¹⁾(k₀R)                  （outgoing；incoming 取共轭）
gₙ(R)  = (1/2π)·K₀(μₙR)
R      = hypot(x−ξ, y−η)   （水平距离）
```

系数由 `(−∇_h² − λₘ)gₘ = δ²` 在正 Rankine 归一下确定：传播模态 `λ₀ = +k₀²` 给出 `(+i/4)H₀⁽¹⁾`，衰减模态 `λₙ = −μₙ²` 给出 `(+1/2π)K₀`。

**一个实现层面的要点**：模态和本身**已经包含** `1/(4πr)` 奇性（它是衰减和在 `R→0` 的极限），因此不另加 Rankine 项。API 里 `include_rankine=False` 的语义是**减掉**该奇性，供后续把 Rankine 部分沿面元解析积分的调用方使用。这一点与深水核 `green_function_3d(include_rankine=True/False)` 的语义相反，已在 docstring 与 §5 明确写出（这是本次实现踩到并修正的第一个坑：早期的双重计数让实部整体偏大 0.16，虚部却完全正确）。

工具链：纯 NumPy（`pyproject.toml` 只依赖 numpy）；`K₀, K₁` 自实现，`J₀,J₁,Y₀,Y₁` 复用 `analytic.bessel_j01_y01`。

## 2. 怎么做的（方法与关键设置）

1. **垂直模态求解直接复用二维模块**：`finite_depth.finite_depth_wavenumber`、`finite_depth.evanescent_wavenumbers`，避免第二份色散求根代码（两处实现漂移是常见失效源）。
2. **`K₀, K₁` 三段式**：`x ≤ 2` 上升级数（无相消）；`2 < x ≤ 20` 用积分表示 `K₀(x)=∫₀^∞ e^{−x cosh t}dt` 的 160 点 Gauss–Legendre（原上升级数在此区间因 `−(ln(x/2)+γ)I₀` 与幂级数相消掉 7 位，实测相对误差从 1e-9 退到 1e-9 以下不可接受）；`x > 20` 渐近级数 `e^{−x}√(π/2x)Σ(−1)^k((2k−1)!!)²/(k!(8x)^k)`；`K₁` 在 `x ≤ 20` 由 Wronskian `K₀I₁ + K₁I₀ = 1/x` 给出，`x > 20` 用自身渐近级数。
3. **溢出安全**：`k₀h` 可以任意大，`cosh(k₀(z+h))` 用 `cosh(u)·e^{−s}` 形式求值（`u ≤ s`），`N₀` 同样乘 `e^{−2s}`；否则 `k₀h ≳ 350` 时直接溢出。
4. **模态数规则**：截断误差 ~ `exp(−μₙR)`，故 `modes ≈ h/(πR)·ln(1/tol)`（`suggested_mode_count`），`modes=None` 时自动取实际点对的最小水平间距；上限硬顶 4096。
5. **验证不靠自述**：所有判据先于计算固定——两个边界条件、互易性、解析梯度对中心差分、`k₀h→∞` 对已验证的 Kelvin 核、以及到二维核的降维恒等式。

## 5. 注意点（踩过的坑、适用范围）

1. **模态和已含 Rankine 奇性**：再加一次会让实部整体偏大而虚部严丝合缝——只查模长或只查「看起来对」会漏掉。判据是「虚部（辐射扇区）是否精确」+「k₀h→∞ 是否退化为 Kelvin 核」，两者同时对才排除双重计数。
2. **`K₀` 上升级数的相消**：`x ≳ 2` 后 `−(ln(x/2)+γ)I₀` 与幂级数相消掉大量有效位，`K₀` 相对误差退化到 1e−9 量级，有限差分验证会被放大成 0.8 % 的假故障。改用积分表示的 Gauss–Legendre 后误差 1e−14。**教训：逼近函数的分支切换点必须用「导数」而非只用「函数值」去卡（值一致、导数不一致就意味着分支精度不够）**。
3. **`cosh(k₀(z+h))` 溢出**：`k₀h ≳ 350` 直接 inf；必须写成 `cosh(u)e^{−s}`。
4. **`R = 0` 不支持**：模态和需要 ~`h/(πR)` 量级的模态数，`R→0` 时模态数发散。近场 Rankine 分离是后续工作，当前 API 对 `R = 0` 明确抛错而不是给出静默的错数。
5. **模态数不是常数**：它是几何（`h/R`）与容差的函数；写成固定 64 会在细网格上悄悄掉精度。
6. **本文件的「深水极限对照」不能当作有限水深精度证据**：`k₀h` 小时有限水深与无限水深本来就不同，那是物理差异。真正的物理基准需要波体解（见 §6）。

## 6. 局限与未完成（honest）

* **只有核，没有波体求解器**：没有把该核接进 `free_surface_solver3d` 式的常值面元（三角形）装配，因此**没有任何有限水深波体物理基准**（如 Garrett 1971 有限水深截断圆柱的附加质量/阻尼）。本文件所有判据都是核的自洽/极限/恒等式类验证，不含文献数值对表。
* **传播扇区的降维恒等式只给闭式、未进测试**：`∫H₀⁽¹⁾dy` 的尾部振荡衰减为 `1/√(kY)`，梯形求积误差 ~10 %（Y=60 实测），故只有衰减扇区（指数衰减，1e−15）进了机器判据，传播扇区在文中以经典 Hankel/Fourier–Bessel 对的身份引用。
* **未做与二维有限水深核的逐点数值对表**：降维恒等式在核的基函数层验证（§3.5），完整的 `−∫G_3D dy = G_2D` 数值对照受上述振荡尾部限制，留待后续用解析尾部修正后再做。
* **只处理轴对称源的水平平移不变性**：本表示依赖水平各向同性（源与场点的水平距离 `R` 单一变量），这对自由面 + 平底问题成立，但不适用于带侧壁/局部变深的情形。
