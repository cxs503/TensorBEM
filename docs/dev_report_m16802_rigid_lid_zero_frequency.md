# 3D 自由面辐射求解器的零频（刚盖）端点锚：精确基准尚未闭合（honest FAIL）

**结论先行**：浮半球升沉附加质量的 `ka->0` 极限是**精确可算**的（刚盖=镜像整球 => `A33(0)=2/3 rho pi a^3`），此前仓内只用「低频 A33 走平」定性控制（anchor C6，仅扁平度不验量级）。本单补上该精确锚并把两个端点一起钉住，结果是**不通过**：256 面板下 `ka=0.1` 处 A33 比精确刚盖值低 **14.4%**，中频段 `ka=2` 掉到 `0.380 rho∇`，低于 `ka->inf` 精确下界 `0.5 rho∇` 达 **24%**。

## ① 案例介绍
半潜浮半球（半径 a=1.0 m，rho=1025 kg/m³，g=9.80665 m/s²，排水质量 rho∇=2146.7550 kg）。两条精确极限：
- `ka->0`（刚盖，∂φ/∂z=0）：半球升沉等价于镜像整球平动 => `A33=2/3 rho pi a^3=2146.7550 kg`（= rho∇）
- `ka->inf`（压力释放 φ=0）：`A33=rho pi a^3/3=1073.3775 kg`（= 0.5 rho∇，仓内 anchor A2）

两点构成**精确包络**（相差 2 倍），不依赖任何文献常量。

## ② 怎么做的
新增驱动 `src/tensorbem/benchmarks/rigid_lid_zero_frequency_anchor.py`（只调 `solve_radiation_3d`，不改进求解器）；网格阶梯 subdivisions=(2,3) => 64/256 面板；`ka` 扫描 0.1→6.0 共 9 点；输出 `results.json` + 程序化生成的 `summary.md` + 图，全部由同一 payload 生成（零手抄）。测试 `tests/test_rigid_lid_zero_frequency_anchor.py`（6 项）从原始行**重算**每条判据，并现场重解一个 ka 点，防止工件与代码漂移。

## ⑤ 注意点
- 低频偏差**随网格加密收窄**（64→256 面板最低 ka 处变化 2.32%），故主要是离散误差，但未做 Richardson 极限（subdivisions=4=1024 面板扫描在本班次墙钟内未跑完，如实记录）。
- 仓内既有 anchor C6（barge）只断言「A33 走平」与「B33/(ωA33)→0」，**扁平度不等于量级**，因此该端点误差长期不可见——这是本次发现的机制性盲区。
- `ka=2` 低于精确下界说明中频段同样有 >20% 量级风险：凡是引用 3D 自由面 A33 的结论（含 Wigley III 系列）都应标注网格证据等级。
