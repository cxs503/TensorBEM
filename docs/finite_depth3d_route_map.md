## 1. What question this answers

`docs/finite_depth3d_deepwater_arbitration.md` closes its erratum with an honest
limit: it does not add an independent evaluation of the finite-depth kernel.  Two
independent representations of that kernel do ship in the package -- the John
eigenseries (`tensorbem.finite_depth3d`, which finds the propagating and every
evanescent root and normalises each mode analytically) and the
wavenumber-quadrature route (`tensorbem.finite_depth3d_quadrature`, which uses no
evanescent root finder and no mode norm at all).  m13811 compared them at a
single depth and frequency.  This page publishes the map over
`(k0 h, z/h, k0 R)` so the *regions* where they stop agreeing are known instead
of assumed, plus the two limits a map cannot show: which route owns a residual
(the panel-rule ladder) and where the deep-water limit actually is.

## 2. Design, and why the naive deep-limit is wrong

`k0 = 1` is pinned throughout, so `depth = k0 h = X` forces `nu = tanh(X)` and
every length is in wavelengths/2pi.  Field elevations run from just below the
free surface (`-0.02 h`) to just above the sea bed (`-0.98 h`), ranges `k0 R` of
0.5 and 2, source at mid-depth.

The deep-water ladder is taken at **fixed absolute elevations**, not at fixed
`z/h`.  At fixed `z/h` the sea bed approaches the points as `h` grows, so the
bottom image stays at a finite distance and the true limit is never measured:
that construct reports a relative difference of 0.77 at `k0 h = 77`,
`z/h = -0.98`, which is physics (the image), not a kernel defect.  Holding the
elevations fixed instead gives the clean decay published below.

## 4. Honest limits

* `k0 = 1` is shared input: the propagating root is pinned by construction, so
  the *propagating* wavenumber is not independent evidence here.  What is
  independent is every evanescent root, every mode norm, the Bessel/Hankel
  evaluation and the vertical mode factors.
* Both routes satisfy the same free-surface and sea-bed conditions by
  construction, so this is a two-route arbitration, not a comparison with
  experiment.  No experimental finite-depth kernel table ships with this
  repository, and none is invented here.
* The near-bed cell at `k0 h = 1`, `z/h = -0.98` is the one cell where refining
  the quadrature rule does *not* help monotonically (3.4e-11 at nodes 32, 7.9e-9
  at nodes 48): the integrand is dominated by the near-bottom reflection there,
  and the published map uses a single rule for all cells.  Recorded, not hidden.
