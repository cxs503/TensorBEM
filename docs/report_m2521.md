## ② 怎么做的

### 方法概述

TensorBEM 采用 Rankine 边界元法（BEM）求解三维势流问题：
- **几何离散**：平板中心面单元（flat centreplane panels），余弦聚类网格（cosine-clustered grid）
- **积分核**：自由面 Green 函数，λ 积分截断 + 尾部外推
- **求解器**：直接法求解线性方程组 $A x = b$，其中 A 为影响系数矩阵

### 关键设置

| 参数 | 值 | 说明 |
|------|-----|------|
| 面板聚类 | cosine-clustered (ψ, φ) | 前缘加密 |
| 每面板积分 | 2×2 Gauss | 二阶精度 |
| λ 截断 | λ_max=40.0 | 兴波积分上限 |
| 尾部处理 | 外推（theta 形式） | 低频阻尼补偿 |
| 有限水深 | 自由面-海底双层 Green 函数 | 解析深度修正 |

### 工具链

- Python 3.11.6 / NumPy 2.0.1
- 验证脚本：`benchmarks/case_cylinder_stream.py`, `benchmarks/verified/bem_finite_depth/` 下的 stage 脚本
- 数据格式：JSON（`results.json` / `result.json`）
