# BEM-HULME-HEMISPHERE：阶梯的"环境"到底是什么（第 2 轮，测量工具与门禁）

**锚点**：CASE-BEM-HULME-HEMISPHERE（Hulme 浮半球，ka=2，容差 <5%）。**状态：测量中（honest partial）**。

## ① 问题与它为什么必须重做

上一轮（m21674，`docs/case_bem_hulme_inhouse_ladder_env_dependence.md`）给出两条阻断级结论：

1. **规模断裂**：4096 面元档 A33/B33 相对参考偏 46.5% / 54.2%，"不是收敛方向"；
2. **numpy 版本漂移**：同一网格（`condition_number` 逐位相同 2.398615400620687）在 numpy 2.4.6 与 2.0.1 上 B33 差 2.05×。

两条结论都建立在同一个未被记录的假设上：被比较的两档由**同一份代码**算出。实际情况是：

| 事实 | 证据 |
|---|---|
| 节点档写于 2026-11-14，行内无 `radiation_relative_residual` | `inhouse_ladder_ka2_rung4_node.json`、`_rung5.json` |
| 记录 solve 残差/稳定性的硬化（m21143）合并于 2026-11-15 | `git log -S _STATIONARITY_TOL` |
| 阶梯工件此前**没有任何字段记录代码版本** | `inhouse_ladder_ka2.json` 的 `provenance` 只有 host |
| 4096 档只在节点上跑过（cj2750），控制面无同网格对照 | 工件 provenance：rows [5] 来自 node330 |

也就是说：4096 档是"另一个执行环境里的唯一一次测量"，把它接在控制面的 64/256/1024 档后面读成"收敛阶梯的第 4 档"是一个**未受控的跨环境比较**，这条既可能被环境效应解释，也可能是真实的规模断裂——工件里没有能把二者分开的对照。

## ② 本轮做了什么（工具 + 门禁，不含结论）

1. **`scripts/hulme_numpy_drift_probe.py`（新增）**：把一次格子计算拆成可逐位比较的阶段指纹——几何、核函数表（Bessel/Struve/Ei、Gauss-Legendre/Laguerre 节点、`wave_function_3d` 在固定网格上的值）、装配算子（`single_layer`/`chief`/`system_matrix`/RHS）、解与后处理系数；并额外给出**解侧敏感性**：同一系统用"实嵌入"驱动（`dgelss` 而非 `zgelss`）重解，以及在 RHS 上加 1e-13 相对扰动后 A33/B33 的散布。**这是把"装配漂移"与"求解漂移"分开的那把尺**：若 1e-13 扰动的散布比观测到的跨机差小几个量级，跨机差就不可能是求解舍入。
2. **阶梯行记录代码版本**（`scripts/hulme_hemisphere_inhouse_ladder.py`）：每行新增 `revision`（commit sha），文件级 `environment.revision = {commit, dirty}`。"同一份代码"从此可审计。
3. **跨环境复算 = 对照**（`merge_ladders`）：同一面板数出现两次时，若数值环境（numpy 版本 / 代码版本）不同，第二次不再报错而是记为 `replicates`（同离散度的跨环境对照，**不是**又一级阶梯）；同一环境下重复的同一档仍然报错。
4. **E10 门禁**（`tensorbem.benchmarks.hemisphere_independent_convergence`）：阶梯"形状"（E7/E9/E8）只有在数值环境**同质**、或混合但**重叠档位已复算且一致到 1e-6** 时才可读。判据写在证据 JSON 里；本轮对已提交工件的裁定是 **FAIL**（`numpy`/`revision` 未知的档 3 个，重叠档 0 个，`reason` 字段写明）。

## ④ 为什么这仍然是一个该合并的改动

因为它把"上一轮的结论"从**断言**变成了**可判定的命题**：现在任何人拿到一台 numpy 2.0.1 的机器，跑
`python scripts/hulme_numpy_drift_probe.py --subdivisions 3 4`，就能用阶段指纹指出漂移发生在装配还是求解；再跑
`python scripts/hulme_hemisphere_inhouse_ladder.py --subdivisions 4 5`，合并后 E10 会自动判断"这个混合阶梯能不能当阶梯读"。若 1024 档在节点上复现控制面的 0.38634/0.10425 到 1e-12，则"numpy 版本漂移"被否定，真正的缺陷是 m21143 之前的**未审计复解**；若不复现，则本工具的指纹直接给出漂移所在阶段。

## ⑤ 注意点与局限

- 本轮的作业（cj4754 / cj4760）在提交时仍在排队（队列 140+），因此**跨环境测量尚未落盘**；本文不给出任何跨环境结论。
- 4096 档在节点上单档约 650 s（1 BLAS 线程），控制面受"<10 min"策略限制无法本地重跑，这是"4096 只有在节点跑过"的结构性原因，短期内不会消失。
- 1e-6 的"环境一致"带宽是**回归级**带宽（比 float64 舍入高 9 个量级，比物理容差 5% 低 4 个量级）；它检验的是"同一份算术"，不是"同一个物理"。
- 阶段指纹用 SHA-256 比较，任何一位不同即报告不同；它不告诉你"差多少"，差多少由 `wave_function_F_probe` 等数值探针给出。

## ⑥ 误差判定（是否 < 3%）

- 本轮**没有新的物理量误差可判定**：可判定的对象是"同一格子在不同环境/驱动下的一致性"，其量纲是相对差，不是对参考解的误差。
- 已测得的一致性：同格 RHS 1e-13 扰动 → 8.2e-14；实/复驱动 → 1.2e-15 → **远小于 3% ✅**。
- 跨环境一致性：**未测**（作业排队中），因此**不能回答是否 <3%**，本文按 honest-FAIL 记录为未完成项。
