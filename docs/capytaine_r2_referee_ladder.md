# capytaine 自身网格收敛（nu = 2 m^-1，裁判侧独立测量）

锚点 `XVAL-BEM-R2-OSS-CROSSVAL-CAPYTAINE` 的内部对角带（5%）在短波端（nu = 2 m^-1）未达标。
此前把该偏差默认读作 TensorBEM 的离散误差，前提是裁判（capytaine）比被告更接近连续极限。
本文件在同一频率上单独加密裁判网格，**不重解 TensorBEM**，测量裁判自身在锚点密度上的移动量。

## 预登记判据

- 指标：关键对角项在裁判两层最细网格之间的相对变化 `|f_n - f_(n-1)| / |f_n|`；
- 阈值：`1%`（`CONVERGENCE_TOL`，在看数之前登记）；
- C1（渐近）：最细两层之间的变化 ≤ 阈值 —— 裁判在这条阶梯上**是否**已经收敛；
- C2（锚点密度）：锚点自己的网格与最细网格之间的变化 ≤ 阈值 —— 锚点用的那个裁判数能否当连续极限读。
- 任一项超过阈值即判裁判**未收敛**，此时锚点的 5 % 带不能被当作 TensorBEM 的对错判决。

## 判定

- **C1**（各算例最细两层）：最大变化 1.08%（sphere_r1_z-0.5 A[2,2] damping），阈值 1% → **不满足**。
- **C2**（锚点自身网格 vs 各算例最细网格）：最大变化 4.69%，阈值 1% → **不满足**。

- 锚点密度处超带的 3 项中，换成最细裁判后有 3 项回到带内：hemisphere_r1 A[2,2] damping: +5.82% -> +3.02%；sphere_r1_z-0.5 A[0,0] added_mass: -6.49% -> -2.14%；sphere_r1_z-0.5 A[1,1] added_mass: -6.52% -> -2.18%。
- 总判定：**NOT_CONVERGED** —— 裁判在锚点密度上仍在移动，锚点的 5% 对角带对这一密度不构成 TensorBEM 的对错判决。

## 注意点

1. 本文件只测裁判侧的移动量，**不**证明 TensorBEM 正确；两侧同时加密才是判决实验。
2. 阶梯只有 4 层、单一频率（nu = 2 m^-1），不外推到其它频率。
3. capytaine 的网格族是 (n_theta, n_phi) 经纬网格，与 TensorBEM 的 icosphere 不同族；两条阶梯的收敛速率不可直接比较，只能各自读趋势。
