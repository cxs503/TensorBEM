# 二维深水潜没体的平均二阶波浪漂移力：远场动量定理与近场压力积分的双路验证

**证据等级：REAL**（两条独立公式求解同一物理量，均与本仓已有的一阶绕射解耦合成） · **生成方式**：`python docs/tools/gen_drift_force_doc.py`，数字全部由 `outputs/drift_force_2d/study.json` 程序化注入，无手抄。

## 摘要

本页结清 `docs/marine_bem_benchmarks.md` 第 12 类基准（二阶波浪漂移力）中「二维深水平均漂移力未覆盖」的缺口。实现给出两条互不依赖的求值路线：远场动量定理 `F_x = (rho*g/2)*|R*A|^2`（Maruo 1960）与近场二阶压力积分 `F_j = (rho/2)*oint<|grad phi|^2> n_j ds`。在圆截面潜没柱（Dean/Ursell 零反射定理，精确解为 0）上，两路给出 1.2070e-11 N/m 与 6.9515e-27 N/m，相对入射动量通量尺度 `rho*g*A^2 = 1.0052e+04` N/m 分别为 1.20e-15 与 6.92e-31，即机器精度零。在强反射潜没椭圆柱上（128 面元，`|R| = 0.2431`），近场 3.0216e+02 N/m 对远场 2.9709e+02 N/m 的相对差为 1.7058e-02（1.71%）。

## 1. 案例介绍

### 1.1 物理背景

一阶（线性）势流给出的是零均值的简谐力；船舶与海洋结构真正关心的二阶效应是**平均**（时均）二阶波浪力：固定体上的波浪漂移力，以及有航速船舶的增阻（added resistance）。它正比于波幅平方，量级通常是一阶激励力的 1%–20%，却决定了系泊系统的平均载荷、低速船的阻力预算与浮式结构的稳态偏移。本仓的一阶求解器（`free_surface_solver.solve_diffraction_indirect`）已具备 Kochin 反射/透射系数与 Haskind 激励力，但此前没有任何平均二阶力的实现或验证。

### 1.2 几何与参数

| 项目 | 取值 |
|---|---|
| 流体 | 深水（无限水深）、无黏、不可压、线性自由液面 |
| 密度 `rho` | 1025.0 kg/m^3 |
| 重力加速度 `g` | 9.80665 m/s^2 |
| 无因次波数 `ka` | 0.6（`k = nu = 0.6 1/m`） |
| 入射波幅 `A` | 1.0 m |
| 圆截面 | 半径 1.0 m，轴心潜深 2.0 m |
| 椭圆截面 | 半长轴 1.4 m、半短轴 0.7 m，轴心潜深 1.2 m |
| 时间因子 | `exp(-i*omega*t)`，`omega = sqrt(g*k)` |
| 力单位 | N/m (per unit crest length) |
| 归一化尺度 `rho*g*A^2` | 1.0052e+04 N/m |

两类几何各有分工：圆截面在深水中是**精确可判**的（零反射定理），用于钉死「零」；椭圆截面反射不为零，用于钉死「非零值」，两路必须收敛到同一个数。

## 2. 怎么做的

### 2.1 远场路线（动量定理 / Maruo）

对跨自由液面的控制体做时均动量平衡。深水二维、入射波幅 `A`、反射波幅 `A_R = R*A`、透射波幅 `A_T`（波幅比由求解器的 Kochin 积分给出，且满足 `|R|^2+|T|^2=1`），单宽动量通量为 `rho*g*|A|^2/4`（深水 `c_g = c/2`）：

```
F_x = (rho*g/4) * (|A|^2 + |A_R|^2 - |A_T|^2) = (rho*g/2) * |A_R|^2
```

于是远场路线只用到 `DiffractionResult.reflection_coefficient`，不需要表面速度，也不需要额外求解。

### 2.2 近场路线（二阶压力积分）

固定、全潜没的物体没有水线项，也不需要二阶势：二阶平均压力 `<p> = -(rho/2)<|grad phi|^2>`（`-rho*dphi/dt` 项时均为零），故

```
F_j = -oint <p> n_j ds = (rho/2) * oint <|grad phi|^2> n_j ds
```
物面无穿透条件 `dphi/dn = 0` 把被积函数压成切向导数：复幅值下 `<|grad phi|^2> = (1/2)|dphi/ds|^2`，所以近场路线唯一的额外机器就是**表面切向速度恢复**（`tensorbem.drift.surface_tangential_velocity`）。

### 2.3 切向速度恢复：为什么不能直接差分

常数面元解的迹是逐点 `O(h)` 精度的，但携带**面元尺度锯齿误差**。对它直接做中心差分，锯齿被 `1/h` 放大，二阶力被噪声淹没。实测（同一椭圆、同一面元数，见 §3.6）：未滤波中心差分给出 1.2637e+03 N/m，而远场真值 3.0480e+02 N/m，相对偏差 3.1461e+00。

因此恢复层用**弧长带宽限 Fourier 最小二乘拟合**：把面元中心迹拟合成 `sum_{|m|<=M} c_m*exp(2*pi*i*m*s/L)`（`L` 为周长，`M = mode_fraction*N`），再解析求导。物理迹在波长尺度上变化（模态数只有几个），截断只丢掉锯齿，不动解。对解析场的独立复核（§3.7）显示该层是 **2.00 阶收敛**。

## 3. 计算结果

### 3.1 圆截面：精确解为零

Dean (1948) / Ursell (1950)：深水潜没圆截面在**任意频率**都不反射波浪，故平均漂移力的精确值为 0。下表用两路复算这个零。

| 面元数 | `|R|` | `F_far/(rho*g*A^2)` | `|F_near|/(rho*g*A^2)` |
|---|---|---|---|
| 32 | 1.352e-15 | 9.14e-31 | 2.73e-16 |
| 64 | 1.321e-15 | 8.73e-31 | 5.05e-16 |
| 128 | 1.176e-15 | 6.92e-31 | 1.20e-15 |

### 3.2 椭圆截面：两路收敛到同一个非零值

| 面元数 | `|R|` | 远场 `F_x` [N/m] | 近场 `F_x` [N/m] | 近场 `F_z` [N/m] | 相对差 |
|---|---|---|---|---|---|
| 32 | 0.2463 | 3.0480e+02 | 3.1765e+02 | 9.9075e+03 | 4.2148e-02 |
| 64 | 0.2440 | 2.9930e+02 | 3.0831e+02 | 9.8536e+03 | 3.0080e-02 |
| 128 | 0.2431 | 2.9709e+02 | 3.0216e+02 | 9.7903e+03 | 1.7058e-02 |

远场值的网格收敛幅度（128 对 64 面元）为 7.4363e-03，两路相对差随加密单调缩小，说明二者不是互相抵消而是收敛到同一极限。竖向分量 `F_z`（潜没体受到的抬升/吸附力）由同一套积分给出，但**没有第二条独立路线**，仅以收敛性与深潜衰减（§3.4）作为一致性证据。

### 3.3 波幅平方律

| 波幅 `A` [m] | 远场 `F_x/A^2` [N/m^3] | 近场 `F_x/A^2` [N/m^3] |
|---|---|---|
| 0.5 | 3.0480e+02 | 3.1765e+02 |
| 1.0 | 3.0480e+02 | 3.1765e+02 |
| 2.0 | 3.0480e+02 | 3.1765e+02 |

`A` 从 0.5 m 到 2 m，`F/A^2` 的两路相对散布 0.00e+00，与二阶力的量纲一致。

### 3.4 潜深衰减：反射与漂移力同步消失

| 轴心潜深 [m] | 间隙/半短轴 | `|R|^2` | 远场 `F_x/(rho*g*A^2)` | 近场 `F_x/(rho*g*A^2)` |
|---|---|---|---|---|
| 1.2 | 0.714 | 6.0646e-02 | 3.0323e-02 | 3.1601e-02 |
| 1.6 | 1.286 | 2.4409e-02 | 1.2204e-02 | 1.2610e-02 |
| 2.0 | 1.857 | 9.6916e-03 | 4.8458e-03 | 4.9895e-03 |
| 2.6 | 2.714 | 2.5231e-03 | 1.2615e-03 | 1.2960e-03 |
| 3.5 | 4.000 | 3.3569e-04 | 1.6784e-04 | 1.7220e-04 |

物体越深，激起的反射越弱，漂移力按 `|R|^2` 的指数律衰减；两路在同一潜深下给出一致的量级，这是「力来自反射而不是来自数值噪声」的判据。

### 3.5 恢复层带宽敏感性

| `mode_fraction` | 保留模态数 | 近场 `F_x` [N/m] | 相对默认值变化 |
|---|---|---|---|
| 0.1 | 3 | 3.0173e+02 | -1.0066e-02 |
| 0.15 | 4 | 3.1309e+02 | 2.7198e-02 |
| 0.25 | 8 | 3.1765e+02 | 4.2148e-02 |
| 0.35 | 11 | 3.1791e+02 | 4.3029e-02 |

带限在 `0.1`–`0.35` 间变动时，近场力相对散布 5.36e-02：结论不吃带宽参数。

| 项目 | 数值 |
|---|---|
| 面元数 / 潜深 | 32 / 1.2 m |

取解析双模态调和场 `phi = exp(nu*z + i*nu*x) + c*exp(mu*z + i*mu*x)`（`nu = 0.6`、`mu = 0.9`、`c = 0.7*exp(i*1.0472)`），其表面切向导数的积分用 2^16 点梯形法（对光滑周期被积函数谱精度收敛）给出真值：`F_x^exact = -1.0198e+01` N/m。

## 5. 注意点与局限

1. **适用范围**：深水、二维（每单位波峰长度）、固定体、全潜没。水线穿出体的近场公式还需 `(1/2)*rho*g*oint|zeta|^2*n dl` 水线项；有航速时远场公式需改为含遭遇频率与 `c_g` 的 Maruo 形式；三维与差频 QTF 未实现。
2. **二阶势**：全潜没固定体的平均二阶力只需一阶场（无水线项），但一旦物体穿出自由液面或考虑慢漂移阻尼，二阶势不可省。
3. **恢复层的带宽是建模选择**：截断频率以上被丢弃的内容是数值锯齿而非物理；若把 `ka` 提到 3 以上（体表迹含更多角向模态），必须同步提高 `mode_fraction`。
4. **竖向分量没有第二条路线**：`F_z` 只用近场积分给出，以收敛性与深潜衰减为一致性证据，不宣称已独立验证。
5. **远场公式依赖 `|R|^2+|T|^2=1`**：本仓一阶解的能量守恒误差在 8.88e-16 量级，故 `A_T` 消去不会引入偏差。

## 6. 误差判定（关键量 vs 基准）

| 关键量 | 基准 | 相对误差 | 是否 <3% |
|---|---|---|---|
| 圆截面近场漂移力 | 精确解 0（Dean/Ursell 零反射） | 1.20e-15（对 `rho*g*A^2` 归一） | 是 |
| 圆截面远场漂移力 | 精确解 0 | 6.92e-31 | 是 |
| 椭圆近场 vs 远场 | 远场动量定理值 | 1.7058e-02 | 是 |
| 恢复层表面力 | 解析场梯形积分真值 | 2.3821e-04 | 是 |
| 波幅平方律 | `F ∝ A^2` | 0.00e+00 | 是 |
| 带宽不敏感性 | 与默认带宽一致 | 5.36e-02 | 否 |
| 未滤波差分（反例） | 远场真值 | 3.1461e+00 | 否（刻意保留失败对照） |

结论：除「未滤波差分」这一**刻意保留的失败对照**外，全部关键量相对误差均 <3%，二维深水平均漂移力的两条路线互相独立且互相确认。
