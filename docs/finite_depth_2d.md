# 二维有限水深自由面 Green 函数（`tensorbem.finite_depth`）

**状态**：新增模块 + 14 条验证测试 + 数值基准工件。**未做**：把该核接入边界元求解器做端到端
辐射/绕射算例（见 §7 局限）。

## 1. 为什么需要独立的核

`tensorbem.free_surface` 的深水核是对 x 方向做 Fourier 变换得到的：竖向结构 `exp(k z)` 在
`z -> -inf` 衰减，使变换对角化，自由面条件退化成分母 `k - nu`，结果是主值积分 + 留数。

一旦加了平底 `z = -h`，这条路失效：竖向结构不再是 `exp(k z)`，z 方向谱变成**离散**的，连续
`k` 的分母 `k - nu` 被超越方程 `k0 tanh(k0 h) = nu` 取代。正确的表示是**竖向本征函数展开**，
不是积分。因此这不是"给深水核加个参数"，而是另一个核。

## 2. 推导

约定：z 向上，静水面 `z = 0`，底 `z = -h`，时间因子 `exp(-i omega t)`，
`nu = omega^2 / g`。竖向本征值问题

```
phi'' = lambda phi,   phi'(0) - nu phi(0) = 0,   phi'(-h) = 0
```

有一个正本征值（传播模）与可数个负本征值（耗散模）：

| 模 | 形状 | 本征值关系 | 模方 `N = ∫_{-h}^{0} phi^2 dz` |
|---|---|---|---|
| 传播模 n=0 | `cosh(k0 (z+h))` | `k0 tanh(k0 h) = nu` | `(h/2)(1 + sinh(2 k0 h)/(2 k0 h))` |
| 耗散模 n≥1 | `cos(mu_n (z+h))` | `mu_n tan(mu_n h) = -nu`，`mu_n ∈ ((n-1/2)π/h, nπ/h)` | `(h/2)(1 + sin(2 mu_n h)/(2 mu_n h))` |

把 delta 函数在这组完备正交基上展开，再逐个解一维水平问题
（`-(g_n'' + lambda_n g_n) = delta(X)`），得

```
G(X, z, z0) = -i/(2 k0) * phi0(z) phi0(z0)/N0 * exp(i k0 |X|)
              - sum_{n>=1} (1/(2 mu_n)) * phi_n(z) phi_n(z0)/N_n * exp(-mu_n |X|)
```

第一项是外行波：二维线源辐射的波**不衰减**（这就是二维问题里 `G` 的量纲可选、辐射问题必须
用间接提法的原因，见 `free_surface_solver` 的模块注释）。第二项是耗散场，其 `X -> 0, z -> z0`
的极限携带对数奇点。

**符号约定不是选的**：要求 `k0 h -> inf` 时逐点复现
`tensorbem.free_surface.green_function`（对数部分与外行波部分同时），符号被这一条锁死。
该极限是一条测试（下表 §5.2），不是假设。

## 3. 求和：Kummer 加速

耗散项按 `sum 1/n` 收敛，不能截断。`n -> inf` 时 `mu_n -> nπ/h`、`N_n -> h/2`、
`phi_n(z)phi_n(z0)/N_n -> (2/h) cos(n a) cos(n b)`（`a = π(z+h)/h`，`b = π(z0+h)/h`），于是

```
sum_{n>=1} a_n = sum_{n=1}^{N} (a_n - b_n) + sum_{n>=1} b_n,
b_n = cos(n a) cos(n b) / (n π) * exp(-n s),   s = π|X|/h
```

第二项有闭式：

```
sum_{n>=1} b_n = (1/(2π)) [L(a-b) + L(a+b)],   L(g) = -log(1 - 2 e^{-s} cos g + e^{-2s})/2
```

即 `L` 本身**就是**对数奇点，被解析地提出。梯度用同样的加速，但闭式换成几何和

```
sum r^n cos(n g) = (r cos g - r^2)/(1 - 2 r cos g + r^2),   sum r^n sin(n g) = r sin g / (1 - 2 r cos g + r^2)
```

**坑（已修）**：`cos(n a) cos(n b)` 在模指标 n 上**振荡**，不能把 `cos a cos b` 提出来当作常数
系数（第一版就是这么写的，耗散项错了 10 倍，而且在深水极限里表现为"虚部对、实部全错"）。
闭式尾项与逐项振荡形式的一致性靠积化和差
`cos(n a)cos(n b) = [cos n(a-b) + cos(n(a+b))]/2` 保证。

模数默认 `max(256, 24*nu*h)`：`nu*h` 越大算术根越挤（`mu_n -> nπ/h`），模态和就越接近连续
积分，收敛越慢。实测 `nu*h = 8` 需 512 模、`nu*h = 400` 需 8192 模。

## 4. 波运动学

```
c = omega / k0,   c_g = (c/2)(1 + 2 k0 h / sinh(2 k0 h))
```

`c_g` 是有限水深能量关系需要的因子：辐射功率 `= 0.5 rho g |a_w|^2 c_g`（单位波峰长）。
`k0 h -> inf` 时 `c_g -> c/2`，`k0 h -> 0` 时 `c_g -> c`。

## 5. 验证（判据先于结论）

测试文件 `tests/test_finite_depth.py`（14 条，全绿）。四条互相独立的性质把核**唯一**钉死：
解满足 strip 的 PDE + 两个边界条件 + 外行辐射条件 + 正确强度的奇点，Green 函数唯一。

### 5.1 波运动学

| 判据 | 实测 | 判据门限 |
|---|---|---|
| `k0 tanh(k0 h) = nu` 残差（多组 nu、h） | `< 1e-12` 相对 | 1e-12 |
| `c_g` 解析 vs `d(omega)/dk` 中心差分 | `6.6e-11` 相对 | 1e-8 |
| 浅水极限 `k0 ≈ sqrt(nu/h)`（h=1e-3） | `8.3e-5` | 1e-3 |
| 深水极限 `c_g/c -> 0.5` | 见下表 h=400 | 1e-8 |

### 5.2 深水极限 = 独立代码路径

与 `tensorbem.free_surface`（Ursell 多重极解已校准的深水核）逐点比较，`nu = 0.5`：

| `h` | `nu h` | `G` 最大相对偏差 | `∇G` 最大相对偏差 |
|---|---|---|---|
| 3 | 1.5 | 3.44e-01 | 4.09e-01 |
| 10 | 5 | 1.27e-02 | 1.61e-02 |
| 50 | 25 | 3.53e-04 | 5.99e-04 |
| 200 | 100 | 2.07e-05 | 3.54e-05 |
| 800 | 400 | **1.28e-06** | **2.18e-06** |

这是本模块最硬的一条：极限由**另一条完全不同的数值路径**（主值积分 + 留数）给出，没有可调
常数，实部与虚部同时吻合。

### 5.3 边界条件残差

| `h` | 自由面 `∂G/∂z - nu G`（相对） | 底面 `∂G/∂z`（相对） |
|---|---|---|
| 1.0 | 2.11e-06 | 6.91e-07 |
| 3.0 | 1.85e-06 | 1.54e-07 |
| 16.0 | 1.66e-06 | 1.01e-08 |

残差由单侧差分步长（1e-6）主导，不是核的误差；`z < -h` 的模态级数不外推（外推是无意义的）。

### 5.4 奇点强度

围绕源点半径 1e-3 的圆周上 `∮ ∇G · n ds = 1.000`（平台约定 `G ~ log r /(2 pi)`），误差 `< 5e-3`。

### 5.5 加速收敛性

`(x, z, z0) = (0.05, -0.7, -1.4)`，参考解取 16384 模：

| `h` | 64 模 | 256 模 | 1024 模 | 4096 模 |
|---|---|---|---|---|
| 3 | 3.4e-13 | 3.4e-13 | 0 | 0 |
| 16 | 1.2e-06 | 1.2e-06 | 1.5e-11 | 0 |

## 7. 局限（诚实清单）

1. **未接入 BEM 求解器**。`free_surface_solver` 的组装只耦合了深水核；本次只交付核 + 核级验证，
   没有做有限水深圆柱辐射/绕射的端到端算例。端到端需要：把 `_free_surface_only_normal_derivative`
   与 `_evaluate_source_potential` 的平滑余项换成有限水深版本，并用 `c_g` 归一化远场阻尼。
   这是 Roadmap 6「有限水深」的下一步。
2. **无实验/文献数值基准**。本节所有基准都是"解析一致性"（极限、边界条件、奇点、唯一性），
   不是实测数据。因此**不能**宣称本模块对任何水动力系数的精度（那要端到端算例才能说）。
3. **精度随 `nu h` 退化**：`nu h = 400` 处模态和的地板约 1e-6（最坏点 2e-5）。该区间本来就
   该用深水核（对 h 是闭式）。默认模数按 `24 nu h` 自适应，代价是 O(modes) 的存储，深水区
   不经济——文档已写明，不是隐藏行为。
4. 只支持常水深、无流、线性势流；不变水深/地形起伏需要别的核（BEM 外挂自由面网格）。

## 8. 与生态的关系

`ship-performance-platform` 的耐波/水动力模块在浅水航道、港口、内河船场景需要有限水深修正；
本核是那条路径的第一步。深水（`nu h > 100`）应继续用现有深水核。
