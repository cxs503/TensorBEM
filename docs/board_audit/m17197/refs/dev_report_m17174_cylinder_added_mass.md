## ① 问题 + ref 出处

**问题**：二维无限流体中平移的圆截面圆柱（半径 `a`），其单位展长附加质量
`m_A = ρπa²`（无自由液面，闭式）。这是经典势流解析解：Lamb (1932) 与
Newman (1977) 的椭圆/圆截面附加质量闭式（`src/tensorbem/analytic.py` 的
`ellipse_added_mass` 文档串引述「the classical results are `rho*pi*b**2`…」，
圆截面 `a=b` 时退化为 `ρπa²`）。本仓 `docs/marine_bem_benchmarks.md` 第 62 行
给出推导 `m_A' = ρπa²`。

**ref 数值**：`ρπa² = 1025 × π × 1² = 3220.13247`（质量/单位展长），由
`density * math.pi * radius**2` 计算得出——**非手抄**，是解析公式的机器求值。

**容差判据**：<3%（任务榜）。

## ② 方法与实现

复用 TensorBEM 既有能力（不另起炉灶）：
- **几何**：`tensorbem.geometry.regular_polygon` 在圆周上生成 `N` 边形（内接多边形
  逼近圆，故按加密趋势评估而非单值）。
- **边界条件**：平移圆柱的精确 Dirichlet 迹 `φ = -U·a·cosθ`（面元中点角度）。
- **求解**：`tensorbem.solver.solve_laplace_dirichlet`（2-D 常数面元配点，直线面元
  解析积分）求未知外法向导数 `q`。
- **附加质量**：边界能量积分 `m_A = ρ/U²·Σ φ_i·q_i·Δs_i`，与解析 `ρπa²` 比较。

工具链：`python -m tensorbem.benchmarks.refinement_study --panels 16 32 64 128 256
--output artifacts/refinement_cylinder.json`（单核，<10s，未走集群）。

## ⑤ 收敛性 / 参数敏感性（至少两点）

1. **网格收敛**：相对误差随 `N` 单调下降——16→2.62e-2、32→6.48e-3、
   64→1.61e-3、128→4.02e-4、256→1.00e-4，观测阶约 2（常数面元直线积分二阶精确）。
   单层矩阵条件数 ~0.6N（9.8→152），无对数容量退化（参考长度 2 下圆半径 1 非退化）。
2. **同族参数敏感性（椭圆）**：`ellipse_added_mass`（`a=1.5,b=0.75`，128 面元）
   x 向 `ρπb²=1811.32` 误差 7.54e-4、y 向 `ρπa²=7245.30` 误差 9.00e-4——与圆柱
   基准同量级，验证「每方向用垂直半轴」的闭式。`a=b` 时两向退化到 `ρπ`，与圆柱一致。
3. **密度/半径标度**：`test_circular_cylinder_added_mass_scales_with_density_and_radius_squared`
   验证 `m_A ∝ ρ·a²`（半径 2、密度 500 时 `m_A` 恰为基准 2 倍）。

## ⑥ 失败模式与工件

- **失败模式**：本基准是**边界迹验证**（`cylinder_added_mass.py` 文档串明言「不验证
  一般外域求解器」）——圆的第一谐波模内外同场，故有界域求解器在连续极限复现外域通量；
  椭圆才首次检验外域算子本身（`ellipse_added_mass.py`）。因此本单不宣称一般外域/
  自由液面/波浪体能力。
- **工件**：`artifacts/refinement_cylinder.json`（5 面元数完整 JSON）、
  `artifacts/fig_cylinder_added_mass.png`（收敛图）、`artifacts/make_fig_cylinder_added_mass.py`
  （图生成脚本，数字由工件注入）。
- **生态摩擦**：无——TensorBEM 已具备该能力（`cylinder_added_mass` 基准 + 门禁 +
  文档 pin），本单为算例池复用，未另起炉灶。
