## 1. 为什么做这件事

README 路线图第 6 项把「Kutta 条件升力水翼」列为未实现；`docs/lifting_foil.md` §4 记录了唯一一次尝试（精确叠加 + 内部点涡）的**诚实失败**：环量大小收敛但**符号相反**，因此当时选择不发布升力求解器。本仓其余求解器（Dirichlet、零净通量 Neumann、自由液面辐射/绕射）都是非升力的；升力问题在数学上是另一类适定问题——环量由后缘 Kutta 条件确定，而不是由边界数据确定。本单把这一项真正做完，并给出可复算的解析基准复核。

## 2. 案例（物理背景与几何参数）

对称 Joukowski 翼型：圆 |ζ+m| = a 经 z = ζ + b²/ζ 映射，m = 0.1b、b = 1，后缘为尖点（cusp）。闭式解（`tensorbem.lifting.JoukowskiAirfoil`）给出 Γ = 4πaU·sin α、C_L = 2Γ/(Uc)，以及同族闭式 C_p。

| 参数 | 值 |
|---|---|
| 厚度参数 m | 0.1 |
| 变换半径 b | 1.0 |
| 弦长 c | 4.0333 |
| 厚度比 t/c | 0.1179 |
| 来流速度 U / 密度 ρ | 1.0 / 1.0 |
| 迎角 | 0°, 2°, 4°, 8° |
| 面元数 | 32, 64, 128, 256, 512 |

解析基准来自 `tensorbem.lifting`，与面元法**零代码共享**，因此两者一致是真正的交叉验证，而不是自证。

## 3. 怎么做的

1. **两条路线，只发货精度够的那条**：
   - *路线 A（源 + 全域常强度涡，Hess-Smith 形）*：实测 128 面元 C_L 误差 **6.9%**，且 N=32→512 只从 12.4% 降到 3.2%，因常强度涡面无法表达后缘处按 1/√x 集中的附着涡，判为不发货。
   - *路线 B（线性强度涡面元，本单发货）*：节点涡强度 γ₀…γ_{N−1} 为未知量，面板内线性变化；N 个控制点法向无穿透方程闭合；Kutta 条件取「后缘涡强度为零」的反对称闭合 γ_N = −γ₀。
2. **影响系数闭式 + 逐项数值复核**：J₀ = β/|y₀|、J₁ = ln(r₂/r₁)、J₂ = l − y₀²J₀，其中 β 取幅值、由目标点所在侧定号，避免共线控制点处 atan2 的分支歧义。测试用 20 万点直接 Biot-Savart 积分对照，误差 ≤ 5×10⁻⁶。
3. **自身面板取外极限**：法向 0、切向 −γ_mid/2（外侧极限），而非主值（两侧平均）。用主值会让每个面元表面速度偏 γ/2，直接毁掉升力。
4. **符号约定**：涡量取逆时针为正，故气动环量 Γ = −∮γ ds，C_L = 2Γ/(Uc)，与 `exact_lift_coefficient` 一致。写反即得到「符号相反、大小合理」的环量——正是 §4 失败尝试的病征。
5. **独立校核**：压力积分 L′ = −∮ p n_y ds（p = ½ρU²C_p）与 Kutta-Joukowski 结果互校。

## 7. 注意点 / 局限（诚实清单）

1. **后缘尖点区的点压力不可用**：两条后缘面元的控制点跨尖点相距仅面板的一个零头，点速度被近奇异邻面元支配，|C_p| 可达数十（`benchmark.json` 的 `pressure_max_abs_aft_30pct`）。升力不受影响（两积分互校 < 1%），但不要把后缘 C_p 当输出；正解是后缘局部加密/对数坐标面元，而非调参。
2. **观测收敛阶 0.86，不是教科书的二阶**：误差由后缘尖点处连续涡强度的 1/√x 奇性主导，线性涡面在等弧长网格上只能一阶左右逼近；但有限面元数下绝对精度已优于 1%（128 面元 0.73%），文档因此不写「二阶」。
3. **三次「看起来收敛」的假结果**：①源+常涡（6.9%）；②自身面板取主值而非外极限（表面速度整体偏 γ/2）；③影响系数投影把目标法向写成源面元法向（转置型下标错）。三者都收敛、都物理上似是而非，只有解析基准与逐项数值积分复核能拆穿。
4. 仅对称（零弯度）尖后缘 Joukowski 翼型；无自由液面、无航速、无粘性/分离/压缩性。求解器本身对任意闭合轮廓通用，但解析基准只对这一族存在。
