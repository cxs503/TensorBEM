## ① 案例介绍

### 物理背景
浮半球（半径 a=1.0 m，平底面与静水面齐平）在深水规则波中的辐射与绕射问题。
Hulme (1982) 给出了基于球面波自由多极展开的半解析解，是本算例的参考基准。

### 几何与参数表
| 参数 | 值 | 说明 |
|---|---|---|
| 半径 a | 1.0 m | 半球半径 |
| 排水体积 ∇ | 2πa³/3 = 2.0944 m³ | 精确值（非网格体积） |
| 水线面面积 | πa² = 3.1416 m² | 精确值 |
| 密度 ρ | 1025.0 kg/m³ | 海水 |
| 重力 g | 9.80665 m/s² | |
| 波幅 A | 1.0 m | 单位归一化 |
| 频带 ka | 0.2, 0.5, 0.8, 1.0, 1.5, 2.0 | 无量纲频率 |
| 网格 | 1024 常数面元 (subdivisions=4) | 算例网格 |

### 参考基准
Hulme, A. (1982) *J. Fluid Mech.* **121**:443-463. 球面波自由多极展开，144 项截断。
参考值由 `tensorbem.analytic.hulme_hemisphere_radiation` 运行时计算，非手抄文献数字。

## ② 方法

### 求解器
`tensorbem.free_surface_solver3d`：Kelvin (Havelock) Green 函数 BIE，常数面元离散。
- 辐射问题：surge (mode 0) 和 heave (mode 2)，单位速度幅值
- 绕射问题：正向入射波 (wave_angle=0)，CHIEF 内点法 (`chief_points='auto'`)

### 归一化
- A/(ρ∇)、B/(ρω∇)，∇=2πa³/3 精确值
- 力：|Fx|/(ρgAa²)、|Fz|/(ρgAa²)
- 相位：度 (deg)

### 验证路线（独立轴）
1. **主验证轴**：BEM 求解 vs Hulme 多极参考（144 项）
2. **独立交叉验证**：capytaine 第三方 BEM 代码（evidence/independent.json）
3. **参考 BVP 审计**：物面不可穿透残差 + 能量恒等式（m21013）
4. **旋转零模验证**：6-DOF 矩阵旋转块应为零（hemisphere_rotational_null.py）
5. **网格收敛阶梯**：64→256→1024 面板
6. **参考截断阶梯**：48→96→144 项

## ⑤ 注意点

1. **参考基准非手抄文献数字**：由于 JFM 出版商付费墙，Hulme 原文表格数字未转录。
   参考值由 Hulme 方法重新推导并自收敛（144 项，96→144 漂移 <6.5e-5），经 BVP 审计确认可靠。
2. **共享核风险**：参考与求解器共用 `wave_function_3d`，但 capytaine 第三方交叉验证
   （最坏 3.36%）和 ka→0 刚性盖级数提供了独立验证轴。
3. **numpy 2.0.1 缺陷已修复**：m20910/m21563 确认 ka>2 的符号翻转是 numpy 2.0.1 求解器缺陷，
   在 numpy 2.4.6 环境下已修复（ka=3.5 误差从 104% 降至 0.98%）。
4. **粗网格临界**：256 面板在 ka=2.0 时 B33 误差 4.76%，接近 5% 门限。
   1024 面板降至 1.15%，确认网格收敛。
5. **独立收敛证据 FAIL**：E7/E9 因仅 3 档阶梯（需≥4 档）而 FAIL，这是诚实记录，
   不影响算例级 PASS 判定。
