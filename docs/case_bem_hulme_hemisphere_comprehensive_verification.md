## ① 案例介绍

### 物理背景
浮半球（半径 a=1.0 m，平底面与静水面齐平）在深水规则波中的辐射与绕射问题。
Hulme (1982) 给出了基于球面波自由多极展开的半解析解，是本算例的参考基准。

## ② 方法

### 求解器
`tensorbem.free_surface_solver3d`：Kelvin (Havelock) Green 函数 BIE，常数面元离散。
- 辐射问题：surge (mode 0) 和 heave (mode 2)，单位速度幅值
- 绕射问题：正向入射波 (wave_angle=0)，CHIEF 内点法 (`chief_points='auto'`)

### 归一化
- A/(ρ∇)、B/(ρω∇)，∇=2πa³/3 精确值
- 力：|Fx|/(ρgAa²)、|Fz|/(ρgAa²)
- 相位：度 (deg)

### 验证路线（独立轴）
1. **主验证轴**：BEM 求解 vs Hulme 多极参考（144 项）
2. **独立交叉验证**：capytaine 第三方 BEM 代码（evidence/independent.json）
3. **参考 BVP 审计**：物面不可穿透残差 + 能量恒等式（m21013）
4. **旋转零模验证**：6-DOF 矩阵旋转块应为零（hemisphere_rotational_null.py）
5. **网格收敛阶梯**：64→256→1024 面板
6. **参考截断阶梯**：48→96→144 项

## ② 方法与流程
### 2.1 求解器链路
1. **几何**：`hemisphere_hull_mesh(subdivisions)` — 八面体四分并径向投影到 r = a、z ≤ 0
2. **自由面算子**：`assemble_free_surface_operators_3d` — Kelvin Green 函数，Van Oosterom–Strackee 立体角 + Duffy 近奇积分
3. **CHIEF 空场方程**：`chief_points='auto'` 抑制不规则频率（ka ≈ 2.58）
4. **辐射求解**：`solve_radiation_3d`，surge (mode 0) + heave (mode 2)
5. **绕射求解**：`solve_diffraction_3d`，wave_angle = 0
6. **参考解**：`hulme_hemisphere_radiation`，144 项球谐展开，自收敛漂移 6.46e-05

### 5.1 已知局限
1. **共享核风险**：参考级数与求解器共享 `wave_function_3d` 核。 agreement 本身不能排除核缺陷。但 capytaine 交叉（3.36% 最坏偏差）和 ka→0 刚盖级数两条独立轴已覆盖此风险。

4. **线性势流假设**：无黏、无航速、无限水深。不适用于强非线性/碎击/浅水工况。
