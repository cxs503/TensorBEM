## ① 案例介绍

半径 a = 1 m 的浮半球（平面与平均自由面 z = 0 齐平，曲面入水）在无限深水中作单位幅值强迫振荡并受迎浪单位波幅入射。求 surge（附加质量 A11、阻尼 B11）与 heave（A33、B33）的无量纲系数，以及绕射激励力 |Fx|、|Fz| 的幅值与相位。

这是频域势流 BEM 的经典验证算例——半球是少数几个存在半解析解的有限吃水浮体，能同时检验自由面 Green 函数、水线积分与 Kochin/Haskind 远场关系。

**参数表**：

| 项目 | 取值 |
|---|---|
| 几何 | 浮半球 a = 1.0 m |
| ∇（精确排水体积） | 2πa³/3 = 2.094395 m³ |
| A_wp（精确水线面积） | πa² = 3.141593 m² |
| ρ / g / A | 1025.0 kg/m³ / 9.80665 m/s² / 1.0 m |
| ka 频带 | 0.2, 0.5, 0.8, 1.0, 1.5, 2.0 |
| 主网格 | 1024 常数面元（subdivisions = 4） |
| 参考截断 | 144 项球谐展开 |
| 时间约定 | exp(−iωt) |

**归一化**：A/(ρ∇)、B/(ρω∇)、|F|/(ρgAa²)。

## ② 方法与流程

### 2.1 求解器链路

1. **几何**：`hemisphere_hull_mesh(subdivisions)` — 八面体四分并径向投影到 r = a、z ≤ 0
2. **自由面算子**：`assemble_free_surface_operators_3d` — Kelvin Green 函数，Van Oosterom–Strackee 立体角 + Duffy 近奇积分
3. **CHIEF 空场方程**：`chief_points='auto'` 抑制不规则频率（ka ≈ 2.58）
4. **辐射求解**：`solve_radiation_3d`，surge (mode 0) + heave (mode 2)
5. **绕射求解**：`solve_diffraction_3d`，wave_angle = 0
6. **参考解**：`hulme_hemisphere_radiation`，144 项球谐展开，自收敛漂移 6.46e-05

## ⑤ 注意点

### 5.1 已知局限

1. **共享核风险**：参考级数与求解器共享 `wave_function_3d` 核。 agreement 本身不能排除核缺陷。但 capytaine 交叉（3.36% 最坏偏差）和 ka→0 刚盖级数两条独立轴已覆盖此风险。
2. **印刷值不可得**：Hulme (1982) 原文表格因出版商付费墙无法获取。"ref" = Hulme 方法的重新推导级数（自收敛 6.46e-05），非印刷数字。证据等级：REAL（半解析方法，可复算）。
3. **4096 面板档缺失**：健康环境的 4096 面板 inhouse 档待集群取回。当前 inhouse 阶梯仅 3 档，E7/E9 收敛判据因此 FAIL（诚实）。
4. **线性势流假设**：无黏、无航速、无限水深。不适用于强非线性/碎击/浅水工况。
