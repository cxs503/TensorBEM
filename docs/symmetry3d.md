## 1. 案例：为什么值得做，以及为什么它可被精确验证

船体关于中纵剖面 `y = 0` 对称。`tensorbem.free_surface_solver3d` 的深水 Kelvin Green 函数只通过
水平距离 `R = hypot(dx, dy)` 与竖向坐标 `(z, z0)` 进入，因此对反射
`M: (x, y, z) -> (x, -y, z)` **逐点严格不变**：

$$G(MP, MQ) = G(P, Q), \qquad \partial G/\partial n_{\rm body}(MP, MQ) = \partial G/\partial n_{\rm body}(P, Q).$$

这不是近似对称（不是"网格看起来对称"），而是核函数对 `y` 只以 `dy²` 出现。于是对具有确定宇称
`phi(Mx) = s phi(x)`（`s = ±1`）的势，边界积分方程可以在**保留下来的半个船体**上闭合：

$$\left[\tfrac12 I - H_{\rm half} - s\,H_{\rm mirror}\right] \phi_{\rm half} = \left[S_{\rm half} + s\,S_{\rm mirror}\right] q_{\rm half},$$

其中 `H_mirror`/`S_mirror` 是镜像半面（带自己的朝外法向）在保留半面配点上算得的算子，
`q = -d(phi)/dn_body` 与 `phi` 同宇称。

六个刚体模态的宇称（`s_i`）：

| 模态 | surge | sway | heave | roll | pitch | yaw |
|---|---|---|---|---|---|---|
| `s_i` | +1 | −1 | +1 | −1 | +1 | −1 |

宇称**不是假设**：`n_i(Mx) = s_i n_i(x)` 由 `verify_generalized_normal_parity` 逐面元数值核验
（本文算例误差 0 ~ 1.1e-16），并写成测试。

**验收判据（先于动手）**：折叠系统与全网格系统是*同一组*方程的受限形式，因此

1. 折叠后的算子矩阵必须逐元素等于全网格算子矩阵的"行取半面、列取半面 ⊕ 宇称×镜像列"；
2. 半体解出的 `A_ij, B_ij`（`s_i = s_j` 项）必须与全体解到舍入量级一致；
3. 不同宇称的耦合项在折叠解中**恒等于 0**（`1 + s_i s_j = 0`），全网格解只剩对消残差；
4. 试验体必须是同一个体：半面 + 镜像 = 全网格，逐面元一致。

## 2. 怎么做

1. `split_patch`：把 `y ≥ 0` 与 `y ≤ 0` 两半切开；跨对称面的面元报错拒绝（镜像不允许切面元）；
   落在面内 `1e-12·L` 以内的顶点**精确吸附到 `y = 0`**，这是两个系统"代数同一"的前提。
2. `mirror_patch`：`y -> -y` 并交换第二、三顶点，使镜像法向为 `(n_x, -n_y, n_z)`（仍朝外）。
3. `assemble_symmetric_blocks`：一次装配 `(S,H)_half` 与 `(S,H)_mirror` 两组块（`2·(N/2)² = N²/2`
   个核矩阵元，全网格为 `N²`），CHIEF 空场行同样拆成 half/mirror 两块。
4. `operators_for_parity`：按 `s` 把两块折叠成 `FreeSurface3DOperators`（含 `½I - H_s` 与 CHIEF 堆叠），
   两种宇称**共用同一次装配**。
5. `solve_radiation_3d_symmetric`：最多两次半规模求解（每个出现的宇称一次），
   后处理用折叠权重 `(1 + s_i s_j)` 组装完整的 `6×6` `A`、`B`。
6. `solve_diffraction_3d_symmetric`：把入射 Airy 波按宇称劈成 `phi_I^±`，
   分别用对应宇称求解（散射问题右端 `q_e = +d phi_I/dn`，与全网格解一致），
   激励力用同一折叠权重合成。

## 4. 误差判定（关键量 vs 基准，逐项列出，是否 <3%）

基准 = 同一面元网格上的全网格解（`solve_radiation_3d` / `solve_diffraction_3d`，已被 Hulme 1982
半解析解验证的求解器），因此这里判的是**缩减的等价性**，不含离散误差。

| 关键量 | 基准 | 相对误差 | <3%？ |
|---|---|---:|---|
| `A_ij`（`s_i = s_j`，64 面元） | 全网格解 | 1.48e-07 | ✅ |
| `B_ij`（`s_i = s_j`，64 面元） | 全网格解 | 2.59e-08 | ✅ |
| `A_ij`（`s_i ≠ s_j`） | 恒等于 0 | 0（全网格残差 6.56e-08） | ✅ |
| 6-DOF 激励力（3 个来流角，最大） | 全网格解 | 4.75e-08 | ✅ |
| 不规则频率 `ν=2.58` 下 `A_33`（CHIEF） | 全网格解 | 1.63e-03 | ✅ |
| 不规则频率 `ν=2.58` 下 `B_33`（CHIEF） | 全网格解 | 3.18e-03 | ✅ |

**结论：全部关键量远低于 3%（正则频率下 1e-7 量级）。**

## 5. 注意点 / 局限

1. **CHIEF 情形不是舍入量级**：不规则频率下 `A_33` 差 1.6e-03、`B_33` 差
   3.2e-03。原因已定位：CHIEF 行堆叠的系统是秩亏的最小二乘，其残差约 1%
   （`relative_residual` = 3.48e-02 / 3.14e-02），因此对折叠与全网格之间
   1e-5 量级的单层算子差分（见 5.3）会被放大到 1e-3。这是 CHIEF 方法本身的敏感性，不是折叠错误；
   两块在 `ν=1`（无 CHIEF）时的一致性回到 1e-7。
2. **只支持 `y = 0`**，且保留 `y ≥ 0` 半侧；`center[1] == 0` 是硬约束（否则广义法向没有确定宇称），
   已写成 `ValueError`。
3. **单层算子的折叠与全网格差 ~1e-5·max|S|**（双层算子的解析立体角差 1e-18）：全网格在
   近邻面元对上用 Duffy 规则，折叠时该对变成"目标面元 vs 其镜像面元"，虽然用的是同一规则，
   但求和顺序与面元编号不同。这是本缩减唯一的精度代价，且远小于离散误差。
4. **远场后处理未折叠**：`far_field_damping_matrix_3d` / `haskind_excitation_force_3d` 需要全表面势，
   当前接口仍要求全网格；单侧求解后可用 `mirror_patch` + 宇称展开成全面后再调用，这是后续项。
5. **不改变物理结论**：三维有限水深 John 本征级数 Green 函数仍然缺（roadmap 第 6 项），本工作只在
   已有的深水 Kelvin 求解器上做等价缩减。
6. 面元数越大收益越大：未知量减半，稠密求解为 `(N/2)³ = N³/8`，两种宇称合计 `N³/4`；
   64 面元实测 ×10.0（小规模下装配占比高，收益被拉低）。

## 远场后处理（m3224 结清的限制）

`docs/symmetry3d.md` 早先声明「远场后处理未折叠：`far_field_damping_matrix_3d` /
`haskind_excitation_force_3d` 需要全表面势」。该限制已结清：宇称确定的势满足

```
K_full(theta) = K_half(theta) + s * K_half(-theta)
```

因为反射 `M: y -> -y` 同时把相位 `exp(νz - iν(x cosθ + y sinθ))` 与方向因子
`n_z - i(n_x cosθ + n_y sinθ)` 映成 `-θ` 的形式。基于此新增
`folded_kochin_function_3d` / `far_field_damping_matrix_3d_symmetric` /
`haskind_excitation_force_3d_symmetric`，半域解由此可直接给出远场阻尼 `B_ij^far`、
Kochin 函数与 Haskind 激励力（RAO 右端项）。验证：折叠恒等式到舍入量级（2e-14），
端到端与全域解一致到 1e-8（`B_ij^far`、激励力）量级，详见
`docs/m3224/symmetry_far_field.md`。
