# 偏心水线面的解析复核与变异盲点收口（m2767, TensorBEM）

**判据先于动手**：这一单不是"再补几条测试"，而是回答三个可机器裁定的问题。

1. `tensorbem.hydrostatic` 的水线面积分在**水线面不跨原点**时是否仍然正确？（此前全部算例
   —— 方箱、圆柱、半球、双体、环形容器 —— 的水线面都对原点对称，一阶矩恒为零。）
2. 上一单 `docs/mutation_audit_tensorbem.md`（m2582）登记的 4 条存活变异体，哪些是真缺口、
   哪些是死代码？逐条复现注入并给出前后判定。
3. 若第 1 问的答案不是"正确"，那就要改算法；如果是"正确"，那要给出**误差为零的证明级别
   证据**（封闭解析解 + 独立算法交叉校验），而不是"测试变绿了"。

结论先说：**积分是正确的**（最大相对误差 2.29e-15，双精度舍入量级）；4 条欠账里 3 条由新增
护栏直接关闭，第 4 条的根因是**死代码**（`df_d_depth`/`dg_d_depth` 算了不用），已按"单一来源"
重构，重构前后数值差 4.18e-16。

## 1. 案例（几何 / 参数）

全部算例是**棱柱**（wall-sided prism）：水线面多边形沿 `z` 挤出到吃水 `T`，底板 + 侧板，`z=0`
开口。这样水线面积分与排水体积**对网格无离散误差**——是"零误差控制"，不是收敛研究。

| 算例 | 水线面多边形 | 吃水 T | 为什么选它 |
|---|---|---|---|
| 偏心矩形 | `x∈[0.5,2.5], y∈[-0.5,1.5]` | 1.3 m | 一阶矩非零（`∫x dA=6`、`∫y dA=2`），`I_xy=0` |
| 偏置直角三角形 | `(0.3,0.2),(2.3,0.2),(0.3,1.4)`，直角边 b=2.0 / h=1.2 | 0.9 m | `I_xy=-A b h/36` 有**符号** |
| 斜平行四边形 | 角点 `(1.0,-1.0)`，张成向量 `u=(2.0,0.4)`、`v=(0.6,1.5)` | 1.1 m | `I_xy=0.391` 非零，检验惯性积的平行轴平移 |
| 双环（不同尺度不同偏置） | 上面的矩形 + `x∈[4,5], y∈[0.5,1.0]` | 1.3 m / 0.4 m | 池化形心 `≠0`，双体的 `A_i d_i²` 项不再两两抵消 |
| 偏心方箱（恢复力矩阵） | `x∈[2.4,8.4], y∈[1.1,3.1]`（6.0 × 2.0） | 1.5 m | `C` 矩阵：`ρgA`、`ρgI_xx`、`ρgI_yy` 三项闭式 |
| 退化/契约分支 | 共线水线（零面积）、空面元表 | — | 见 §5 说明：构造器不可达，只做契约级钉桩 |

密度/重力用模块默认 `ρ=1025 kg/m³`、`g=9.80665 m/s²`；单位 SI（m、m²、m⁴、N/m、N·m/rad）。

## 2. 怎么做的

1. **先读账**：`docs/mutation_audit_tensorbem.md` §5 的 4 条待办 + `src/tensorbem/hydrostatic.py`
   的 `compute_waterplane_properties` / `compute_displaced_volume_and_buoyancy` 实现。
2. **封闭解析参考**（与库代码零共享）：

   - 矩形：`A=b_x b_y`，`I_xx=b_x b_y³/12`，`I_yy=b_y b_x³/12`；
   - 直角三角形（绕形心）：`I_xx=A h²/18`，`I_yy=A b²/18`，`I_xy=-A b h/36`；
   - 平行四边形（绕形心）：`I_xx=A(u_y²+v_y²)/12`，`I_yy=A(u_x²+v_x²)/12`，
     `I_xy=A(u_x u_y+v_x v_y)/12`；
   - 池化：`A=ΣA_i`，`c=ΣA_i c_i/A`，`I=I_i + A_i d_i d_i`（含 `I_xy` 项）。
3. **第二条独立算法**：测试文件内用**扇形三角剖分 + 三角形二阶精确三点中点积分规则**重算
   面积/形心/二阶矩/惯性积。这与库里的"逐边 Green 定理求和"是不同算法，两条封闭式与它三方
   一致才算过。
4. **物理交叉校验**：wall-sided 棱柱的浮心水平坐标必须等于水线面形心——浮心来自三维四面体
   求和、形心来自二维 Green 定理，两个积分共享零行代码。
5. **恢复力矩阵**：用"重心置于浮心"（`GM_T=BM_T`）这一构型，使 `C[3,3]=ρgI_xx`、`C[4,4]=ρgI_yy`
   成为恒等式，把水线面二阶矩直接对到刚度矩阵；并验证平移不变性（横向平移船体，`C[2,2]`、
   `C[3,3]`、`C[4,4]` 必须不变 —— 库报告的是**绕池化形心**的二阶矩）。
6. **变异复现**：`docs/m2767/tools/closure_replay.py` 把 m2582 登记的 4 条变异体按字面片段注入
   私有影子包（`PYTHONPATH` 只指向影子，先断言导入落在影子内），分别在"旧套件"和"旧套件 +
   新测试"下跑，判定 killed/survived。
7. **模块级变异再抽样**：`python -m tensorbem.benchmarks.mutation_audit --module tensorbem.hydrostatic
   --module tensorbem.free_surface --max-per-module 8 --seed 20261103`，前测（现有套件）与后测
   （加新测试文件）各跑一次，产物在 `artifacts/mutation_closure/{baseline,after}/`。
8. **工具链**：Python 3.11 + NumPy（无额外依赖）；`matplotlib` 只用于出图；
   全部数字由 `docs/m2767/tools/eccentric_waterplane_figure.py` 写入
   `artifacts/hydrostatic_eccentric/waterplane_checks.json`，文档零手抄。

## 4. 死代码定因（`free_surface.green_gradient`）

`dg_d_source_z` 原本把 `∂G/∂A` 那一项**内联重写**了一遍，于是局部量
`df_d_depth → dg_d_depth` 算完再也没有人读：

- 代数上两者等价：`∂/∂z₀ = −∂/∂A − (1/2π)(z−z₀)/r²`（`A = −(z+z₀)` 随源点下潜而减小，
  Rankine 项另有 `∂ log r/∂z₀ = −(z−z₀)/r²`）。
- 因此把 `df_d_depth` 的 `2.0 *` 改成 `2.0 /` **改变不了任何返回值** —— 这不是"缺一条护栏"，
  而是"被判定的代码根本不参与计算"。
- 处理：不再重述，改为 `dg_d_source_z = -dg_d_depth - (1/2π)(z-z₀)/r²`，让 `A` 导数只有
  一处来源。重构前后在 7×7 网格（`x∈[-3,3]`、`z∈[-4,-0.4]`，源点 `(-0.7,-1.9)`，`ν=0.6`）
  上逐点比较：**最大相对差 4.18e-16**（纯舍入）。重构后该变异体由既有差分护栏杀死。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **零面积 / 零体积分支无法用合法网格触发**。`WettedHullMesh` 构造器要求正排水体积，而水线面
   零面积的湿表面必然围出零体积 —— 两条早退分支在公开 API 下**不可达**，属防御性代码。本单用
   属性级的属性替身（duck-typed stand-in）在契约层钉桩，并在测试文件里写明这一点；**不要**把
   它当成"物理算例已覆盖"。顺带一提：构造器拒绝这类网格时给出的信息是
   "positive displaced volume"，与几何原因（共线水线）匹配。
2. **惯性积 `I_xy` 此前从未被断言**。所有既有算例都关于两轴对称，`I_xy≡0`，其平移项
   `I_xy − A c_x c_y` 的符号错误不可能被发现。斜平行四边形把 `I_xy` 钉到 `+0.391`，符号错了会
   差 `2Ac_xc_y=−0.46`。
3. **参考点约定（重要且尚未建模）**。库报告的 `C` 是**绕水线面池化形心**的二阶矩版本，等价于
   "坐标系竖轴穿过漂心"。若船体坐标原点不在漂心（真实非对称船几乎都如此），标准小角度恢复力
   矩阵还应有耦合项 `C[3,2]=C[2,3]=ρgA y_c`、`C[4,2]=C[2,4]=−ρgA x_c` 等，而本模块把它们
   置零。以 §3.2 的方箱为例，被略去的 `ρgA x_c = 6.51e5 N/rad` 是已报 `C[4,4]=3.62e5` 的
   **1.80 倍**、`ρgA y_c = 2.53e5` 是 `C[2,2]=1.21e5` 的 **2.10 倍** —— 不是小修正。因此本模块
   的 `C` 只在"原点位于漂心"或"水线面关于原点对称"时才可直接用，否则必须先做参考点转移。
   本单**没有**实现转移/补项（超出单干范围，见 §7 后续）。
4. **抽样而非穷举**。模块级 score 是 8/233、8/232 的固定种子抽样；本次抽样未包含上表 4 条，
   所以分数不动不等于没改进 —— 直接证据是定向复现。
5. **本抽样仍存活的 3 条（如实登记为下一单待办）**：
   `_pv_cosine` 里 `exp(-kA)cos(kX) − reference` 的 `−` → `+`、`_pv_sine` 里 `nu * x` 的 `*` → `/`
   两条**真缺口**（主值积分的被积式细节，现有套件对它们的灵敏度不足），以及
   `0.0 → -0.0` 一条**等价变异体**（IEEE 下同值，不应为它写测试）。
6. **只验证了几何为棱柱的情形**（水线面为直线多边形、直立舷侧）。曲面水线（圆、椭圆）的
   形心/二阶矩复核已在既有 `test_hydrostatic_analytic_benchmark.py` 里覆盖，但那批算例都对称，
   曲面 + 偏心组合仍未覆盖。
7. **无实验数据需求**：本单的靶是封闭解析解与不同算法，不是实测；因此不涉及"文献值不可得"
   这类 WITHHELD。

## 6. 误差判定（关键量 vs 基准，逐项）

| 关键量 | 基准 | 实测偏差 | 是否 <3% |
