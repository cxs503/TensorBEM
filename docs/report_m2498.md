## 1. 案例介绍（物理背景 / 几何 / 参数表）

**物理背景**：半径 \(a\) 的圆柱截面潜没于常水深 \(h\) 的静水中，轴心在水面下 \(f\)，作垂荡（heave）或
横荡（sway）受迫振荡，频率 \(\omega\)，波数 \(k_0\) 满足 \(k_0\tanh(k_0 h)=\nu=\omega^2/g\)。与深水 Ursell
问题相比多了一个平底 \(z=-h\)：竖向本征结构由连续谱变成离散模态（有限水深 Green 函数
\(G_h=\frac{1}{2\pi}\log r+G_{\text{smooth}}\)）。

**本单要闭合的欠账**（`docs/finite_depth_radiation.md` §5 局限 1）：有限水深求解器在 64 面元下，
远场（波幅）阻尼 \(B_{\rm far}\) 与近场（压力）阻尼 \(B_{\rm near}\) 相差约 1%（有限水深 \(+1.06\%\)、
深水求解器同网格 \(-1.04\%\)，量级相同、方向相反）。一个带未解释符号的 1% 偏移正是"归一化写错"的
典型外观——**必须归因**：是离散误差、求积误差、还是远场积分器误差？

**几何与参数**（程序化提取自 `convergence.json`）：

| 参数 | 值 | 来源 |
|---|---|---|
| 半径 \(a\) | 1.0 m | json `radius` |
| 潜深 \(f\)（\(f/a\)） | 2.0 m（2） | json `submergence` |
| 波数 \(ka\) / \(\nu\) | 0.6 / 0.6 | json `ka`,`nu` |
| 水深 \(h/a\) | 3.2（shallow）/ 4（medium）/ 50（deep） | json `rows[].depth_label` |
| 密度 \(\rho\) / 重力 \(g\) | 1025 kg/m³ / 9.80665 m/s² | json `density`,`gravity` |
| 面元数 \(N\) | 32 / 64 / 128 / 256（常数面元） | json `rows[].panels` |
| 每面元 Gauss 节点 | 8（扫描 4/8/16） | json `panel_nodes`,`node_sweep` |

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

**方法**：单层位势（间接）BEM，与深水求解器同构、只换核。奇异部分 \(\frac{1}{2\pi}\log r\) 在直线
面元上**解析积分**（复用 `_log_panel_primitive`），只对 \(G_{\text{smooth}}\) 做 Gauss 求积；法向导数
矩阵 = 精确 Rankine 行积分 + `finite_depth.green_gradient(include_rankine=False)`；单层位势法向导数
跃度 \(1/2\)，系统为 \(A+\tfrac12 I\)。

**远场阻尼**（本单唯一的新归一化，非拟合）：核的传播模态远场
\(G\sim-\frac{i}{2k_0N_0}\phi_0(z)\phi_0(z_0)e^{ik_0|x-x_0|}\)，对单位速度
\(B_{\rm far}=2\rho g c_g|\eta_a|^2\)（系数 2 = 两个传播方向；深水极限下与已验证的
`free_surface_solver.far_field_damping`（Haskind 形式）一致，是唯一锚）。

**归因流程**（三轴 + 深水对照，`benchmarks/finite_depth_energy_convergence.py`）：
1. **网格细化轴**：\(N=32\to256\)，观察偏移是否随细化减半（若是 → 一阶离散误差 \(O(h^1)\)）；
2. **求积轴**：每面元 Gauss 节点 4→16，观察偏移是否移动（若不动 → 非求积限制）；
3. **远场积分器轴**：面元中心点读值 vs 面板求积（`far_field_damping_panel_quadrature`），
   观察差值（~1e-4 → 非振幅积分器）；
4. **深水对照**：已独立验证的深水求解器同网格跑同一偏移（同量级、反号 → 偏移是面板离散性质，
   不是有限水深核的问题）；
5. **MFS 独立离散**：同一核换离散（源数 16→96），确认 MFS 在自身参数上收敛、但**不是**独立物理基准。

**工具链**：`tensorbem.benchmarks.finite_depth_energy_convergence`（基准）→ `convergence.json` →
`docs/finite_depth_energy_identity/build_tables.py`（报告表格由 JSON 程序化生成）→ 8 条回归测试
`tests/test_finite_depth_energy_convergence.py`。

**本补报验证**：`python3 -m pytest tests/test_finite_depth_energy_convergence.py -q` →
**5 passed, 3 skipped**（42.9 s；3 条 skip 为工件路径断言，见 §5）。

## 3. 计算结果（数字表，程序化注入自 `convergence.json`，零手抄）

### 3.1 能量恒等式偏移收敛（shallow \(h/a=3.2\)，heave）

| \(N\) | \(A_{33}\) | \(B_{\rm near}\) | \(B_{\rm far}\) | 偏移 \(B_{\rm far}/B_{\rm near}-1\) | 偏移(面板求积) |
|---:|---:|---:|---:|---:|---:|
| 32 | 4949.784 | 2421.198 | 2470.191 | **2.0235e-02** | 2.0549e-02 |
| 64 | 4851.711 | 2349.827 | 2374.430 | **1.0470e-02** | 1.0547e-02 |
| 128 | 4795.281 | 2309.140 | 2321.429 | **5.3218e-03** | 5.3406e-03 |
| 256 | 4765.305 | 2287.623 | 2293.756 | **2.6807e-03** | 2.6854e-03 |

**偏移随细化逐次减半**（2.02e-2 → 1.05e-2 → 5.32e-3 → 2.68e-3），即一阶离散误差 \(O(h^1)\)。

### 3.2 各工况收敛阶与极限（`summaries`）

| 工况 | 观测阶中位数 | Richardson 偏移极限 | 近/远极限相对差 |
|---|---:|---:|---:|
| shallow:heave | 0.9763 | **-4.92e-05**（→0） | 1.02e-04 |
| shallow:sway | 0.9807 | -3.58e-05 | 7.49e-05 |
| medium:heave | 0.9821 | -2.90e-05 | 6.89e-05 |
| deep:heave | 0.9699 | 0.00e+00 | 3.70e-05 |
| 深水对照 heave/sway | 0.9726 | +5.22e-05 | — |

**结论**：偏移极限外推 \(\sim -5\times10^{-5}\to0\)，即偏移**完全归因于常数面元一阶离散误差**，
不是归一化 bug、不是求积限制、不是远场积分器。

### 3.3 深水对照（已独立验证的深水求解器，同网格）

| \(N\) | \(B_{\rm near}\) | \(B_{\rm far}\) | 偏移 |
|---:|---:|---:|---:|
| 32 | 2841.749 | 2784.700 | -2.0075e-02 |
| 64 | 2787.237 | 2758.177 | **-1.0426e-02** |
| 128 | 2754.470 | 2739.836 | -5.3130e-03 |
| 256 | 2736.749 | 2729.410 | -2.6819e-03 |

深水求解器在 64 面元同样 ~1%（**-1.04%**，与有限水深 **+1.05%** 量级相同、方向相反）→ 偏移是
**面板离散性质**，与有限水深核无关。

### 3.4 排除性证据

| 判据 | 实测 | 门限 | 结论 |
|---|---|---|---|
| 求积轴：Gauss 节点 4→16 偏移变化 | 5.05e-06（`node_sweep_offset_spread`） | 1e-4 | **非求积** |
| 远场积分器：中点 vs 面板求积差 | ~7.6e-05（`far_reading_difference`） | 1e-3 | **非振幅积分器** |

   `build_tables.py` 对 `docs/finite_depth_energy_identity/report.md` 做"表格=JSON 程序化生成"核验，
   **0/5 表匹配**（仅 64 面元行一致；32/128/256 行及 sway 表数值与 `convergence.json` 不符，如

   即原单"零手抄"承诺在 `report.md` 上**未兑现**；本补报一律以**已归档 JSON** 为准，report.md 的
   不一致数字不采信、不转抄。
2. **【如实保留·缺陷②】8 条回归测试 3 条 skip（未全绿）**：`test_report_tables_match_the_artifact_verbatim`
   等 3 条按 `outputs/finite_depth_energy_identity/convergence.json` 找工件，但工件实际归档在
   `docs/m2498/outputs/...`（路径错位）→ 被 skip；若路径修正，缺陷①的核验测试会**红**。本补报
   未改业务代码、未改测试（补报单纪律），仅如实记录。
3. **无实验/文献值**：有限水深附加质量的文献表（Yu & Ursell 类）本机不可得，未做数值对表；
   本单三条判据均为"解析一致性 + 独立离散一致性"，只能说"实现正确性"得到支持，不能说
   "对某船型/某工况的精度"。
4. **偏移是离散化常数**：\(B_{\rm far}/B_{\rm near}\) 恒为 ~1.01（与深度、运动、净空无关），是
   常数面元的一阶离散偏移而非物理差异；**不能**宣称"能量恒等式到 1%"，只能"闭合到约 1.06%"
   （64 面元）或 0.27%（256 面元）。
5. **适用范围**：常数水深、无流、线性势流；圆形截面、\(ka=0.6\)、\(f/a=2\)；\(\nu h\gtrsim100\)
   时应改用深水核（模态和收敛变慢）。
