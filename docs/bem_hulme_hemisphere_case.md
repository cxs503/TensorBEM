# BEM-HULME-HEMISPHERE：浮半球辐射/绕射（3D 自由面 Kelvin 边界面元）

算例池 `tensor_case_pool.id = 138`（`BEM-HULME-HEMISPHERE`，repo TensorBEM，容差 `<5%`）。实现入口 `src/tensorbem/benchmarks/hulme_hemisphere_case.py`（注册于 `tensorbem.benchmarks.case_pool`，并由 `benchmarks/verified/casepool_bem_hulme_hemisphere/run_case.py` 薄驱动调用）。本文每个数字都由运行工件 `results.json` / `benchmark.json` 程序化注入（`render_doc`），无手抄。

**本版变更（返修轮 m17337，针对 m17235 审计 F1–F5）**

1. 算例网格由 256 面元改为 1024 面元：256 面元的排水体积偏差 2.32% 越过 2% 几何前置门，且其「5% 达标」在独立裁判下退化为参考巧合（F1/F2）。1024 面元把几何偏差压到 0.59%，全频带最差误差降到 1.15%。
2. 新增第三方独立裁判（capytaine，4 级网格 + 两种外推变体构成的区间），作为门 G5/G6；并修正了审计脚本里 Richardson 外推的符号/标度错误（旧式给出低于阶梯全部实测值的「极限」，物理上不可能）——修正后同一 ka=2 heave damping 单元由 6.56% 变为 4.39%。
3. 实现搬进 `src/tensorbem/benchmarks/hulme_hemisphere_case.py` 并注册进 `tensorbem.benchmarks.case_pool`（`run_anchor`），驱动脚本退化为薄壳；运行工件、复现脚本、逐文件 sha256 落到 `evidence/`（F3/F5：面板数排版错误、空表、工件不入库一并修掉）。

## ① 问题与参考解出处

半径 a = 1 m 的浮半球，圆盘面与平均自由液面齐平，深水、无航速、线性势流。ρ = 1025 kg/m³，g = 9.80665 m/s²，入射波幅 A = 1 m；∇ = 2πa³/3 = 2.094395 m³，A_wp = πa² = 3.141593 m²；激励力标度 ρgAa² = 10051.8 N。无量纲频率 ka（k = ω²/g），约定 `exp(-iωt)`；A 以 ρ∇、B 以 ρω∇ 无量纲化（∇ 取解析值，不取网格体积）。

**参考解出处**：Hulme, A. (1982) *The wave forces acting on a floating hemisphere undergoing forced periodic oscillations*, J. Fluid Mech. **121**:443-463（球坐标 wave-free 多极展开，满足自由液面条件 dψ/dz − Kψ = 0 的球谐波族在半球的奇次 Legendre 谐波上投影配点）。

**诚实声明（零手抄约束的真实边界）**：Hulme 1982 的印刷表值在本沙箱**不可得**（出版商付费墙），因此参考值取仓内重推的多极级数 `tensorbem.analytic.hulme_hemisphere_radiation`（144 项），并以两条独立证据兜底：①级数自身截断自收敛（48/96/144 项阶梯，门 G4）；②第三方 BEM 代码 capytaine（Rankine 面元，`src/` 从不 import）在 4 级网格上重算并做 Richardson 外推给出与级数无关的独立极限（门 G5）。即「可信参考」≠「原表值」：缺原表就无法证明级数与 Hulme 1982 的归一化/相位约定一致，这一点在工件 `reference_provenance` 中留有原话。

## ② 方法与实现

求解器 `tensorbem.free_surface_solver3d`：深水 Kelvin（Havelock）Green 函数边界面元 + 常值面元；浸湿面由 `tensorbem.geometry3d.hemisphere_hull_mesh` 递归八面体细分给出（面板数 = 4·4ⁿ，水线顶点严格落在 z = 0，法向指向流体）。

流程：①几何前置校验（网格排水体积/水线面积 vs 解析值）；②装配自由面算子 `assemble_free_surface_operators_3d`（CHIEF 空场方程 `chief_points='auto'` 抑制不规则频率）；③辐射解（surge mode 0、heave mode 2，单位速度幅值）；④绕射解（迎浪 wave_angle = 0）得复数激励力；⑤对 Hulme 级数逐项求相对误差；⑥网格阶梯 64/256/1024 面元与 h 收敛；⑦capytaine 独立裁判（4 级网格 + Richardson 外推）；⑧CHIEF on/off 对照。

复现命令（`results.json.repro_cmd` 同源；集群多分片只是同一任务表的轮转切分）：

```bash
PYTHONPATH=src python3 -m tensorbem.benchmarks.hulme_hemisphere_case --out benchmarks/verified/casepool_bem_hulme_hemisphere/evidence --shard 0 --shards 1
PYTHONPATH=src python3 -m tensorbem.benchmarks.hulme_hemisphere_case --out benchmarks/verified/casepool_bem_hulme_hemisphere/evidence --merge
```

运行环境：Python 3.11.6，numpy 2.4.6，host 36cb7828dbd5，arch loongarch64。

### 误差判定（逐项回答）

- 算例池容差（<5%）：算例网格 1024 面元全频带最差 1.15%（B33_dimless @ ka=2）→ **是否 <5%：是**。
- 独立裁判（<5%，vs capytaine Richardson 极限）：最差 4.39% （2.000/B33_dimless）→ **是否 <5%：是**。
- 更严的平台通用线（<3%）：同一算例网格全频带最差 1.15% → **是否 <3%：是**。

### 失败模式与适用边界

1. **常数面元的几何地板**：半球是曲率面，常值面元以平面近似曲面，排水体积/水线面积有 O(h²) 偏差，这一几何误差是系数误差的下界（G2 把它钉在 2% 以内；256 面元时体积偏差 2.32%，故算例网格取 1024 面元）。
2. **ka > 2 的短波分辨不足**：ka 越大每波长面板越少，相位误差先于幅值误差增大；本算例把频带上限固定 ka = 2.0。
3. **不规则频率**：本水线圆的第一个内部 Dirichlet 特征频率在 ka ≈ 2.58，无 CHIEF 时该点附近条件数陡升；本算例频带避开该点，并用 CHIEF on/off 对照（5.3）确认抑制机制有效。
4. **参考解截断**：多极级数在 ka → 2 时收敛变慢（尾部比见 5.2）；本文用 144 项并把 96→144 漂移量化（G4）。
5. **参考出处**：印刷表值不可得（付费墙），G5 的第三方裁判是 <5% 结论的**约束性证据**；若日后取得原表，应先把原表与本级数逐点对照，再决定是否改判。
6. **capytaine 外推**：ka=1 的低频档残差比落在 (0,1) 之外（相邻网格差分近乎相等），处按「最细网格值」回退，方法列已逐项标注，不得当成已收敛极限。
