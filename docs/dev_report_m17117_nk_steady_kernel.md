## 1. 案例介绍（欠账陈述）

`tensorbem.neumann_kelvin` 是前进速度（Neumann-Kelvin，NK）稳态波阻的验证面。模块自述的
`KERNEL_STATUS` 是 **WITHHELD**：其波部分

```
G_W = (K/2π) PV ∫₀^∞ exp(-K u |z+ζ|) J₀(K u R) / (u-1) du
```

是**频域** Havelock 深水核（径向 J₀ 依赖、极点 k₀ = K），而稳态 NK 自由面条件要求的是
`α² = K k`（Kelvin 曲线 `k = K sec²θ`）。因此 `solve_nk_wave_resistance` 返回的是"数、不是证据"
（实测 Cw ~ 10⁸，m16830 已把该非物理行为登记为已知问题）。**判据（先于动手）**：
模块自带的裁判函数 `steady_free_surface_residual`，即相对残差
`|K G_z + G_xx| / (|K G_z| + |G_xx|) → 0`。

## 2. 怎么做的（方法/流程/关键设置）

1. **独立重推稳态核的精确谱表示**（不抄原文，逐项推导并自校）：
   `G = G_R + G_W`，`G_R = 1/(4πr) + 1/(4πr₁)`（Rankine + 镜像，`∂_z G_R|_{z=0} = 0`），
   `G_W = (1/(2π)²)∬ A(α,β) e^{i(αx+βy)} e^{-kh} dα dβ`，
   `A = α²/(k(Kk-α²))`，`h = -(z+ζ)`；其中幅值由
   `(Kk - α²)A = -∂_xx G_R` 与 `F[∂_xx G_R]_{z=0} = -α²/k` 定出。
   极点轨迹 `α² = Kk` 即 Kelvin 曲线 `k₀(θ) = K sec²θ`。
2. **极坐标约化**：`α = k cosθ`，令 `a = h - iR cos(θ-θ_R)`、`c = k₀a`，内层 k 积分解析可做：
   `G_W = -(1/(2π)²) ∫₀^{2π} Q(c)/a² dθ`，`Q(c) = 1 + c - c² e^{-c}(Ei(c) + iπ s)`（`|c|` 小），
   `Q(c) ~ -2/c - 6/c² - 24/c³ - …`（`|c|` 大），`s` 为 Lighthill 绕射符号。
3. **定位符号**：`s = sign(cosθ)`（下游半球 +1、上游半球 -1）是唯一使 θ 积分为**实数**的选择——
   同一 θ 与 θ+π 的配对在 `s` 反号时给出纯虚项乘 `i` 的实贡献。均匀取号（`s = ±1` 常数）会留下
   O(波幅) 的虚部（实测 Im/Re ~ 1，已记录在案）。
4. **实现**：新模块 `src/tensorbem/nk_steady_kernel.py`（`q_kernel` 双分支 + 重叠区一致性、
   `steady_wave_part`、`steady_green`、同口径裁判 `free_surface_residual`、`residual_table`）。
   分支切换点 `|c| = 25`，小 `|c|` 走 `scipy.special.exp1`，大 `|c|` 走渐近级数（`Re c = k₀h > 0`，
   故 `|arg c| < π/2`，级数有效）。
5. **对照实验**：候选核 vs 现行频域核，同一裁判、同一有限差分步长、同一点位；
   并做 θ 节点数收敛（2000 vs 12000 vs 32000）与步长收敛（1e-2 / 1e-3），以区分"离散误差"与"系统性误差"。

## 5. 注意点（坑与局限）

- **为什么不是一次修好**：推导在谱空间是严格的，但 θ 约化后残差 2e-2…1.8e-1 且**不随** θ 节点数
  （2000→32000 变化 < 4e-10）与差分步长（1e-2→1e-3 变化 < 3%）改善 ⇒ 误差是**系统性的**，
  在"局部项记账"（`1 + c - c²e^{-c}Ei(c)` 与 `-∂_xx G_R` 的抵消）而非离散化。
- **符号陷阱**：`s = 常数` 的均匀绕射使核变复、上游/下游幅值镜像（同一包络），看上去"对称且合理"，
  其实是丢掉了辐射条件；只有实部校验才会立刻暴露。
- **不能用它做证据**：候选核未接入 `solve_nk_wave_resistance`，`KERNEL_STATUS` 仍是 WITHHELD。
  测试 `test_free_surface_referee_is_not_yet_satisfied` 是**故意钉住的 FAIL**，防止后续单子静默宣称已修好。
- 适用范围：深水、线性 NK、无限水深谱；有限水深（John 特征级数）不在此列。

## 6. 误差判定

- 关键量 = 自由面裁判相对残差，基准 = **恒等式成立即 0**（不是文献值）。
  候选 1.8e-1 / 1.0e-1 / 2.0e-2，对照目标 <1e-3：**均未达标，全部 >3%** ⇒ 显式回答：**否，未 <3%**。
- 结论：**honest FAIL**。能力级别**维持 WITHHELD**；本单增量是"把欠账从'核是错的'推进到
  '候选核的符号/实数性/收敛性已解决，剩余误差定位在局部项记账'"，并留下可直接续做的工装与基线。
- 下一步（建议）：在 `R→0, h→0` 极限下**整体**求谱积分的局部项（而不是逐项拼装），
  或改用经典 Havelock 单积分形式（`|θ| ≤ π/2` + 不完全积分），两者都用同一裁判验收。
