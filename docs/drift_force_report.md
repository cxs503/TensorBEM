# 二阶平均波浪漂移力：近场压力积分 / Maruo 远场动量通量 / 直墙解析锚（m5242）

**结论先行**：二维竖直直墙（全反射）算例上，近场二阶压力积分与远场辐射应力（Maruo 动量）两条
完全独立的路径都以远优于 3% 的精度钉住闭式解析锚 `Fbar = rho g a^2/2`；面板收敛外推残差
8.339e-05 < 2%。三维 Maruo 远场（Kochin）通道**未通过** `(ka)^3` 渐近门 —— 未约化的数值通量积分
在辐射半径 kR 上不收敛（见第 ⑤、⑥ 节），按纪律记为 **honest FAIL**，未做任何粉饰或覆盖。

## ① 案例介绍（物理背景 / 几何 / 参数）

规则波中的固定物体受二阶时间平均水平载荷，其首阶（与波幅平方成正比）部分即平均漂移力。
量级上：一阶力 ∝ a，二阶漂移力 ∝ a²，因此低频、大波幅海况下它支配系泊/动力定位载荷。

**硬基准案例**：二维竖直直墙，位于 `x = 0`，流体占 `x < 0`，无限水深，入射波沿 +x 传播、
波幅 a，全反射（反射系数 1）。动量平衡给出单位长度平均漂移力

    Fbar = rho * g * a^2 / 2

推导：深水中每支前进波携带 `S_xx = E/2 = rho g a^2/4`；入射与反射各贡献一份且无波透过直墙，
故净 x 动量通量 = `rho g a^2/2`。近场同值：体项 `int_{-inf}^{0} -(1/2) rho <|grad phi|^2> dz
= -rho g a^2/2` 加水线项 `+(1/2) rho g <zeta_r^2> = +rho g a^2`。

参数表（程序化写入）：

| 量 | 值 |
|---|---|
| 波幅 a | 1.0 m |
| 圆频率 ω | 1.0 rad/s |
| 波数 k = ω²/g | 0.101937 1/m |
| 周期 T | 6.2832 s |
| 密度 ρ | 1025.0 kg/m³ |
| 重力 g | 9.81 m/s² |
| 解析锚 Fbar | 5027.6250 N/m |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

三条互不依赖的路径，全部落在 `src/tensorbem/drift_force.py`，由
`tensorbem.benchmarks.drift_force_study` 一键运行（JSON + 4 图）：

1. **近场（Route 1）**：在**瞬时湿表面**上做二阶压力积分
   `F(t) = int_{S(t)} n [ -rho*phi_t - (1/2) rho |grad phi|^2 ] dS`，`Fbar = (1/T) int F dt`
   （n_time = 64 个时层）。每个时层的积分上限取瞬时波面 `z = zeta(0,t)`，因此移动水线项
   由积分自动携带（不是手工加项）；另加静水补偿 `-(1/2) rho g eta^2`（见 ⑤ 坑 1）。
   深度截断 `z_bottom = -8/k`，截面节点向自由面加密（`z = z_bottom (1-u)^2`）。
   该路径**完全没有使用 `rho g a^2/2`**——它只把精确一阶场（驻波解）当作输入。
2. **近场（Route 1b，代数互证）**：教材形式
   `Fbar_x = int_{S0} (1/2) rho <|grad phi|^2> n_x dS - (1/2) rho g <zeta_r^2> n_x`
   （`n_x = -1`，物体外法向指向流体），两项分别独立求积以便逐项审计。
3. **远场（Route 2）**：远场两站位（x = -30/-40 m 与 -60/-80 m）对波面做走行波复数最小二乘
   分解得到入射/反射幅值 `A_±`（无任何压力积分进入），再用深水辐射应力平衡
   `Fbar_x = (rho g/4)(A_i^2 + A_r^2 - A_t^2)`（全反射时 A_t = 0）。
4. **三维 Maruo 远场（Route 3）**：`maruo_far_field_drift_3d` 由 Kochin 值重构远场波面
   `zeta_s ~ -beta0 * exp(i(kR - pi/4)) * K(theta)`，`beta0 = (k^2/(2 omega)) sqrt(2/(pi kR))`，
   叠加入射波后在半径 kR 的大圆上做 x 方向动量通量积分
   `Fbar_x = -(rho g/4) int |zeta_s + zeta_i|^2 R cos(theta) dtheta`。
5. **收敛门（Route 4）**：面板数 50/100/200 三档 + Richardson 外推（等细化比），外推残差 < 2%。

工具链：NumPy + matplotlib(Agg) + pytest；本报告与 JSON 中全部数字由
`python3 -m tensorbem.benchmarks.drift_force_study` 程序化生成，零手抄。

### 三维 Maruo 远场探针（Route 3，honest FAIL 证据）

长波偶极型 Kochin 假设 `K(theta) = (ka)^2 cos theta`（悬垂直圆柱 ka→0 的水平偶极主项）：

| 圆柱半径 a [m] | ka | Fbar_x（kR=100 档，任意单位） | 四个 kR 档相对离散度 |
|---|---|---|---|
| 0.05 | 0.05 | 0.526 | 298 % |
| 0.10 | 0.10 | 2.102 | 298 % |
| 0.20 | 0.20 | 8.409 | 298 % |
| 0.40 | 0.40 | 33.635 | 298 % |
| 0.80 | 0.80 | 134.539 | 298 % |

关键事实两条：(i) 该假设下 `int |K|^2 cos theta dtheta ≡ 0`（前后对称偶极无净 x 动量通量），
漂移力**全部**来自入射/散射干涉通道；(ii) 该通道的数值通量在 kR 上振荡（相位 ~exp(-2ikR)）、
不收敛，四档离散度 ~100%。故 `(ka)^3` 门**无法用本实现评估**：名义斜率 2.00 只是不收敛
序列的伪值，判据记为 **FAIL（不可评估）**，未做任何放宽。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

**坑 1（因子 3 事故）**：直接把 `q = -rho phi_t - (1/2) rho |grad phi|^2` 积到瞬时波面，得到
`3 rho g a^2/2`，正好是解析锚的 3.0 倍。根因：`q = p + rho g z`，积到瞬时表面时会多算
`rho g <eta^2>/2`。补上静水补偿 `-(1/2) rho g <eta^2>`（等价于恢复 `-(1/2) rho g zeta_r^2` 水线项）
后误差降到 0.02%。任何近场实现都必须显式出现这一项，否则是 O(1) 误差而非 O(h) 误差。
**坑 2**：`int |K|^2 cos theta dtheta ≡ 0` 对前后对称物体成立，所以不能把「散射能量通道」当
漂移力主项；小物体漂移力几乎全部来自干涉（shadow）项 —— 这正是必须做 Maruo 核解析约化
（`(1+cos theta)` 型）而不能依赖原始通量积分的原因。
**适用范围**：无限水深、固定物体（无一阶运动）、单一频率、零航速。**不覆盖**：二阶速度势
（慢漂/差频）、航速项、有限水深、多向不规则波。
**局限（显式记录）**：三维远场通道未收敛；圆柱 `(ka)^3` 渐近门未评估；三维 Kochin 值来自解析
偶极假设，尚未与 `tensorbem.free_surface_solver3d.kochin_function_3d` 的 BEM 求解输出耦合。

## ⑥ 误差判定（逐项显式回答）

| 判据 | 目标 | 实测 | 是否达标 |
|---|---|---|---|
| 近场 vs 解析锚 `rho g a^2/2` | < 3% | -0.0190% | **是** |
| 近场教材形式 vs 解析锚 | < 3% | -9.56e-08 | **是** |
| 远场（动量/走行波）vs 解析锚 | < 3% | 7.2e-16 | **是** |
| 面板收敛外推残差 | < 2% | 8.339e-05 | **是** |

「关键量是否 < 3%」的显式回答：**二维直墙基准上是 —— 近场 ≤ 0.02%、远场 ≈ 1e-15；
三维圆柱渐近判据不是（不可评估），已如实记为 FAIL 且未覆盖。**
