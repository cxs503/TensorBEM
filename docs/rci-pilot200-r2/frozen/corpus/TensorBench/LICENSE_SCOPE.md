# TensorBench License Scope

## Project software license

The Apache-2.0 license in the repository root applies to original TensorBench software code and project-authored software documentation, unless a file or component carries a more specific notice.

## Assets not automatically covered

The root license does **not** automatically relicense or grant rights to:

- third-party benchmark suites, test harnesses, or reference implementations;
- datasets, source documents, scientific measurements, and benchmark input files;
- papers, publisher PDFs, figures, tables, and excerpts;
- images, videos, audio, CAD/mesh/geometry assets, and other media;
- model weights, checkpoints, prompts, or externally supplied evaluation tasks;
- customer, partner, institutional, or otherwise restricted data;
- dependencies and vendored components governed by their own licenses.

Each imported asset must retain its original license and attribution requirements. Where rights are unclear, do not redistribute the asset; record provenance and use a link or retrieval instruction where appropriate.

## Required provenance for benchmark assets

A benchmark contribution should record, as applicable:

- source URL or originating project;
- author, owner, or publisher;
- license or terms of use;
- version, release, commit, or retrieval date;
- modifications made by TensorBench;
- redistribution permission and required attribution;
- whether the asset is public, restricted, or generated internally.

## No blanket rights statement

The presence of Apache-2.0 at the repository root must not be interpreted as permission to redistribute every file, dataset, benchmark workload, or result artifact stored alongside TensorBench.

When adding assets with separate terms, include a local NOTICE or metadata record that makes the boundary visible.
