# TensorFVM 粘性算子耗散性定因与能量相容装配（native compatible viscous operator）

## ① 案例介绍
仓库长期挂 `xfail(strict=True)` 开放缺陷 `test_two_cell_skew_viscosity_must_dissipate`：两单元非正交网格上
离散粘性算子会**造动能**。几何族 `two_tetrahedra(skew)`：两共享面四面体，5 顶点 / 2 单元 / 7 面，
全部静止 Dirichlet，μ=ρ=1，单元 0 速度规定为 (1,0,0)；skew∈[0,1] 共 41 点（skew>1 面定向非法）。
判据：动能变化率 E = uᵀA u（A 为融合槽位矩阵，E<0 = 耗散），以及对称部分特征值证书。

## ② 怎么做的
1. 给 `NativeViscous3D` 增加**逐面非正交修正阻尼** `correction_damping∈[0,1]`（默认 1.0 → 与 HEAD 逐位相同），
   用于检验「非正交修正是造能主因」这一既有归因（m2431 / report 2468）。
2. 新建 `src/tensorfvm/native_compatible_viscous3d.py`：把同一物理量按**能量（Galerkin）形式**装配
   `K = Σ_c 2 μ_c V_c [Σ_i S_iiᵀS_ii + 2Σ_{i<j} S_ijᵀS_ij]`，`S = sym(∇u)`（可去偏）。
   该矩阵是平方和，故对任意网格、任意 u 恒为**对称半正定**，耗散性由构造保证；边界数据经
   `compatible_boundary_source` 线性进入，与 K 严格配对。
3. 工具链：`scripts/audit_compatible_viscous_dissipativity.py`（41 点扫掠 → JSON/CSV/表/PNG）+ pytest
   （`tests/test_native_compatible_viscous3d.py`，6 条用例）+ matplotlib。算力开销可忽略（2 单元）。

## ⑤ 注意点与局限
- **归因修正**：m2431 把造能归给非正交修正（"延迟修正恒耗散"）。本单用逐面阻尼扫掠证明该结论在其自己的几何族上不成立：
  α=0 仍造能，且 α 越小失效面越大 → 主因是融合装配 `D A G` 的**面/能量对偶性（sum-by-parts）不成立**，修正项只是把它放大。
- **默认路径未改**：`correction_damping=1.0` 与 HEAD 矩阵逐位相同（有回归用例），仓库唯一 strict xfail 保持红灯（诚实保留欠账）。
- **只认证耗散性，不认证标度**：native 单元梯度模板未做体积归一（本单实测其仿射场梯度偏离解析值，最大 6.17），
  故 K 的绝对标度/与 −∇·(2μS) 的一致性**未认证**，需另单标定后才能进求解器；hexa 插值网格上的仿射一致性
  与二阶收敛用例因同一原因从本单测试集中撤下（如实留白，非粉饰）。
- K 的模板是两跳（单元梯度用邻居的邻居），引入求解器需评估稀疏度/带宽。

## ⑥ 误差判定
本单判据是**符号/特征值证书**而非与解析解的相对误差，无文献基准可比，故不适用「<3%」条款（显式声明，不含糊）：
- 相容装配 E ≤ 0：41/41 点满足，最坏值 -3.935422（距 0 的余量 100%）。
- 相容装配 λmin(K) > 0：41/41 点满足，最小值 +0.360339。
- 若把「首个失效几何」当关键量：本单 λmin 交叉点 0.975/86.22° 与 m2431 报告数值一致到所列有效位（0.000）。
- 未认证项：标度/一致性（见⑤），明确不计入「<3%」。
