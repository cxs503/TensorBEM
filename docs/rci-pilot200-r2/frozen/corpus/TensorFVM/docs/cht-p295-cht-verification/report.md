## 1. 案例介绍

## 2. 怎么做的

**界面耦合（单场）**：流体与固体共用一张网格，每个面用距离加权调和平均导热系数`C_f = A_f / (s_P/κ_P + s_N/κ_N)`，界面热流是**单一未知量**，故 q_fluid=q_solid 由构造成立；审计再用两侧各自的 κ 与半格距独立重建界面温度与热流，把「由构造成立」变成「数值可证」。
**界面耦合（分块，真正会失败的那条）**：钢块（水侧 Robin + 界面 Neumann）与冰块（界面 Dirichlet + 空气侧 Robin）分别求解，按 Dirichlet-Neumann 迭代交换信息。交换方向按阻力比选取（R_steel/R_ice≈0.045，向冰块喂温度、向钢块喂热流才收缩），界面热流残差 = 末次耦合扫掠的界面热流变化率——它是耦合迭代的性质，因此可以失败。
**Stefan 焓法**：守恒型有限体积 + 后向 Euler；未知量取温度，焓 `h(T)` 经窄两相带`[T_f-ΔT, T_f+ΔT]` 精确反演（`c_eff = c_s + L/2ΔT`）。非线性用**焓变量 Newton**求解：两相格的巨大表观热容在 Jacobian 对角上表现为 `dT/dh = 2ΔT/L`，条件数良好。前沿位置取焓（体积平均固相分数）重建，是能量守恒估计；另报几何 `f_l=1/2` 穿越点作交叉核对。
**积冰表面热平衡**：五项（对流 / 蒸发升华 / 长波辐射 / 飞沫显热 / 冻结潜热）按公开关联式独立实现（平板受迫+自然对流立方和合成、Chilton-Colburn 传质类比、Idso-Jackson 晴空长波），与 W4-N08 存档的 reference_panel 同工况逐项比对，再叠加 CHT 给出的结构导热项。

## 5. 注意点与局限

1. **焓法初始条件必须落在液相线上**：把初始温度取成 T_f（两相带中心）会让初场已含一半潜热，前沿重建出现常数偏置（实测偏小 ~31%）。改为 T_f+ΔT 后偏差降到 0.1%。
2. **窄两相带 + Picard 迭代会卡死在液相线**：`c_eff` 在带边界跳变，Picard 在 c_s 与 L/2ΔT 之间振荡（40 次不收敛）。改成**焓变量 Newton**（对角项为 dT/dh=2ΔT/L）后 5–7 次收敛。
3. **界面温度不能用距离线性插值重建**：k 跳变时线性插值把界面温度插错位置（本算例残差 96%）。必须用调和平均面导热量反解 q=(T_P-T_N)/(s_P/k_P+s_N/k_N)，再各自单侧微分。
4. **Dirichlet-Neumann 交换方向决定收敛**：向冰块（大阻力）喂热流、向钢块喂温度才收缩；反方向放大 R_ice/R_steel≈20 倍，必然发散。
5. **W4-N08「基底绝热」假设的适用域**：设计工况（T_sea=T_f）偏差仅数个百分点，但海侧水温升高时冰层自身 0.0136 m²K/W 的热阻主导，偏差迅速超 30%——该假设只在接近冰点的海况下成立。见 §3.3 敏感性表。
6. **通道 (a) 的关联式不确定度**：Eckert-Soehngen(1952) 与 Churchill-Bernstein 本身在 Re=40 相差 ~6%，故 10% 判据的物理含义应理解为「落在实验关联式自身散布带内」，不应读作 10% 的高精度验证。
7. **极坐标 CHT 路径原本是死路**：`periodic_overlap_matrix` 的逐段推进循环在等分划（n_from=n_to）时 floor 舍入使 `pos` 不再前进 → 死循环，`ConjugateCylinder` 根本无法构造，这也是该路径长期无人验证的原因（CHT_SLOW 默认关闭）。改为按目标格枚举重叠源格后，48×48/48×32/48×96/30×44 均在毫秒级返回且行和=1。
8. **流体/固体能量算子的符号约定不一致**：矩阵装配成 `-(M T)=b` 形式，但 Dirichlet 右端项按 `+M T=b` 写，导致纯导热环套的温度场整体变号（壁面节点被 BC 覆写，所以错误藏在内部），等温壁 Nu 达 326.9。右端取负后纯导热壁面热流与解析解吻合到 0.01%。固体块的 Neumann 项与 `solve_solid` 的符号同源，一并修正（绝热界面应回到 T=1，修复前给 T=−1）。
9. **`one_sided_derivative` 的 Lagrange 系数写错**：旧系数不能精确重现线性函数（`a1 s1 + a2 s2 = 1.157 ≠ 1`），使壁面热流虚高约 16%（等分划 s2=2s1 时）。改为正确的非均匀三点系数后，线性/二次多项式精确重现。
10. **变异注入**：Stefan 通道把潜热 L→0，前沿误差由 0.1% 涨到 400%+；冰-钢通道把耦合扫掠截断到 2 次，界面热流残差由 1e-11 涨到 2.8%（>1%）。两条 H 判据均为「物理/耦合承重」而非恒真断言。

Eckert-Soehngen 3.1369，偏 +24.52%；Churchill-Bernstein 3.3639，偏 +16.12%），超出 10% 判据。诊断（**假设，未证伪**）：极坐标能量方程为方位角一阶迎风 + 5° 方位分辨率，数值扩散抬高壁面梯度；同一求解器的纯导热环套已吻合到 0.01%，说明扩散算子本身无误，残余误差集中在对流离散与网格分辨率。修复方向：二阶延迟修正或方位加密，超出本节点预算，如实报 FAIL。另：本工况 Cd=1.93，显著高于文献 Re=40 的 ~1.5，流场力归一化亦待审计（不影响本通道的 Nu 判定，但提示极坐标算子还有未清问题）。
