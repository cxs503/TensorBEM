# Ursell 潜没圆柱：精度包络（频率 × 潜深 × 面元）

**性质**：验证欠账收口（`docs/ursell_error_budget.md` 局限 2 明写「仅审计了一个 (ka, a/f) 点，ka ≥ 1 未验证」）。本文件与图、表全部由 `python -m tensorbem.benchmarks.ursell_precision_envelope --report` 从 `docs/ursell_precision_envelope/envelope.json` 生成，数字零手抄。

## 1. 案例与参数

| 量 | 值 |
|---|---|
| 圆柱半径 a | 1.0 m |
| 潜深 f | f/a ∈ {1.1, 1.2, 1.5, 2, 3} |
| 无量纲频率 ka | {0.4, 0.6, 0.9, 1.2, 1.6} |
| 面元数 N | {32, 64, 128, 256} |
| ρ, g | 1025 kg/m³, 9.80665 m/s² |
| 参考解 | Ursell 多极子闭式解（`analytic.py`，与被测面板代码零共享）+ MFS 交叉校验 |

无量纲系数 $A^\ast = A/(\rho\pi a^2)$、$B^\ast = B/(\rho\pi a^2\omega)$；两者都用量纲尺度归一，而不是「相对参考值」，因为 $A$ 在 $f/a\approx1.13$ 变号（$A(1.10)=-238$、$A(1.20)=+1160$ kg/m），相对误差在那附近没有意义。

## 2. 方法与判据

对每个 (ka, f/a) 做面板加密序列，逐点计算：与多极子解的相对误差、观测收敛阶 $p=\log_2(\varepsilon_N/\varepsilon_{2N})$、$N\varepsilon$ 常数性（一阶收敛的签名）、近场/远场阻尼比（辐射条件）、MFS 独立解与多极子的一致程度（参考解本身的可信度）、条件数与残差。

判据两条：面板误差 ≤ 0.01（本仓 Ursell 基准的既定门槛）与 ≤ 0.03（平台通用门槛）；并回答「达到门槛所需的最小面元数」。

最差组合：ka = 0.4、f/a = 1.1，$|\Delta A|/(\rho\pi a^2)$ = 2.555e-02（2.56 % of displaced mass）。
## 5. 注意点与局限

1. **f/a ≥ 1.5 时是一阶收敛**：观测阶 $p_A$ 落在 [0.92, 1.17]，与常数面元的固有阶一致，所以在整个 ka 带（0.4–1.6）上都没有换阶机制。
2. **f/a ≤ 1.2 的近水面角点不是一阶、甚至不单调**：同一带内 $p_A$ 落在 [-1.66, 1.67]，在 (ka, f/a) = (0.9, 1.1)、(0.9, 1.2)、(0.6, 1.1) 处出现 $p_A<0$（加密反而暂时变差）。这是本文件最重要的负面结果：**该角点上「128 面元约 1 %」的经验规律不成立**，（ka=0.4, f/a=1.1）在 N=256 时仍有 2.6 % 的位移质量归一误差。原因未做归因（候选：常数面元对近水面强奇性核的一阶表示在低 ka 时不适用），取用时应当加密到 256 以上并做序列检查，而不是只看单点。
3. **辐射条件**：近场/远场阻尼比在全部算例中落在 [1.0026, 1.0218]，随 N 单调收敛、与 ka、f/a 基本无关；它是一阶离散的常数偏移（已由 `docs/finite_depth_energy_identity/report.md` 归因），不是物理差异，故本文件不把「能量恒等式到 0.1 %」当判据。
4. **参考解在 f/a ≥ 1.5 上被独立确认**：MFS（独立离散，与被测面板代码共享核但不共享离散）与 Ursell 多极子解的最大相对偏差 5.54e-03，比被测量的面板误差小 1–2 个量级。
5. **近水面角点的参考解只靠多极子**：$f/a\le1.2$ 处同一 MFS 交叉校验偏差最大到 5.51e-01（24 个源不足以分辨贴近自由面的强相互作用），因此该角点的数字应读作「面板 vs 多极子」，多极子级数截断本身未被独立确认。这是本文件在该角点上的置信度上限，不向下游宣称更高。
6. **$A$ 的变号陷阱**：$A$ 在 $f/a\approx1.13$ 过零（$A(1.10)<0<A(1.20)$），相对误差在那里发散且无物理意义；§4 的判定一律用位移质量归一 $|\Delta A|/(\rho\pi a^2)$，§3.1 同时给出相对误差供对照。下游代码引用本表前应做同样的归一化。
7. **适用范围**：二维、无限水深、常潜深、无航速、线性势流，只扫圆形截面。三维、有限水深、航速（Kelvin/Havelock 核）与真实船体剖面不在覆盖范围内。
8. **成本**：单点 128 面元约 11 s、256 面元约 43 s（单核、空载），整张 25 格 × 4 面元网格用 7 进程在负载机器上约 20 分钟；未使用集群。
