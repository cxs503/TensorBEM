## 1. 案例介绍

`docs/verification.md` §1（2026-10-24 审计表）把三项能力列为「后续」，即当时**未实现**：

| 缺口 | 原文表述 | 本次状态 |
|---|---|---|
| 多连通域（>1 条边界环） | 「圆环径向导热，u=A log r+B —— 后续：需多边界组件」 | **已实现并验证** |
| 混合 Dirichlet/Neumann 边界 | 「混合边界方形导热、纯 Neumann 问题 —— 后续：需相应边界条件求解器」 | **已实现并验证** |
| 纯 Neumann 问题（相容条件+常数度规） | 同上 | **已实现并验证** |

原 `tensorbem.solver` 只能解**单环、全 Dirichlet** 内域问题（`solve_laplace_dirichlet`）；
外域 Neumann 是另一套（`solve_laplace_exterior_neumann`）。本工作补的是内域
（有界域）的混合/纯 Neumann 与多连通三格。

### 1.1 物理与数学提法

二维 Laplace 方程 $\nabla^2 u = 0$，常数面元 + 中点配点的直接边界积分方程：

$$\tfrac12 u_i + \sum_j H_{ij} u_j - \sum_j S_{ij} q_j = 0,\qquad q=\partial u/\partial n$$

其中 $S$ 为单层矩阵、$H$ 为双层矩阵，二者均用**直线面元解析积分**（与仓库既有
`kernels.integrate_single_layer_panel / integrate_double_layer_panel` 同一套公式），
所以本工作没有引入任何新的数值积分误差源。

未知量分配：Dirichlet 面板上 $u$ 已知、$q$ 未知；Neumann 面板上 $q$ 已知、$u$ 未知。
每面板一条方程 → 方阵。法向约定沿用 `PanelMesh` 的 $n=(t_y,-t_x)$：外环逆时针
（法向朝外），孔环顺时针（法向朝孔内）。

### 1.2 几何与参数表

| 参数 | 值 |
|---|---|
| 圆环内半径 $a$ | 1.0 m |
| 圆环外半径 $R$ | 2.0 m |
| 径向解 | $u = A\log r + B$，$A=1.0$，$B=0.5$ |
| 精确法向导数 | $q = A\,(x n_x + y n_y)/r^{2}$ |
| 参考长度 $L$ | 1.0 m（见 §5.1：必须避开环半径） |
| 圆盘（光滑边界混合）半径 | 1.5 m |
| 光滑边界混合解 | $u = x$，$q = n_x = \cos\theta$ |
| 方形（角点混合）边长 | 1.0 m，$u = x^2-y^2$ |
| 面板数 | 每环/每边 16, 32, 64, 128 |
| 边界离散 | 内接正多边形（顶点落在圆上），直线常数面元 |

## 2. 怎么做的

1. **先读后写**：先确认 `solver.assemble_matrices` 的符号约定（`S q = (1/2 I + H) u`），
   新的 `mixed_bc.solve_mixed` 在其基础上重排为 $(\tfrac12 I+H)u - Sq=0$ 并按边界类型分块，
   保证「全 Dirichlet 单环」时与既有求解器**逐位一致**（有测试钉住，见 §4）。
2. **多环面板容器**：`PanelSet`（起点/切向/法向/长度/环号）不依赖 `PanelMesh` 的
   单环 CCW 校验（孔的顺时针环会被 `PanelMesh` 拒绝）。
3. **纯 Neumann 的正规处理**：无 Dirichlet 面板时系统矩阵奇异（常数向量在零空间），
   用一次 SVD 同时取右零空间（常数，用于去掉度规）、左零空间（用于给出**离散相容残差**
   $\lvert w^T b\rvert/(\lVert w\rVert\lVert b\rVert)$），再以最小范数伪逆求解；
   结果显式返回 `rank_deficiency`、`solvability_residual`、`gauge_removed`，
   而不是悄悄给出一个不可解问题的"答案"。
4. **解析基准**：所有误差都在**同一批面板中点**上对解析解求值（不用第二个离散解当真值）。
5. **收敛研究**：每环/每边 16→128 面板，输出 JSON；`summary.md` 与三张图由脚本从 JSON
   重生成，报告里的数字全部来自 `results.json`，零手抄。
6. **负控**：故意破坏纯 Neumann 相容条件（孔环通量 ×1.5）→ `solvability_residual`
   从 $3.0\times10^{-4}$ 升到 $2.5\times10^{-2}$ 量级（§3.4），说明该指标真在起作用。

## 4. 误差判定（逐项 vs 基准，是否 <3%）

| 关键量 | 基准 | 128 面板误差 | <3%？ |
|---|---|---|---|
| 圆环全 Dirichlet 通量（双环） | 解析 $q=A(xn_x+yn_y)/r^2$ | 2.142e-4（0.021%） | **是** |
| 圆环混合 Dirichlet 侧通量 | 同上 | 7.420e-5（0.0074%） | **是** |

| 圆环纯 Neumann 势（去常数） | 同上 | 2.716e-4（0.027%） | **是** |
| 圆盘混合（光滑边界交界）通量 | 解析 $\cos\theta$ | 3.407e-4（0.034%） | **是** |
| 方形混合（角点交界）通量 | 解析 $2x n_x-2y n_y$ | 5.902e-3（0.59%） | **是**（但收敛仅半阶，见 §5.2） |

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

### 5.1 参考长度 $L$ 撞上环半径会让均值通量模失效（真坑，已用测试钉住）

圆环外半径 $R=2$，仓库默认 `REFERENCE_LENGTH = 2.0`。此时 $L=R$，单层算子对**常数通量模**
（$\oint q\,ds$ 方向）出现零特征值——这正是 `solver.py` 注释里写的"对数容量退化"
（logarithmic capacity，判据是 $G$ 取 $-\frac{1}{2\pi}\log(r/L)$ 时圆的容量半径恰为 $R$）。
后果非常隐蔽：**条件数只有 609（远低于 `_MAX_CONDITION=1e13` 的既有护栏），
但通量 L2 误差停在 9.4e-2 不再收敛**：

| L | 通量相对 L2 | 外环通量 | κ |
|---|---|---|---|
| 0.25 | 7.968e-4 | 8.6e-4 | 350 |
| 0.50 | 8.082e-4 | 9.3e-4 | 230 |
| **1.00** | **8.451e-4** | **1.08e-3** | 111 |
| 1.50 | 9.678e-4 | 1.6e-3 | 66.5 |
| **2.00（=R）** | **9.423e-2** | **2.21e-1** | 609 |
| 3.00 | 7.034e-4 | 2.6e-4 | 88.1 |

判据：内环误差在 $L=2$ 时仍正常（8.34e-4），只有外环坏——说明这是**单环的均值通量模**
退化，不是整体装配错误。本工作的基准统一取 $L=1.0$，并用
`test_reference_length_at_loop_radius_is_degenerate` 断言"坏点误差 > 好点 20 倍、
且只有外环坏"。**建议**：既有 `_MAX_CONDITION` 护栏抓不到这种量级（κ~10²），
后续可考虑对 $L$ 与几何特征半径的比值加诊断（本次未改 `solver.py`，避免影响已合并行为）。

### 5.2 90° 角点上的边界条件交界处：局部误差不随网格衰减

方形混合算例的误差**几乎全部集中**在 Dirichlet/Neumann 交界的两个角点面板：

| 每边面板 | 全 Dirichlet 侧误差 | 去掉交界面板 | 交界面板最大绝对误差 |
|---|---|---|---|
| 8 | 2.374e-2 | 1.136e-2 | 9.495e-2 |
| 16 | 1.669e-2 | 7.374e-3 | 9.508e-2 |
| 32 | 1.180e-2 | 5.065e-3 | 9.508e-2 |
| 64 | 8.343e-3 | 3.541e-3 | 9.507e-2 |

交界面板的误差**与 h 无关**（≈9.5e-2，占该侧精确通量尺度的 ~4.8%），
这是角点处边界条件类型突变 + 90° 几何的经典局部奇异效应，不是本实现的符号/装配错误：
把同一个边界条件切换放到**光滑闭环**（`circle_mixed`，圆盘上下半各一半）上，
误差立刻恢复二阶（1.94e-2→5.07e-3→1.32e-3→3.41e-4）。另外，该仓库既有的
`square_separable`（纯 Dirichlet 方形）在 128 面板的通量误差为 2.90%（`docs/verification.md`），
同类角点限制早已存在——本工作只是把它在混合边界下定位到了具体面板。

适用范围/建议：光滑或分段光滑外形的混合问题可直接用；若外形含角点且角点是边界条件
切换点，应（a）在角点附近局部加密，或（b）改用不连续/渐变面元与角点奇异基函数。
本次未实现 (a)(b)。

### 5.3 其它

- **纯 Neumann 的"解"没有绝对基准**：只能在与常数无关的范数下比较；本实现返回最小范数、
  零常数度规的代表，并显式回报 `gauge_removed`，避免把"差一个常数"当成错误或掩盖错误。
- **单层算子的对数容量退化对多连通域同样存在**（§5.1），多环并不缓解反而更容易撞上。
- **仅内域（有界域）**：外域混合边界未实现；`solve_laplace_exterior_neumann` 仍是独立路径。
- **常数面元**：解本身是分片常数近似，通量在面板上分段常值，因此角点/奇异性处的点值误差
  不能指望去到二阶。
- 计算量：解析装配 $O(n^2)$ 次 Python 级核函数调用，128 面板/环（共 256 面板）单次装配约数秒；
  基准脚本对同一几何做了矩阵缓存，五个算例共享。
