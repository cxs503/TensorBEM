# 3-D 自由液面 BEM 的 xOz 镜面对称减半：精确性证明与 Hull 收敛收益

> 本文件的全部表格由 `python -m tensorbem.benchmarks.symmetry_reduction_study` 程序化生成（零手抄），原始记录见 `docs/symmetry_reduction_3d.json`。

## 1. 为什么需要它

三维自由液面求解器组装稠密复矩阵：内存 O(N²)、直接解 O(N³)。Hulme 漂浮半球、潜没球体、一般对称船体都关于纵中剖面 xOz 对称，此前 `docs/marine_bem_benchmarks.md` §5.3 明确把「对称面减半」列为未实现能力。本模块 `tensorbem.symmetry3d` 把它补齐：镜像面元作为额外源列，半域未知量、折叠核，**代数上与原全域系统等价**。

## 2. 折叠核的构造

零航速深水 Green 函数只依赖水平距离 R 与 z、ζ，故 G(Rp, q) = G(p, Rq)。对具确定奇偶性 s 的势场 φ(Rp) = s φ(p)，边界积分方程限制到半域后为

```
H_eff(p,q) = H(p,q) + s·H(p,Rq),   S_eff(p,q) = S(p,q) + s·S(p,Rq)
```

即 n 个半域面元 × 2n 个（原+镜像）源列，核求值 2n² 而非 4n²。刚体六自由度的奇偶性：纵荡/垂荡/纵摇 +1，横荡/横摇/艏摇 −1。全表面上的压力型积分按因子 (1 + s_i s_j) 由半域积分还原：同奇偶类翻倍，跨奇偶类**恒为零**，这正是几何对称所要求的。

## 5. 注意点与适用范围

* 只支持 xOz（纵中剖面）镜像：零航速深水核关于该面对称，但**有航速 Rankine 核不对称**，有航速问题不能这样减半；
* 网格必须沿对称面**切成两半**（对称面是网格边而非面元割线）；未切的闭合网格（如 icosphere 潜没球）会被直接拒绝并给出明确错误；
* CHIEF 内部点只保留 y > 0 的一侧；落在对称面上的点被丢弃，否则会把镜像后等价的方程重复喂进系统；
* 斜浪入射（|sin β| > 0）没有确定奇偶性，必须走全域求解器；
* 折叠解与非折叠解在启用 CHIEF 时会有 ~5e-4 的差异：CHIEF 行本身在离散层不相容，两种最小二乘对同一组约束的加权不同——折叠版严格保持奇偶性，全域版不。
