# TensorBEM 有限水深 Green 函数与浅水耐波能力

## 1. 案例介绍

本模块实现了 TensorBEM 的有限水深 Green 函数求解能力，填补了 BEM 浅水耐波能力的空白。

**物理背景**：在有限水深中，自由面色散关系为 ω² = gk·tanh(kh)，与深水形式 ω² = gk 不同。当水深与波长之比 h/L 较小时（浅水），波浪传播特性发生显著变化：相速度趋于 √(gh)，群速度等于相速度（非频散），兴波阻力受水深影响显著。

**几何与参数**：
- 船型：Wigley 抛物线船型（L=100m, B=15m, T=5m, Cb=4/9）
- 水深比：h/L ∈ {0.1, 0.2, 0.5, 1.0, 2.0}
- 傅汝德数：Fn ∈ {0.1, 0.2, 0.3, 0.4}
- 重力加速度：g = 9.80665 m/s²
- 水密度：ρ = 1025 kg/m³

## 2. 方法

### 2.1 色散关系反演（Newton-Raphson）

求解 ω² = gk·tanh(kh) 的波数 k：

- **初值**：k₀ = ω²/g（深水近似）
- **迭代公式**：k_{n+1} = k_n - (g·k_n·tanh(k_n·h) - ω²) / (g·(tanh(k_n·h) + k_n·h/cosh²(k_n·h)))
- **收敛容差**：1e-12
- **溢出保护**：对大 kh 值使用渐近展开 tanh(kh) ≈ 1 - 2exp(-2kh)

### 2.2 定常流色散关系（兴波阻力）

对于以速度 U 航行的船舶，遭遇频率 ω_e = ω - kUcosθ。定常波（ω_e = 0）满足：

tanh(kh) = k·U²·cos²θ / g

深水极限：k = g/(U²·cos²θ)

### 2.3 有限水深 Green 函数

基于 Wehausen-Laitone 模态展开形式，利用已有的 `tensorbem.finite_depth` 模块。深水退化验证：h→∞ 时 tanh(kh)→1，Green 函数趋于深水形式。

### 2.4 Havelock 有限水深兴波阻力

Kochin 函数（有限水深修正）：
A(θ) = ∫∫ y_x(x,z) · [φ₀(z)/φ₀(0)] · exp(iαx) dx dz

其中 φ₀(z)/φ₀(0) = cosh(k(z+h))/cosh(kh) 为垂直模态因子。

兴波阻力：
R_w = ρg/(4π) · ∫₀^{π/2} |A(θ)|² · cosθ dθ

### 2.5 浅水长波极限

相速度：c = ω/k → √(gh)（当 kh→0）
群速度：c_g = c（非频散）

## 5. 注意点

### 5.1 已知局限

1. **Kummer 余项限制**：有限水深 Green 函数在 νh > 400 时精度受 Kummer 加速余项限制（~2e-5），此时应直接使用深水核。
2. **薄船理论**：兴波阻力基于 Michell 薄船理论，适用于小 B/L、小 T/L 船型。对肥大型船（如油轮）误差可达数十百分比。
3. **无粘性效应**：未考虑粘性阻力、波浪破碎、下沉和纵倾。

### 5.2 数值稳定性

- 对大 kh 值（>350）使用渐近展开避免溢出
- Newton-Raphson 迭代步为负时自动回退到二分法
- 垂直模态因子使用数值稳定形式：(exp(kz) + exp(-k(z+2h))) / (1 + exp(-2kh))

### 5.3 适用范围

- 水深比：h/L ≥ 0.1（更浅的水域需考虑非线性效应）
- 傅汝德数：Fn ≤ 0.4（更高速度需考虑兴波非线性）
- 船型：细长船（B/L < 0.2, T/L < 0.1）
