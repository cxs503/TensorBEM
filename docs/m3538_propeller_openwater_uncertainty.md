## 1. 案例介绍

### 1.1 缺口定义（机器判据）

课题 `propeller-openwater-bem` 的 W9 `facts.json:gaps` 旗标为「缺不确定度 / 误差棒 / GCI」。
该课题窗口内的既有证据锚点：

| report id | scenario_key | 已给出的东西 |
|---|---|---|
| 3247 | propeller_open_water_verification | 服务核 `K_T` 偏差 24%→5.4% |
| 3291 | propulsion | B 系列敞水回归 + Holtrop 功率链 |
| 3398 | vibration_noise_closure | 振动噪声四链解析核 |
| 3578 | propeller_open_water_verification | 锚审定 7/18 物理不可能；四内核 15% 分级（`table_interp` 0.0%、`hand_fit` 17.1%、`bem_services` 58.3%、`ll_api` 63.9% 的 `K_T` MAPE）；`eta_0` 恒等式、作动盘上界、Froude 不变性等无系数解析电池 |

**这四份报告共同的结构性空白**：全部指标都是**点估计**，而且四个敞水内核里
没有任何一个带离散化参数——于是「这个 MAPE 里有多少是离散误差、多少是模型误差」
在这条链上**根本无法提问**。这就是 UNCERT 旗标指向的东西。

### 1.2 本单在 TensorBEM 里补的两件事

1. `src/tensorbem/uq.py`：仓内缺失的统一不确定度层（GCI/Richardson、bootstrap
   置信区间、参考值不确定度传播）。仓里原先有 9 处各自手写的
   `observed_order`/`richardson_limit`，但没有 GCI、没有置信区间、没有把
   「参考值本身不确定」这件事量化的工具。
2. **对这层工具本身的验证**（下文 §3）：不确定度工具如果不先验证，写出来的
   误差棒毫无意义。验证用 TensorBEM 既有、带闭式参考的 5 级网格计算
   （半球静水：排水体积、水线面面积、横向二次矩、`KB`），其解析误差已知，
   因此可以逐点给 GCI 打分。

**算例几何/参数**（验证数据集，`tensorbem.benchmarks.hydrostatic_convergence.hemisphere_study`）：
单位半球 `R = 1`，内接多面体网格，细分数 `1..5` → 面板数 `16, 64, 256, 1024, 4096`；
面板块按 `h ∝ panels^{-1/2}` 细化，故相邻两级 `h` 比恰为 2；参考值为闭式解
（`V = 2πR³/3`、`A_wp = πR²`、`I_T = πR⁴/4`、`KB = 5R/8`）。

## 2. 怎么做的（方法 / 流程 / 工具链）

1. **GCI（Roache 1994/1998；ASME V&V 20 / Celik et al. 2008）**：三级、等比细化，
   `p = ln|(f_coarse-f_medium)/(f_medium-f_fine)| / ln r`，
   `f_ext = f_fine + (f_fine-f_medium)/(r^p-1)`，
   `GCI_fine = Fs |(f_medium-f_fine)/f_fine| / |r^p-1|`，`Fs = 1.25`（三级研究默认），
   并给出渐近比 `GCI_medium/(r^p GCI_fine)`（纯幂律下恒等于 `f_fine/f_medium`）、
   振荡/单调标志与 `converged` 判决。全部量都返回，**不静默修数**：
   `p` 为负或振荡时 `converged=False`，调用方不得把外推值当收敛答案。
2. **bootstrap 置信区间**（百分位法，不做 BCa——n≈10 时偏倚校正不可估）：
   对逐点相对误差重采样，给 MAPE 的 95% 区间。
3. **参考值不确定度传播**：把「图表读数的参考值本身有 ±x% 不确定度」用 Monte-Carlo
   传进误差指标，回答「报出来的误差里有多少可能只是参考值的错」。
4. **工具链**：Python 3.11 + numpy；`tools/uq_selfcheck.py` 单次运行 ~4 s。

## 5. 注意点（坑 / 局限 / 适用范围）

- **本单没有产出螺旋桨的误差棒，这是有意的取舍，不是遗漏。** 四个既有敞水内核
  （`table_interp` / `hand_fit` / `bem_services` / `ll_api`）都**没有离散化参数**
  （报告 3578 §2），因此 GCI 对它们**无定义**——给它们套一个误差棒只能靠猜。
  唯一诚实的做法是补一个带面板数参数的一阶原理敞水内核。
- **本次尝试该内核（涡格法 lifting-surface）失败并已从工作树删除**：符号链未闭合，
  解出的 `K_Q < 0`（`J = 0.2..0.8` 时为 −0.83…−0.09）而 `K_T` 量级高一个数量级
  （`J = 0.4` 时 `K_T = 4.04`，而报告 3578 过闸锚为 0.205），即解出了
  违反能量守恒的「永动螺旋桨」。已确认的两处根因：
  ①马鞍涡的返回腿必须沿上游方向闭合（两条腿同向下游 → 下洗反向、解发散）；
  ②Kutta-Joukowski 力号与右手螺旋环流约定需统一（`F = -ρΓ(dl̂×W)`，用平板/圆柱
  两个解析判例校准）。修好前任何 `K_T`/`K_Q`/`eta_0` 数字都不能入库，故整模块未提交。
- 半球静水验证数据不是螺旋桨数据：它验证的是**不确定度工具**，不是敞水内核精度。
  两者不可互相顶替。
- `Fs = 1.25` 只对**三级、等比**研究成立；非等比细化或已进入机器精度的量
  （`kb` 在 4096 级已到 3.1e-2 %）不适用。
- bootstrap 区间随 n 增大而收窄，n≈10 时本仓取值宽度可观（见 T4 的 [5.9, 16.5]）：
  报「MAPE = x%」时必须带这个宽度，否则评审无法区分系统偏差与抽样噪声。

## 6. 误差判定（逐项显式回答「是否 <3%」）

| # | 关键量 | 基准 | 本单数值 | 是否 <3% |
|---|---|---|---|---|
| 1 | Richardson 观测阶 `p`（制造解） | 真值 `p = 2` | `|Δp| = 5.3e-14` | **是**（机器精度） |
| 2 | Richardson 外推极限（制造解） | 真值 5.0 | 误差 8.9e-16 | **是** |
| 3 | GCI 是否保守（8 个量） | 闭式参考真误差 | `真误差/GCI ∈ [0.747, 0.798] ≤ 1`，8/8 | **是** |
| 4 | `Fs = 1.25` 的余量是否恰如设计（≈1/1.25 = 0.8） | `真误差/GCI = 0.8` | 偏差 ≤ 7%（0.747 vs 0.8 最差） | 边缘：**否**（7% > 3%），属三级研究的正常离散，不修数 |
| 5 | 外推极限 vs 闭式（4096 级，4 个量） | 闭式解 | 2.1e-06 … 2.35e-05 | **是** |
| 6 | 观测阶 vs 理论阶 2（4096 级） | 2 | 1.979 / 1.997 / 1.992 / 1.991 | **是**（偏差 ≤1.1%） |
| 7 | 螺旋桨 `K_T`/`K_Q`/`eta_0` 的 GCI 误差棒 | 报告 3578 过闸锚（11 点） | **NO-DATA-TBD** | **无法回答**：既有四内核无离散化参数，GCI 无定义；自研 VLM 未通过自检已删除 |
| 8 | 报告 3578 的 MAPE 点估计（0.0 / 17.1 / 58.3 / 63.9%）的置信区间 | 同上 | **NO-DATA-TBD** | **无法回答**：需逐点为四个内核取值，仓内无此数据；且该锚表本身 7/18 点非物理（3578 T1），任何 <3% 判据在其上都无基准意义 |

**一句话结论**：不确定度**方法层**已交付并自证（判据 1–6 通过，判据 4 的 7% 属
估计器余量与设计值的正常离散，如实记录）；课题缺口所要求的**螺旋桨敞水误差棒
本身仍是 NO-DATA-TBD**，缺口只被部分关闭，原因是缺一个带离散化参数且通过物理
自检的敞水内核，而不是缺分析方法。

## 7. 后续（关闭缺口的最短路径）

1. 用统一约定重写敞水涡格内核：马鞍涡返回腿上游闭合 + `F = -ρΓ(dl̂×W)`；
   以两个解析判例（二维平板升力方向、旋转圆柱 Magnus 方向）做回归测试；
   以 `eta_0 = J K_T/(2π K_Q) > 0`、`K_Q > 0`、`eta_0 ≤ 2/(1+√(1+C_T))`、
   Froude 相似不变性作为准入门。
2. 准入通过后，对 `(n_radial, n_chord) ∈ {(8,4),(16,8),(32,16)}` 三级跑

   再与报告 3578 的过闸锚逐点对表，逐项回答「是否 <3%」。
