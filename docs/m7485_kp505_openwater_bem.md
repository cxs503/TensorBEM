## 2. 怎么做的

### 2.1 求解器（`src/tensorbem/propeller.py`）

- **叶片固定系涡格升力面**：`D=1`、`n=1` rev/s 无量纲化，来流 `W_inf = J x_hat - omega r (x_hat x e_r)`；每面板一条等强度马蹄涡（束缚涡在 1/4 弦、控制点在 3/4 弦），尾涡两条螺旋拖出腿，三段按 `远场→A→B→远场` 连成一条连续涡路。上一版被删除的内核（`docs/m3538_propeller_openwater_uncertainty.md` §5）就是把返回腿方向搞反了，现在由数据结构保证，调用方无法写错符号。
- **五叶对称**：`copies=Z` 只旋转复制涡系（控制点不转），未知量仍是单叶环流。
- **尾涡模型**：`geometric`（跟随几何螺距 P/D = 0.95）、`kinematic`（跟随自由来流 `tan(beta_w) = J/(2 pi r)`）、`induced`（对收敛的 kinematic 解做一次力自由对齐）。
- **粘性耦合**：ITTC-1978 剖面阻力律 `C_D = 2(1+2t/c)[0.044/Re^(1/6) - 5/Re^(2/3)]`，沿局部相对速度方向作为分布力加在每面板（升力只用 Kutta-Joukowski `F = rho Gamma (W x dl)`）。标准原文离线不可得，故只引用不引句（§5.5）。
- **几何重建**（表 1 之外的全部内容，均标为假设）：
  `c(u) = A (u + 0.12)^0.8 (1 - u)^0.5 with A from Ae/Ao = 0.800 matched by quadrature; constant pitch P/D = 0.950; zero skew and rake; flat (uncambered) sections of thickness ratio 0.06`

### 2.3 主配置与设计 J（先于扫掠固定）

- 主配置：`{"n_radial": 16, "n_chord": 2, "wake_model": "geometric", "wake_length": 1.0, "wake_steps": 24, "rev_per_second": 10.0, "thickness_ratio": 0.06, "viscous": true, "radial_spacing": "cosine", "root_chord_offset": 0.12}`
- 依据：n_radial=16 / n_chord=2 sits in the well-conditioned band of the lattice (condition number < 1e3; finer radial meshes without the strip-width core regularisation pick up the odd-even mode, see docs/m7485_kp505_openwater_bem.md §5); the geometric wake is the only model of the three that stays physical down to J = 0.1 (kinematic and induced helices collapse as tan(beta_w) = J/(2 pi r) -> 0).
- 设计 J：argmax over the transcribed anchor table of eta_0 = J K_T / (2 pi K_Q); derived in code, not recalled → J = 0.8；J = 0.7 is reported as well because it is the usual nominal design point quoted for this propeller class; no threshold is attached to it（J = 0.7）。
- 环境：Python 3.11.6 / numpy 2.4.6 / commit 6047b13；复现：`PYTHONPATH=src python -m tensorbem.benchmarks.kp505_openwater_bem`。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **低 J 螺旋尾涡退化**：尾涡螺距 ∝ J，J→0 时退化为同心圆环，近场诱导发散，会解出负推力负扭矩（K_T ≈ −12）。这是模型有效域边界而非实现 bug；尾涡模型必须显式声明，低 J 段只能用几何螺距尾涡。
2. **细网格奇偶失稳**：拖出腿距控制点半个条带宽，若正则化核只按段长取，法向 wash 随条带变窄按 1/Δr 增长，径向细化到 n_r ≳ 18 出现锯齿模态、条件数按 1/Δr 增长（n_r = 10/14/18/24 时 cond = 12/192/611/1799）。修法：核半径不小于半个条带宽，把近场限制在离散尺度内；改后 n_r 到 32 仍单调。
3. **几何是重建不是原图**：表 1 只给 6 个标量，弦长/径向螺距/侧斜/纵倾/拱度/厚度律都缺。本单按 Ae/Ao 精确配平弦长、等平均螺距、平板截面。因此本单偏差**不能**当作“面元法误差”的通用结论，只能当作“在这套可公开复现的几何重建 + 该尾涡/粘性模型下的偏差”。
4. **近零载荷段不可信**：J = 1.0 时 K_T < 0 且动量上界被违反，属该涡格在零升力附近的失效；已按原值报出并标 unphysical，未剔除。
