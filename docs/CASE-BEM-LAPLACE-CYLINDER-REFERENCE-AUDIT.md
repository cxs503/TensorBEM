# CASE-BEM-LAPLACE-CYLINDER：参考解链的独立复核

本文件复核的不是 BEM 数值解，而是**判据所对标的参考解本身**。该算例的全部判据都用一组手推闭式公式做基准：

```
W(z)          = U (z + a^2/z)
dW/dz = u - i v = U (1 - a^2/z^2)
Cp            = 1 - (v/U)^2
W_Gamma(z)    = U (z + a^2/z) - i Gamma/(2 pi) ln(z/a)
L'            = -rho U Gamma        (Kutta-Joukowski, rho = 1)
sin(theta_s)  = Gamma/(4 pi U a)
```

如果其中任何一条在转录时写错，**所有判据会一起对错**，记录仍然全绿——即「自证」风险。下面的复核只用上面声明的**复势本身**，不调用任何被复核的导数公式。

## 方法

1. **速度＝复势导数**，用离散 Cauchy 积分在半径 $r=0.05|z|$ 的小圆上算：

   $$W'(z)=\frac{1}{2\pi r}\oint W(z+r e^{i\theta})e^{-i\theta}\,d\theta$$

   被积函数解析时梯形公式谱精度收敛，且公式内无「相近数相减」，因此误差直接落在双精度舍入底噪（实测 ~3e-15，见图 1）。升力势的 $\ln(z/a)$ 沿回路用 `np.unwrap` 连续化，避免主值支割线切过小圆。
2. **升力＝压力积分**：$L'=-\int_0^{2\pi} p\sin\theta\,a\,d\theta$，$p=\tfrac12\rho(U^2-|v|^2)$，$|v|$ 取上一步的数值导数；4096 点梯形对三角多项式谱精度。
3. **驻点角＝数值零点**：对数值切向速度做 721 点扫描 + 二分（收敛到 $10^{-13}$ rad），不代入 $\sin\theta_s=\Gamma/4\pi U a$。

## 适用范围与局限

- 复核对象是**参考解**，不是 BEM 离散解：它保证「判据对标的靶子是对的」，不保证边界元实现无误；后者由算例自身的 44 条判据与收敛阶负责。
- Cauchy 求导要求复势在探针周围解析。本算例的奇点只有 $z=0$（体内），小圆半径取 $0.05|z|$ 恒不含奇点；对带支割线的升力势用相位连续化处理。因此结论不外推到含其它奇点的场（如自由面、多体近场遮挡）。
- 谱精度依赖被积函数的解析性；若把该方法用于含奇异积分的源分布本身，需另做奇性处理。
- 复核下限受双精度限制（~1e-15）；要判定更小的参考解误差需高阶精度算术。
