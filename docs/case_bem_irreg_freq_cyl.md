## 1. 案例介绍（物理背景 / 几何 / 参数表）

锚点 `CASE-BEM-IRREG-FREQ-CYL`：**不规则频率 Bessel 零点预测**。模型试验/面元法里，穿透自由面的物体（本文取直立圆柱）在其内部本征频率处会让边界积分方程失秩，出现伪共振——这些"不规则频率"由水线面内 Dirichlet 本征问题给出；对圆形水线面其无量纲波数就是 Bessel 零点：

$$\nu_{m,s} = j_{m,s}/R_{wp},\qquad R_{wp}=R,\qquad \omega_{m,s}=\sqrt{g\nu_{m,s}}$$

本单考的不是这条公式的推导，而是**TensorBEM 的 `predict_irregular_frequencies` 从湿表面网格反推出来的数，是否等于手册里的 $j_{m,s}$**，容差判据 **< 2 %**。

**ref 出处（原表原页）**：Abramowitz M. & Stegun I. A. (eds.), Handbook of Mathematical Functions with Formulas, Graphs, and Mathematical Tables, NBS Applied Mathematics Series 55, 1964 (10th printing, 1972), Chapter 9 'Bessel Functions of Integer Order', section 9.5 'Zeros', Table 9.5 'Zeros of Bessel Functions J_0(x), J_1(x), Y_0(x), Y_1(x)', printed pages 370-373；节/页 pin：section 9.5 starts on printed page 370 and runs to printed page 373 (verified 2026-11-13 against the table of contents of the electronic 10th printing: entry '9.5. Zeros 370 371 372 373', https://personal.math.ubc.ca/~cbm/aands/toc.htm)。该表只制表 $J_0,J_1,Y_0,Y_1$ 的零点（即 $j_{0,s},j_{1,s}$ 家族）；$m\ge2$ 的零点不在该表内，故本单对 $m\ge 2$ 的行标注 `source=computed`（40 位 mpmath + scipy + 仓内 numpy 递推三路独立计算），**不冒称手册读数**。

几何：直立圆柱，半径 $R$，吃水 $T=T/R\cdot R$ 比取 0.5–4，水线面离散为内接正 $N$ 边形（$N$ = 水线面周向面元数），周向分带 $n_{levels}=4$，水深按深水处理。

## 2. 方法与实现（工具链 / 关键设置）

- **复用而非重写**：算例不自己写 Bessel 零点预测，直接调 `tensorbem.irregular_frequency.predict_irregular_frequencies(mesh)`，网格由 `tensorbem.diffraction_drift_maturity.vertical_cylinder_hull_mesh` 生成——预测器拿到的只有湿表面网格，`R_wp` 由水线面鞋带公式反推（`_waterplane_equivalent_radius`），这是被审对象本身。
- **外部锚**：`src/tensorbem/benchmarks/data/as_9_5_bessel_zeros.json`，20 个零点 + 出处块（表名/节/印刷页）。运行期对每个字面值做 **40 位 mpmath 逐位审计**（容差 6e-11 绝对 ≈ 10 位小数的 1.2 ULP），任一位错即中止判决 —— 审计当场揪出 3 处录入错误（$j_{1,5},j_{3,1},j_{3,2}$）后才进入判决，这也是审计有效性的实证。
- **误差二分**：把总误差拆成"常量误差"（预测器内建 Bessel 常数 vs 手册零点，反推为 $\nu R_{wp}$）与"几何误差"（鞋带面积反推的 $R_{wp}$ vs 真半径 $R$），并证明 $(1+e_c)(1+e_g)-1=e_{total}$ 恒等（残差 <1e-15）。
- **解析模型**：内接正 N 边形面积 = $\frac{N}{2}R^2\sin(2\pi/N)$，故
  $R_{wp}/R=\sqrt{\sin x/x}$、$e_g=\sqrt{x/\sin x}-1\approx\pi^2/(3N^2)$，$x=2\pi/N$。
  由此得到一条可证伪的预测：**<2 % 判据等价于 $N\ge\lceil\pi/\sqrt{3\times0.02}\rceil=13$**。
- **物理旁证（Route C）**：复用 `benchmarks.irregular_frequency_cylinder_exact.observed_spurious_band`，不增强地扫裸辐射求解，取条件数峰值位置作为"代码实际有的"不规则频率。
- 工具链：Python 3.11.6 / numpy 2.4.6 / scipy / mpmath / matplotlib；机器 loongarch64。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **判据被几何支配，不是物理**：2 % 的通过与否由水线面多边形面积决定（$e_g\approx\pi^2/3N^2$），Bessel 常量本身精确到 1e-16。因此"通过 2 %"只说明网格够细，不说明预测在哪里都对。
2. **预测器只支持一阶零点**：`predict_irregular_frequencies` 内建 $j_{m,1}$ 三个常数，$n\ge2$ 的零点（$j_{0,2}=5.520$ 等）无法从公开 API 取（`dirichlet_zeros` 能算但未接入），属能力缺口，本单未扩权。
3. **公式与自由面本征问题不同源**：$j_{m,s}/R$ 是"刚性盖"内部本征值（John 1950 / Zhu 1993）。仓内 `irregular_frequency_cylinder_exact` 已证明自由面一致的 Route B 比它高 16–39 %（$T/R$=0.5–1），本单的预测器与 Route C 实测都跟随刚性盖支，故本单不主张"物理正确"，只主张"与手册零点一致"。
4. **手册页无 OCR（生态摩擦）**：电子版 §9.5 页面为扫描图（page_370.jpg…page_373.jpg），本环境无 OCR 引擎，无法机读印刷数字；改用"出处块 + 40 位逐位审计"保证数字链，且 2 % 判据远大于末位舍入 1e-10，故不影响判决。审计当场揪出 3 处录入错，说明该闸门不是形式。
5. **预登记偏离**：A1 阈值初稿为 1e-12，实测 3 个模式为 2e-12…8e-12——因为常量是以 $\nu R_{wp}$ 反推的，含鞋带面积的浮点舍入（重建地板 ~8e-12）。故 A1 阈值改为 1e-10 并记录理由；`err_const` 实测值原样报告，未做修饰。
6. **Route C 是粗定位**：31 点扫描 + 抛物插值，容差 10 %；它验证"代码实际的不规则带在预测点附近"，不能当精度基准。
