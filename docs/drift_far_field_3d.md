# 三维远场漂移力通道：真实 BEM Kochin 耦合、半径外推可评性与能量恒等式（m9286）

**节点**：`p40w4-n02-bem-drift-force-3d`（TensorBEM）。**任务背景**：清偿
`dev_report_m5242_second_order_drift.md` 记录的三维远场通道 honest FAIL——当时三维 Maruo
远场路线喂的是玩具 Kochin ansatz，且在控制圆柱半径上不收敛（`kR` 散布 ~100%）。

**本单做了什么（三句话）**：①把三维远场通道改成**消费
`free_surface_solver3d.kochin_function_3d` 的真实 BEM 求解输出**（散射势 + `-∂φ_I/∂n`），
并用 MacCamy–Fuchs 精确解做真值耦合；②把「控制圆柱半径扫描 + Richardson 外推」这条历史路线
**测量并钉死**为不可外推（给出因果解释与回归测试），同时给出正确的**半径无关约化核**通道；
③新增一条**能量恒等式**（固定不吸收体的光学定理）审计，它在精确解上残差 < 1e-12，因此可以把
BEM 远场幅值的误差单独量出来。

**结论先行（诚实版，全部数字见 §③ 生成表）**：

1. **远场通道本身达标**：真实 BEM Kochin + 约化 Maruo 的远场漂移力，在 800 面板网格上对
   MacCamy–Fuchs 精确解的偏差为 **0.9%–2.5%**（8 个 ka 全部 ≤3%）；面板阶梯
   （208 → 456 → 800）做面板轴 Richardson，观测阶 **2.15**、外推自残差 **0.30%**、
   外推值与精确解偏差 **0.62%**。也就是说：m5242 缺口（远场通道不消费真实 BEM 输出）**在物理上
   已经清偿**。
2. **近场 vs 远场 ≤3% 未通过（honest FAIL）**：最细网格实测 **9.22%**（粗网格 36.86%）。
   拆账后责任在**近场路线**（Pinkster 表面梯度恢复，误差 7.1%–10.1%），远场路线同网格只有
   0.9%–2.5%。阶梯上偏差单调收窄 33.2% → 13.7% → 8.1%，趋势支持再加密可达 3%，但**本单没有
   测到 3% 以内**，判据记为 FAIL。
3. **半径扫描不可外推（honest FAIL，保留）**：`r/R = 5…40` 上力值在 `-4.5e3 … +7.9e3 N` 之间
   振荡（含**符号翻转**），散布 **530%**，残差非单调，Richardson 拒绝输出阶。因果解释见 §⑤ 第 3 条
   （缺竖直圆柱面动量通量项，量级 `O(ρgA²/k)`）。历史 honest FAIL 原样保留。
4. **`(ka)^3` 只在渐近带成立**：ka=0.2 处局部斜率 BEM **2.882** / 精确 **2.874**（带内通过）；
   全带 ka∈[0.2,3] 不通过（BEM 最大偏差 3.09、精确 3.08、出带边界 ka≈0.20）。这是**物理性质**
   （精确解同样不满足），不是数值缺陷，两条判据分别报告。
5. **面板加倍 ≤2% 未通过**：4× 口径（208 → 800）逐 ka 最大 **7.36%**（ka=0.2），ka=1 阶梯上为
   3.17%；最接近「×2」的阶梯步（208 → 456，2.19×）为 **2.39%**，仍差 0.4 个百分点；最细一步
   （456 → 800）已降到 **0.71%**。但**面板轴 Richardson 是收敛的**：观测阶 2.15、外推自残差
   0.30%、外推值与精确解偏差 0.62%（→ 本判据按阶梯口径记 FAIL，按外推口径已达标，两者都列出）。
6. **能量恒等式残差 ≤1e-3 未通过**（800 面板 2.8e-3–5.0e-3；阶梯 1.17e-2 → 4.88e-3 → 2.80e-3，
   实测阶约 1）。恒等式常数本身在精确解上残差 <1e-12（见 §② 第 4 步、单测），因此这条残差是
   **BEM 远场幅值的一阶离散误差**，不是公式错误。

## ① 案例介绍

**物理背景**：规则波中固定物体受二阶时间平均水平波浪载荷（漂移力），与波幅平方成正比，是系泊/
DP 载荷与波浪谱二阶矩的主项。二阶平均量有两条量级相同、公式完全独立的估法：

- **近场（Pinkster）**：在瞬时湿表面上积分二阶压力项 `(1/2)ρ⟨|∇φ|²⟩ n dS` 和自由面项；
- **远场（Maruo/Kochin）**：大控制面上的动量通量，最终化为 Kochin 函数 `K(θ)` 的方位积分
  `F_j = (ρk²/8π) ∮ |K(θ)|² [e_β − e_θ]_j dθ`。

`K(θ)` 是散射势的远场角幅值，它是**唯一**把 BEM 面板解与远场公式接起来的量，因此远场通道的
证据等级取决于 `K` 是不是真实 BEM 输出（m5242 的缺口正在这里）。

**几何/参数**（`artifacts/drift_far_field_3d/study.json` 的 `geometry` 段）：

| 项 | 值 |
|---|---|
| 物体 | 底置水线截断竖直圆柱（侧面三角化 + 底板），半径 1 m |
| 水深 | `5 / ka`（**固定网格形状**：ka 一族只有整体尺度变，离散误差才可比） |
| 流体 | ρ = 1025 kg/m³，g = 9.81 m/s²，深水自由面 Green 函数 |
| 入射 | 波幅 1 m，方向 +x（β = 0），深水 |
| 网格 | 粗 16×6 = 208 面板；细 32×12 = 800 面板；阶梯 16×6 / 24×9 / 32×12 |
| 真值参照 | MacCamy–Fuchs 精确解：`cylinder_drift.far_field_cylinder_drift`（远场）与 `near_field_cylinder_drift`（近场） |

## ② 怎么做的

1. **BEM 耦合**（`tensorbem.drift_far_field3d.bem_kochin`）：`solve_diffraction_3d` 解散射问题，
   取 `diffraction.scattered_potential` 与 `-diffraction.incident_normal_velocity`（固定体上总法向
   速度为零，故 `∂φ_s/∂n = -∂φ_I/∂n`），送进仓库唯一的 Kochin 实现
   `free_surface_solver3d.kochin_function_3d`。同时在加倍方位网格上重算并报告
   `azimuth_rel_change`（方位谱分辨率诊断），避免下游积分被方位插值限死。
2. **约化 Maruo 通道**（`maruo_far_field_drift`）：权重与仓库已验证的
   `drift.far_field_mean_drift_3d` **完全相同**（单测比对到 1e-12，不是另起一套）——喂精确
   MacCamy–Fuchs 的物理归一化 `K` 时，它复现 `far_field_cylinder_drift` 到 1e-10。
3. **半径扫描 + 外推可评性**（`control_circle_drift` / `radius_scan`）：在 `r/R = 5, 7.5, 10, 15,
   20, 30, 40` 上算历史「未约化」辐射应力通量，并对残差序列做**可评性判定**：只有当残差随半径
   单调下降且拟合出正的收敛阶时才输出 order/Richardson 残差，否则显式返回
   `richardson_evaluable = False`（拒绝为不收敛序列编造阶）。
4. **能量恒等式**（`optical_theorem_residual`）：固定不吸收体净做功为零，散射波能量通量必须被
   入射/散射干扰通量精确抵消。用驻相法把干扰项化为 `2ω Re S(0)`，得到
   `∮|K|²dθ = (4π/k)(gA/ω) Re K(0)`。**该恒等式不含任何物体尺度**（本单用半径 1 m 与 2 m 的同一
   `ka` 解，`∮|K|²/预测值` 两者相差 3.4e-16），精确解上残差 < 1e-12。
5. **判据**（全部由驱动写成布尔量，报告不手改）：近/远场 ≤3%、r 扫描阶 ≥1.5 且 Richardson ≤2%、
   渐近带斜率 3±0.2、全带斜率 3±0.2、面板加倍 ≤2%、能量恒等式 ≤1e-3。
6. **工具链**：NumPy（无 SciPy/无 torch）+ matplotlib(Agg) + pytest；重计算在集群
   （外协方 loong64 双节点）上跑，本文件数字由 `--inject-docs` 注入，手抄无法通过
   `tests/test_drift_far_field3d.py::test_report_block_matches_the_committed_study`。

## ⑤ 注意点（坑、局限、适用范围）

1. **Kochin 归一化有两条链，混用会差 `(g/ω)²`**。`free_surface_solver3d.kochin_function_3d`
   的输入势来自 `-(i g A/ω)exp(νz + iνx)`，所以它输出的是**物理** `K`（幅值含 `gA/ω`）；
   而 `cylinder_drift.kochin_3d` 由单位势幅值的模态和导出。喂错链会把力整体缩放 `(g/ω)² =
   g/k`——本单单测 `test_energy_identity_detects_a_normalisation_error` 把这条钉住（喂错链时
   能量恒等式残差 > 0.5）。这是 m7374 记录的另一条 `2π` 归一化陷阱的同族问题：远场通道的
   前因子必须在**同一个 K 归一化**下核对。
2. **能量恒等式不含物体尺度**。恒等式里出现 `k` 与 `gA/ω`，但**不**出现半径；插入任何 `a` 的
   幂次都会破坏量纲一致性（本单实测：同一 `ka`、半径 1 m 与 2 m 的两个 BEM 解，比值差 3.4e-16；
   若插入 `a¹` 则差 2 倍）。单测
   `test_energy_identity_carries_no_body_length_scale` 钉住。
3. **为什么半径扫描注定不可外推（因果解释，不是「数值不准」）**。历史公式只保留了控制圆上的
   自由面辐射应力 `-(ρg/4)∮|ζ|²R cosθ dθ`，它**不是**闭合动量平衡。闭合还需竖直圆柱面上的
   `⟨p⟩n_x + ρ⟨u_x u·n⟩`：散射波 `φ ~ R^{-1/2}` 给出 `|∇φ|² ~ 1/R`，柱面面积元 `R dθ`、
   竖向 `∫exp(2νz)dz = 1/(2ν)`，合起来是 `O(ρgA²/k)`；漂移力本身是 `O(ρgA²a(ka)³)`。
   两者之比 `~ (ka)^{-2}`，即**在 ka<1 的窗口里缺项比保留项更大**，且缺项带
   `e^{ikR(1-\cosθ)}` 相位，因此残差只能是 O(1) 的相对振荡，**任何** Richardson 都无法把它
   外推掉。这一条是量级论证（不是拟合结果）；本单另外用精确 MacCamy–Fuchs 场试过「柱面项 +
   自由面环带项」的朴素闭合写法，**同样不收敛**，故不作为修复宣称（不入账为正结果），
   只记录为否定性结论：该写法在符号/项完备性上仍未过关。正确替换是半径无关的约化核
   （驻相法解析约化），本单第 2 步即为该实现并被精确解验证。
   生成表里可以直接看到机制：**散射项 `∮|K_s|²` 在整个半径族上恒为同一值**（半径无关），
   全部 530% 散布都来自**干扰项**（入射×散射，量级 ±6e3 N）——正是那一项带 `e^{ikR(1-\cosθ)}`
   相位、在缺项补偿不存在时无法收敛。
4. **`(ka)^3` 只是 `ka→0` 的陈述**。精确解在 ka=0.2 处局部斜率 2.87（带内），ka=0.3 已 2.71、
   ka=1 处 0.17、ka=3 处 0.02；m7374 记录 ka=2 处与渐近式相差 39 倍。把「全带 3.0±0.2」当成
   物理性质会得到假 FAIL/假 PASS，本单分别报告「渐近带」与「全带」两条判据。
5. **近场路线的离散误差主导 3% 门（实测归属）**。同网格上把两条路线都对精确解拆账（生成表「路线归属」）：
   远场路线误差显著小于近场路线。近场 Pinkster 走面板表面梯度恢复 + 水线积分，水线项在 ka≈1 时
   甚至大于压力项，粗网格上梯度恢复噪声直接进 3% 门。因此 3% 门的可达性取决于网格，而不是取决于
   远场通道本身。
6. **适用范围**：深水、固定体、一阶线性衍射场上的二阶平均漂移力；不含二阶势（慢漂移/差频）、
   不含航速（无 `τ` 修正、无定常兴波）、不含有限水深（水深取 `5/ka`，`e^{-5}` 残余 ~0.7%）。
   底面封闭使圆柱成为真正的底置体（无底部绕流），与 MacCamy–Fuchs 的无限深假设之间存在
   该 0.7% 量级的模型差，已在近/远场对精确解的偏差里一并体现。
7. **精确解的数值上限**：`cylinder_drift` 的升阶 Bessel 级数在 `kR > 35` 失准（m7374 同结论），
   本单的精确解参照只用于 `ka ≤ 3`、`r/R ≤ 40` 的场合，且远场参照不引入半径。
