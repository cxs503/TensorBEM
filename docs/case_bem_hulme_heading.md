## ① 案例介绍与为什么需要这个扩展

半径 a = 1 m 的浮半球（平面与平均自由面齐平、曲面入水）在无限深静水中受单位波幅规则波入射。锚点算例此前只在**迎浪（wave_angle = 0）**一个浪向下给出数值，因此整条斜浪向代码路径——入射波相位、载荷投影、横向力的符号约定——没有任何参考：一个 `sin β` 符号错误在只有迎浪列的表中完全不可见。

对**回转体**（绕 z 轴的旋转对称浮体）这一缺口可以被精确闭式填上：流体域、自由面条件、物面与辐射条件全部绕 z 轴不变，而入射势

```
phi_I(beta) = -(i g A / omega) exp(nu z + i nu (x cos beta + y sin beta))
```

正是 `beta = 0` 入射势绕 z 轴转 beta 的结果，于是连续问题的复载荷六维矢量满足精确关系

```
V(beta) = R_beta V(0),   V = (Fx, Fy, Fz, Mx, My, Mz)
```

其中 `R_beta` 只作用在 (x, y) 分量上，`Fz`、`Mz` 不变。由此得到两条可判定的精确命题：① 水平力大小与浪向无关，横向（侧向）力**不是**自由的而是 `Fy = Fx(0) sin beta`；② 艏摇激励力矩恒为零，`Mz(beta) = 0`。

## ② 怎么做（方法 / 流程 / 工具链）

同一个物理问题用**三条互不相同的路线**测量离散化，避免「自己说自己」：

1. **headed 网格扫描（heading cells）**：主网格上 ka ∈ {0.5, 1, 2}，十个浪向，逐点与同行同一网格 `R_beta V(0)` 比较。偏差是纯网格各向异性，按算例容差 +5% 判定。
2. **旋转网格代数恒等式（rotated cells）**：把**网格本身**绕 z 轴转 −β，在 `wave_angle = 0` 下求解，再把答案转回 +β，必须复现未旋转网格上 `wave_angle = β` 的直接解。两个离散问题是同一个问题写在旋转后的坐标里，因此这条恒等式只考验 heading 的**实现**（相位前置因子、正负号、(x, y) 是否被转置），容差 1e-03：一个符号错误是 O(1) 偏差，比门槛高三个数量级以上。
3. **Haskind / Kochin 斜浪互易（haskind）**：只用辐射势（surge/sway/heave）经 Haskind 近场积分与 Kochin 远场关系算斜浪激励力，与直接绕射解比较。锚点此前只在迎浪验证过这条互易关系。

工具链：`tensorbem.geometry3d.hemisphere_hull_mesh`（八面体下四面细分并径向投影到 r = a、z ≤ 0）；`tensorbem.free_surface_solver3d.assemble_free_surface_operators_3d`（深水 Green 函数 BIE，CHIEF 内部空场点 `chief_points='auto'`，每个 (ka, 网格) 只组装一次，十个浪向复用）；`solve_diffraction_3d`、`solve_radiation_3d`、`haskind_excitation_force_3d`。驱动：`run_case.py`（确定性任务表 → 分片 → merge 出判据）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

- **这条对称性只对回转体成立**，不能外推到任意浮体；半球之所以能用，是因为其湿表面绕 z 轴旋转对称、且水位面不随浪向改变。非回转体（含方箱、多体）只能用逐浪向数值解。
- **主网格不是旋转对称的**（八面体细分只在 90° 步长上自映射），所以固定网格扫浪向测到的是**离散各向异性**，不是零；把它与旋转网格恒等式分开记，正是为了不把「离散各向异性」误读成「heading 实现有错」。
- **旋转网格恒等式的门槛不是机器精度**：它受制于线性求解的迭代残差（表中逐格列出），故门槛取 0.0 而非 1e-12；这也是它能抓住 O(1) 约定错误、又不会被残差噪声误判的原因。
- **CHIEF 点随网格一起旋转**：旋转网格单元里的内部空场点是由旋转后的网格重算的，若沿用未旋转的点，恒等式会被人为破坏——这是该单元必须重新组装算子的原因。
- 参考值来自解析对称性（无离散、无截断），因此**不需要** Hulme 级数的自收敛阶梯；但它只约束「浪向」，不约束「频率/网格」，后者仍由锚点主算例与 capytaine 第三方轴负责。
- 线性势流、无限水深、无航速；不含黏性、碎击、非线性与浅水效应。
