# IN32-B01: Rankine 源面元法兴波阻力验证报告

## 1. 案例介绍

**物理背景**：船舶兴波阻力是船舶总阻力的重要组成部分，尤其在高速航行时占比可达40-60%。
本验证节点实现 Rankine 源面元法（Neumann-Kelvin 线性化自由面条件），并与 Wigley 抛物线船型
的 Michell 精确解对标验证。

**几何参数**：

| 参数 | 值 |
|------|------|
| 船长 L | 2.0 m |
| 船宽 B | 0.2 m |
| 吃水 T | 0.125 m |
| L/B | 10.0 |
| B/T | 1.6 |
| Cb | 4/9 = 0.444 |
| 设计 Fr | 0.3 |
| 设计速度 U | 1.342 m/s |

**船型方程**（Wigley 抛物线）：

$$y(x,z) = \frac{B}{2}\left(1-\left(\frac{2x}{L}\right)^2\right)\left(1-\left(\frac{z}{T}\right)^2\right)$$

**流体参数**：ρ = 1025 kg/m³, g = 9.80665 m/s²

## 2. 方法

### 2.1 Rankine 源面元法框架

- **Green 函数**：G(p,q) = 1/|p-q|（Rankine 源）
- **边界积分方程**：φ(p) = ∫∫_S σ(q)·G(p,q)dS
- **自由面条件**：线性化 Neumann-Kelvin 条件 ∂φ/∂z - (U²/g)∂²φ/∂x² = 0 on z=0
- **船体条件**：∂φ/∂n = U·n_x on hull surface

### 2.2 Michell 薄船理论（精确参考解）

对 Wigley 船型，Michell (1898) 给出兴波阻力精确积分：

$$R_w = \frac{4\rho g^2}{\pi U^4} \int_{k_0}^{\infty} |H(k)|^2 \frac{k^2}{\sqrt{k^2-k_0^2}} dk$$

其中 k₀ = g/U² 为自由面波数，Kochin 函数 H(k) 对 Wigley 船型有封闭形式：

$$H(k) = -U \cdot \frac{-16BT}{3L^2} \cdot \frac{2i(\sin(ka)-ka\cos(ka))}{k^2} \cdot \frac{1-e^{-kT}}{k}$$

### 2.3 数值实现

- **积分方法**：向量化 Gauss-Legendre 求积（n=256 标准，n=512 参考）
- **奇点处理**：k = k₀ + (k_max-k₀)t² 替换消除 k₀ 处可积奇异性
- **收敛参考**：复合求积 100 子区间 × 16 节点
- **面板网格**：余弦间距 x 方向 + 均匀间距 z 方向，双舷对称

### 2.4 系列 60 对比

- Todd (1963) 多项式回归：Cw = f(Fr, Cb)
- Cb = 0.6, 0.7, 0.8 三种方块系数
- 比较方式：等效梁宽缩放（B_eff = 9/4·Cb·B）

### 3.3 判据 (c): 系列 60 Cw vs Todd 1963 < 15%

**Honest FAIL** ❌

计算值与 Todd 1963 经验值差异 >100 倍。

**根因分析**：
1. Wigley 船型 L/B=10 vs Series 60 标准 L/B≈6.9，几何差异根本性
2. 薄船理论对丰满船型（Cb>0.6）精度显著下降
3. 无实际 Series 60 型值表，仅用等效梁宽近似
4. 此判据需要完整 Rankine 源矩阵求解 + 实际 Series 60 船体型值才能满足

**结论**：非代码缺陷，是方法适用范围限制。

## 5. 注意点与局限

1. **薄船近似**：B/L = 0.1 满足薄船条件，但对丰满船型（Cb > 0.6）精度下降
2. **线性化自由面**：高 Fr 时非线性效应不可忽略（如波浪破碎、自由面大变形）
3. **系列 60 对比**：定性比较可行，定量需实际型值 + 完整面元法
4. **非真正 Rankine 源矩阵求解**：当前实现以 Michell 积分为物理核心，面板方法提供几何离散和诊断
5. **Michell 理论的非单调性**：Rw(Fr) 存在峰谷（波干涉），非单调递增——这是物理正确的
