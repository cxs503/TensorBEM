## 1. 案例介绍

`docs/verification.md` 的算例选择表把「圆环径向导热 $u=A\log r+B$（多连通边界、内外法向）」
登记为**后续：需多边界组件**——即能力缺口，而不是已验证能力。本单问一个可判定的问题：
**把两条环拼成一次装配（外环逆时针 + 内环顺时针），现有常数面元配点求解器能否把这个算例做到 3%？**

| 项 | 值 |
|---|---|
| 域 | 同心圆环 $r_{in}=0.5<r<r_{out}=1.0$ |
| 参考解 | $u=A\log r+B$，$A=1,B=0$（除原点外调和，闭式） |
| 边界数据 | 每块面元**中点**处的解析值（不是圆上的常数，避免把几何误差混进数据） |
| 离散 | 外环 $2n$、内环 $n$ 块常数面元（$n=8,16,32,64$ → $N=24..192$），中点配点 |
| 核 | 直线面元解析单/双层积分，$G=-\frac1{2\pi}\log(r/L)$，程序取 $L=0.5$ |
| 判据 | 逐环通量 $\pm2\pi A$、未知迹 $q=\pm A/r$、内部场 $A\log r$ |

**为什么 $L$ 要换**：默认 $L=1.0$ 恰好接近圆环的容量（单层算子在该模态上近奇异），实测 $N=192$ 时 $\kappa$ 达 $1.5\times10^4$；改 $L=0.5$ 后 $\kappa$ 回到 $1.7\times10^2$。默认值未改（动它会牵动全部既有基准）。

## 2. 怎么做的

1. `multicomponent.annulus_mesh` 按「外环逆时针 + 内环顺时针」拼接顶点，使**每块面元的法向都指向流体之外**（内环法向指向孔内）——这是内域公式 $\mathbf S\mathbf q=(\tfrac12\mathbf I+\mathbf H)\mathbf u$ 唯一自洽的做法。
2. `check_loop_orientation` 用两条独立判据（各环有向面积符号、法向与径向的投影符号）在**构造后与求解前各校验一次**；方向反了直接 `ValueError`。
3. `log_potential_*` 给出闭式边界数据与闭式 $q$；`loop_fluxes` 给出逐环通量与净通量。
4. `benchmarks.annulus_log_potential` 跑加密序列，输出 JSON；`docs` 里所有数字由该 JSON 注入（零手抄），`tests/test_multicomponent.py::test_committed_study_reproduces_from_the_module` 重跑并与已提交 JSON 逐字段比对（`rel=1e-9`）。
5. **方向陷阱的判别力做成了实验**：`wrong_winding_control` 把内环反绕后再解一次，看残差与误差。

## 4. 注意点（坑 / 局限）

1. **结论是 FAIL，不是通过**：逐环通量进 3% 以内（$|\cdot|<1.3\%$），但**未知迹 11–17%、内部场 28–32%**，
   且加密几乎不改善（内部场 32.3%→28.6%）。内部场误差呈**近似常值偏移**，指向单层算子在
   双连通边界上的近容量模态（其单层势在边界上近似为常数，进入内部即成为一个常数偏置），
   而不是面板分辨不足。定因到这一步为止，未做进一步证明。
2. **不要把"拼接循环"当成"已支持多连通域"**：方程能解、残差舍入级、通量还对，唯独解本身是错的。
   本仓 `docs/verification.md` 该行因此**保持为「后续」**，只把手上的组件与量化结论挂上去。
3. **`PanelMesh.area` 不是圆环面积**：它是拼接顶点表的鞋带和，会把内环末点回到外环首点的跨接边算进去，
   只保证为正（`PanelMesh` 的构造校验需要它）。逐环面积必须对各环自己算。
4. **默认参考长度 $L=1.0$ 对此几何接近容量**，$\kappa$ 可到 $1.5\times10^4$；本单没改默认值。
5. 未做：偏心圆环、多个孔、内域 Neumann/混合边界。

## 5. 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 最好实测（$N=192$） | 是否 <3% |
|---|---|---|---|
| 外环通量 | 闭式 $+2\pi A$ | -0.761% | 是（连续弦积分对多边形本来精确，中点规则只带 $O(h^2)$） |
| 内环通量 | 闭式 $-2\pi A$ | -0.608% | 是 |
| 净通量（两环一致性的证据） | 0 | 1.533e-03 | 是 |
| 未知迹 $q$ | 闭式 $\pm A/r$ | 10.9% | **否** |
| 内部场 | 闭式 $A\log r$ | 28.6% | **否** |

结论：**本算例不满足 3% 判据**，故 `docs/verification.md` 中该行不改为「已实现」。
