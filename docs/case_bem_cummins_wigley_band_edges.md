# CASE-BEM-CUMMINS-WIGLEY — 频带两端实测：低频谱指数与高频弦斜率

锚点 `CASE-BEM-CUMMINS-WIGLEY`（算例池·Wigley 船 Cummins 记忆核 6DOF；ref = Cummins 方程 + Kramers-Kronig 因果；容差 <10 %）。任务 m20974。

## 1 案例介绍（物理背景/几何/参数）

Wigley III：L=3.0 m，B=0.3 m，T=0.1875 m，Cb=0.543，ρ=1025.0 kg/m³，g=9.80665 m/s²，无限水深，旋转中心 (0.0, 0.0, -0.09375)。几何门先于一切数字：Cb 由体积反算 0.543000（|误差| 0.0e+00），L/B=10.00，B/T=1.60，C33=7368.4839 N/m，passed=True。

判据为 Cummins 方程与其 Hilbert 对（Kotik & Mangulis 1962；Newman 1977 ch.6）：

```
(M + A_inf) x'' + ∫_0^t K(t-s) x'(s) ds + C x = F(t),   K(t) = (2/π)∫_0^∞ B(ω)cos(ωt)dω
B(ω) = −(2/π) PV∫_0^∞ s²(A(s)−A∞)/(s²−ω²)ds,   A(ω) = A∞ + (2/π) PV∫_0^∞ B(s)/(s²−ω²)ds
```

## 2 怎么做的（方法/流程/关键设置/工具链）

扩展带 medium 面板扫频（28 节点，[0.10, 20] rad/s，800 三角形）由集群作业 `cj3099`（`scripts/run_cummins_wigley_closure_full.py --stage solve --grid extended --level medium`，8 分片）求解，回传 14 个节点入 worktree （`artifacts/case_bem_cummins_wigley_ext/points`）。本轮**只**用这些真实面板数据判定两件事——生产中一直被当作“模型假设”的两端：

1. **低频谱指数 q**：在预声明节点 0.10/0.15/0.20/0.25/0.30 rad/s 上对 `ln B` 做 `ln ω` 的一次拟合（`scripts/cummins_wigley_band_edges.py`，`_loglog_slope`）。这是本算例第一次有 0.30 rad/s 以下的面板数据（rounds 1–6 全部缺失）。

2. **子带对 K(0) 的贡献**：`K(0) = (2/π)∫_0^∞ B dω` 的 [0, ω_min] 段，分别用“实测幂律精确积分”与“出货常值闭合”两种写法量化占比——即生产闭包的误差上界。

3. **高频端点**：4.7→12.5 rad/s 的两点弦斜率（15/20 rad/s 节点尚未回传），用于检验 `causality.kkr_added_mass` docstring 中“阻尼在 ω_max 以上指数衰减”的说法。

## 5 注意点（踩过的坑/局限/适用范围）

* 低频指数是**近乎整数**的：q = surge 6.998、sway 7.000、heave 2.995、roll 7.000、pitch 6.997、yaw 10.999，R² 全部 >0.999。这既是好消息（面板解在长波极限上干净、无奇异性污染），也是警告：**出货的偶极闭合 `B ~ c ω³` 只对 heave 成立**，对 surge/sway/roll （q≈7）与 yaw（q≈11）低了 4–8 阶；在本数据上这段子带对 K(0) 的占比 <0.01 %，所以结论是“闭合写错但不要紧”，而不是“闭合对”。

* 高频端**不可判定**：p = surge -0.31、sway -0.89、heave -1.21、roll -1.10、pitch 1.34、yaw -0.53，四个 DOF 的弦斜率为负（4.7→12.5 之间 B 还在**上升**）。因此“ω_max 以上指数衰减”这一 docstring 断言在本数据上**无法支持**；真正的渐近检验需要 15/20 rad/s 节点（`EXTENDED_GRID` 已声明、本轮未回传）。

* 本轮 `cj3099` 只回传了 14 个节点（分片 0.10–1.50 + 4.70 + 12.50），扩展带与共振簇其余节点仍在队列；因此 `--stage gates` 按设计**拒判**（缺节点不插值），G4 依旧不可判。
