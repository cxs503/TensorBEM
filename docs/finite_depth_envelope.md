# 有限水深辐射求解器的验证包络：ka × f/a 网格（m2874）

**状态**：`docs/finite_depth_radiation.md` §5 局限 5 的收口 —— 该局限原文是「只在圆形截面、ka=0.6、f/a=2 上验证；未扫 ka 与 f/a」。本文把三条独立判据（深水塌缩对 Ursell 闭式解、能量恒等式、堵塞/分模物理趋势）在 3×3 参数网格上重跑，并用面板梯度给出 N=64 的适用边界。

本文件所有数字由 `python -m tensorbem.benchmarks.finite_depth_envelope` 程序化写入（工件 `docs/finite_depth_envelope/benchmark.json`，图由同一次运行生成），无手抄。

## 1. 案例与参数

半径 \(a\) 的圆柱截面潜没于常水深 \(h\) 静水中，轴心深 \(f\)，作垂荡/横荡受迫振荡，\(\nu=\omega^2/g\)，波数 \(k_0\) 由 \(k_0\tanh k_0h=\nu\) 定。深水极限下其附加质量与阻尼有 Ursell 多极子闭式解，是本文唯一的物理基准。

| 参数 | 值 |
|---|---|
| \(a\) | 1 m |
| \(ka\) | 0.3, 0.6, 1.2（扫掠） |
| \(f/a\) | 1.5, 2, 3（扫掠） |
| 网格水深 \(h/a\) | 25 |
| 深度控制列 \(h/a\) | 50（\(f/a=2\)，对齐已发表单点研究的水深） |
| 浅水/堵塞 \(h/a\) | \(f/a+1+0.2\)（龙骨下净空 0.2\(a\)） |
| \(\rho\)、\(g\) | 1025 kg/m³、9.80665 m/s² |
| 面元数 \(N\) | 64（常数面元，等角分布；另做 32/64/128 面板梯度） |
| 判据 | 深水塌缩 <3%、能量恒等式 <3%、堵塞单调 |

## 2. 方法

单层位势（间接）提法，核 \(G_h=\tfrac{1}{2\pi}\log r+G_{\rm smooth}\)：奇异部分在直线面元上解析积分，只对光滑余项做 Gauss 求积。这与 `docs/finite_depth_radiation.md` §2 是同一套装配——本单**未改求解器一行**，只扩参数网格与判据覆盖。

三条判据都不依赖求解器自身的输出：

1. **深水塌缩**：\(h/a\) 大时系数须回到 `tensorbem.analytic.ursell_cylinder_added_mass`（Ursell 多极子闭式解，与面元法不共享任何代码）；
2. **能量恒等式**：远场波幅给出的阻尼 \(B_{\rm far}=2\rho g c_g|\eta_a|^2\) 与物面压力给出的 \(B_{\rm near}=\omega\rho\,\mathrm{Im}\,F\) 必须相等；
3. **堵塞与分模**：把海床压到「龙骨净空 0.2\(a\)」须抬高附加质量；有限水深下垂荡与横荡附加质量须分裂（深水二者一致）。

复现命令（多进程，单次约 64.5 s，12 进程）：

```bash
PYTHONPATH=src python3 -m tensorbem.benchmarks.finite_depth_envelope \
    --json docs/finite_depth_envelope/benchmark.json \
    --figures docs/finite_depth_envelope --workers 8
PYTHONPATH=src python3 -m pytest tests/test_finite_depth_envelope.py -q
```

## 6. 误差判定（逐项回答「是否 <3%」）

| 判据 | 最差值 | 出现位置 | <3%？ |
|---|---:|---|---|
| 深水塌缩（附加质量） | 2.36 % | ka=0.3, f/a=3, heave, N=64 | 是 |
| 深水塌缩（阻尼） | 4.19 % | ka=0.3, f/a=1.5, heave, N=64 | **否** |
| 能量恒等式 B_far/B_near | 1.082 % | 全网格 | 是 |

网格在 \(N=64\) 上的最差阻尼偏差出现在低 \(ka\)、浅潜深角落，超过 3% 验收带；第 4 节的面板梯度表明这是离散误差：最细网格 \(N=128\) 上同两点的最差偏差降到 2.40 %（<3%，观测阶见上表）。因此**该模块的「<3%」成立范围是 \(N\gtrsim 128\)**，\(N=64\) 只在 \(ka\gtrsim0.6\) 的角落内成立。

## 7. 注意点与局限

1. **仍无实验/文献数值表**：基准只有 Ursell 深水闭式解与能量恒等式；有限水深文献表本机仍不可得（与 `docs/finite_depth_radiation.md` §5 局限 2 同一欠账，本单未解除）。
2. **仍是圆形截面**、常水深、无流、线性势流；未接船体几何。
3. **网格水深只到 \(h/a=25\)**（\(\nu h\) 见第 3 节），深度控制列（\(h/a=50\)）用来说明 25 倍半径处的剩余水深效应，其量级见第 3 节表末列。
4. **等角常数面元**，偏差含 \(O(h)\) 离散误差；本单给的是「实现正确性的适用边界」，不是「对某船型的物理精度」。
5. 面板梯度只在两个最差点上做（\(N\) 到 128），没有对全部 9 点做梯度，其余点仍只报 \(N=64\) 的值。

## 8. 与生态的关系

浅水航道、港口与内河船的耐波/水动力系数需要有限水深修正。本文把该模块的验证包络从单点扩到 \(ka\times f/a\) 网格并给出面元数门槛，`ship-performance-platform` 接入时可据此判断某工况是落在已验证区、还是需要加密网格。
