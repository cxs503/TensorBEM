## ① 案例介绍（物理背景 / 几何 / 参数表）

**物理背景**：边界元（BEM）场点 `x` 常位于某面板上方小距离 `eps` 处——off-body 压力、自由面附近波高、近场速度、薄间隙、多体间隙。被积函数

```
S = ∫_T G dS,        G        = 1/(4πr),
D = ∫_T ∂G/∂n_y dS,  ∂G/∂n_y  = -n_y·(x-y)/(4πr³),
```

在 `eps/h → 0` 时于面板内形成宽度 `eps` 的峰。**固定张量 Gauss 规则（含固定阶 Duffy 变换）无法分辨该峰**：其误差随 `eps → 0` 无界增长，即使积分本身有界（趋于有限极限）。本单的目标即「三维近壁面场量求积」：把固定阶 Duffy 的失效实测确认（负对照），并代之以对 `eps` 均匀的**平坦面元精确/半解析边界积分**。

**几何与参数**（单位球，无界流体，均匀来流沿 `+z`）：

| 参数 | 值 |
|---|---|
| 半径 `a` | 1.0 m |
| 来流速度 `U` | 1.0 m/s |
| 解析场 | 球在均匀来流中的扰动势 `u = z/(2r³) = cosθ/(2r²)`，`r = |x| ≥ a` |
| 边界迹 | `u = cosθ/2`；流体域法向（`-r_hat`）`du/dn = +cosθ` |
| 网格 | icosphere 细分 1 / 2 / 3 → 80 / 320 / 1280 面板 |
| `h_max`（细分 2） | 3.249e-1 m |
| 清空扫描 | `d/h_max` = 1e-1 … 2e-4（至 `1e-5` 面板尺寸） |
| 求解设置 | `quadrature_order=8`, `split_ratio=1.0`, `max_level=24` |
| 求积参考 | `order=14`, `split_ratio=2.0`, `max_level=32` |
| 数据组 | 表示（精确解析迹，纯求积+迹离散）；端到端（`solve_laplace_surface` 外域解，再加稠密解） |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **旧规则为何失效**：`evaluate_surface_field` 用固定阶 Duffy-Gauss 规则积分单层核 `G=1/(4πr)`。目标接近面板时 `1/r` 峰落在面板内，固定规则无法分辨；双层项不是问题——常值面板密度下它是**闭式符号立体角**，任意清空下精确（这正是「平坦面元精确边界积分」的第一块）。
2. **新规则**（`src/tensorbem/near_field_quadrature.py` / `near_singular.py`）：两条独立、对 `eps` 均匀的路线——
   - `adaptive_triangle_quadrature`：递归中点二分，子三角形满足 `distance(x,sub) ≥ split_ratio·size(sub)`（well-separated 判据）即接受；只细化含峰的收缩链，成本随 `h/eps` **对数**增长，误差与 `d` 无关。
   - `polar_triangle_quadrature`：以脚点 `F`（`x` 在面板平面的投影）为极坐标，`ρ = eps·sinh(t)` 代换使每个径向被积函数解析无峰（`ρdρ/r = eps·sinh(t)dt`）；角向按顶点分三扇区，径向范围 `ρ_max(θ)` 为精确射线/边交点。
   - `semi_analytic_reference`：**独立仲裁者**——同扇区径向闭式积分（`∫ρdρ/r = R-eps`，`∫ρdρ/r³ = 1/eps - 1/R`）+ 仅 `θ` 方向 1-D Gauss；与上述两路线**无共享代码路径**，三路对比把求积误差与建模误差隔离。
   - `plain_duffy_quadrature`：未变换 Duffy 规则，**负对照**（必须随 `eps→0` 失效）。
3. **两个新入口**：`evaluate_surface_field_near_surface` / `evaluate_surface_velocity_near_surface`（`solver3d.py`），镜像旧远场函数、保留符号约定，仅拒绝恰在面上的点（表示在那里不连续）。旧函数不动——**没破坏任何已工作的路径**。
4. **误差隔离**：参考 = 同自适应规则 `order=14, split_ratio=2.0`（与 `order=16, split_ratio=3.0` 一致到 1e-13）；生产设置与参考之差 = 纯求积误差；再与解析场比较 = 加常值面板迹误差。
5. **途中修一个 bug**（首轮扫描看似不收敛的原因）：`_bisect` 把四个子三角形**按块**堆叠，子三角形须用 `np.tile(parents,4)` 而非 `np.repeat(parents,4)` 映射回父。`repeat` 下总和对网格守恒（看似合理）但单面板值被置换，`S @ q` 随细化漂移 30%；修复后规则跨设置收敛到 1e-13，面板级测试钉住。
6. **验证欠账结清**（`near_surface_error_budget`）：闭式 `grad(Ω_j)` 与独立有限差分 oracle 逐面板对账（两套代码路径）；闭网格恒等式 `sum_j grad(Ω_j)=0`；失败案例对求积阶（8→12）与网格（320→1280）的敏感性；放大模型 `d(v)/d(μ_j) = -grad(Ω_j)/(4π)`。

**工具链**：`python -m tensorbem.benchmarks.near_surface_field` / `near_surface_error_budget` 写 `results.json` + Markdown + PNG（数字程序化注入，零手抄）；`pytest` 验证（`test_near_singular.py` 10 测试 + `test_near_surface_error_budget.py` 8 测试等）。

## ③ 计算结果（数字表，程序化注入）

### 3.1 核层面（单面板，纯求积误差）——固定阶 Duffy 失效的实测确认

| `d / 面板尺寸` | 固定 Duffy order 8 | 自适应（新） |
|---|---|---|
| 1e-1 | 3.19e-3 | 3.9e-14 |
| 3e-2 | 3.20e-2 | 1.5e-14 |
| 1e-2 | 6.19e-2 | 1.9e-14 |
| 1e-3 | 8.11e-2 | 1.9e-14 |
| 1e-4 | 8.33e-2 | 1.4e-14 |
| 1e-5 | 8.35e-2 | 2.4e-14 |

梯度核（`∫ grad_x G dS`）同向：`d=1e-4` 时固定规则 **98%** 误差，自适应规则每个清空 **<1e-6**。固定规则误差随 `eps→0` 单调无界（8.35e-2 封顶于 `1e-5`），**负对照按预期失效**；自适应规则 6e12 量级改善。

### 3.4 网格收敛（固定清空比，精确迹）

| 细分 | 面板 | `d/h_max` | 势误差 | 速度误差 |
|---|---|---|---|---|
| 1 | 80 | 1e-2 | 6.3e-2 | 1.96e-1 |
| 2 | 320 | 1e-2 | 1.56e-2 | 1.41e-1 |
| 3 | 1280 | 1e-2 | 3.85e-3 | 7.95e-2 |
| 3 | 1280 | 1e-3 | 3.52e-3 | 1.72e-1 |

势按常值面板迹**二阶**收敛（4.0× / 4.1× 每细化）；速度收敛慢且随清空缩小误差增长——放大在双层项。

### 3.5 近壁压力

`d = 0.03 h_max = 9.75e-3 m`（低于旧限 1.63e-2 m）时 `max|dCp| = 7.5`（= **3.34 倍** Cp 尺度 2.25）；`d = 0.1 h_max` 时 `|dCp| = 1.18`（0.53 倍尺度）。表面 Cp RMS（切向恢复路径）5.5e-2。**对 3% 线诚实 FAIL**。

### 3.6 误差预算（验证欠账结清）

- **闭式 `grad(Ω_j)` 精确**：1280 面板 `d=0.03 h_max` 时 max 相对误差 **2.45e-8**（oracle 对账），闭网格和 **2.15e-13**（面板梯度尺度 195.8）——**无消去**。
- **求积无关**：`order 8 → 12`（约 4× 工作量）误差 4 位全同（ratio 1.000000）。
- **网格无关**：320 → 1280 观测阶 **-0.034**（`d=0.1`）/ **-0.044**（`d=0.03`）——不收敛。
- **放大模型**：`max_j |gradΩ_j|/(4π)` 随 `1/d` 增长（0.09 @ `d=h_max` → 7.27 @ `d=0.03 h_max`，320 面板），与 `O(h)` 面板内迹变化的乘积对 `h` 不变（6.87e-1 → 7.30e-1）——**常值面板双层对近壁梯度无收敛率**，误差是局部场的固定比例，由分段常值密度设定而非面板尺寸。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

- **速度操作包络（2026-11-03 修订）**：`d ≥ 0.5 h_max` 才在最差探针（赤道）满足 3%（2.66% 局部梯度尺度）；早前「`d ≥ 0.1 h_max` 即 3%」**不成立**（赤道 79%）。低于 `0.5 h_max` 误差由表示驱动、不随网格细化改善——**更紧清空不能用面板买**。
- **Cp 失败原因（实测修正）**：不是闭式、不是求积——双层项微分**分段常值**迹，迹误差 `dμ_j` 经 `grad(Ω_j)dμ_j/(4π)` 放大（`max|gradΩ|/(4π)` 随 `1/d` 增长），把 `O(h)` 面板内迹变化变成 `O(1)` 速度误差；因放大 `O(1/h)` 与变化 `O(h)` 乘积不收缩。**正则化超奇异求积无济于事**；出路是更高阶（线性/二次）密度表示，或不做微分（切向恢复路径表面已 2.4%）。
- **不要用面-精确点**：两入口仍拒绝恰在面上的目标（表示在那里跳跃）。
- **成本**：每目标工作随 `h/d` 对数增长；整个基准（含稠密解）单核 ~30 s；1280 面板稠密装配 ~2 min，故收敛研究用精确迹。
- **参考规则陷阱**：`split_ratio` 越小 = 细化越少（`refine while distance < split_ratio·size`）；搞反会让「参考」变成不精确运行，扫描立即暴露。
- **统计口径**：`error_budget` 是单探针点值（赤道/极/斜向，精确迹）；`near_surface_field` 是端到端解的扫描统计——**两表不可互换**；赤道是最差探针，结论建立在它上。
- **内接网格质心在球内**（`r<1`），精确迹不是光滑球迹（~2.5% 差异）——这是常值面板表示的正确选择（配点解收敛到它），但数字**不是**关于多面体几何误差的陈述。
- **适用范围**：本单结论针对**常值面板**表示与 Laplace 单/双层核；更高阶密度、自由面/水动力核、超奇异（hypersingular）求积均属后续工作（未在本单内）。

## ⑥ 误差判定（关键量 vs 基准，逐项显式回答「是否 <3%」）

| 关键量 | 基准 | 实测 | <3%? |
|---|---|---|---|
| 单层核求积（自适应，`d=1e-5`） | 收敛参考（order 14/16） | 2.4e-14 | **是**（超 12 个数量级） |
| 固定 Duffy（`d=1e-5`） | 收敛参考 | 8.35e-2 | **否**（负对照，预期失效） |
| 近壁势（端到端，`d=2e-4 h_max`） | 解析 `u` | 7.16e-3（<1%） | **是** |
| 近壁速度（赤道，`d=0.5 h_max`，320 面板） | 解析 `grad(u)` | 8.46e-3（2.66% 局部尺度） | **是**（临界） |
| 近壁速度（赤道，`d=0.1 h_max`） | 解析 | 3.59e-1（79%） | **否——诚实 FAIL** |
| 近壁速度（赤道，`d=0.03 h_max`） | 解析 | 1.63e+0（335%） | **否——诚实 FAIL** |
| 近壁 `|dCp|/尺度`（`d=0.03 h_max`） | 解析 `1-(9/4)sin²θ` | 1.49 | **否——诚实 FAIL** |
| 闭式 `grad(Ω_j)`（1280 面板，`d=0.03 h_max`） | 有限差分 oracle | 2.45e-8 相对 | **是**（超 7 个数量级） |
| 闭网格 `sum_j grad(Ω_j)` | 0（恒等式） | 2.15e-13 | **是** |

**总判定**：求积层（功能补全）**全面达标**——固定阶 Duffy 失效被实测确认（负对照），平坦面元精确/半解析边界积分（自适应 + 极坐标 + 半解析参考）把求积误差压到机器级，近壁势 <1% 达标。但近壁**速度/压力**（验证欠账结清后归因）是表示层（分段常值密度微分）问题，对 3% 线**诚实 FAIL**——**原单 FAIL 结论如实保留**，未做任何基准调整或数字粉饰。
