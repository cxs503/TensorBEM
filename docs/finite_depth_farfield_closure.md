## 1. 案例介绍（欠账是什么）

`docs/finite_depth_radiation.md`（m2388）把有限水深 Green 函数接进二维间接边界元后，给出了
\(h/a=3.2\ldots50\) 的端到端水动力系数，但留下一条**未解释的验证缺口**：

> 每个水深下 \(B_{\rm far}/B_{\rm near}=1.0106\)，即远场（波幅能量）与近场（表面压力做功）
> 两种互不依赖的阻尼公式相差 1.06%。文档只能说"闭合到约 1.06%"，不能说"闭合到 1%"。

这条缺口有两种互斥解释，**判决方式完全不同**：

| 解释 | 判据 | 若成立的后果 |
|---|---|---|
| A. **归一化缺陷**（因子 2、群速 \(c_g\)、模方 \(N_0\)、运动学因子 \(i\omega/g\) 有一处错） | 比值收敛到一个 \(\neq1\) 的常数，加密网格不动 | 求解器**有 bug**，须改代码 |
| B. **离散误差**（面元密度一阶精度，近/远场各自带 \(O(1/N)\) 误差） | 残差随 \(N\) 按一阶下降，外推极限为 1 | 文档措辞须改，代码不动 |

判别只需要"加密"，不需要论证。为此本单做了三件事：**加密收敛序列 + 独立振幅交叉验证 +
求积误差定量 + 故障注入**。

算例与 m2388 一致：半径 \(a=1\) m 的圆柱截面轴心潜没 \(f=2a\)，作垂荡振荡，
\(ka=0.6\)（\(\nu=\omega^2/g=0.6\ {\rm m^{-1}}\)，\(\omega=2.425694\) rad/s），
\(\rho=1025\ {\rm kg/m^3}\)，\(g=9.80665\ {\rm m/s^2}\)，面元数 \(N=64,128\)。
水深 \(h/a=3.2\)（净空 0.2）、\(5\)、\(50\)，另设**深水解对照**（同一网格，`free_surface_solver`）。

---

## 2. 怎么做的（方法与关键设置）

1. **加密收敛序列**：对每个水深取 \(N=64,128\)，记录 \(B_{\rm near}\)（压力积分）、
   \(B_{\rm far}=2\rho g c_g|\eta_a|^2\)（波幅能量）、比值，并用两点法拟合观测阶
   \(p=\log(e_{64}/e_{128})/\log 2\)，再做 Richardson 外推得 \(N\to\infty\) 的极限比值。
   \(p\approx1\) 且外推 \(\to1\) ⇒ 解释 B；\(p\approx0\) 且外推 \(\ne1\) ⇒ 解释 A。
2. **独立振幅交叉验证**（排除"核与投影共用一个错因子"的自洽盲区）：把波幅 \(\eta_a\)
   再用**完全不同的路线**算一遍——在自由面上取 \(x=12\)、\(24\) 个耗散模衰减长度处的场点，
   直接用有限水深 Green 函数 `finite_depth.green_function` 积分求势，
   除以载波 \(e^{ik_0x}\) 得振幅，与投影公式给出的 \(\eta_a\) 比。
   探针放到 12/24 个衰减长度上，耗散模残留 \(\sim10^{-5}\)，只余传播模。
3. **求积误差定量**（排除"投影积分的面板中点求积不准"这一嫌疑）：同一 \(\sigma\) 用
   16 点 Gauss 在面板上重算投影积分，取相对差。
4. **深度无关性归因**：比值在 \(h/a=3.2,5,50\) 三个物理上完全不同的解上几乎相同（1.01047/1.01058/1.01067），
   这是"共享离散化"而非"某深度特有物理"的指纹，故必须用加密而非逐深度调参来判定。
5. **故障注入**（测试有没有牙）：同一 \(\sigma\) 下，把远场系数故意弄错——
   (i) 只算一个传播方向（丢掉因子 2）；(ii) 用相速 \(c_p\) 代替群速 \(c_g\)；
   (iii) 浅水处沿用深水 \(c_g=\omega/(2k_0)\)——看比值落到哪里，用以标定容差。
6. **深水塌缩锚**：\(h/a=50\) 时 \(k_0h=30\)，两种核之差为 \(O(e^{-2k_0h})=O(10^{-26})\)，
   故有限水深解**必须**收敛到深水 Ursell 解析值 \(B=2718.1540\)。
   这给近场一个独立的**解析**目标；同时用 MFS（点源，无面板）给第二个独立离散。

工具链：纯 `numpy`/`matplotlib`，所有数字由
`PYTHONPATH=src python -m tensorbem.benchmarks.finite_depth_farfield --panels 64 128` 程序化写出，
报告与文档中的数值全部取自 `closure.json`，零手抄。判据回归见
`tests/test_finite_depth_farfield.py`（6 条，10.6 s）。

## 3. 计算结果（零手抄，取自 `closure.json`）

### 3.1 闭合残差与观测阶

| 算例 | \(B_{\rm near}\)（N=64 / 128） | \(B_{\rm far}\)（N=64 / 128） | \(B_{\rm far}/B_{\rm near}\)（64 / 128） | 观测阶 \(p\) | 外推 \(N\to\infty\) |
|---|---:|---:|---:|---:|---:|
| 有限水深 \(h/a=3.2\) | 2349.827 / 2309.140 | 2374.430 / 2321.429 | 1.010470 / 1.005322 | **0.976** | **1.000** |
| 有限水深 \(h/a=5\) | 2974.661 / 2935.795 | 3006.123 / 2951.514 | 1.010577 / 1.005354 | **0.982** | **1.000** |
| 有限水深 \(h/a=50\) | 2789.085 / 2756.295 | 2818.845 / 2771.315 | 1.010670 / 1.005450 | **0.969** | **1.000** |
| 深水解对照（同网格） | 2787.237 / 2754.470 | 2758.177 / 2739.836 | 0.989574 / 0.994687 | **0.973** | **1.000** |

（单位 kg/(m·s)。"外推"= 用观测阶的 Richardson 极限，四舍五入到 1e-3。）

**判决：解释 B 成立。** 三个水深 + 深水对照，残差全部按 \(p\approx0.97\text{–}0.98\)（一阶）减半，
外推极限为 1.000。归一化若有常数错，外推不会回到 1 —— 因子 2、\(c_g\)、\(N_0\)、\(i\omega/g\)
四者**全部被钉住**。

注意深水解的残差从**下方**逼近（0.9896 → 0.9947），有限水深从**上方**（1.0106 → 1.0054）。
两条路线（Haskind 表面积分 vs 源密度投影）离散误差符号相反是正常的：二者的误差来自不同的
求和路径，但都以一阶消失。这解释了 m2388 当初"符号相反、量级相同"的困惑。

### 3.2 振幅交叉验证与求积误差

| 算例 | 直接远场振幅 vs 投影振幅（N=64 / 128） | 投影积分中点 vs 16 点 Gauss |
|---|---:|---:|
| \(h/a=3.2\) | 6.5e-05 / 1.6e-05 | 6.5e-05 |
| \(h/a=5\) | 3.9e-05 / 1.0e-05 | 3.9e-05 |
| \(h/a=50\) | 3.9e-05 / 9.6e-06 | 3.9e-05 |

投影公式与 Green 函数的直接远场一致到 \(10^{-5}\) 量级 ⇒ 传播模形状、模方 \(N_0\)、
\(i\omega/g\) 三者与核自洽。面板中点求积误差 \(\le6.5\times10^{-5}\)，比观测缺口小两个数量级
⇒ **求积不是缺口来源**（缺口的量级只能来自 \(\sigma\) 的一阶面板误差）。

### 3.3 故障注入（测试容差落在哪）

\(N=128\) 时同一 \(\sigma\) 下人为把远场系数弄错，比值会落到：

| 算例 | 正确 | 丢因子 2 | 用 \(c_p\) 代 \(c_g\) | 浅水沿用深水 \(c_g\) |
|---|---:|---:|---:|---:|
| \(h/a=3.2\) | 1.00532 | 0.50266 | 1.75115 | 0.87557 |
| \(h/a=5\) | 1.00535 | 0.50268 | 1.95397 | 0.97699 |
| \(h/a=50\) | 1.00545 | 0.50272 | 2.01090 | 1.00545¹ |

¹ 深水 \(c_g=\omega/(2k_0)\) 与有限水深 \(c_g=\tfrac{c}{2}(1+2k_0h/\sinh 2k_0h)\) 在 \(k_0h=30\) 时差别
\(<10^{-25}\)，故此格不具区分力；\(h/a=3.2\) 处才有 12.4% 的区分力。

结论：三种错误与正确值的最小距离是 0.12（\(h/a=3.2\) 的深水 \(c_g\)），远大于恒等式判定所用的
±2% 容差 ⇒ **回归测试确有牙**。

### 3.4 深水塌缩：有限水深解对上 Ursell 解析基准

\(h/a=50\)（\(k_0h=30\)）时两种核在解析上已经等价，所以 Ursell 深水解析解
\(B=2718.1540\) 是有限水深算例的合法目标：

| 离散 | \(N=64\) | \(N=128\) |
|---|---:|---:|
| 面板近场 \(B_{\rm near}\) | 2789.085（+2.61%） | 2756.295（+1.40%） |
| MFS 近场（无面板，独立离散） | 2710.086（**−0.30%**） | 2717.345（**−0.03%**） |
| 深水 Ursell 解析（目标） | 2718.1540 | 2718.1540 |

面板解从上方一阶收敛到解析值（+2.61% → +1.40%），MFS 已经站在 0.03% 上。
两者给出同一极限，且极限就是解析值 ⇒ 有限水深核在深水极限无系统偏差。
（\(h/a=3.2,5\) 一列与深水解析的"误差"是**物理**差异，不能当误差读：\(h/a=3.2\) 时
\(B\) 比深水低 13.6%/15.0%，是浅水效应本身。）

![closure](outputs/finite_depth_farfield/closure.png)

左：\(|B_{\rm far}/B_{\rm near}-1|\) 随面板数的双对数收敛（点线为一阶参考斜率）；
三个有限水深算例与深水解对照全部落在 \(N^{-1}\) 斜率上。右：\(h/a=50\) 的近场对深水 Ursell 解析值
的误差，面板法一阶收敛，MFS（无面板）已到 0.03%。

## 4. 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 误差 | <3%？ |
|---|---|---|---|
| 闭合残差外推极限 \(\lim_{N\to\infty}B_{\rm far}/B_{\rm near}-1\) | 0（能量守恒） | **≤1e-3**（Richardson 外推，三算例同） | ✅ 是 |
| \(N=64\) 闭合残差 | 0 | 1.05e-2（一阶离散，非缺陷） | ✅ 是（<3%） |
| 直接远场振幅 vs 投影振幅 | 同一核的解析恒等 | **1.6e-5…6.5e-5** | ✅ 是 |
| 投影积分求积误差 | 16 点 Gauss | **≤6.5e-5** | ✅ 是 |
| \(h/a=50\) 近场 vs Ursell 解析 \(B=2718.1540\)（面板 \(N=128\)） | 解析 | +1.40%（\(N=64\): +2.61%） | ✅ 是 |
| \(h/a=50\) 近场 vs Ursell 解析（MFS \(N=128\)） | 解析 | **−0.03%** | ✅ 是 |
| 故障注入区分度（最小） | — | 0.124（12.4%） | 判据有效 |

**结论**：文档里那条"闭合到约 1.06%"应改为"闭合残差一阶收敛、外推为零；
\(N=64\) 时残差 1.06%，\(N=128\) 时 0.53%"。物理与实现均无需改动，无一关键量超出 3% 判据。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **直接远场探针的距离必须按耗散模衰减长度取，不能按 \(1/k_0\) 取**。第一版按 \(10/k_0\)、
   \(20/k_0\) 放探针，在 \(h/a=50\) 处耗散模 \(\mu_1\approx0.0314\)、衰减长度 32 m，探针在 17 m/33 m
   处残留 \(e^{-0.5}\approx0.6\)，振幅偏差被污染到 **1.06e-2**——量级恰好与待判缺口相同，若不追查
   就会得出"振幅归一化有问题"的错误结论。改成 12/24 个衰减长度后偏差降到 \(10^{-5}\)。
   **教训**：验证一个 1% 量级的恒等式时，探针/求积的截断误差必须先压到 1e-4 以下，否则测的是工具本身。
2. **深水解与有限水深的闭合残差符号相反**（−1.04% vs +1.06%），初期容易误判为"其中一个实现有错"。
   正确读法是两条不同的离散路径各带一阶误差、符号可以不同；判据只能是"是否随 \(N\) 消失"。
3. **\(h/a=3.2\) 与深水解析之差不是误差**：浅水把 \(B\) 压低 13.6%（\(N=64\)）、15.0%（\(N=128\)），
   这是物理。只有 \(k_0h\gg1\) 的 \(h/a=50\) 才能拿深水解析当目标。
4. **未做**：\(N=256\) 及以上的加密未纳入（单次约 400 s，本机 load15 ≈ 110，按容量纪律止步于
   \(N=128\) 两点 + 一阶拟合）；本机无有限水深附加质量的文献表（Yu & Ursell 类），文献对表仍是
   `docs/finite_depth_radiation.md` §5 的未结项；只做二维垂荡，横荡与三维情形未覆盖。
5. **未改求解器代码**：本单是验证欠账结清 + 判据钉桩，`finite_depth*.py` 一字未动。
