## 5. 注意点（踩的坑 / 局限）
发现的既有缺陷（全部留痕，不静默覆盖）：
1. **参数表 ω=1.905 rad/s 错**：与同表 ka=0.6/a=1/g=9.80665 矛盾（应为 2.425694），也与自引 B_ref=2718.154 矛盾（ω=1.905 时为 2135）。已改为 2.425694。
2. **三行数值与同行相对误差不自洽**：A(16) 2697.5→2697.8241；B(32) 2851.7→2841.7492（两表重复同一错值）；A(64) 2587.6→2587.7627。
3. **近/远场列粗网格陈旧**：旧 2850.1/2813.8/2762.1 vs 重算 2796.6000/2784.7004/2758.1774（128 行旧值 2739.9 仍逐位复现 → 是粗网格陈旧值，非定义差异）。
4. **同一比量两个定义**：§3.1/§4.2 用 (near−far)/near，§6 用 near/far−1；已统一为 |near/far−1|。
5. **README 对照过期**：旧稿拿 README 已废弃的 7.7e-3 比出 10.6%「FAIL」；README 现声明 8.51e-3（m2265 已结案），实测偏差 +0.0%。旧 MFS 0.234%/0.412% 无法归因到任何配点数。
