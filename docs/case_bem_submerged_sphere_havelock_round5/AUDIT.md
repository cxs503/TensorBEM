# 第 5 轮对抗性复核 — ka=4,5 案定网格实算（m22072）

锚点 `CASE-BEM-SUBMERGED-SPHERE-HAVELOCK`（算例池·Havelock 潜球辐射·频域，
验收 `<5%`）。本轮**只处理第 4 轮（m21580）审计遗留的 major #2**：
案定网格 1280 面元的 `ka=4,5` 两行原为 320 面元 GCI 外推估计值，
`condition_number` 为两位占位符 `2.05`，却参与"全带 28 项 PASS"的判决。

本轮工作性质 = **对已合并功能做独立复核**（不是加功能）：把估计换成实算，
并复核"实算之后 PASS 是否还成立"。

## 0. 独立性说明（limitation）

- 计算由同一仓库代码路径完成（`run_frequency_sweep`，与表中其余 5 行**同一路径**），
  因此这不是"第二套求解器"的独立验证，而是**同一实现的自洽性 + 与解析参考的比对**。
- 唯一的外部锚点仍是 Havelock 多极级数（`analytic.submerged_sphere_wave_multipole`），
  其本身由三项不变量自证（截断无关 1e-12、Haskind 互易 8.8e-16、Lamb 深潜极限）。
  `ka=4,5` 的文献表格（Wang 1986 / Linton & McIver 1991）在本沙箱内不可得（付费墙），
  故**参考侧没有第三方数值**。这是本轮最大的证据弱点，如实登记。
- 本机不允许长算，计算递交 `cj3884`（n330，4 核，1288 s）执行；
  代理只拿回工件，未手工转抄任何数字（`ka45_case_mesh_computed.json` 为程序直出）。

## 3. 分级发现

**F1（major，已关闭）** 两行估计值曾支撑"全带 28 项 PASS"的表述。现已替换为实算，
PASS 成立且最大误差反而略降（1.1947% 对 1.1880% 的估计值，同量级）。
→ 结论方向未变，但**证据强度变了**：这是本轮唯一实质闭环。

**F2（major，新，证伪前单假设）** m21647 预判"实算与 GCI 估计偏差 <0.2%（G4 门控要求
预测比 ∈[1/2,2]）"对 3 个量不成立：`ka=5 b11` 偏差 **6.58%**、`ka=4 b11` 3.21%、
`ka=4 b33` 1.89%。偏差全部出现在量级最小的阻尼项上（`B'` 1e-6~1e-5），
即 GCI 缩放对**小量**的外推能力被高估。加性质量项（`A'`）偏差 ≤0.22%，符合预期。
→ 纪律含义：小量外推不得用于闭合判决（本轮已由实算替代）。

**F3（major，标注而非放宽）** `ka≥4` 的 4 项阻尼（`B'`~1e-6…1e-5）用 5% 相对判据
携带的信息量低：其相对误差 ~1% 主要由离散偏置（面积赤字 0.48% 的映射）决定。
`sweep` 常量注释里"5% 相对判据在 ka=4,5 仍有区分力"的说法过强。本轮不撤判据，
只把它们单列 `degenerate_items` 并给出尺度归一误差（1e-4 尺度下 ~1e-5），
使 PASS 不被过度解读。

**F4（minor）** `condition_number` 占位符 2.05 恰好与真实值 2.048 重合，
"占位符"只能靠位数（两位数）识别，不能靠值识别。溯源守卫改用**有效位数 ≥10**。
