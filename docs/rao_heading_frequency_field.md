# 耐波响应场（频率 x 浪向）交付：浮半球 |RAO| 云图与独立基准核验

> 数据工件：`data/rao_heading_field_2026-11-05/rao_field.json`（场量全量）、`data/rao_heading_field_2026-11-05/rao_field_coarse.json`（64 面板对照）、`data/rao_heading_field_2026-11-05/verification.json`（判据表）。
> 复现：`python -m tensorbem.benchmarks.rao_heading_field --out data/rao_heading_field_2026-11-05 --figures figures` 然后 `python tools/rao_field_report.py`（数字零手抄，全部由工件注入）。

## 1. 案例介绍

**物理背景.** 频域耐波性的核心量是响应幅值算子 $|\mathrm{RAO}_i(\omega,\beta)|$，它把入射波幅映射到 6 自由度运动幅值；耐波性后处理（谱矩、短期统计、极值）本质上是这张 $\omega\times\beta$ 响应场的加权积分。平台此前只在单个 $(\omega,\beta)$ 上给出 RAO 数值，从未交付过场量本身，因此本单补齐**响应场云图**这一交付物。

**几何/参数表**（浮半球，深水，零航速；场量对尺度不变，故取 $a=1$ m）：

| 量 | 值 | 来源 |
|---|---|---|
| 半径 $a$ | 1.0 m | 几何 |
| 面板数（细网格） | 256 | `hemisphere_hull_mesh(3)` |
| 位移体积 $\nabla$（网格） | 2.0458 m^3 | `compute_displaced_volume_and_buoyancy` |
| 质量 $m=\rho\nabla$ | 2096.95 kg | $\rho=1025$ kg/m^3 |
| 重心 $z_G$ | $-0.5a$ | 与已入库 RAO 基线一致 |
| 恢复矩阵 $C_33$ | 31376.2 N/m | 网格静水（$\rho g A_{wp}$） |
| 惯量 $J$ | $m\cdot 0.4a^2\cdot I$ | 与已入库基线的测试惯量一致 |
| 无量纲波数 $ka$ | 0.20 … 2.00（11 点） | 深水色散 |
| 对应圆频率 $\omega$ | 1.400 … 4.429 rad/s | $\omega=\sqrt{g\,ka/a}$ |
| 浪向 $\beta$ | 0 … 180 deg（11 点） | $0$ = 波沿 $+x$ 传播 |

## 2. 怎么做的

1. **算子复用但零妥协**：自由面算子只依赖（网格, $\nu$），辐射问题与浪向无关，故每个频率只装配一次算子、解一次辐射，再对每个浪向只解一次绕射；RAO 由 6x6 阻抗 $Z=-\omega^2(M+A)+i\omega B+C$ 直接求解。复用后的结果与公开入口 `compute_rao_at_frequency` 逐元素一致（本单实测 $\max|\Delta|$RAO$||=0$、$\max|\Delta F|=0$，机器判据见 `tests/test_rao_heading_field.py`）。
2. **判据先于计算**：验证只用与面元算子无关的参照——
   (a) Hulme (1982) 多极级数（文献）给出的 $A_{33},B_{33},F_3$，配合单自由度垂荡传递函数得到闭式 $|$RAO$_3|$ 参照；(b) 回转体激励的 Haskind 精确指向律 $F_1(\beta)=F_h\cos\beta$、$F_3$ 与浪向无关；(c) 长波极限 $|$RAO$_3|(ka\to0)=1$；(d) 仓内已入库基线 `docs/rao_verification_metrics.json`（64 面板）；(e) 256 vs 64 面板离散收敛。
3. **工具链**：Python 3 / numpy / matplotlib（Agg，无中文字体故图内标注为英文）；50 个 BEM 频率-浪向组合并行 4 进程，单核约 11x(装配+辐射+11x绕射)。

## 5. 注意点与适用边界

- **无粘绕射/辐射**：只含辐射阻尼（无粘性），横摇在共振区响应偏大，云图中现出的 RAO$_4$ 峰值不可直接当实船横摇幅值用，需另加粘性阻尼。
- **对象是浮半球**（回转体），不是船体：无航速、无细长体、无 Wigley/实船几何；响应场用于**校核求解器场量链**，不构成某型船的耐波性结论。
- **深水、线性、单色波**：无浅水/有限水深修正，无二阶力。
- $ka$ 上限 2.00：更高频需要更密网格（256 面板在 $ka>2$ 已开始欠分辨）。
- 浪向对称律只在回转体上严格成立；对一般船体，$\beta$ 与 $180^\circ-\beta$ 不再等价。

**无基准项（显式声明）**：纵摇/横摇/surge 的 RAO 本身在仓内没有闭式参照（Hulme 级数只给垂荡 $m=0$ 与纵荡 $m=1$ 的激励与附加质量），因此这三个自由度的云图**不声称** <3% 精度，只给出：激励场指向律核验（上表）、长波垂荡极限、以及与已入库基线的复现。要补齐需要额外引入文献 RAO 表或模型试验数据。
