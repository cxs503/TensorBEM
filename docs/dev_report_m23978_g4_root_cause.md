# CASE-BEM-CUMMINS-WIGLEY：G4 自由衰减闸门 28% 失败的根因验证（验证欠账）

**Mission**: m23978 ｜ **Anchor**: `CASE-BEM-CUMMINS-WIGLEY`（feature_ledger: open）｜ **仓**: TensorBEM
**角色**: verifier（tp-ver-5）｜ **对象**: 扩展闭包带 G4（`zeta_decay` vs `zeta_half_power`）的 28% 失败

## 1 这条欠账从哪来

m23208 把扩展闭包带（69 频点 0.10–20 rad/s）的 G3/G5 用**独立镜像 A_∞** 判为通过后，
剩余缺口被缩到一条：**G4（自由衰减）**。G4 在独立 A_∞ 下仍 FAIL（heave 28%，
`zeta_decay=0.213` vs `zeta_half_power=0.167`）。总账锚点因此**不能**标 verified。

本单（verifier）把这条欠账的**根因**独立验证清楚：G4 的 28% 是**估计器偏置**，
不是求解器 bug。

## 2 怎么做的（方法）

G4 比较的是**两条不同路线**的阻尼比：
- `zeta_decay`：时域 Cummins 卷积自由衰减的**实际**衰减率（自由运动的真阻尼比）；
- `zeta_half_power`：频域响应 `1/|kappa|` 的**半功率带宽**（局部代理量，
  仅对**常系数**单自由度振子精确）。

对真实船，`A(ω)`/`B(ω)` 在半功率宽度内变化，频域峰不是干净 Lorentzian，
半功率带宽被偏置。验证流程（全部输入来自已提交的 `sweep_closure_medium800.npz`，
不重解）：

1. 重放 Wigley heave 的 G4（`zeta_decay`/`zeta_half_power`/半功率宽度）；
2. 量化半功率宽度内 `A(ω)`/`B(ω)` 的变化幅度（偏置驱动量）；
3. 对照合成因果对（弱频变，测试断言 <10%）——证明弱频变下两估计器一致；
4. 常系数控制——证明半功率与衰减**不可比**（Cummins 记忆核需要频变 B 才有记忆）。

## 3 计算结果（`artifacts/g4_root_cause/g4_root_cause.json` 程序化注入）

| 量 | 值 |
|---|---|
| Wigley heave `zeta_decay` | 0.2256 |
| Wigley heave `zeta_half_power` | 0.1666 |
| G4 rel_err | 35.4 %（FAIL，容差 10%） |
| 半功率宽度 | 2.478 rad/s = 33.6 % of ω_n |
| `A(ω)` 跨宽度变化 | 13.0 % |
| `B(ω)` 跨宽度变化 | **40.3 %**（偏置主驱动） |
| 合成因果对（弱频变）rel_err | 9.33 %（<10%，通过） |

**根因**：Wigley heave 的 `B(ω)` 在半功率宽度（2.48 rad/s）内变化 **40%**，
半功率带宽代理量（假设 B 在宽度内恒定）被系统性偏置；时域衰减 `zeta_decay`
是自由响应的**真**阻尼比。G4 的 28–35% 是**估计器偏置**，不是求解器/网格问题。

## 4 误差判定（逐项）

| 关键量 | 基准 | 误差 | <3 % ? |
|---|---|---:|---|
| G4 重放（decay vs half-power） | 两条路线 | 35.4 % | ❌ 否（这是被验证的偏置本身） |
| 合成因果对（弱频变） | 自洽 | 9.33 % | ❌ 否（但 <10% 容差，证明弱频变下一致） |
| `B(ω)` 跨宽度变化 | 半功率宽度内 | 40.3 % | ❌ 否（偏置驱动量，非误差） |

## 5 注意点 / 局限

* **本单不改 G4 判决**：G4 仍是 FAIL（`zeta_decay` vs `zeta_half_power` 35%）。
  本单交付的是**根因验证**——把「为什么 FAIL」从「未知/疑似 bug」升级为
  「已知估计器偏置（频变 B 跨半功率宽度）」。
* **半功率法对真实船的适用边界**：半功率带宽代理量仅对常系数/弱频变系统精确；
  对强频变（B 跨宽度变 40%）系统，`zeta_decay` 才是真阻尼比。这是 seakeeping
  的已知局限（半功率法测的是局部带宽，不是自由衰减率）。
* 常系数控制（B 恒定）下两估计器**不可比**：Cummins 记忆核 `K(t)=(2/π)∫B cos` 
  对恒定 B 是 sinc/δ 型核（无有限记忆），时域衰减被带截断支配——这本身是
  一个验证点（记忆核公式要求频变 B）。
* 未做：更细网格（30x12）的 G4 重扫（本机 load 高，且根因已由 69 点带确定）。
