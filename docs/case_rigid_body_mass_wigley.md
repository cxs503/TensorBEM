# CASE-BEM-RIGID-BODY-MASS（船型扩展）：Wigley 解析船体的 6×6 刚体质量矩阵

**锚点**：`CASE-BEM-RIGID-BODY-MASS`（算例池·刚体质量矩阵，ref=刚体质量矩阵闭式块形式，容差 <3%）
**仓**：TensorBEM ｜ **模块**：`src/tensorbem/benchmarks/case_rigid_body_mass_wigley.py`
**工件**：`docs/cases/case_bem_rigid_body_mass_wigley/run.json`（+ `fig_convergence.png` / `fig_block_matrix.png`）
**测试**：`tests/test_case_rigid_body_mass_wigley.py`（15 项）

## ① 为什么还要一个船型算例

既有锚点（`case_rigid_body_mass`）钉在**实心椭球**上。椭球 `Cb = π/6` 是构造出来的，没有水线面、没有平行中体、没有首尾瘦削，
因此生态要求的**几何先验证（Cb/L/B）**在这个算例上无法真正被执行——几何门形同虚设。
本单把同一锚点扩展到唯一具有船型特征的**解析船体**：抛物型 Wigley 船，

```
y(x, z) = (B/2)(1 - (2x/L)^2)(1 - (z/T)^2),   x∈[-L/2, L/2], z∈[-T, 0]
```

其质量特性全是初等积分，可以给出**闭式**参考值；且 `Cb = 4/9`、`L`、`B` 均为解析已知，几何门可判。

## ② 方法与三条独立路线

| 路线 | 内容 | 自由度 |
|---|---|---|
| **R** 闭式 | 初等积分降维：`V=4LBT/9`、`z_B=-3T/8`、`∫x²=V L²/20`、`∫y²=48B²V/1225`、`∫z²=V T²/5`，得 `I_cg` 对角；再按平行轴定理搬到设计质心 | 无离散误差 |
| **Q** 求积 | 在参数域 `(s, η, t)`（Jacobian `L T·2B s(1-s)(1-t²)`）上做 24 点 Gauss–Legendre 三维积分，积分对象是**定义**（体积/一阶矩/二阶矩） | 无（被积函数为多项式，机器精度精确） |
| **M** BEM 网格 | `wigley_wetted_hull_mesh`（水动力静水算例同一生成器）→ 水线面三角扇封闭 → `mesh_mass_properties`（有符号四面体，精确）→ **平台路径** `hydrostatic.compute_mass_matrix`（`rao.py`/`ice_rao.py` 实际调用者） | 有，面元离散误差被 3% 判据度量 |

参考矩阵**手写装配**（显式 `S(r)`、`-mS`/`+mS`、`I_g+m(|r|²I-rrᵀ)`），不复用 `rigid_body_mass_matrix`，因此"装配器=手写块形式"是一条真判据而非自比。

质量模型：均匀密度船体（`m = ρV`），设计质心 `r_g = (0.05L, 0, -0.45T) = (6, 0, -3.6) m`；
网格路线的惯量先在其自身质心求得，再按平行轴定理搬到同一设计质心，使 ref 与 got 是**同一组 10 个质量数**，差异只来自离散化。
这一步顺带产生了**非零惯性积** `I_xz = -m d_x d_z = +3.77856e7 kg·m²`，即文献里"给出全张量"的分支被真实走到。

## ④ 计算结果（程序化注入，`run.json` 为准）

### 4.1 路线互校（无离散误差的两条）

| 对比 | 相对差 |
|---|---|
| R 闭式 vs Q 求积：体积 | 1.07e-15 |
| R vs Q：形心 | 2.22e-17（按 L 归一） |
| R vs Q：设计质心处惯量张量 | 7.00e-16 |
| 手写块形式 vs `rigid_body_mass_matrix` | < 1e-15 |
| 参考矩阵动能恒等式残差 | ~2e-16 |

三条路线中的两条（R、Q）在机器精度上一致 ⇒ 闭式降维系数无误、不是拟合。

### 4.2 平台装配路径的面元收敛阶梯（这是 3% 判据度量的量）

| 网格 (n_s×n_l) | 面元 | max 逐元素误差 | I 张量误差 | 体积误差 | Cb 误差 | <3% |
|---|---|---|---|---|---|---|
| 6×3 | 84 | 7.5189 % | 2.550 % | 3.3951 % | 3.40e-2 | ❌ |
| 12×6 | 312 | 1.9688 % | 0.633 % | 0.8632 % | 8.63e-3 | ✅ |
| 24×12 | 1200 | 0.4979 % | 0.158 % | 0.2167 % | 2.17e-3 | ✅ |
| 48×24 | 4704 | 0.1248 % | 0.039 % | 0.0542 % | 5.42e-4 | ✅ |
| 96×48 | 18624 | 0.0312 % | 0.010 % | 0.0136 % | 1.36e-4 | ✅ |

细化比 2（n_sections 加倍）时误差降 4 倍 ⇒ **O(h²)**，与内接多面体体积/二阶矩误差阶一致；最粗一档 7.52% **不过判据**，
即本算例具备判别力，不是"任何网格都过"。

## ⑥ 注意点与误差判定

- **是否 <3%**：在 312 面元（12×6）及以上**逐项满足**，收敛档最差元素 1.9688%，最细 0.0312%；
  但在 84 面元档为 7.5189%，**不满足**——判据成立的前提是 `n_sections ≥ 12`，已如实标注在阶梯表中。
- 几何门（Cb、L、B）在同一档位也 <3%（Cb 误差 8.63e-3），符合"先验几何再判容差"的纪律；L 由网格解析给出，误差 <1e-12。
- 本算例是**刚体**惯量，不含附连质量 `A(ω)`（另有算例锚）；`I_g` 是"均匀密度船体 + 平移至设计质心"的模型，
  不是某一实船的分舱质量分布——不主张 L5 外部锚点（未做文献页级核对），但结论不依赖外部数据：R/Q 互校 + 动能恒等式 + 负对照三者独立。
- 水线面封闭用三角扇（扇形顶点取平面形心，平面 `|y|≤2Bs(1-s)` 相对该点星形），并逐半边缘验证**水密性**：
  每条有向半边出现恰一次、其反向半边恰一次（测试 `test_closed_mesh_is_watertight`）。
  首版把扇边写成 `(apex,i,j)` 会与湿表面边同向，产生 96 条重复半边——由水密性测试抓出并修正。
- 平行轴定理的**单向性**踩过一次：`I_O = I_cg + m(|d|²I-ddᵀ)` 位移项只依赖 `|d|²`，所以"搬回去"必须做减法；
  用同一个正向函数往返会重复相加（测试里已按减法写）。
