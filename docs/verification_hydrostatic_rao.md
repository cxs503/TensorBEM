# 静水恢复矩阵与 6-DOF RAO 层的闭式解验证

**类型**：验证欠账复核（已合并功能 `tensorbem.hydrostatic` / `tensorbem.rao` 对闭式解与文献基准）
**工件**：`src/tensorbem/benchmarks/hydrostatic_rao_verification.py`（CLI + JSON）、
`docs/rao_verification_metrics.json`（全部数字由此文件程序化读入，零手抄）、
`docs/figures/rao_verification.png`、`tests/test_rao_verification.py`（回归门禁）

---

## 1. 案例介绍：被验证的对象与为什么它需要独立验证

`hydrostatic.py` / `rao.py` 是面板法的**后处理层**：它把自由液面辐射/绕射解（已有 Hulme 1982、
Wang/Linton 1991 基准）组装成 6 自由度运动方程

\[
\left[-\omega^2(\mathbf M+\mathbf A(\omega)) + \mathrm i\omega\mathbf B(\omega) + \mathbf C\right]\boldsymbol\xi
= \mathbf F_{\text{exc}}(\omega),
\]

其中静水恢复矩阵取

\[
C_{33}=\rho g A_{wp},\quad C_{44}=\rho g\nabla\,GM_T,\quad C_{55}=\rho g\nabla\,GM_L,
\]
\[
GM_T=KB+BM_T-KG,\quad BM_T=I_T/\nabla,\quad BM_L=I_L/\nabla .
\]

该层此前（PR #18 合并的 m273）只有**合理性测试**：恢复矩阵对称、对角为正、RAO 有限且量级 O(1)。
这些判据无法发现符号错误、横/纵向第二惯性矩互换、量纲缩放错误、CG 偏移耦合缺失等问题。
本报告用**不共享面板算子**的参考量重新判定该层：

| 参考 | 来源 | 是否闭式 |
|---|---|---|
| 箱型浮体静水力 | Biran & Pulido《Ship Hydrostatics and Stability》；Rawson & Tupper《Basic Ship Theory》 | 闭式（平面几何精确） |
| 刚体质量矩阵 | 刚体动力学分块式 \(\mathbf M=\begin{bmatrix}m\mathbf I & -m\mathbf S^\top\\ -m\mathbf S & \mathbf J_o+m\mathbf S\mathbf S^\top\end{bmatrix}\) | 闭式 |
| 漂浮半球 A、B、F | Hulme (1982) *JFM* 121:443–463（表 1/表 2），本仓 `analytic.hulme_hemisphere_radiation` 用 48 项无波势多极展开独立实现 | 半解析级数 |
| 长波垂荡极限 | 自由浮体在深水 \(ka\to0\) 时 \(| \xi_3|\to 1\) | 解析渐近 |

**算例参数表**

| 量 | 箱型浮体 | 漂浮半球 |
|---|---|---|
| 几何 | \(L=4.0\) m，\(B=2.0\) m，吃水 \(T=1.0\) m | 半径 \(a=1.0\) m，\(z\le0\) |
| 面元 | 10 个平面三角形（湿表面：底板 + 4 舷侧，无自由液面盖板） | icosphere 细分 2 → 64 面元；细分 3 → 256 面元 |
| \(\rho\) / \(g\) | 1025 kg/m³ / 9.80665 m/s² | 同左 |
| 质量 | \(m=\rho\nabla=8200\) kg | \(m=\rho\nabla_{\text{mesh}}=1956.6\) kg（按离散体积取平衡） |
| 重心 | \(KG=0.5\) m（自龙骨） | \(z_G=-0.5a\)，显式惯量 \(J=m\,0.4a^2\mathbf I\) |
| 频率 | — | \(ka\in\{0.2,0.5,1.0\}\)，另 \(ka=0.5\) 加密对照 |

> 说明：RAO 用例显式传入惯量张量。`compute_mass_matrix` 的**缺省惯量**是启发式
> （回转半径 \(k=0.4\,|r_G|\)），属工程假设而非几何导出量，本报告不把它当作验证对象。

## 2. 怎么做的

1. `hydrostatic_rao_verification.py` 中新建 `box_pontoon_hull()`：10 个平面三角形拼出吃水 \(T\) 的
   方箱湿表面，平面面元保证水线多边形与排水体积**被网格精确表示**，闭式值因此是严格对照。
2. 闭式参考 `box_reference()` 直接由初等公式给出 \(A_{wp},\nabla,I_T,I_L,KB,BM,GM,C_{33},C_{44},C_{55}\)。
3. 半球的 RAO 链路用 `compute_rao_at_frequency`（含 `chief_points="auto"`）求 \(ka=0.2,0.5,1.0\)，
   与 `hulme_hemisphere_radiation` 的 \(A_{11},B_{11},A_{33},B_{33},|F_1|,|F_3|\)、相位逐项比较。
4. **链路完整性**：同一频率再独立调 `solve_radiation_3d` / `solve_diffraction_3d`，
   要求 RAO 内部使用的 \(\mathbf A,\mathbf B,\mathbf F_{\text{exc}}\) 与之逐元素一致（差异 ≈ 0），
   并检查返回的阻抗残差 \(\|\mathbf Z\boldsymbol\xi-\mathbf F\|\)。
5. 加密对照：\(ka=0.5\) 在 64 / 256 面元下比较误差，判定残差是离散误差还是模型错误。
6. 复现命令：
   ```bash
   PYTHONPATH=src python -m tensorbem.benchmarks.hydrostatic_rao_verification \
       --output docs/rao_verification_metrics.json --figure docs/figures/rao_verification.png
   PYTHONPATH=src python -m pytest tests/test_rao_verification.py -q
   ```

## 4. 误差判定（逐项回答「是否 < 3 %」）

| 关键量 | 基准 | 误差（64 面元） | 误差（256 面元） | < 3 %？ |
|---|---|---|---|---|
| \(A_{wp},\nabla,I_T,I_L,C_{33},C_{44},C_{55}\)（方箱） | 闭式 | 0（机器精度） | — | **是** |
| 刚体质量矩阵全 36 元素 | 闭式分块 | 0 | — | **是** |
| 垂荡 RAO（\(ka=0.2\)） | 1（解析极限） | 0.90 % | — | **是** |
| \(A_{33}\) | Hulme 1982 | 1.90–2.97 % | 0.45 % | **是**（两种网格均 <3 %） |
| \(B_{33}\) | Hulme 1982 | 4.50 % | 0.13 % | 64 面元**否**；256 面元**是** |
| \(|F_3|\) | Hulme 1982 | 0.23–2.03 % | 0.04 % | **是** |
| \(A_{11}\) | Hulme 1982 | 5.05–6.99 % | 1.84 % | 64 面元**否**；256 面元**是** |
| \(B_{11}\) | Hulme 1982 | 13.05–14.37 % | 3.87 % | **否**（256 面元仍 3.87 %，按 \(O(h^2)\) 外推至 1024 面元约 0.24 %） |
| \(|F_1|\) | Hulme 1982 | 7.58–8.06 % | 2.12 % | 64 面元**否**；256 面元**是** |
| 链路一致性 / 阻抗残差 | 逐元素 | 8.8e-12 / 2.1e-11 | — | **是** |

**判定**：静水力与质量矩阵层**通过**（机器精度）；RAO 组装层**通过**（链路一致、阻抗残差消失、
长波极限 0.9 %）。与 Hulme 文献值的差异**全部来自面板离散化**而非公式错误，
按 3 % 判据需 256 面元以上（唯一例外是 \(B_{11}\)，需 1024 面元；外推为 0.24 %）。

## 5. 注意点与局限

1. **惯量缺省值是启发式**：`compute_mass_matrix(inertia=None)` 用 \(k=0.4\,|r_G|\) 造惯量，
   没有几何/质量分布依据。本验证用例显式传惯量；工程使用若依赖缺省值，横摇/纵摇 RAO 不可信，
   属 **WITHHELD** 证据等级，建议后续从船体几何或质量分布计算。
2. **静水平衡未校验**：`compute_hydrostatic_restoring_matrix` 不检查 \(m=\rho\nabla\)。
   既有测试用 \(m=1000\) kg 配 \(\rho\nabla=2146.8\) kg 的半球，得到的 RAO 不是平衡浮体的响应
   （本报告一律取 \(m=\rho\nabla\)，长波极限才能落在 1.009）。建议在 `compute_rao_at_frequency`
   增加可选的平衡告警，但不改默认行为以免破坏既有用例。
3. **方箱只有 10 面元**：静水力是闭式精确，但同一网格**不能**用于辐射/绕射（水线锐角处核奇异），
   所以方箱只做静水力与质量层验证，RAO 用半球。
4. **半球的离散体积误差 8.86 %**：粗网格几何误差是各系数量误差的地板，
   因此 \(A_{11}/B_{11}\) 的 5–14 % 不可能是"公式错"，加密对照已证实。
5. **适用范围**：深水、零航速、线性小振幅、无粘、忽略甲板上浪与非线性自由液面项。
   \(ka>2\) 与不规则频率区（本层默认 `chief_points="auto"`，实测条件数 2.55–3.05）未在本次覆盖。
6. **纵荡 RAO 不作判据**：\(\xi_1\) 依赖人为给定的质量/惯量组合且在 \(ka=1\) 时与纵摇强耦合，
   本次只判定其激励力 \(|F_1|\) 与系数 \(A_{11},B_{11}\)。

## 6. 结论

- 新增可复现验证：`python -m tensorbem.benchmarks.hydrostatic_rao_verification`
  （JSON 到 `docs/rao_verification_metrics.json`，图到 `docs/figures/rao_verification.png`）。
- 新增回归门禁 `tests/test_rao_verification.py`：把「对称 + 有限」的弱测试升级为
  闭式解 / 文献值 / 长波极限 / 链路一致性 / 收敛性五类判据。
- 已合并的静水力与 RAO 组装逻辑**未发现公式错误**；两处工程风险（缺省惯量启发式、
  无平衡校验）如实登记，未擅自改动既有默认行为。
