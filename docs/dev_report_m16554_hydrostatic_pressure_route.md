## 1 案例介绍（为什么这是验证欠账）

`C` 矩阵是频域运动方程 `[-ω²(M+A) + iωB + C]ξ = F` 里唯一的静水恢复项，GM、横摇固有周期、
稳性高度全部由它派生。仓内 `compute_hydrostatic_restoring_matrix` 只有**一条**路线：
追踪水线环 → 水线面 `A, S_x, S_y, I_xx, I_yy, I_xy` → 教科书闭式（Journée & Massie §3.2.2），
再用 `hydrostatic_energy_reference` 做势能数值 Hessian 复核——但后者复用的是**同一套水线面/体积积分**，
所以"水线环追踪错"和"公式写错"在外部看起来一模一样，误差不可归因。

本单补的是**结构性不同的第二条路线**：不碰水线面，直接对压力场积分。

| 环节 | 水线面路线（既有） | 压力积分路线（本单新增） |
|---|---|---|
| 几何 | 把物体截到 `z=0`，追踪水线闭环 | 用**完整封闭**体表面，不做水线追踪 |
| 积分 | 水线面面积/一次矩/二次矩 | 湿表面 `∮ p n dS`、`∮ p (r×n) dS` |
| 物理量 | 水线面几何 → 闭式公式 | `p = ρg(z_fs − z)` 场 → 合力/合力矩 |
| 导出 | 公式（`ρgA`、`ρgI`、`ρg∇(z_B−z_G)`…） | 数值微分 `C = −d(load)/dξ`（中心差分 + Richardson） |
| 共同失效点 | 无 | 无 |

路线约定（与 `hydrostatic.py` 一致）：`z` 向上、自由面 `z=0`、`ξ=(surge,sway,heave,roll,pitch,yaw)`、
绕 `+x/+y/+z` 右手、关于**坐标原点**取矩、`load` 含**静水压力 + 恒重（作用于被刚体运动带动的重心）**，
`C = −d(load)/dξ`。有限转角用精确旋转矩阵 `Rz·Ry·Rx`（不做小角展开），线性化只发生在差分里。

## 2 怎么做的

1. **裁剪**：`clip_to_fluid` 对移动后的封闭三角面片做 Sutherland–Hodgman 裁剪（保留 `z≤0`），
   交点在共享边上用同一参数化计算、按 1e-12 焊接，保证水线处水密；三角形定向（外法向）不变。
2. **压力积分**：线性压力场在平面三角形上用形心规则**精确**；`F=−Σ p_c A n`、`M=−Σ p_c A (c×n)`。
   湿体积用散度定理 `∇=(1/3)Σ(c·n)A`（`z=0` 盖板贡献为 0）——即体积**不来自**压力积分，保持两条通道独立。
3. **恒重项**：`W = ρg∇`（用平衡态体积，常量），作用点在**被运动带动的重心**上，矩 `r_G(ξ)×(0,0,−W)`。
   这一项是必需的：它使 sway–roll / surge–pitch 的 `±ρg∇` 项互相抵消，与水线面路线一致（实测 <1e-13）。
4. **求导**：`C = −(load(+ξ) − load(−ξ))/(2ξ)`；再对 `step ∈ {2e-3,1e-3,5e-4}`（m / rad）
   做 **Richardson 外推**（中心差分误差偶次）消掉 `O(step²)` 偏置，避免把截断误差误判成路线差异。
5. **同网格对照**：`wetted_hull_from_closed` 用**同一批面元**建平衡态 `WettedHullMesh` 喂给水线面路线，
   于是两条路线的差**不可能**来自网格差异。

三个校验体：`barge-L10B4T2`（10×4×2 m，干舷 0.5 m，`z_G=−1.5 m`，**全平面**→两路线都应精确）、
`spheroid-a5b2c1.5`（半潜椭球，曲水线面，`z_G=0`）、`spheroid-offset`（椭球平移 (1.2,0.7)，
`x_G=1.5,y_G=1.0`，用于激活水线面一次矩与 `I_xy` 耦合）。

## 5 注意点（踩过的坑）

1. **零干舷体会给出"半刚度"**：最早用 `z∈[−2,0]` 的无干舷箱体，heave 中心差分得到 `ρgA/2` 而不是 `ρgA`。
   原因不是差分错，而是**物理**：heave 向下时整箱恰好全潜，排水体积不再随下沉增加 → `V(ξ3)` 在 0 处单侧折返，
   中心差分给单边斜率的一半。所有校验体因此都必须有**正干舷**（这也是线性静水理论的标准前提）。
2. **湿体积的散度定理必须用完整点积** `Σ(c·n)A/3`，不能只用 `Σ c_z n_z A/3`：竖壁面元 `n_z=0`，
   只用 `z` 分量会漏掉 2/3 的体积（本单第一版即如此，导致恒重项偏小 3 倍、耦合项全部失真）。
3. **恒重项不可省**：只留压力项会让 `C[roll,sway]` 出现 `∓ρg∇`（本单第一版实测 8.0e5），
   这是**游离**（未抵消）的浮力项，不是新物理。
4. **有限转角 vs 小角展开**：用精确旋转矩阵后，中心差分的截断是 `O(step²)` 且偶次，Richardson 才成立。
5. **零元的相对误差没有意义**：`C` 的 yaw 行列解析上恒为 0，报告里凡以 0 为分母的"相对差"
   均按 `|Δ|/max|C|` 记账（否则出现 1e+300 的伪数值）。

## 6 误差判定（honest FAIL，不粉饰）

| 关键量 | 基准（水线面公式路线） | 压力积分路线 | 相对差 | <3%？ |
|---|---|---|---|---|
| 静水压剖面 `p(z)`（20 点） | `ρg(z_fs−z)` 解析 | 同上 | 0.00e+00 | ✅ 是 |
| 排水体积 / 浮心 | 水线面路线 | 散度定理 / 压力矩 | ≤5.9e-6（曲）/ 0（平面） | ✅ 是 |
| `C[heave,heave]`（barge） | 4.0207265e5 | 4.0207265e5 | 1.28e-13 | ✅ 是 |
| `C[heave,heave]`（spheroid） | 3.1418e5 | 3.1418e5 | 5.89e-6 | ✅ 是 |
| `C[roll,roll]` / `C[pitch,pitch]`（spheroid） | 水线面路线 | 压力路线 | 1.17e-3 / 2.86e-3，加密至 7.1e-4 | ✅ 是 |
| `C[roll,roll]` / `C[pitch,pitch]`（barge，全平面） | 9.38169e5 / 3.752678e6 | 差值 4.12e-2 / 3.69e-2 | **4%** | ❌ **否** |
| `C[roll,yaw]` / `C[pitch,yaw]`（解析应为 0） | 0 | 残量 ≈ 4.2e-2·max\|C\|（仅 offset 体） | 定性不符 | ❌ **否** |

**结论（honest FAIL + 归因线索）**：本单交付的是一条可复用的第二路线与其不变量（体积/浮心/heave 行/压力剖面
全部到机器精度，曲面 roll/pitch 收敛到 1e-3 并显式 O(h²)），但**判据 <1e-3 未达成**，且差异分两类：

* **平移/体积驱动的行（heave 及其耦合）**：1e-13～1e-6，**通过**。
* **转动驱动的行（roll/pitch 对角、yaw 耦合）**：平面箱体上 4%（无离散误差可归咎，即**系统性**），
  曲面椭球上随加密 O(h²) 收敛；差异随 `|z_G|` 增大（barge `z_G=−1.5 m` 为 4%，
  椭球 `z_G=0` 为 1e-3；`z_G=0` 且 `x_G,y_G≠0` 的 offset 体 roll/pitch 仅 5.7e-4/2.3e-3，但 yaw 耦合残量最大）。
  → 差异定位在**重心垂向偏置项** `ρg∇(z_B−z_G)`（水线面路线把它并入公式）与**恒重矩的线性化**
  （压力路线直接对移动后的重心取矩）这两者的**等价性**上；本单**未**判定是哪一侧错，
  故不覆盖任何既有结论，按 §7 立新缺口条目并写明下一步（扫 `z_G` 的线性标定 + 与
  `hydrostatic_energy_reference` 势能 Hessian 的三方对照）。
  这也正是缺口账要求的"超判据须有归因结论"的**部分**回答：已排除离散化（平面体 4% 不随加密变化）
  与网格失配（两路线用同一批面元）。
