# TensorBEM m16850 — 浮半球升沉附加质量「刚盖端点」基准纠错：报告 #15809 的 honest FAIL 是假 FAIL

**仓库** TensorBEM · **分支** `agent/m16850` · **基线** `29f8ce8` (main @ 2026-11-13)
**锚点** NEW: 报告 #15809 的「精确刚盖端点 A33(ka→0)=ρ∇」是错基准（镜像论证用错），需独立复算并纠正端点锚

## 1. 案例介绍

半潜浮半球（半径 a=1.0 m，rho=1025 kg/m³，g=9.80665 m/s²，∇=(2/3)πa³=2.0944 m³，排水质量 ρ∇=2146.755 kg），升沉（heave, mode 2）附加质量 A33。

session 报告 #15809 把两条端点钉成"精确包络"：

| 端点 | #15809 采用的值 | 依据 |
|---|---|---|
| `ka→0`（刚盖 ∂φ/∂z=0） | `A33 = 2/3 ρπa³ = ρ∇`（无量纲 1.0） | "镜像=整球平动" |
| `ka→∞`（压力释放 φ=0） | `A33 = ρπa³/3 = 0.5ρ∇` | odd 单模（仓内 anchor A2） |

实测 256 面元 `ka=0.1` 给 0.8564 ρ∇，比 1.0 低 14.36%，于是记为 honest FAIL。
本单复核发现：**4. 低端点基准本身错了**，14.4% 不是求解器缺陷。

## 2. 怎么做的

### 2.1 错在哪（解析）

镜像论证只对"平行于对称面运动"成立。升沉是**垂直**于自由面，反射后镜像体的竖直速度反号
⇒ 双体流不是"整球平动"，而是**偶宇称**问题：

```
r=a 上：∂φ/∂r = -U |cosθ|      （偶延拓后；不是 -U cosθ 的单一 P₁ 模）
φ = U a Σ_{n 偶} c_n (a/r)^{n+1} P_n(μ),   -(n+1)c_n = a_n,   |μ| = Σ a_n P_n(μ)
A33/(ρ∇) = -3 Σ_{n 偶} c_n I_n ,   I_n = ∫_{-1}^{0} μ P_n(μ) dμ
```

而 `ka→∞` 的压力释放是**奇宇称**：`μ = P₁` 本身就是单一奇模，`c₁=-1/2` ⇒ `A33 = 0.5ρ∇` **精确**。
两条端点因此长期被混为一谈（都用"整球"图像）。

### 2.2 三条独立路线

1. **偶模级数（本单新增，半解析、机器精度）**：`even_mode_added_mass_dimless(degree_max=60)` → **0.8309541**，末两项部分和差 4.6e-9（收敛）；同一函数对奇宇称给 0.5（严格校验 anchor A2）。
2. **三维面元求解器** `solve_radiation_3d`（Kelvin Green 函数；`ka→0` 时退化为镜像 Rankine 核=刚盖）：subdivisions=2/3（64/256 面板），`ka` 扫 1e-3…1.0。
3. **仓内既有的 Hulme (1982) 半解析解** `analytic.hulme_hemisphere_radiation`（独立基函数展开，另一条代码路径）。

工具链：`src/tensorbem/benchmarks/rigid_lid_hemisphere_attribution.py` 一次产出
`benchmarks/verified/bem_rigid_lid_hemisphere/{results.json, summary.md, figure.png}`（同一 payload 渲染，零手抄）；
`tests/test_rigid_lid_hemisphere_attribution.py`（9 项）从原始行重算全部判据、现场重解一个 ka 点、并在小网格上复跑整条链路。

## 5. 注意点

- **#15809 的 R2/R3（`ka→∞` 下界 0.5ρ∇ 在有限 ka 是否成立）本单不推翻**：端点值 0.5 是对的，但"有限 ka 是否可低于 0.5"缺独立基准（Hulme 在 ka>1 的精度未审），`ka=2` 掉到 0.38 仍未解释 → 列入 payload `open_items`。
- `ka→0` 处 A33 从 0.831 抬到 0.855（ka=1e-3→1e-2）是真实的 `ka ln ka` 低频修正与数值误差的混合，本单只用最小 ka 判 R4，不用 0.03/0.1 判端点。
- 偶模级数的符号约定与 `ka→∞` 端点的交叉校验（同一函数同时给出 0.830954 与 0.5）是本单最强自证：两条端点用同一套矩积分，符号错则两者不可能同时对。
- 本单**未**改求解器代码（无缺陷可改）；改的是基准与文档口径。
