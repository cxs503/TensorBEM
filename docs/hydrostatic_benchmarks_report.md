# Hydrostatic verification against closed-form solutions

Generated by `python -m tensorbem.benchmarks.hydrostatic_benchmarks --report docs/hydrostatic_benchmarks_report.md --figure docs/figures/hydrostatic_convergence.png`. Every number below is emitted by that command.

## 1. What is verified

`tensorbem.hydrostatic` supplies displaced volume, centre of buoyancy, waterplane area / second moments and the 6x6 restoring matrix `C`, which is the only restoring term of the frequency-domain RAO system `[-w^2 (M + A) + i w B + C] xi = F`. Two hulls with closed-form hydrostatics are used as references:

* **barge** `L x B x T` - flat panels, so the discrete result must be *exact* up to round-off. Any deviation is an implementation error.
* **half-ellipsoid** `a, b, c` (and the unit hemisphere `a = b = c = R`) - curved surface and elliptical waterplane, so the measured error is the faceting error, which must fall at the expected second order.

## 2. Error verdict

At the finest hemisphere mesh (1024 panels, subdivisions=4) the largest relative error over all 8 quantities is **5.870e-03** (0.59 %), i.e. inside the 3 % gate.

The 64-panel geodesic hemisphere carries a 8.86 % volume deficit and a 2.55 % waterplane-area deficit; these reproduce the values quoted in the m273 hydrostatic/RAO development report (8.8 % and 2.5 %) and identify them as faceting error of a coarse mesh, not an implementation defect: refining 64 -> 256 -> 1024 panels drives the volume error to 8.86 % -> 2.32 % -> 0.59 %, an observed order of 1.98.

The barge column is exact to machine precision (worst case 2.2e-16), which is the strongest available statement that the volume, waterplane and second-moment integrations are correctly implemented.

## 3. Scope and limitations

* Only hydrostatics is verified; added mass/damping and the exciting forces are covered by the radiation/diffraction benchmarks.
* The bodies are symmetric fore-and-aft, so the waterplane-centroid routine is not exercised on an asymmetric waterplane; a hull whose waterline loop needs more than one polygon (twin hull, appendage piersings) is not covered.
* Wall-sided barge panels are planar, so the barge case cannot detect quadrature error on curved panels; that check is supplied by the half-ellipsoid case.
* The restoring matrix is linearised about zero heel/trim, as documented in the module docstring; large-angle stability is out of scope.
