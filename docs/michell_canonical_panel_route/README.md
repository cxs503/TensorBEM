## 1 案例介绍

**物理背景**：薄船理论（Michell 1898）把兴波阻力写成 Kochin 幅值的单重积分。
定常自由面条件 `U^2 phi_xx + g phi_z = 0` 对 `phi ~ exp(k z + i alpha x)` **只允许**
`(k, alpha) = (alpha^2/k0, alpha)`，`k0 = g/U^2`。m16274 在 Wigley 闭式解上做出了唯一
满足该条件的实现 `wigley.michell_wave_resistance_canonical`；m16345 仲裁了"旧口径"并把
**广义面元通路**（`michell.michell_resistance` / `wave_resistance_from_panels` /
`tandem_interference_factor`，多船型与多体船舶共用）的重钉留给了后续单。本单即该重钉：
把规范谱通路推到**任意中心面源分布**（面元、椭球、串列双体）。

**几何与参数**（薄船基准 Wigley，`Cb = 4/9`，与 m16274/m16345 同几何以便对表）：
| 量 | 值 |
|---|---|
| 船长 L | 1.0 m |
| 船宽 B | 0.1 m（L/B = 10） |
| 吃水 T | 0.06250 m（B/T = 1.6） |
| Cb | 0.4444 |
| rho / g | 1025.0 / 9.80665 |
| 傅汝德数 | Fr = 0.20, 0.25, 0.30, 0.35, 0.40 |
| 面元 | 中心面 (x, z) 张量积 Gauss 网格，64x32（收敛性另给 8x4 至 64x32 阶梯） |

## 2 怎么做的

1. **解耦波数**：`CenterplanePanels.kochin_pair(k_depth, alpha)` 计算
   `H(k_depth, alpha) = sum_p w_p exp(k_depth z_p + i alpha x_p)`。原 `kochin(k)` 强制
   `k_depth = alpha`，只能当诊断幅值，不能进阻力积分。分块外积（`_CHUNK_ELEMENTS`）保内存。
2. **规范谱求积**：`canonical_resistance_nodes` 给
   `Rw = (rho g^2/(pi U^2)) ∫_1^inf lam^2 |H(k0 lam^2, k0 lam)|^2 / sqrt(lam^2-1) dlam`
   的节点与权重，用 `lam = 1 + s^2` 精确消掉 `lam -> 1` 的可积端点奇性。
   权重与旧权重严格满足 `w_canonical = lam^4 * w_legacy`（实测最大相对偏差
   3.3e-16）。
3. **三个新出口**：`michell_resistance_canonical`（任意 Kochin 对函数）、
   `wave_resistance_from_panels_canonical`（任意中心面源分布）、
   `ellipsoid_wave_resistance_canonical`（谱椭球面元），以及
   `tandem_interference_factor_canonical` / `tandem_pair_resistance_canonical`（串列双体，
   因子式 `(1+e^{i alpha s})` 与合并源分布两条独立通路互校）。
4. **验证面（判据先于计算）**：
   (a) 面元通路 vs `wigley.michell_wave_resistance_canonical` 闭式解（**独立实现**，m16274
   已与 `thin_ship_michell` theta 形式对到 <1e-5）；
   (b) 面元加密阶梯（谱收敛）；
   (c) 相似律：`(L, B, T, U, g)` 同乘 s 时 `k0 T` 不变、积分严格自相似，力必须按 s^4 缩放；
   (d) 求积收敛 `n_quad` 32 vs 128；
   (e) 因子式 vs 合并式互校；
   (f) 旧口径缺陷保持性（防止无声回潮）。
5. **工具链**：纯 numpy/matplotlib，单进程，全随机种子无；未起重型算力进程（load15 ~ 80–115）。

## 5 注意点

- **旧出口未动**：`michell.michell_resistance`、`wigley.michell_wave_resistance`、
  `rankine_wave`/`neumann_kelvin`/`series60` 等 ~20 个调用点的数字全部逐位不变
  （它们挂在 `benchmarks/verified` 与 ~8 个测试模块的 pin 上）。本单只做**加法**，
  旧口径标注仍未清除——"删旧/改默认"需要一次跨仓 pin 迁移，不在单干范围。
- **串列干涉因子是谱相关的**：同一间隙、同一 Fr 下旧 sigma 与规范 sigma 最多差
  +36.3 %（Fr=0.25, s=0.5L），
  最少 -10.5 %。旧 sigma 被 `lam^-2` 权重压向短波、
  规范权重 `lam^2` 强调 `lam -> 1` 的长横波，所以多体船舶干涉结论在旧口径下是**带偏**的。
  能力台账中 `michell-general-and-tandem` 行的 sigma claim 现在只对旧口径成立，须以本节修正。
- 两条串列通路（因子式/合并式）最大相对差 3.9e-08，是同一积分的两种写法，
  互校只证实现正确，不涉及实验。
- 对实验的绝对量级仍 **WITHHELD**：仓内无 Wigley/椭球实验 Cw 数据；薄船理论对实船
  绝对阻力本身偏差可达数十个百分点（`docs/michell_validation.md` 已登记）。
- 椭球规范通路与"参考 Kochin 规则"（`ellipsoid_kochin_reference`，单波数）不可直接对比：
  后者仍是旧口径输入，本单未重钉它。

## 6 误差判定（逐项 vs 基准，并显式回答是否 <3%）

| 量 | 基准 | 误差 | <3%? |
|---|---|---:|---|
| 规范面元通路 Rw（5 个 Fr，64x32） | Wigley 闭式解（独立实现，m16274 已交叉验证） | 最大 2.7e-10 % | **是** |
| 规范面元通路 Rw（5 个 Fr，32x16） | 同上 | 最大 7.07 % | 否（Fr=0.20 网格欠解析，加密即收敛，见上表） |
| 相似律指数（规范） | 4（力的量纲） | 0.0e+00 | **是** |
| 相似律指数（旧） | 2（kg s^2/m 的量纲缺陷） | 0（缺陷已如实钉住） | 不适用（缺陷） |
| 求积加权比 vs `lam^4` | 解析恒等 | 3.3e-16 | **是** |
| 求积收敛 `n_quad` 32 vs 128 | 自身加密 | 2.2e-16 | **是** |
| 串列 sigma 因子式 vs 合并式 | 同一积分的独立写法 | 3.9e-08 | **是** |
| 椭球面元加密 48x192 vs 96x384 | 自身加密 | 2.4e-11 % | **是** |
| 旧面元通路 vs 规范 | 规范谱 | 低 0.041-0.097 倍（即低 90-96 %） | 否（已知缺陷，保留） |

**结论**：规范谱广义通路在 64x32 面元下与独立闭式解吻合到 2.7e-10 %（远优于 3 % 门限），
量纲（相似律指数 4）与求积收敛均闭合；旧口径的 12-24 倍偏低与串列 sigma 的 ±
10-36 % 偏差是**已量化并钉住**的缺陷，
本单未修改它们（改动面=新增加法），已如实登记为后续跨仓 pin 迁移单。
