# Maruo far-field mean drift force: convention, defect, and verification

**Scope**: `src/tensorbem/maruo_drift.py` — the analytically reduced Maruo (1957)
far-field mean second-order drift force on a **fixed** body in **deep water**, for
an arbitrary wave heading.
**Mission**: m6271. **Artifact**: `docs/maruo_drift/verification.json`
(generated by `src/tensorbem/benchmarks/maruo_drift_verification.py`, exercised by
`tests/test_maruo_drift.py`).

---

## 1. What is computed

The routine takes a sampled Kochin function `K(theta)` of the *scattered* wave and
returns a force **vector**

    F_j = (rho omega^2 / 4k) * Int_0^{2 pi} |K(theta)|^2 [ e_beta_j - e_theta_j ] dtheta

with `e_beta = (cos beta, sin beta)` the direction of wave propagation,
`e_theta = (cos theta, sin theta)` the radiation direction, and — in deep water —
`omega^2 = g k`, so the prefactor collapses to

    rho omega^2 / 4k = rho g / 4 = 2513.8125 N/m^2   (rho = 1025 kg/m^3, g = 9.81 m/s^2)

**independent of the wave number**. The head-sea entry point `maruo_mean_drift_force`
is the `beta = 0` case of the same weight, `e_beta - e_theta = (1 - cos theta, -sin theta)`.

`theta` and `beta` are expressed in **one** frame (0 = +x), so the result is a vector
that must transform properly: any correct implementation has to be *frame covariant*.

### Why the weight has this shape

Integrating the time-averaged momentum flux `p n + rho V (V·n)` over a large control
cylinder gives two contributions. The isotropic one is the incident wave momentum
flux, `(rho omega^2/4k) S e_beta` with `S = Int |K|^2 dtheta`, pointing downwave. The
other is the moment of the radiated momentum flux, `-(rho omega^2/4k) Int |K|^2 e_theta
dtheta`, pointing upstream. Their difference is the drift force. The term that does
*not* appear is the incident–scattered interference term: it oscillates like
`exp(i k R cos(...))` and does not converge under numerical quadrature (documented in
`dev_report_m5242_second_order_drift.md`); the stationary-phase reduction is exactly
what removes the `k R` dependence and leaves the `|K|^2` integral above.

The same weight, derived independently from the control-surface expression, is used by
the verified 3-D routine `tensorbem.drift.far_field_drift_3d`
(`weight="maruo"`), which is what made the cross-check below possible.

## 2. The defect fixed in m6271

`maruo_mean_drift_force_general` used the weight

    (cos beta - cos(theta - beta),  sin beta - sin(theta - beta))

instead of `(cos beta - cos theta, sin beta - sin theta)`. At `beta = 0` the two are
identical, so every head-sea check (the only heading exercised anywhere in the
repository — the function had no test and no in-library caller) passed. For `beta != 0`
the substitute weight is **not covariant**: rotating body and incident waves together by
`alpha` moves the force by the wrong amount (residual up to 38 %, table 2), and it
cancels the lateral force that a fore-aft asymmetric scattering pattern must feel.

Physically the old weight mixes the incident-flux term with a *rotated* radiation
direction, so it loses the `Int |K|^2 e_theta dtheta` moment in the body frame while
keeping it in the isotropic term.

## 3. Verification setup

Analytic reference. For a scattering pattern
`|K(theta)|^2 = C^2 (1 + a cos(theta - gamma))` the azimuthal moments are elementary,

    S = 2 pi C^2,   Int |K|^2 cos(theta) dtheta = a pi C^2 cos(gamma),
                    Int |K|^2 sin(theta) dtheta = a pi C^2 sin(gamma)

so the exact force is

    F(beta) = (rho g/4) [ 2 pi C^2 e_beta - a pi C^2 e_gamma ] .

All numbers below use `C = 1`, `a = 0.5` (fore-aft asymmetric), `gamma = 0`,
`k = 0.5 m^-1`, `rho = 1025 kg/m^3`, `g = 9.81 m/s^2`, and a Kochin table of 3600
azimuth samples. Nothing here is a recorded program output: the reference column is the
closed form above.

### 4.2 Rotational covariance

Rotating body (`gamma -> gamma + alpha`) and waves (`beta -> beta + alpha`) together by
`alpha` must rotate the force, `F -> R(alpha) F`, with `beta = 60 deg`, `gamma = 0.3`.

| alpha (deg) | residual, covariant | residual, pre-m6271 |
|---:|---:|---:|
| 17.19 | 8.6e-17 | 5.70e-02 |
| 40.11 | 1.4e-16 | 1.46e-01 |
| 74.49 | 0.0 | 2.78e-01 |
| 143.24 | 1.4e-16 | 3.84e-01 |

The fixed weight is covariant to round-off; the old one drifted to 38 %.

### 4.3 Where the accuracy floor comes from

Dipole pattern `K = cos(theta)` (exact `F_x = pi rho g/4 = 7897.3749 N`):

| Kochin table samples | rel. error of Fx |
|---:|---:|
| 8 | 9.763e-02 |
| 12 | 4.466e-02 |
| 24 | 1.136e-02 |
| 48 | 2.852e-03 |
| 96 | 7.137e-04 |
| 360 | 5.077e-05 |
| 3600 | 5.077e-07 |

| azimuthal quadrature `n_theta` | rel. error of Fx (3600-sample table) |
|---:|---:|
| 128 | 4.998e-07 |
| 256 | 5.057e-07 |
| 1024 | 5.076e-07 |
| 16384 | 5.077e-07 |

Second order in the table spacing, and **flat in `n_theta`**: the integrand is the
linear interpolant of the caller's table, so refining the quadrature past 128 points buys
nothing. The knob a caller owns is the table, not `n_theta`
(`docs/maruo_drift/maruo_drift_resolution.png`).

## 5. Error judgement against the analytic baseline

| key quantity | baseline | fixed module | verdict (< 3 %) |
|---|---:|---:|---|
| `Fx` over the heading sweep | closed form, 8.4e-08 floor | max rel. err 6.3e-08 | **yes**, by five orders of magnitude |
| `Fy` over the heading sweep | same | max rel. err 6.3e-08 | **yes** |
| force under a rigid rotation of body+waves | `R(alpha) F` | residual 1.4e-16 | **yes** |
| same three checks, pre-m6271 | closed form / `R(alpha) F` | 40 % / 38 % | **no** — the defect is an order of magnitude past any acceptance band |

The remaining error is *table interpolation*, not the physics: with a 3600-sample table
it is 5.1e-07 relative, and it is reported rather than hidden.

## 6. Limitations and scope

- **Deep water only.** `omega^2 = g k` is used both for the prefactor and implicitly for
  the far-field radiation condition. A finite-depth version needs
  `omega^2 = g k tanh(k h)` and a `1/cosh(k h)`-type normalisation of `K`; the weight
  itself (`e_beta - e_theta`) is unchanged, but nothing in this document verifies the
  finite-depth case. The finite-depth machinery lives elsewhere
  (`finite_depth_solver.py`, `finite_depth3d.py`).
- **Fixed body, no forward speed.** With forward speed the Kochin function acquires a
  Doppler-shifted argument and an extra `Re{K}` interference term; not covered.
- **`|K|` normalisation is the caller's convention.** Only `|K|^2` enters and no wave
  amplitude is assumed, so the returned force is in newtons only for `K` in metre units
  with the amplitude absorbed. This is documented in the module docstring but is exactly
  the sort of convention that silently doubles a reported force; check it at the call
  site.
- **The interference term is dropped by construction** (stationary-phase reduction).
  This is the intended reduced form, not an omission; the un-reduced flux integral does
  not converge in `k R` (`dev_report_m5242_second_order_drift.md`).
- **Interpolation is linear.** No spectral resampling is done, so an under-resolved table
  biases the result low by an O(h^2) amount (table 4). A caller that only has 8–24
  azimuth samples should expect percent-level errors.
- The head-sea entry point is unchanged by m6271 and its results are unaffected.
