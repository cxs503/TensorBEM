**锚点**：NEW —— 总账无 Michell/Wigley 阻力锚点；本单收编 `docs/michell_unit_arbitration.md` §6

## ① 案例介绍（物理背景/几何/参数）

Michell 薄船理论给出 Wigley 抛物型数学船型的兴波阻力。稳态自由面条件
`U² φ_xx + g φ_z = 0` 只允许 `φ ~ exp(k z + i α x)` 于**规范对** `(k, α) = (α²/k0, α)`，
`k0 = g/U²`。仓内三条 Michell 路径里，`tensorbem.thin_ship_michell`（θ 形式）用的是规范对，
而默认出口 `tensorbem.wigley.michell_wave_resistance` 对深度衰减与相位**用同一个波数**
（`(k0λ, k0λ)`，自由面残差 `λ-1`），权重取 `λ^-2`，前置因子取 `4ρ/U²` —— 量纲上返回
`kg s² m⁻¹`（**不是力**），数值低 10–24 倍（m3125 / `docs/michell_unit_arbitration.md` 已定性，
本单给定量修复与验证面）。

| 参数 | 值 |
|---|---|
| 几何 A（m3125 判例） | L=3.0 m, B=0.3 m, T=0.1875 m |
| 几何 B（Wigley III） | L=10.0 m, B=1.0 m, T=0.625 m |
| 密度 / 重力 | ρ=1025 kg/m³, g=9.80665 m/s² |
| Froude 带 | 0.20, 0.25, 0.30, 0.35, 0.40 |
| 判据（先于计算固定） | 规范式 vs 独立 θ 形式 <3%；量纲指数 = 力的 (-1,-1,+2)；128/256 点求积 <1e-3 |

## ② 怎么做的

1. `wigley.michell_kochin_function(L,B,T,k,alpha=None)` 增加**相位波数**参数：`k` 只做深度衰减，
   `alpha` 做流向相位（缺省 = `k`，保留逐位旧语义，H 仍是可公开求值的函数）。
2. 新增 `wigley.michell_wave_resistance_canonical(...)`：
   `Rw = (ρg²/(πU²)) ∫₁^∞ λ² |H(k0λ², k0λ)|² dλ/√(λ²-1)`，`λ = 1+s²` 去奇点。
   因子 4 说明：`H` 含两舷（幅值因子 2），`|H|²=4|A|²`，故教科书 `4ρg²/(πU²)` 作用在单舷幅值 `A`
   上，作用在 `H` 上时除以 4 → `ρg²/(πU²)`（与 `docs/michell_unit_arbitration.md` §5 修配方案同源，
   本单首次把它做成仓内一等函数）。
3. **不改默认出口**：`michell_wave_resistance` 保持逐位旧公式（docstring 明标 DEFECTIVE），
   因为它的值被 `benchmarks/verified`、`docs/` 与 ~8 个测试模块钉住；改默认 = 另一张重钉单
   （已按任务要求 POST 派单，见 ⑥）。
4. 证据全部程序化：`scripts/m16274_canonical_wigley.py` → `docs/m16274/numbers.json`
   + `fig_canonical_vs_legacy.png`；README 数字逐条读回，零手抄。
5. 机器门：`tests/test_wigley_canonical_resistance.py`（12 例）：量纲指数、θ 形式互证（5 个 Froude）、
   旧口径 ratchet、审计方案值 3.891778 N、求积收敛、规范对自由面残差、零/负速、单调性。

## ⑤ 注意点（坑/局限）

1. **默认出口仍是旧公式**（有意）：本单不重钉既有数字。任何新工作必须调
   `michell_wave_resistance_canonical`；`michell.michell_resistance`、面板路径
   `wave_resistance_from_panels`、`rankine_wave.michell_wave_resistance` 同属旧口径，
   一并留给重钉单（否则跨路径 pin 会互相矛盾）。
2. **两舷约定未裁决**：`H` 含因子 2（两舷）；教科书 `4ρg²/(πU²)` 与单舷幅值配对。本单与
   θ 形式（同为单舷幅值口径）互证，故内部自洽；绝对量级对外部实验仍 **WITHHELD**（仓内无
   Wigley 实验 Cw）。
3. 旧公式的错因有两条不可互相吸收：波数配对（`λ-1` 的相对残差随 λ 变）与前置因子；只补 `g²/C`
   不够（`docs/michell_unit_arbitration.md` §4）。
4. `numbers.json` 里 θ 形式的量纲指数行已标注**无效**（closure 内把几何钉死，探针看不见重标定），
   README 只引 `legacy_default` 与 `canonical` 两行。
5. 容量纪律：本机 load15≈110（≥100），全程轻量（一维求积，毫秒级），未起重算力。

## ⑥ 误差判定（关键量 vs 基准，逐项）

| 关键量 | 基准 | 实测误差 | 是否 <3% |
|---|---|---:|---|
| Rw 规范式 @Fr=0.20..0.40（几何 B） | 独立 θ 形式（`thin_ship_michell`） | ≤0.061% | **是** |
| Rw 规范式 @Fr=0.30（几何 A） | 审计修配方案 3.891778 N | 3e-5 | **是** |
| Rw 规范式 @Fr=0.30（几何 B） | 平台报告 15330 闭式 144.1403 N | 0.003% | **是** |
| 量纲指数 | 力 (-1,-1,+2) | 0（精确） | **是** |
| Rw 旧默认 | 同上三个基准 | 90–96% 偏低 | **否**（缺陷，留重钉单） |

结论：规范式通道三项独立基准全部 <0.1%（远严于 3% 门限）且量纲指数精确为力；
旧默认口径的 10–24 倍偏低是本次修复针对的缺陷，默认出口按纪律暂不移动，
重钉（含 `benchmarks/verified`、`docs/`、8 个测试模块）已派单。
