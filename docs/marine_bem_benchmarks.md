# 船舶与海洋工程边界元基准问题综述与实现

## 摘要

边界元法（BEM）以边界积分方程代替流场区域离散，常用于船舶耐波性、海洋结构物水动力、波浪辐射与绕射及水声问题。可信的数值验证应从有解析解的问题开始，再逐步扩展到自由液面解析基准、三维几何和试验数据。本文梳理了适用于船舶与海洋工程的主要基准问题，并针对 TensorBEM 当前仅支持二维 Laplace 方程、闭合多边形和常数面元的能力，实现了二维圆柱横向平移附加质量基准。该问题解析附加质量为每单位跨长 \(\rho\pi a^2\)。以半径 \(a=1\)、水密度 \(\rho=1025\) 和 16–128 个直线面元进行计算，附加质量相对误差由 \(6.41\times10^{-3}\) 降至 \(1.00\times10^{-4}\)，法向导数均方根误差随网格加密持续减小。该结果验证了一个特定解析边界迹及其积分量，并不意味着程序已具备一般外域或自由液面水动力求解能力。

**关键词：** 边界元法；船舶水动力；附加质量；圆柱；数值验证；势流

## 1. 引言

船舶与海洋工程中的经典势流模型通常将流体速度表示为速度势的梯度，并在无旋、不可压条件下求解 Laplace 方程。BEM 将该区域方程转换为物体表面、自由液面或远场边界上的积分方程；因此，边界条件、法向方向、自由液面处理以及几何离散误差均会直接影响结果。附加质量、阻尼、波浪激励力和运动响应等工程量又通常由边界势函数积分获得。

基准测试应区分**验证**与**确认**：解析解或独立高精度解用于检验离散方程、积分和求解器；与水池试验的对比则检验物理模型与工程预测能力，受黏性、尺度效应和试验不确定度影响。Newman 对海洋势流水动力问题及辐射、绕射理论作了系统论述；Ursell 和 John 分别给出自由液面圆柱运动问题及浮体简谐运动的经典解析理论 [1–3]。

TensorBEM 当前是二维有界域 Laplace BEM 原型，采用直线常数面元与中点配点。故本文先实现与其数值基础相匹配的圆柱附加质量边界迹基准，并明确说明其适用边界，不将其误称为成熟的船舶耐波性计算器。

## 2. 船海 BEM 基准问题类别

建议按由简至繁的层级建立验证集。下表中的“适用性”指其与当前 TensorBEM 实现的关系。

| 类别 | 典型基准及参考量 | 主要检验内容 | 当前适用性 |
|---|---|---|---|
| 制造解 / 调和场 | 圆域或多边形域的线性调和势，边界势与法向导数已知 | 核函数符号、边界积分方程、网格收敛 | 已有单位圆制造解 |
| 二维圆柱附加质量 | 无限流体中圆柱横向平移；\(m_A'=\rho\pi a^2\) | 势与通量边界迹、法向和力积分、几何离散收敛 | 本文实现；仅验证一个特定 Fourier 模态 |
| 三维球体附加质量 | 无界流体中球体平移；\(m_A=\tfrac12\rho V\) | 三维曲面网格、面元积分及方向性 | 需要三维曲面 BEM；可作为不含自由液面的首个三维基准 [1, 4] |
| 垂直圆柱规则波绕射 | MacCamy–Fuchs 圆柱绕射级数；比较无量纲波浪力随 \(ka\) 的变化 | 入射波、自由液面/海床条件、辐射条件及压力积分 | 需要自由液面模型；垂直贯底圆柱是经典解析基准 [5] |
| 自由液面圆柱辐射 | 圆柱简谐升沉；比较频率相关的附加质量与阻尼 | 自由液面条件、辐射条件、频率扫掠 | 需要相应边界条件；Ursell [2] 是重要解析参照 |
| 浮动半球辐射 / 绕射 | 强迫简谐运动浮动半球的波浪力与运动势 | 三维自由液面、刚体运动与辐射/绕射耦合 | 中阶解析/理论参照；几何简单但边界条件比球体附加质量复杂 [6] |
| 有限水深与复杂截面 | 矩形驳船、带棱角浮体、近自由液面结构 | 角点/水线附近奇异性、近奇异积分及网格敏感性 | 需强化积分和几何处理 |
| 船型模型试验对比 | Wigley 等规则船型或标准集装箱船的运动响应、波浪载荷 | 工程几何、边界条件与试验可比性 | 属于确认；须明确船模、航速、波况、尺度和数据来源 |

实现顺序宜为：先用制造解验证数值实现，再用圆柱/球体解析解验证几何和积分量，继而验证自由液面圆柱辐射与绕射，最后开展有限水深、复杂船型和试验对比。对试验基准，应报告实验条件及不确定度；不可将与某一组试验吻合等同于通用正确性。

对自由液面问题，可将独立势流程序（例如 WAMIT、NEMOH 或 Capytaine）作为数值互证来源；它们不是解析真值。比较前必须统一时间因子、坐标、法向、系数定义和正负号，并报告参考网格与收敛信息。Capytaine 的公开方法论文可作为软件和数值方法的可追溯来源 [7]。

## 3. 已实现基准：二维圆柱横向平移

### 3.1 物理模型与解析解

考虑半径 \(a\) 的无限长圆柱在无限、无黏、不可压流体中沿 \(x\) 方向以速度 \(U\) 平移。令极坐标角 \(\theta\) 从 \(x\) 轴起算，则满足无穿透条件且远场速度趋于零的外域势为

\[
\phi(r,\theta)=-\frac{Ua^2}{r}\cos\theta,\qquad r\ge a.
\]

圆柱表面上的势为 \(\phi|_{r=a}=-Ua\cos\theta\)。流体外域的边界法向指向物体内部，故表面法向导数为 \(q_f=-U\cos\theta\)。以物体外法向 \(n_{b,x}=\cos\theta\) 计算每单位跨长附加质量：

\[
m_A'=-\frac{\rho}{U}\int_{S}\phi\,n_{b,x}\,ds
=\rho\pi a^2.
\]

这一解析结果来自经典势流理论 [1, 4]。需特别指出，当前程序的多边形法向是有界多边形的外法向，而物理外域法向指向圆柱内部。对本例的一阶角向模态，程序所得有界域法向导数标量与外域物理法向导数相同；这一特定边界迹关系不能推广为一般外域 Dirichlet-to-Neumann 算子的等价性。

### 3.2 数值实现

`tensorbem.benchmarks.cylinder_added_mass` 在圆周上生成 \(N\) 边形，取面元中点角度 \(\theta_i\)，给定常数面元势值
\[
\phi_i=-Ua\cos\theta_i.
\]
随后调用现有二维 Laplace Dirichlet 求解器得到法向导数，并与 \(q_i=-U\cos\theta_i\) 比较。附加质量按多边形离散积分
\[
m_{A,N}'=-\frac{\rho}{U}\sum_{i=1}^{N}\phi_i n_{b,x,i}\,\Delta s_i
\]
计算，并与 \(\rho\pi a^2\) 比较。直线面元几何逼近圆形，故应考察网格加密趋势而非要求任一有限面元数下完全相等。

可复现实验命令：

```bash
python -m tensorbem.benchmarks.cylinder_added_mass --panels 64
```

命令将 JSON 结果写入标准输出，支持 `--radius`、`--speed` 和 `--density` 参数。返回值包含计算及解析附加质量、相对误差、法向导数均方根误差、线性系统残差和条件数。

## 4. 结果

基准参数为 \(a=1\)、\(U=1\)、\(\rho=1025\)，解析附加质量为 \(3220.13247\)（质量/长度单位）。表 1 报告直接运行基准所得数值；法向导数误差与速度同量纲，此处 \(U=1\)。

**表 1. 圆柱附加质量基准的网格收敛**

| 面元数 \(N\) | 数值附加质量 \(m_{A,N}'\) | 相对误差 | 法向导数 RMSE |
|---:|---:|---:|---:|
| 16 | 3199.48128 | \(6.4131\times10^{-3}\) | \(6.4377\times10^{-2}\) |
| 32 | 3214.96220 | \(1.6056\times10^{-3}\) | \(3.0104\times10^{-2}\) |
| 64 | 3218.83944 | \(4.0155\times10^{-4}\) | \(1.4622\times10^{-2}\) |
| 128 | 3219.80918 | \(1.0040\times10^{-4}\) | \(7.2137\times10^{-3}\) |

该系列中附加质量相对误差约按 \(N^{-2}\) 下降，与规则多边形弦长几何误差的二阶收敛趋势相符；法向导数误差亦随细化降低。64 面元时线性系统相对解析积分量误差约 \(4.02\times10^{-4}\)，线性系统残差约 \(6.91\times10^{-16}\)。小代数残差仅说明离散线性系统已求解，并不能单独证明连续问题或外域问题正确。

## 5. 讨论与适用限制

1. **验证范围有限。** 该例覆盖二维 Laplace 求解、常数面元离散、特定圆柱边界迹以及附加质量面积分。它不验证任意边界数据下的外域算子。
2. **不含自由液面与波浪。** 当前实现没有线性自由液面条件、辐射条件、入射波或频域阻尼/激励力求解；因而不能据此声称完成耐波性、波浪绕射或辐射分析。
3. **不含三维几何。** 实现为二维闭合多边形，未处理船体曲面、水线、艉部几何或三维面元。
4. **势流假设不包含黏性效应。** 圆柱解析附加质量基准不覆盖分离、涡脱落、阻力及黏性阻尼。
5. **试验验证仍不可或缺。** 真实船型确认需要可追溯的几何、质量/惯性、航速、波况和实验数据，且需讨论尺度效应与测量不确定度。

后续宜先实现外域势流的独立解析基准，再实现 Ursell 型自由液面圆柱辐射/绕射解 [2]，接着增加三维球体附加质量，最后采用公开船模试验数据开展确认。

辐射/绕射系数的对比报告还应明确复势时间因子、法向取向和力正方向；不同惯例会改变附加质量、阻尼或激励力分量的符号。圆柱绕射基准需注明贯底/非贯底、水深及入射波定义，不能只报告 \(ka\)。

## 6. 结论

船海 BEM 的基准体系应包括数学制造解、简单体解析势流、自由液面频域解、几何/奇异积分测试以及有条件可追溯的船模试验。本文完成了当前 TensorBEM 能力范围内最直接的海洋势流应用基准：二维圆柱横向平移附加质量。网格细化显示附加质量与边界通量误差均收敛至解析结果。此结果适合作为原型代码的回归验证，不应被外推为复杂船型、三维自由液面或黏性流动的验证。
