## 1. 案例介绍

### 1.1 物理背景

Ursell (1949) 潜没圆柱辐射问题是船舶水动力边界元法最经典的自由液面基准之一。半径为 $a$ 的圆柱轴线位于静水面以下深度 $f$ 处，在深水条件下以频率 $\omega$ 作垂荡或横荡运动。该问题同时检验：

- 线性自由液面条件 $\partial\phi/\partial z - \nu\phi = 0$（$z=0$，$\nu=\omega^2/g$）
- 远场辐射条件（出射波携带能量离开物体）
- 近/远场阻尼能量恒等式

### 1.2 几何与参数

| 参数 | 符号 | 值 | 单位 |
|------|------|-----|------|
| 圆柱半径 | $a$ | 1.0 | m |
| 淹没深度 | $f$ | 2.0 | m |
| 淹没比 | $a/f$ | 0.5 | — |
| 无量纲波数 | $ka$ | 0.6 | — |
| 角频率 | $\omega$ | 1.905 | rad/s |
| 流体密度 | $\rho$ | 1025 | kg/m³ |
| 重力加速度 | $g$ | 9.80665 | m/s² |

### 1.3 参考解

参考解为 Ursell 多极子解析解，通过将辐射条件满足的速度势展开为无波调和函数，将物面条件约化为无穷线性方程组：

$$-\frac{a_m}{m} + \sum_n a_n A_{mn} = -\delta_{m1}, \quad m = 1, 2, \ldots$$

其中矩阵元 $A_{mn}$ 有闭式表达（含指数积分 $\mathrm{Ei}$）。水动力系数由第一个系数给出：

$$\mu + i\nu = -1 + 2a_1$$

其中 $\mu = A/(\rho\pi a^2)$ 为无量纲附加质量，$\nu = B/(\omega\rho\pi a^2)$ 为无量纲阻尼。

本实现取截断项数 $N=40$，经测试截断误差 $<10^{-12}$。

**参考值**（$ka=0.6$, $a/f=0.5$）：
- 附加质量：$A_\text{ref} = 2545.167$ kg/m
- 阻尼：$B_\text{ref} = 2718.154$ kg/(m·s)

## 2. 方法

### 2.1 数值方法

采用间接源公式（indirect source formulation）：

$$\phi(P) = \int_\Gamma G(P, Q)\sigma(Q)\,ds(Q)$$

其中 $G$ 为深水自由液面 Green 函数，满足自由液面条件和辐射条件。物面条件 $\partial\phi/\partial n = U\cdot n$ 给出边界积分方程：

$$\left(\frac{1}{2}I + K'\right)\sigma = U\cdot n$$

其中 $K'$ 为 Green 函数法向导数算子。

### 2.2 离散设置

- 面元类型：二维直线常数面元（P0）
- 配点：面元中点
- 奇异积分：对数核 $\log r$ 在直线面元上解析积分
- 光滑部分：Gauss-Legendre 求积（默认 24 节点）
- 主值积分：Legendre 80 节点 + Laguerre 160 节点

### 2.3 收敛性预期

对于常数面元（P0）离散二维 Laplace 型问题，理论收敛阶为 $O(h^2)$。但自由液面 Green 函数包含对数奇异性，且圆柱几何用多边形逼近，实际观测收敛阶通常介于 $O(h)$ 和 $O(h^2)$ 之间。

## 5. 注意点

### 5.1 README 数字偏差说明

README 和 `docs/marine_bem_benchmarks.md` 中声明的 128 面元附加质量误差为 $7.7\times 10^{-3}$，但实测为 $8.513\times 10^{-3}$，偏差 10.6%。可能原因：

1. **文档生成时的参数差异**：原始文档可能使用了不同的 `panel_nodes`（高斯积分点数）或 `source_count`（MFS 参考解源点数）
2. **数值环境差异**：不同 NumPy/BLAS 版本可能导致微小差异，但 10.6% 的偏差远超浮点精度范围
3. **文档与代码版本不同步**：文档可能在代码修改后未更新

**处理**：本文档提供实测数据，建议更新 README 和 marine_bem_benchmarks.md 中的数字为实测值。

### 5.2 收敛阶低于理论值的原因

理论预期常数面元 Laplace 问题为 $O(h^2)$ 收敛，但实测为 $O(h)$。原因：

1. **对数核奇异性**：自由液面 Green 函数包含 $\log r$ 项，在自面元处奇异，降低收敛阶
2. **几何逼近误差**：圆柱用多边形逼近，几何误差为 $O(h^2)$，但与核奇异性耦合后主导误差为 $O(h)$
3. **主值积分截断**：主值积分的数值求积引入额外误差

### 5.3 适用范围

- 本基准仅适用于**深水**条件（$kh \gg 1$）
- 淹没比 $a/f = 0.5$ 为中等淹没深度；极浅淹没（$a/f \to 1$）时收敛更慢
- 常数面元（P0）离散；高阶面元可改善收敛阶
