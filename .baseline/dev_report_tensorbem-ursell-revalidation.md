# TensorBEM 验证欠账清偿：Ursell 128 面元文档数字失效定因与钉桩

**日期**：2026-11-03  **分支**：agent/m2173  **基线**：main f0bfb41
**环境**：Python 3.11.6 · NumPy 2.4.6 · 单机 128 核（load15 > 100，全部算例为秒级 2-D BEM，未起重算力）

## 1. 欠账是什么

`expand_audit_tensorbem.md §2.2` 记了一条未结案 HONEST FAIL：Ursell 潜没圆柱 128 面元附加质量实测相对误差 8.513e-3，而 README 与 `docs/marine_bem_benchmarks.md` 声明 7.7e-3（误差量相差 10.6%）。

## 2. 定因（三条证据，均可复算）

1. **文档数字来自哪个提交**：把两个历史 commit 的 `src/` 取到 `/tmp` 直接跑基准 —— `878834a`（引入本基准的提交）给出 A=2564.8138、err=7.719e-3，与文档表格逐位吻合；`267d5a3` 给出 A=2566.8343、err=8.513e-3，与当前 HEAD 一致。**即漂移由 `267d5a3` 引入，该提交把核函数奇异部分 log r/(2π) 改为逐面元解析积分、光滑余项走 Gauss 求积（`green_function(..., include_rankine=False)`）并新增绕射/Helmholtz 模块，文档未随之重生成。**
2. **哪一版才是收敛值**：对 `panel_nodes` 作节点加密 —— 旧实现在 128 面元下 A(pn=16)=2563.8329、A(pn=24)=2564.8138、A(pn=48)=2565.8139，按 A∞+C/pn 最小二乘外推得 **A∞=2566.8012**；新实现对 pn=8 与 pn=40 给出**逐位相同**的结果（相对差 0.000e+00 / 1.6e-16），常数点值 2566.8343 与外推极限相差 **1.29e-5**。故旧值偏小 0.078% 是求积未收敛的系统偏差，其「更接近 Ursell 解」属误差抵消，不能作为精度声明。
3. **面板离散误差本身干净**：N·ε_A 在 N=64/128/256 为 1.071/1.090/1.099，近似常数，佐证 ε∝h¹ 且以 Ursell 多极子解（与面板代码零共享）为无偏靶；近场/远场阻尼比同一网格下由 1.0113/1.0057/1.0029 改善为 1.0105/1.0053/1.0027，说明该重构对辐射条件的检验不是回归。

## 5. 局限

- 未改代码：本单判定为「文档欠账 + 测试缺口」，求解器实现（`267d5a3` 起）保持不动；若后续要把 128 面元误差压回 7e-3 量级，正确方向是加密面板/高阶面元，而非回调求积。
