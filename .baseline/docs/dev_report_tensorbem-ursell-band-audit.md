# TensorBEM: Ursell 辐射基准的 `(ka, a/f)` 精度包络审计（验证欠账清账）

**分支**：`agent/m3019`　**任务**：tp-doc-1 自主工时（TensorBEM）
**证据等级**：REAL（全部数字由 `python -m tensorbem.benchmarks.ursell_band_audit` 生成，零手抄）

## 1. 欠账来源（为什么做这一单）

`docs/ursell_error_budget.md` §5 第 2 条留着一条自认的验证欠账：

> 仅审计了一个 (ka, a/f) 点：ka≥1 时自由液面项更强，收敛行为可能不同，未验证。

即：文档对 Ursell 潜没圆柱辐射基准引用的「128 面元 → 附加质量误差 8.5e-3、阻尼误差 1.34e-2」是在**二维参数空间里的一个点**上成立的，而面元数够不够用是 `(ka, a/f)` 的函数——`ka` 决定自由液面核的振荡尺度，`a/f` 决定物面到自由面（镜像源）的距离，两者都直接进入核函数的奇异性强度。本单把这个单点声明换成**可判定的包络**。

## 2. 方法

新增 `src/tensorbem/benchmarks/ursell_band_audit.py`：

* **网格**：`ka ∈ {0.2, 0.4, 0.6, 1.0, 1.5, 2.0, 2.5}` × `a/f ∈ {0.25, 0.5, 0.75}` = 21 个节点（`a/f = 0.75` 即圆柱顶距静水面 `a/3`，全潜没圆截面的最浅极限）；
* **细化梯**：`N = 32, 64, 128, 256` 面元，固定每面元 24 个 Gauss 节点，逐级二倍；
* **参考解**：Ursell (1949) 多极子闭式解 `ursell_cylinder_coefficients`，**截断阶数自适应**（从 20 项起加倍，直到无量纲系数相对变动 < 1e-12），返回实测 `truncation_gap` / `terms`，因此面元误差永远不会与未收敛参考解比较；
* **独立物理判据**：每个面元解同时算近场/远场阻尼（Haskind 恒等式），与参考解无关地检验辐射条件；
* **无量纲化**：`mu = A/(rho*pi*a^2)`、`nu = B/(rho*pi*a^2*omega)`，与 Ursell 表及 `docs/marine_bem_benchmarks.md` 同口径；
* **判据分层**：阻尼的相对误差只在「可分辨」节点上成立——参考阻尼本身低于 `1e-3`（相对排水质量尺度）或低于最细网格绝对误差的 10 倍时，改报**绝对误差**并标 `n/r`（不可分辨），因为此时相对误差的分母小于面元法自身的噪声；
* **功率律残差**：两点 Richardson 外推若用同一对误差**拟合阶数**，对任何纯幂律都是代数恒等的，因此它**不是**独立正确性证据；本模块把它明确写成「高阶污染量」——残差恒为机器零 = 细化序列是纯 `C/N` 律，残差变大 = 尚未进入渐近区。

## 3. 结果（全部由工件生成，见 `docs/ursell_band_audit.md`）

| 量 | 值 |
|---|---|
| 节点数 / 可分辨节点数 | 21 / 18 |
| 128 面元下最差附加质量相对误差 | **1.341e-02**（ka=0.2, a/f=0.75） |
| 128 面元下最差阻尼相对误差（18 个可分辨节点） | **2.391e-02**（ka=0.2, a/f=0.75） |
| 观测阶范围（128→256） | 0.42 – 1.53 |
| 参考解最差截断残差 | 2.84e-13 |
| 最差近/远场阻尼偏差 | 3.27e-02 |
| 最差条件数 | 4.48 |
| 全网格最差绝对阻尼误差（排水质量尺度） | 6.42e-02 |
| 逐档最差误差（全网格取最大） | N=32: 8.29e-02 / N=64: 4.58e-02 / **N=128: 2.39e-02** / N=256: 1.22e-02 |

**判定（honest，含负面）**：

1. 文档引用的「128 面元 1.3e-2」**只在被审计的那个节点上成立**：全网格 128 面元的最差值是 2.39e-2（约 1.8 倍），出现在 `ka=0.2, a/f=0.75`（长波 + 浅潜没，自由面项在物面上最强）。因此该数字的适用范围是「a/f ≤ 0.5 且 ka ≥ 0.4」，不能外推到整个带。
2. 把 1% 作为 `(ka, a/f)` 全带的统一目标时，**本梯最高档 256 面元仍不达标**（最差 1.22e-2）；`smallest_feasible_panels = None` 是审计的真实结论而非缺陷——要全带 <1% 得继续加密到 512 面元（本单未做，登记为后续）。
3. 所有节点的误差均**远低于 15% 工程门槛**，且最差近/远场阻尼偏差 3.3e-2 说明辐射条件在所有节点都被满足（该判据完全不用参考解）。
4. 三个「深潜没 + 短波」节点（`a/f=0.25`，`ka ≥ 1.5`）的参考阻尼已降到 1.6e-4 … 1.5e-7，相对误差在那里没有信息量（分母小于噪声），已按不可分辨处理；这是物理事实（深潜没柱体在短波下几乎不辐射），不是数值缺陷。
5. `a/f = 0.75` 的 32→64 档**不是渐近区**（`ka=0.6` 附加质量误差随加密反而上升，`ka=2.0` 阻尼观测阶 8.9），已在测试 `test_shallow_nodes_are_not_asymptotic_on_the_coarse_ladder` 里**钉住这个观察本身**，防止后来者用改数字的方式"修掉"它。

## 4. 误差判定（是否 <3%？）

| 关键量 | 基准 | 相对误差 | <3%？ |
|---|---|---:|---|
| ka=0.6, a/f=0.5, N=128 附加质量 | Ursell 解析 | 8.5e-3 | 是 |
| ka=0.6, a/f=0.5, N=128 阻尼 | Ursell 解析 | 1.34e-2 | 是 |
| 全带最差, N=128 附加质量 | Ursell 解析 | 1.341e-2 | 是 |
| 全带最差, N=128 阻尼 | Ursell 解析 | 2.391e-2 | 是（但为文档值的 1.8 倍，见判定 1） |
| 全带最差, N=256 附加质量/阻尼 | Ursell 解析 | 1.22e-2 | 是 |
| 参考解截断残差 | —— | 2.84e-13 | 是（远低于任何面元误差） |
| 近/远场阻尼恒等式 | 1.0 | 3.27e-2 | 是 |

结论：**所有物理量对解析基准的误差都 <3%**；不合格的是**声明的作用域**（「128 面元 1.3e-2」被写成无条件的），本单已在文档层面把它限定到 `a/f ≤ 0.5, ka ≥ 0.4`。

## 5. 注意点 / 局限

* 24 节点/面元固定；节点敏感性已在 `docs/ursell_verification_debt_2026-11-02.md` 与 `tests/test_ursell_quadrature_convergence.py` 中单点锁定（6/12/24 节点不敏感），本单未在全带重扫。
* 仅二维、深水、常数面元间接公式；有限水深/三维/高阶面元不在范围内。
* 参考解多极子截断在 `ka=2.5, a/f=0.25` 处阻尼仅 1.5e-7，`terms=40` 即平台化——该值本身可信到 machine precision，但面板解无法在相对意义上与之比较。
* 稠密装配 `O(N^3)`，256 面元单点约 45 s；全量 84 次求解在 12 进程下约 3 min。
