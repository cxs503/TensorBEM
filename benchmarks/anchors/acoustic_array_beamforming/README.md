## 2. How it was done

1. **Derivation** (`pekeris_anchor.derive_dispersion`, sympy): the pressure modal problem
   `p1 = A sin(k_z z)` in the layer and `p2 = B exp(-alpha (z-H))` in the half space, with
   continuity of pressure and of `(1/rho) dp/dz`, gives

   `tan(k_z H) + (rho2/rho1) k_z / alpha = 0`

   The three symbolic residuals (Helmholtz in each medium, interface elimination after the
   flux condition is divided by `cos(k_z H)` and the branch equation is substituted back) are
   all `0`; the branch equation is *derived*, not transcribed.
2. **Root solver** (`pekeris_roots`): the branch structure `k_z H in (pi/2 + n pi, pi + n pi)`
   supplies brackets, Brent solves them and four Newton steps polish each root; two residual
   forms `F = alpha sin(k_z H) + m k_z cos(k_z H)` and `G = tan(k_z H) + m k_z / alpha` are
   reported per root.
3. **Independent discretisation** (`fem_branch_roots`): 1-D P1 finite elements of
   `(1/rho p')' + (omega^2/(rho c^2) - k_r^2/rho) p = 0` on a graded mesh with Dirichlet
   truncation; the generalised symmetric eigenproblem shares no algebra with the branch
   equation.  Mesh refinement 100/200/400 layer elements per frequency.
4. **Mode-count cross-check** (`analytic_mode_count`): closed-form count
   `N = 1 + floor(k_z_max H/pi - 1/2)`, derived from the bracket structure independently of
   the solver.
5. **Conversion chain** (`to_case_frame`): four literature-side representations
   (`k_r` in rad/m, `c_ph` in m/s, dimensionless `k_r H`, grazing angle) mapped exactly to
   `s = k_r/k1`, each with a round-trip identity residual.
6. **Quote gate** (`validate_quote_record`, `anchor_status`): a record is `ELIGIBLE` only with
   `source_id`, non-empty `verbatim_quote`, `locator`, `table_or_page`, `quantity`, numeric
   `value` and `units`; the anchor is `VERIFIED` only if at least one record is eligible.
7. **Source access log** (`probe_sources`): live Crossref resolution of both named sources and
   live reachability probes of the full-text hosts.

## 5. Points to note

* **The external anchor is withheld, not satisfied.** Full text was not retrievable:
  archive.org unreachable, `pubs.geoscienceworld.org` answered HTTP 403, the Springer chapter
  page was blocked by egress policy (see `sources.reachability_probes`, timestamps included).
  Crossref *bibliographic* metadata did resolve (4/4 DOIs, incl. Pekeris Memoir 27 chapter
  `10.1130/mem27-2-p1`, pp. 1–116, and Jensen et al. 2011 ch. 5 "Normal Modes", pp. 337–455),
  but metadata is not the numerical root and is not used as one.
* **No value was reconstructed from memory**, and the candidate registry is empty by
  construction. The gate rejects incomplete records (demonstrated in
  `external_anchor.structural_rejection_demo`), so a hand-typed number can never re-enter as
  an anchor.
* The waveguide parameters above are *our declared case*, not a claim about the parameters
  used by the sources; even after C1 is met, a parameter-frame check will be needed before any
  difference is interpreted as a method error.
* FEM truncation depth is `max(6/alpha_min, 3 c2/f)`, so the FEM route is a cross-check at the
  1e-5 level rather than a 1e-12 instrument; it is used only for agreement, not for residuals.
* Conversion chain is exercised on internally derived roots because no external value passed
  the gate; the algebra is nonetheless exactly what will be applied to the transcribed value.
