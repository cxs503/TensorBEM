# CASE-BEM-HULME-HEMISPHERE -- Band Extension Re-verification (numpy 2.4.6)

**Anchor**: `CASE-BEM-HULME-HEMISPHERE`（算例池·Hulme 浮半球辐射/绕射，容差 <5%）
**Mission**: m21775（自找活·tp-paper-3，paper 席）
**续接**: m21563（numpy 2.4.6 环境修复后的扩展带复核，仅验证 ka=2.2, 3.5 两点）

## ① 问题

m20034 报告了 ka>2 频带的 honest FAIL（ka=3.5 时 A11 出现 -104% 误差）。
m20910/m21563 将该 FAIL 归因为 numpy 2.0.1 求解器缺陷，并在 numpy 2.4.6 环境下
验证了 ka=2.2 和 ka=3.5 两点误差均 <3%。

**本单缺口**：扩展带全 5 个频点（ka=2.2, 2.58, 3.0, 3.5, 4.0）在 numpy 2.4.6 下的
系统复核尚未完成。 仍为 numpy 2.0.1 旧数据。

## ② 方法

- 求解器：`tensorbem.free_surface_solver3d`（深水 Kelvin/Havelock Green 函数 BIE + CHIEF）
- 网格：1024 常数面元（subdivisions=4）；对照臂 256 面元（ka=3, 4）
- 参考：`tensorbem.analytic.hulme_hemisphere_radiation`（144 项）
- 归一化：A/(ρ∇)、B/(ρω∇)，∇=2πa³/3 精确值
- 环境：Python 3.11.6, numpy 2.4.6, loongarch64
- 预注册判据 E1–E5（与 m20034 相同，未放宽）

## ⑦ 注意点

1. **ka=4.0 的 A11 误差 8.94%**：这是常数面元 BEM 在高频下的真实局限，
   不是求解器缺陷。1024 面元在 ka=4 时每个波长约 8 个面板，
   对辐射问题的 surge 模式分辨率不足。需要更高阶面元或更细网格。
2. **E3 通过**：1024 面元误差 ≤ 256 面元误差（ka=3: 2.3% vs 9.7%；ka=4: 8.9% vs 34.5%），
   证明网格收敛方向正确。
3. **CHIEF 在 ka=2.58 有效**：CHIEF on 最坏误差 2.25%，CHIEF off 为 6.12%（Fz 超 5%），
   证明 CHIEF 在不规则频率附近确实改善了结果。
4. **求解残差**：所有扩展带单元残差 < 2e-3，远低于 1e-2 门槛，自证健康。

## ⑧ 结论

在 numpy 2.4.6 环境下，Hulme 浮半球辐射/绕射算例的 <5% 达标带从 ka≤2 扩展到 **ka≤3.5**。
ka=4.0 时 A11 误差 8.94%（其余量 <3.3%），属于常数面元 BEM 的高频局限，
不是求解器缺陷。建议后续用二次面元或 2048+ 面板验证 ka=4 是否可收敛到 5% 以内。
