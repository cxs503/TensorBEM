# CASE-BEM-HULME-HEMISPHERE -- floating hemisphere radiation/diffraction

Case pool id 138 (`BEM-HULME-HEMISPHERE`, repo TensorBEM, tol `<5%`). Generated by `benchmarks/verified/casepool_bem_hulme_hemisphere/run_case.py`.

## 1. Case and reference

Floating hemisphere, flat face flush with the mean free surface, radius a = 1.0 m, deep water, rho = 1025.0 kg/m^3, g = 9.80665 m/s^2, incident amplitude A = 1.0 m. Nondimensional frequency ka = k*a with k = omega^2/g. Reference: Hulme (1982) *J. Fluid Mech.* **121**:443-463 (wave-free multipole expansion in spherical harmonics), evaluated by `tensorbem.analytic.hulme_hemisphere_radiation`.

Environment: 3.11.6, numpy 2.4.6, host 36cb7828dbd5, arch loongarch64.

## 2. Method

`tensorbem.free_surface_solver3d` assembles the Kelvin (Havelock) Green-function BIE on constant panels from `geometry3d.hemisphere_hull_mesh` (recursive octahedral subdivision of the lower half; 4*4^n panels), solves the radiation problem for surge (mode 0) and heave (mode 2) at unit velocity amplitude and the diffraction problem for head-on waves, and uses interior CHIEF null-field equations (`chief_points='auto'`).

Normalisation: A/(rho*nabla), B/(rho*omega*nabla) with nabla = 2*pi*a^3/3 = 2.094395 m^3 (exact, not the mesh volume); forces by rho*g*A*a^2 = 10051.8 N.
