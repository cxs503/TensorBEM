# CASE-BEM-HULME-HEMISPHERE -- floating hemisphere radiation/diffraction

Case pool id 138 (`BEM-HULME-HEMISPHERE`, repo TensorBEM, tol `<5%`). Generated by `src/tensorbem/benchmarks/hulme_hemisphere_case.py`; every number below is read out of `results.json`.

## 1. Case and reference

Floating hemisphere, flat face flush with the mean free surface, radius a = 1 m, deep water, rho = 1025 kg/m^3, g = 9.80665 m/s^2, incident amplitude A = 1 m; ka = k*a with k = omega^2/g.

Reference: Hulme (1982) *J. Fluid Mech.* **121**:443-463, wave-free multipole expansion, evaluated by `tensorbem.analytic.hulme_hemisphere_radiation` at 144 terms. **Provenance caveat**: the printed table digits are not available in this sandbox (publisher paywall); the reference is the re-derived series, self-converged (G4) and cross-checked against capytaine (G5).

Environment: python 3.11.6, numpy 2.4.6, host 36cb7828dbd5, arch loongarch64.

## 2. Method

`tensorbem.free_surface_solver3d` assembles the Kelvin (Havelock) Green-function BIE on constant panels from `geometry3d.hemisphere_hull_mesh` (recursive octahedral subdivision, `4*4**n` panels), solves radiation (surge mode 0, heave mode 2, unit velocity amplitude) and head-on diffraction, with interior CHIEF null-field equations (`chief_points='auto'`).

Normalisation: A/(rho*nabla), B/(rho*omega*nabla) with nabla = 2*pi*a^3/3 = 2.094395 m^3 (exact, not the mesh volume); forces by rho*g*A*a^2 = 10051.8 N.

Failure modes and applicability:

1. Constant panels approximate the curved hull: the displaced-volume and waterplane-area errors are O(h^2) and set the floor of the coefficient error (G2 pins them).
2. Short-wave resolution: at ka = 2 a panel spans lambda/pi; the band stops at ka = 2, where G1/G5 are the binding constraints.
3. Irregular frequencies: the first interior Dirichlet eigenfrequency of this waterplane is ka ~ 2.58; the band avoids it and the CHIEF on/off control (5.3) shows the null-field equations are active.
4. Reference truncation: the multi-pole series converges more slowly as ka grows; G4 keeps the 96->144 drift 20x below the tolerance.
5. Reference provenance: the Hulme (1982) printed digits are unavailable here (paywall); G5 supplies an independent third-code judge, which is the binding evidence for the 5 % claim.
