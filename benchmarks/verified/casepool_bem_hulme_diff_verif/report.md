## 1. 案例与判据

- 算例码 `CASE-BEM-HULME-DIFF-VERIF`（算例池 id 177，仓库 TensorBEM）
- 几何：floating hemisphere, r = a = 1 m, waterplane z = 0，体积 2.094395 m³，
  水线面面积 3.141593 m²，ρ = 1025.0 kg/m³
- 频率带 ka = [0.2, 0.5, 0.8, 1.0, 1.5, 2.0]
- 参考解：`tensorbem.analytic.hulme_hemisphere_radiation`（Hulme 1982 无波势多极级数，项数阶梯 [48, 96, 144]，激励力取原点 Kochin 振幅/Haskind 互易）
- 求解器：`tensorbem.free_surface_solver3d.solve_diffraction_3d`，面元阶梯 [2, 3, 4]（算例网格 sub=4）
- 独立路线：scripts/capytaine_hulme_diff_scattered.py (capytaine DiffractionProblem, scattered force) + exact Froude-Krylov quadrature from this module

## 6. 注意点与适用边界

- **口径坑（本算例的核心发现）**：capytaine 的 `DiffractionProblem.forces` 只含绕射（散射压力）力，
  不含入射波（Froude-Krylov）部分；直接拿它和 Hulme 总激励力比对会得到「假失败」或
  「假成功」。冻结文件中 `convention_probe` 用 ka→0 极限（总激励力 → π·ρg·a²·A ≠ 0）钉死该口径。
- TensorBEM 的 `solve_diffraction_3d(...).excitation_force` 是**总**激励力（FK + 绕射），
  与 `froude_krylov_force_3d` 的 docstring 一致；`scattered-only` 另存于 results 里便于逐项对账。
- 参考解不是 Hulme 原文印刷数字（本环境无该文获取途径）：它是 Hulme 方法的重新推导级数，
  因此本算例额外给出 G4（第三方代码）与 G5（长波解析极限）两条**非自证**外部锚。
- ka 带 0.2–2.0 对应 a = 1 m 时的 λ/a ≈ 3.1–31；亚 ka = 0.2 的长波段受消波/截断影响更大，
  超 ka = 2 需加密网格，均不在本算例适用范围内。
