## 1. 案例介绍（物理背景 / 几何 / 参数）

无限域无粘不可压流体中，横截面为椭圆的柱体作横向平移运动时的附加质量（单位展长）。该量只有闭式解、无实验散布，因此是检验**外域边界积分算子**本身（而非某个浮体装配流程）的干净靶子。

闭式解：`m_A,x = ρπb²`（沿 x 平移）、`m_A,y = ρπa²`（沿 y 平移）——每个值取**垂直于运动方向**的半轴，故细长截面轴向附加质量小、法向大；`a = b` 退化为圆柱，`m_A = ρπR²` 恰等于排开质量（Ca = 1）。

|---|---|
| a（x 半轴） | 1.5 m |
| b（y 半轴） | 0.75 m |
| a/b | 2.0 |
| ρ | 1025.0 kg/m³ |
| U | 1.0 m/s |
| 面板预算 | 128 |

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

两条**独立**数值路线对同一闭式解：

| 路线 | 边界积分方程 | 精确给定 | 数值未知 | 附加质量 |
|---|---|---|---|---|
| `dirichlet` | 第一类单层 `S q = u` | 迹 `u = −U k x_axis`（椭圆坐标闭式） | 通量 q | `m = ρ/U² ∮ u q ds` |
| `neumann` | 第二类 `(½I − H) u = S q` | 通量 `q = −U n_axis` | 迹 u | `m = ρ/U² ∮ u q ds` |

两式的**算子不同、未知量不同、条件数行为不同**（第一类有对数容量退化，第二类 O(1)），却必须收敛到同一个闭式值——这构成互证。迹系数 k 由 `tensorbem.analytic.ellipse_translation_trace_scale` 给出：x 向 k = b/a = 0.500000，y 向 k = a/b = 2.000000。

工具链：`tensorbem.geometry.ellipse_mesh`（内接多边形，等角度布点）、`tensorbem.solver.solve_laplace_exterior_dirichlet` / `solve_laplace_exterior_neumann`、闭式解 `tensorbem.analytic.ellipse_added_mass`。**本算例不改求解器**，只做记录与判定。

## 5. 注意点（踩坑 / 局限 / 适用范围）

**踩过的坑**：

1. **圆截面巧合**：`a = b` 时针首谐波在内外域同为线性场，内域解与外域解在连续极限下重合，用圆做附加质量验证**完全无法**检验外域算子。椭圆在本仓库是第一个真正检验外域算子的几何；本算例已内置反向控制量化这一差别（§3.3）。
2. **内接多边形**：网格是椭圆的内接多边形，面积/周长系统性低估，故参考值取**真椭圆**闭式解、按 O(h²) 收敛评估，不追求单点数值等于闭式。
3. **面元不等弧长**：等角度布点使 h_max/h_min > 1；这是刻意的，但引用 h 时必须用 h_max 而非均值。
4. **迹系数的来源**：`k = b/a` 用于构造精确 Dirichlet 迹，它本身由闭式附加质量关系给出；因此本算例验证的是「给定精确边界数据时算子是否还原正确通量/势」，不是「迹系数是否被独立推导」——后者由 §3.3 的闭式一致性间接支撑。

**局限**：

- ref 页码未离线核验（Lamb 1932 §71 / Newman 1977 §4.3 书不可达），**页引用状态 WITHHELD**；闭式表达式本身是验证对象（能量积分 + 两路线互证）。
- 仅扫形状（a/b ∈ [1, 6]）与离散度两维；密度/速度是线性依赖，未扫（解析显然）。
- 无实验对照：二维附加质量无实验散布，本算例是同族**数值-解析**验证。
- 只锚平移两模态（surge/heave），未评估旋转附加惯性矩与 3×3 全矩阵。
- 外域场量（流体域内势)未做体积云图：库内没有外域场的场求值器（`evaluate_interior_field` 明确只支持内域），故场量视图取边界通量分布。

**适用范围**：

- 无限域、无自由面、无粘不可压的二维 Laplace 外问题（深水高频极限下的横剖面附加质量）；
- 常数面元、中点配点的边界积分方程（第一类 S / 第二类 ½I−H）；
- 结论不外推到有限水深/自由面（那需要 Green 函数与色散关系，见 `docs/BEM_FINITE_DEPTH_GREEN.md`）。
