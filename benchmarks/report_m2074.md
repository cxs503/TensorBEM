## 1. 案例介绍（物理背景 / 几何 / 参数表）

### 1.1 物理背景

敞水试验（ITTC 7.5-02-03-02）在均匀来流中测量螺旋桨的推力系数 K_T = T/(ρn²D⁴)、扭矩系数 K_Q = Q/(ρn²D⁵) 及敞水效率 η₀ = J·K_T/(2πK_Q)，其中进速比 J = V/(nD)。本案例将 TensorBEM 仓内的涡格升力面 BEM 求解器与 **Wageningen B4-70** 标准系列回归逐点对账。

### 1.2 外部定量锚

Oosterveld, M.W.C. & van Oossanen, P.（1975），"Further computer-analyzed data of the Wageningen B-screw series"，*International Shipbuilding Progress*, 22(251)；NSMB Publication 479。工件内为 39 项 K_T / 47 项 K_Q 回归系数，由 `tools/build_wageningen_anchor.py` 以 importlib 从生态内参考实现机器抽取，锚件 sha256 = `fa8635c1892613ba15656a34d1b3fd263e73a2782f0754d25d7661faf7cd0988`。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **锚先自审**：先把回归锚件建立为可机读工件并对其做完整性 + 物理锚点验收（39/47 项系数、指纹、跨实现 1e-12 复现、J₀/(P/D) 带、η 峰值单调性）。判官先受审。
2. **稳定性包络先探测**：3 档网格 × 4 种尾涡设定 × 6 个 J，逐点判定数值稳定性（|K_T| ≤ 1、|K_Q| ≤ 0.2）。kinematic/induced 螺旋在低 J 下产生近奇异影响矩阵（J=0.1 时 K_T ~ −9.6×10⁴），几何尾涡则稳定。
3. **细配置按规则推导**：尾涡设定必须在所有网格档都稳定 → 取保真序中第一个满足者 → 在 400 面板预算内取最大网格 → 输出 24×2 + geometric L2.0/48。
4. **误差面扫描**：J 10 点 × 基准/细配置，逐点相对偏差（K_T、K_Q、10K_Q、η₀）。
5. **两维消融 + 精确 Shapley**：因子 mesh（8×1→24×2）、wake（geometric L1.0/24→L2.0/48）、friction（无粘→ITTC-78），遍历 2³=8 联盟，Shapley 恒等式残差 < 1e-15。
6. **零推力进速比**：对锚与 BEM 各自二分求 J₀。
7. **工具链**：Python 3.11 / numpy 2.4.6 / loongarch64；驱动 `src/tensorbem/benchmarks/b4_70_error_surface.py`，内核 `src/tensorbem/propeller.py`；测试 26 项。

## 5. 注意点

1. **几何假设是最大误差源**：B4-70 真实剖面为 NACA66 加弯度，本单用零弯度平板；径向螺距取常数而非真实分布。
2. **高 J 端崩解**：J > 0.833 时 K_T 趋零，相对误差失去意义。
3. **尾涡模型选择**：kinematic/induced 螺旋在低 J 下数值崩解，只有 geometric 尾涡全 J 域稳定。
4. **未留档项**：原单未留存运行日志时间戳、具体 git commit SHA、CPU 耗时等运维信息。

### 6.2 是否 < 3%？

**显式回答：否。** J ≤ 0.8 区内最好点 ΔK_T = −0.18%（J=0.467）达到 3% 以内，但最差 |ΔK_T| = 8.37%（J=0.711），最差 |Δη₀| = 10.81%（J=0.100）。原单按 15% 门判 PASS，绝不把 15% 说成 3%。

### 6.3 未达到 3% 的原因

误差主因是几何假设（零弯度平板 vs NACA66、常螺距 vs 径向分布），Shapley 余项在 J=0.1 时 36.19%。
